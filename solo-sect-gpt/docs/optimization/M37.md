# M37 三項 review 必修：實作前規格

base `b43e375`（fa001ce 加上原樣提交的 GPT / Codex M37–M40 計畫）；實作主筆 Claude Opus 5.5（Anthropic），單一作者。本節先 commit，結果另列。M31 的舊測試、證據與 marker 保留不改。

## 玩家問題（三個反例）

1. **暫停時退出演練，同 tick 的試招被算進演練**（`src/joint-drill.mjs`）：暫停中沈禾按「自己退出」，再切武學朝空地試拳，兩個命令同一 tick。退出精力 9609、試拳後 9409，回顧記耗精力 200（應為 0）。原因：截止快照 `bodyAt` 要等下一次 `jointTick` 才拍；統計也以「tick 小於離開 tick」判斷，同 tick 的試拳出手被算進去。
2. **一鍋飯在路上，總覽卻寫在途 0**（`src/resource-view.mjs`、`src/facility-view.mjs`）：做飯成品在 `haulOutput` 階段，阿木背著餐 4、`dest:table:meal` 預約 4，總覽 known 0。M31 的在途查詢只認採集的 `deliver` 階段，兩個面板各寫一份。
3. **紀事游標離開 ring 後跳過第一筆非數字事件**（`src/event-feed.mjs`）：讀一次後，追加一筆 `mentor.direction-set` 和 499 筆數字事件；核心保留這 500 筆，adapter 只給 499 筆，師徒事件遺失。

## 修改範圍

1. **演練截止在命令當下**：每個命令處理完時（`command()` 結尾），對進行中的聯合演練做一次截止檢查——參加者已不在這場演練（`practiceStop`、`stop`、改派、外部切磋…任何讓 `combatSession` 移走的命令）就立即：先把截至此刻的紀錄併入統計，再記 `left`、`cut`（命令截止）與 v2 的 `bodyAt`。演練因命令結束（`endDrill`、全員退出）時，對還在場的人記 `bodyAt` 並記 `closedAt`（之後的事件不算）。統計依紀錄實際先後：截止前同 tick 的出手照算，截止後的不算。step 內發生的離開（倒地、被擊退）沿原本 `jointTick` 的偵測，不改。新持久欄位 `cut`、`closedAt` 加進存檔驗證；舊檔沒有這兩欄照舊讀，舊的 `bodyAt` 缺快照寫 null 的路徑不變；不改核心事件 id。
2. **共用在途查詢** `src/transit.mjs`：`transit(w,inv)` 回 `{moving,held}`。moving 只收能證明「誰、帶著什麼、正往這裡」的：採集／施工取料的 `deliver`（`dest:` 預約＋背包實物，數量取兩者較小）、烹調／製作成品的 `haulOutput`（批次 `output.locations` 裡在該搬運者背包的單位，目的地＝批次 `target`）、地面撿拾與收成搬運（`collect`／`harvestHaul`，目的地是倉庫）。受阻（例如目的倉滿）或已不在搬運的人手上的貨列 held，不算在途。鍋內未領出的成品不算。設施卡與資源總覽都改用它；容量預留照舊另列。不改任何生產或物流規則。
3. **有界紀事 reader**：`createGptEventFeed` 改以「上次讀到時 ring 裡的那些紀錄物件」判斷新舊（核心只對 journal `push`／`shift`，物件不換），新紀錄＝目前 ring 中不在上次集合裡的，依 ring 順序；集合每次換成目前的 ring，上限即 ring 大小 500。非數字與重複 id 都照收、同 tick 順序不變；已被 ring 清掉的不補造。換世界、時間倒退照 M28 重置 epoch。

## 事前驗收（真命令反例）

1. 演練（M23 示範存檔＋標註休養 fixture，兩翼包抄、阿木前攔、沈禾守線）：`practiceStop` 後同 tick 試拳→回顧沈禾耗精力＝退出時的值、出手數不含那拳；先試拳再同 tick 退出→那拳照算；`stop`、改派、外部切磋各一次同樣；兩人同 tick 退出；直接 `endDrill` 後同 tick 試拳不算；退出後未 step 就存讀再試拳；退出後正常推進 10 tick；step 內倒地（標註 fixture）沿原路徑；`cut` 給沒退出的人被存檔驗證拒絕。
2. 在途：一鍋飯從做到交——鍋內時在途 0、領出搬運時在途＝背包餐數且列在膳房／總覽、交付後 0 且桌上增加；搬運途中停工→在途 0、held 列出阿木；另一人接手被核心擋下時在途 0；採集剛出發 0、回程＝背包、目的倉滿受阻→held；撿地面物資回倉在途；存讀後相同。
3. 紀事：讀一次後追加 1 筆 `mentor.direction-set`＋499 筆數字→收到 500 筆、第一筆是師徒；連續多筆非數字、同 id 多次、整窗 500 筆替換、超過保留窗（只收 ring 裡的 500）、重讀不重收；成功／失敗讀檔沿 M28。ring 壓力全部是標註模型 fixture。
4. 正常 UI（1440×900、1280×800）：暫停中退出演練後同 tick 試招→回顧耗精力 0；做一鍋飯，搬運時總覽餐的在途 4、交付後 0、實存上升。
5. 修前同一份測試在 base 上失敗的紀錄；M31 舊測試與完整回歸全過。

## 實作紀錄

- `joint-drill.mjs`：把「併入紀錄」抽成 `absorb()`；新增 `jointCut(w)`，`world.mjs` 的 `command()` 在每個命令處理完時呼叫。參加者被命令移出演練時，先併入截至此刻的紀錄，再記 `left`、`cut`（同值）與 v2 `bodyAt`；命令讓演練結束時記 `closedAt` 並替還在場的人記 `bodyAt`。之後的紀錄對 cut 的人（或 closed 後的所有人）不算。step 內的離開沿 M24 的 tick 規則。`save.mjs`：`cut` 只能給已離開且值等於 `left` 的人、`closedAt` 只能在演練已不在進行時出現；`bodyAt` 也可以屬於 closed 時還在場的人。舊檔沒有這兩欄照常讀。
- `src/transit.mjs`：`transit(w,inv)` 回 `{moving,held}`，涵蓋採集／施工取料的 deliver、烹調／製作成品的 haulOutput（批次 `output.locations` 中在搬運者背包的單位）、撿地面物資與收成搬運；受阻或不在搬運的人手上的貨列 held。`facility-view.mjs`、`resource-view.mjs` 都改用它；總覽的說明另寫「手上有貨但沒有在送」。
- `event-feed.mjs`：游標換成「上次讀到時 ring 裡的紀錄物件」集合（上限＝ring 500），新紀錄＝目前 ring 中不在集合裡的，依 ring 順序。數字游標與 `NUMERIC` 判斷移除。
