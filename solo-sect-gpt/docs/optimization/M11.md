# M11 人物有後續：實作前規格

base `f388227`；Claude Opus 5.5（Anthropic），單一作者。M10 已記錄。本節先 commit；實作補記另列，不回改標準。

## 盤點

- 人物 ID 穩定；雙向關係 `relationships['a|b']`（互信、意願、記憶種類、事件 ID、accepted）；共同記憶 `memories`（交談、鼓勵、共作、指點、照料、護衛，同一對同種 2400 tick 內不重複）；結伴有「提議＋本人接受」兩步；M4 事件以資料描述、後續要再走到場。
- 沒有師徒關係，也沒有把「一起遠行」記成兩人共同經歷；後續事件都綁經典人物或門風，不是由兩個普通人實際的歷史觸發。
- 小禾是未成年家人：不勞作、不參戰、不授武，必須保留。

## 參考（2026-10-26 實讀）

[Wildermyth Story Inputs and Outputs](https://wildermyth.com/wiki/Story_Inputs_and_Outputs)：事件以「角色、關係、歷史計數」為輸入，以「歷史紀錄、關係變化、少量永久成長」為輸出；建議永久獎勵只放在不能反覆刷的故事、選項要種類不同而非單純優劣。採用「以實際歷史為輸入」「歷史紀錄作輸出」「不可刷的少量成長」；頁面沒有寫防重複機制，本作自行以事件 ID 一次領取與冷卻處理。不搬其角色槽位評分、外觀變異或 overland 系統。

## 有限實作（師徒約定 v1，明示採用）

1. 明示採用「師徒約定 v1」（`w.mentorPlan`），標記 `chapter1-mentor-1`（最高優先），舊 reader 拒絕；未採用不變。
2. **一師一徒**：同時最多一段有效關係；師父與弟子都必須是成年常住人物，未成年與訪客不可。
3. **兩步成立，不強制**：師父提出（選一個約定），弟子本人再接受或婉拒。提出條件：雙方空閒（無 M7 共享安排、不在遠行）、師父任一武學熟練至少比弟子高 10、兩人之間已有至少一次真實「指點」記憶。弟子接受條件：弟子對師父互信 ≥ 8 且意願 ≥ 3；不足時接受被拒並寫出缺什麼。婉拒永遠可以，婉拒後 1 日內不能再提。
4. **約定**（三選一，期限 3 個活動日）：
   - 傳藝：成立後師父對弟子再完成 2 次真實指點／同堂。
   - 同行：兩人一起遠行並都平安返院 1 次。
   - 照看：弟子受傷時師父實際照料 1 次。
   到期時依實際紀錄判定「守約」或「未守」，只判一次。
5. **共同記憶只記成立後真實發生的事**：兩人之間新產生的指點、照料、護衛、共作、交談記憶；兩人同隊遠行並返院（記錄遠行 ID 與結果）。不回填成立前的經歷。
6. **後續事件**（每個只能領一次；兩個後續之間至少隔 1200 tick；要兩人空閒並實走到廊前相處 10 秒才結算）：
   - 初次指點：成立後即可。弟子對師父主修武學理解 +2（有上限）。
   - 歸途夜談：需至少一次共同遠行。內容依那次遠行實際結果不同：完成目標／未完成但平安返院／途中受傷撤退，各有不同對話與互信變化。
   - 照料之恩：需成立後至少一次照料記憶。
   - 守約／失約：約定到期後依結果二選一，失約的後續是坦白與修補，不是懲罰數值。
   - 沒有對應歷史時，事件不出現在可約清單，畫面說明「還沒有一起遠行過」等。
7. 「師徒」分組出現在人物頁：候選與缺少的條件、待回應的提議、約定進度、共同記憶清單（時間、種類、來源）、可約與已完成的後續。

## 事前驗收

1. 成立與拒絕：條件齊全時提出＋接受成立；弟子條件不足時接受被拒並說明；婉拒成立且 1 日內不能再提；一師一徒限制；未成年、訪客、同一人皆拒絕；拒絕都不改世界（去掉指令紀錄後 hash 相同）。
2. 忙碌／遠行：任一方在遠征、同堂、切磋等共享安排中時，提出與後續都被拒絕並寫出原因；返院後可再進行。
3. 共同記憶：成立前已有的記憶不出現在共同記憶；成立後真實產生的指點／照料與共同遠行都被記下，且引用的記憶／遠行 ID 存在。
4. 事件去重：每個後續只能完成一次；冷卻內不能約下一個；重複送出相同指令不重複領取；叫停或一方失能時不結算、可重約。
5. 有／無歷史的不同後續：沒有共同遠行時「歸途夜談」不可約；有完成目標的遠行與有受傷撤退的遠行，夜談內容與互信變化不同（同一起點配對）。
6. 約定：傳藝／同行守約與到期未守各至少一例，只判一次。
7. 保存：關係、約定、記憶引用、已完成後續在中途存讀後雙軌 hash 相同；版本、人物、記憶／遠行引用、事件 ID 不合法或未知版本拒絕；舊檔讀入不默補。
8. 既有回歸、M7–M10 測試照常通過；未成年界線測試通過。
9. 正常 UI：從 showcase 匯入，經正式 UI 採用師徒約定 → 先讓兩人真實指點 → 提出（選「同行」）→ 弟子接受 → 完成初次指點 → 兩人一起遠行並返院 → 約「歸途夜談」並完成 → 看到守約。1440×900 與 1280×800 至少各一次。
