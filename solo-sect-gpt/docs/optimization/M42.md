# M42 最小本地導航包與唯讀投影：實作前規格

base `60a870c`（M41 交付）；規劃 GPT / Codex（M41-M44-PLAN），實作主筆 Claude Opus 5.5（Anthropic），單一作者。本節先 commit，結果另列。

## 玩家問題與來源

生活、演武、遠征之間，大場景裡常找不到人、看不出鏡頭在哪。公版 dev `00f4dbe26be5765a9622957b7c6a636ab5039f96`（PR #371 已合）提供場景導覽：`sect-chronicle/navigation-view/{contract,render,style.css}`。上游 GPT 驗證接的是舊核心 `6cbd3e6…` 的 harness，不等於本分支正式入口；`official.mjs` 是 Gemini 正式入口的接線，不採用。

本階段只做資料層：固定來源的本地副本與一個讀目前 GPT 世界的唯讀轉接；M43 才接畫面。

## 修改範圍

1. **本地副本** `vendor/public/00f4dbe/navigation-view/`：`contract.mjs`、`render.mjs` 原樣（只加來源註解）；`style.css` 的 `@import url('../public-ui/style.css')` 改指已固定的 `../../6f959f5/public-ui/style.css`（與 00f4dbe 的 `public-ui/style.css` 逐位元組相同，sha256 `58659ff5…1a`），其餘不改。`SOURCES.md` 記上游與本地 sha256、改動與 import 閉包（`render.mjs` → `contract.mjs`；`style.css` → 6f959f5 tokens）。不搬 `official.mjs`、checks、evidence、scene-shared、Pixi。
2. **轉接** `src/navigation-view.mjs`：`createGptNavigation({getWorld})`：
   - 邊界：`MAP.world`（目前 2400×1800 DU），不另乘倍率。
   - 人物：與水彩場景畫人物同一條件（`residence!=='departed'`、`!inactive`、`visibleEntity`），只交 `{id,label:name,x,y}`，座標只做 Q256→DU；名字表只含這些人。不傳 known、path、journal、意圖、數值。
   - 地點：只收 `FACILITY_CARDS` 的倉庫、膳房、外功場（`w.facilities` 有這一筆才收），點取 `rects[id].rect` 中心——和既有「在地圖上看」（facilityLocate）同一個點。不掃 stations、床位、其他建物或背景。
   - 相機：本地 `{x,y,span}` → 公版 `{x,y,zoom}`，`zoom = Canvas CSS 寬 / span`；viewport＝Canvas 的 CSS 寬高（呼叫者傳入，不用 window 或 DPR bitmap）。跟隨中的相機位置由呼叫者在本幀 render 之後傳入。
   - epoch：同一頁的讀取生命週期；`getWorld()` 換成另一個物件（新局、成功讀檔／匯入）或 tick 倒退時 +1；失敗讀檔、預覽取消世界不變，不換。epoch 不進存檔。
   - `source`：`gpt-local:solo-sect-gpt/src/navigation-view.mjs@00f4dbe`，不冒用上游舊 GPT SHA。
   - 路線維持公版的 unsupported 說明，不讀 path、不推算。
   - `locate(id)` 回傳 facilityLocate 的相機（rect 中心、span 520）。
3. 不改世界、命令、時鐘、存檔。

## 事前驗收（模型）

1. 快照只有白名單欄位：人物 `{kind,id,label,x,y}`、地點同；野外人物不在視線內就沒有，進入視線出現、離開又消失（標註 placement fixture：移動觀察者，不冒充玩家走到那裡）；`inactive`、`departed` 不在。
2. 圖層關閉後 `pickNavigation` 拿不到；換世界 epoch 變、identity 變；同世界前進不變；tick 倒退變；失敗讀檔（解碼失敗、世界沒換）不變。
3. 座標：人物 x,y＝`p.x/Q`；地點＝rect 中心；鏡頭框對不同 Canvas 寬高（含 1440 與 1280 扣掉側欄）＝公版 `cameraFrame` 用 `zoom=width/span`；超出邊界被截；非有限座標的人被濾掉。
4. 大量讀取與 pick 前後世界 hash、RNG、journal 長度、存檔 bytes 不變；同命令 twin 續跑一致。
5. 回歸全過。
