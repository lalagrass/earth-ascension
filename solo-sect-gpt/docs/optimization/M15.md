# M15 一次有分工的門派聯合演練：實作前規格

base `dec793a`；Claude Opus 5.5（Anthropic），單一作者。本節先 commit，結果另列。

## 盤點

- 第一版已有「有限兩波演武」：玩家選成年門人與甲（正面守線）／乙（側路協作）兩種站位，兩波各兩名訓練對手從外功場東側走入，安全規則（生命降到一半即退場、不增加傷勢），對手走過 x 1300 記為「漏過」，結束後對手退場、家園恢復平靜。演武不會自動發生，未成年不能被選、也不是對手的目標。
- 缺：沒有「目標」與「分工」——所有人都追最近的對手，沒有人守線；結束後只有一行完成事件，看不出誰做了什麼、漏了幾個、M14 的招式有沒有派上用場。

## 有限實作（聯合演練 v1，明示採用）

1. 遠征頁演武區明示採用「聯合演練 v1」（`w.jointDrill`），標記 `chapter1-joint-1`（最高優先），舊 reader 拒絕；未採用的舊演武完全不變。
2. 目標只做一種：**守住外功場前線**（對手越過 x 1300 算漏過）。站位沿用甲／乙。
3. 分工：每位參加者選「前攔」或「守線」。前攔＝沿用原行為追擊對手；守線＝站在前線（x 1316 一帶）只攔 70 DU 內的對手，對手不在範圍就走回線上。最多三名成年常住門人、兩波共四名有限對手，來源與安全後果沿用原演武。
4. 指令走 M7 所有權：演練中個別叫回／停工＝該人退出；「終止演武」＝全體結束；結束一律清掉交手、站位與鎖定，參加者回到原生活。
5. 回顧（存在 `jointDrill.history`，最多 8 筆，並寫紀事）：結果（守住＝0 漏過／部分守住／失守＝參加者全數退出／終止）、漏過數、擊退數、用時、每人分工、起手次數依招式（含 M14 內容招）、命中、受擊。只寫實際發生的事；沒參加的人不出現在回顧。師徒若一起參加，只會留下原有規則自然產生的記憶（例如護衛），不額外給師徒履約或成長。

## 事前比較（模型，結果照實記錄）

起點：showcase 正常 UI 存檔（tick 183574），採用聯合演練，參加者阿木、沈禾、林青；每格一次確定性執行至結束（上限 6000 tick）。

| 格 | 站位 | 分工 |
| --- | --- | --- |
| A-front | 甲 | 三人前攔 |
| A-split | 甲 | 阿木、沈禾前攔；林青守線 |
| B-front | 乙 | 三人前攔 |
| B-split | 乙 | 同 A-split |

指標：結果、漏過、擊退、用時、每人命中與受擊。事前方向：同一站位下，「守線」安排的漏過數不多於「全前攔」；「全前攔」的用時不長於「守線」安排。

## 事前驗收

1. 採用前舊演武行為與 hash 不變；採用後未成年、訪客、遠行中的人、超過三人、未知站位／分工都拒絕且不改世界。
2. 守線者在對手不在 70 DU 內時確實回到線上；前攔者照原行為追擊。
3. 正常完成、主動終止、參加者全數退出三種結束都清乾淨（無殘留交手、站位、storyBusy、活性問題），回顧只含參加者。
4. M14 招式：參加者偏好短打快拳時，回顧的起手次數中出現該招。
5. 存讀：演練進行中存讀雙軌 hash 相同；jointDrill 版本、分工、回顧引用不合法或未知版本拒絕。
6. 回歸全部通過；家園在演練結束後不再有訓練對手活動。
7. 正常 UI（1440×900、1280×800）：showcase 匯入→採用→選三人與分工→甲站位開始→完成並看到回顧；另一次開始後中途按「終止演武」，回顧寫「終止」，人物回到生活（人物卡無殘留共享安排）。

## 第一次比較後的追加註冊（結果出來前寫定）

第一次比較（comparison.json）四格都「守住、0 漏過、擊退 4」：阿木與沈禾都是拳熟練 100 的深修者，兩波對手在接近前線前就被擊退，林青無論前攔或守線都沒有出手機會；方向 A 兩項、B 漏過項成立但只因為沒有任何漏過，B「全前攔不慢於守線」不成立（810 對 795 tick）。這表示此起點測不出分工差異。

追加比較 C（同一起點、同一甲站位）：只派一般熟練的人，讓前線真的有壓力——C1 林青一人前攔、C2 林青一人守線、C3 阿木前攔＋林青前攔、C4 阿木前攔＋林青守線。指標同前；方向：C2 漏過不多於 C1；C4 漏過不多於 C3。

## 實作紀錄

新增 `src/joint-drill.mjs`（採用、開始、守線行為、即時統計、回顧與收場）、遠征頁「聯合演練」區（逐人選不參加／前攔／守線、甲乙站位、即時狀態、上次回顧）、存檔標記 `chapter1-joint-1` 與 jointDrill／drill.joint 驗證。M7 所有權閘門涵蓋 `jointDrill`。實作中發現：舊演武在「參加者全數退出」或「終止」時，場上的訓練對手不會離開，一直站在外功場；聯合演練收場時把它們送回場外（舊演武行為不改）。
