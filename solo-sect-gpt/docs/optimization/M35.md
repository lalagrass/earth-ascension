# M35 共用紙墨呈現與穩定操作：實作前規格

base `84b000f`（M34 交付）；規劃 GPT / Codex（M31-M36-PLAN），實作主筆 Claude Opus 5.5（Anthropic），單一作者。本節先 commit，結果另列。

## 玩家問題（已在目前版本重現）

1. **值寫成程式字樣**：工作目標面板寫「明確停工：true」「待改派：沒有 · false停工」；公版值元件把布林、清單直接印出。
2. **展開狀態跨人串場**：工作目標面板（`data-view-key="intent"`）與人物頁各段（勞作與修行、近期紀事、職務…，`data-section`）的展開狀態是全頁一份：阿木展開「勞作與修行」，切到小禾也展開；武學「條件四層」換了武學仍展開。換新世界也不會清掉。
3. **空白鍵搶走按鈕**：鍵盤聚焦在按鈕或 `summary` 上按空白鍵，全頁快捷鍵先把遊戲暫停／繼續並 `preventDefault`，按鈕本身沒有反應。
4. **重繪丟焦點**：播放中面板每次重繪，鍵盤焦點掉回頁首，Tab 走到一半要重來。
5. **紙塊與按鈕樣式各自一套**：intent、資源、紀事、武學四個公版區塊沒有共同的紙底／邊線，停用按鈕只是半透明，沒有焦點框。

## 來源

新公版 6f959f5：`public-ui/style.css`（少量 tokens：紙、墨、次文字、邊線、焦點、錯誤色、12／13px 字級、間距、圓角；紙塊、`summary` 焦點、`.btn` 與停用樣式）、`public-ui/values.mjs`（M32 已採用）、`public-fix/view-state.mjs` 的原則（每人物 scope、穩定 key、同人刷新保留焦點、切人不帶過去）。`preview-fixtures.mjs` 依賴 dev 研究目錄，不採用。

## 修改範圍

1. **樣式**：採用 `public-ui/style.css`（原樣，只加來源註解）到 `vendor/public/6f959f5/public-ui/style.css`，在 `index.html` 的 `style.css` 之後載入。它只作用在 `.public-*`、`.btn`、`summary`／`select` 的 `:focus-visible` 與 `[role=alert]`；不動 GPT 版面、Canvas、HUD、對話框。
2. **值呈現**（`vendor/public/6f959f5/public-ui/values.mjs` 本地改）：known 的布林寫「是／否」，清單寫成「、」相接、空清單寫「無」；0 仍是 0；unknown／hidden／unsupported／notApplicable 的文字不變，hidden 仍沒有 tooltip。
3. **一套本頁狀態**：拿掉 `view.openKeys` 與 `view.openSections` 兩套，改成一份 `view.open`：人物相關的鍵（工作目標、自主政策、簡介背景、人物頁各段）存在「人物 id」之下，武學條件存在「人物＋武學」之下，資源與上手提示全頁共用。成功換世界（新局、讀檔）清空；讀檔失敗世界沒換，保留。所有段落都帶 `data-view-key`，畫出時就按這份狀態決定開合。`view-state.mjs` 本身不採用（它在 `innerHTML` 後才補狀態，而本版有段落要依開合決定是否產生內容，例如近期紀事），只借原則，不保留第二套 writer。
4. **焦點**：重繪前記下面板內的焦點（依 `data-intent-command`、`data-cmd`、`data-person`、`data-tab`、`id` 或所屬 `summary` 的 key），重繪後若是同一分頁、同一人物就把焦點放回去；切人或換分頁不搬。輸入框／下拉選單聚焦時照舊不重繪（既有保護）。
5. **鍵盤**：空白鍵在按鈕、`summary`、連結上時交給元素本身，不觸發暫停。
6. 不做開發預覽頁。

## 事前驗收（正常 UI，1440×900、1280×800，播放中）

1. 工作目標面板寫「明確停工：否」「是」，沒有 `true`／`false`；資源總覽的 0 仍是 0。
2. 阿木展開「勞作與修行」與「工作目標」→ 切到小禾兩者都是收合 → 回阿木仍展開；武學條件四層對拳展開、換棍收合；資源總覽展開的列跨人物保留；讀檔成功後全部回預設，讀壞檔失敗時保留。
3. 播放中用 Tab 走到某人的「停工」按鈕，等幾次重繪後焦點仍在同一顆；按 Enter 送出一次；Tab 到 `summary` 按空白鍵會展開、遊戲不暫停；在按鈕上按空白鍵送出該按鈕而不暫停；焦點不在按鈕時空白鍵仍是暫停。
4. 停用按鈕可讀（虛線邊、文字原因）；intent 回覆與停用原因照字面顯示。
5. 既有存檔選檔、匯入預覽、資料包選檔仍可用（重跑 M30 存讀驅動）；零頁面錯誤；回歸全過。

## 實作紀錄

- `vendor/public/6f959f5/public-ui/style.css` 原樣採用，`index.html` 在 `style.css` 之後載入。只作用在公版區塊（工作目標、資源、紀事、武學）與 `.btn`、`summary`／`select` 焦點框、停用按鈕（虛線、文字原因）。
- `vendor/public/6f959f5/public-ui/values.mjs` 本地改：known 布林寫「是／否」、清單「、」相接、空清單「無」；0、unknown、hidden（無 tooltip）、unsupported、notApplicable 不變。ef823ac 舊版 `text.mjs` 不動，舊 import 照用。
- `ui.mjs`：`view.openKeys`、`view.openSections` 合成一份 `view.open`；`openKey()` 把工作目標、自主政策、簡介背景、人物頁各段掛在人物 id 之下，武學條件掛在人物＋武學之下，資源與上手提示全頁共用；所有段落帶 `data-view-key`，畫出時就按狀態開合（近期紀事仍依開合決定是否產生內容）。世界物件換掉（新局、成功讀檔）時清空；讀檔失敗世界不變，保留。重繪前記下面板內焦點（`data-intent-command`、`data-cmd`、`data-person`、`data-person-tab`、`data-person-art`、`data-tab`、`id`，或 `summary` 所屬的 key），同分頁同人物時放回；空白鍵在按鈕、`summary`、連結上交給元素本身。
- 修 M33 留下的相容問題：M33 把舊名稱（`data-action="stop"` 等）同時加在「待改派」列與主操作列、自主政策裡也有一顆，舊驅動用嚴格選擇器時找到兩顆而失敗（M6 驅動重跑時發現）。改成只加在主操作列，每個舊名稱只對到一顆。
