## 玩家問題與來源

本版能選郭靖、令狐沖開局，卡上卻只有色塊和首字（M29 起「經典範本掌門沒有核准的外觀」）。公版 dev `3079a03de5c2e8c79af64b0962ae3da75f274466` 已合 PR #370 的研究立繪，其中兩張正好是本版既有模板的人物。

- 固定讀取：`sect-chronicle/docs/PUBLIC_PORTRAIT_IMPORT_SPEC.md`、`assets/shared/manifests/gemini-1.1.0.mjs`、`assets/shared/resolve.mjs`、`assets/shared/portraits/1.1.0/{guojing,linghuchong}.png`（`gh api` 按 SHA）。
- 已實看兩張圖：郭靖——蒙古袍打補丁、抓頭、嘴裡塞饅頭、腰掛葫蘆，老實少年，符合本版「未成名、草原上長大的老實少年」；令狐沖——藍白長衣、提酒葫蘆、背劍、笑，年輕劍客，符合「愛喝酒、愛自由」。兩張都是 3:4 RGB 整圖（郭靖 864×1152、令狐沖 480×640，PNG color type 2，無 alpha），水彩紙底，不是去背圖或動作圖集。
- 兩張都屬上游「直接複用」的 7 張：作者 Grok Bot，原提交 `6760f21c342cbf72fc9fb4baf0aec8655abd0dd2`，原路徑 `solo-sect/assets/portraits/v2/guojing-v2-b.png`、`solo-sect/assets/portraits/linghuchong.png`（同一 blob），dev 接受提交 `3079a03`。不是本輪生成。權利照上游：`repository-research-reuse; third-party-rights-unverified`。

## 事前驗收

1. 兩張本地檔 sha256、寬高、PNG color type 2（RGB、無 alpha）與 manifest 一致；1.1.0 檔案 sha256 等於 pin digest，改一個字就不合；1.0.0 檔與舊 digest、舊五筆資產仍通過原驗證。
2. 來源欄位：兩筆的 `source.commit`、`originPath`、作者、`acceptedCommit`、權利與上游 manifest 一致；沒有任何欄位寫成本輪生成。
3. resolver：兩筆解析為「公開立繪」、整圖矩形；hero 仍是「既有活動圖裁切（非新立繪）」；`templateAppearance` 對 guo、linghu 回對應資產，custom／yue／未知回不支援；矩形不是整圖、對照指向不存在的資產時 manifest 被拒；圖片檔缺失（URL 404）時 M39 走文字回退（本階段以 manifest 層面驗）。
4. 只讀解析不改世界與 RNG；M29 測試與回歸全過。
