# M23 場景可讀性與整批交付：實作前規格

base `162a263`（M22 交付）；規劃 GPT / Codex（M17-M23-PLAN），實作主筆 Claude Opus 5.5（Anthropic），單一作者。本節先 commit，結果另列。完成 M23 即停止，不延伸 M24。

## 玩家問題（重讀 render.mjs 後確認）

不開面板時，地圖上的人物只有「睡覺」與「授課舉手」兩種姿態；交談、聆聽、照料、研讀、坐休、練功都是同一個站姿。搬運只看得到徽記文字，看不到手上拿什麼。工地只有三塊料堆，看不出進度；聯合演練的前線與集合點畫面上沒有標示；出招只在起手時有扇形提示，出招後收勢看不出來。

## 修改範圍（只改繪圖，讀現有狀態；不改規則、命中與時間）

1. 姿態：依既有 `p.pose`／活動種類畫出可辨的差別——交談（頭旁小對話記號）、聆聽（頭微側、手垂）、照料（半蹲、手前伸）、研讀（手持書卷）、坐休（坐姿、較矮）、練功（不出招時雙拳交替前推）、耕作／採集（手持工具）。
2. 搬運：背上或手上畫出真正背著的物品（木柴、石塊、水桶、菜籃、餐碗、乾糧包、器械），讀 `inventories[bag]`。
3. 工地：開工中的設施畫進度條（施工秒數／該階段需要秒數）與「第 n 階」字樣；膳房有人烹調時冒煙、靜室有人研讀時書案亮起（讀實際活動）。
4. 聯合演練：v2 集合與交手中畫出前線（x1300 虛線，標「前線」）與每位參加者的集合點（已就位＝實心、路程中＝空心）。
5. 出招：收勢階段在人物腳下畫灰色半圈；起手與出招沿用原本。招式畫面一律讀 `action.phase`，沒有專屬圖形的招式用同兵器的通用畫法。
6. 不重畫大地圖、不加素材檔、不做手機版；大型新遠征圖列為下一批候選。
