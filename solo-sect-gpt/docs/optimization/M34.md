# M34 選人與人物卡共用公開簡介：實作前規格

base `ff8da30`（M33 交付）；規劃 GPT / Codex（M31-M36-PLAN），實作主筆 Claude Opus 5.5（Anthropic），單一作者。本節先 commit，結果另列。

## 玩家問題與來源

開局對話框只有「人物模板」下拉和配點，選郭靖、令狐沖、岳不群或自創時看不到這個人是誰；進局後人物卡也只有名字、身分和數值。

- 新公版 6f959f5：`character-card/contract.mjs` 的 `sanitizeProfile`（已在 M32 採用：只放行公開字串欄位，丟掉其他鍵）、`character-card/render.mjs` 的 `profileHtml`（短介＋作品／版本／階段＋可展開背景＋來源）、`character-card/profiles.mjs`（dev 研究目錄，含郭靖、令狐沖兩段研究用文字；沒有岳不群、自創）、`docs/PUBLIC_PROFILE_SPEC.md`（簡介不進存檔、能力只讀規則）。`profiles.mjs` 的 dev `hero/cousin/girl` 綁定不對應本版 `leader/amu/child`。
- 本核心權威：`TEMPLATES`（custom／guo／linghu／yue 的預設配點與性向）、`w.template`、`leader.canonicalIdentity`（非自創模板＝模板 id）、`p.stats`（本局真開局配點）、開局表單目前值。

## 修改範圍

1. **本地簡介資料** `src/profiles.mjs`：六筆公開簡介（自創、郭靖、令狐沖、岳不群、小禾、阿木），每筆分短介、背景、作品／版本／故事階段、來源（`kind`／`ref`）、`designId`、`portraitAssetId`（只填已接受的素材，沒有就空）。郭靖、令狐沖的短介核對階段後借 dev 研究文字（來源標明），背景改寫成本版開局的階段；dev 的「遊戲裡沒有開局」「只供對照」之類研究頁說明不搬。岳不群、自創、小禾、阿木新寫。不寫隱藏性格、未來劇情或未揭露身分，不寫數值效果。全部經 `sanitizeProfile`。
2. **明確綁定**：主角按本局模板（`w.template`，舊檔沒有時用 `canonicalIdentity`，都沒有算自創）；小禾綁 `child`、阿木綁 `amu`（actor id，不看名字）。自創改名不換簡介；同名訪客（例如成熟作客的 `legend.guo`）不拿主角的簡介——本批沒有訪客簡介，卡上不顯示。
3. **呈現**：從 6f959f5 `render.mjs` 摘出 `profileHtml` 到 `vendor/public/6f959f5/character-card/profile-html.mjs`（本地改：拿掉研究頁才用的「只供對照，不是可選開局」字樣）。開局對話框：模板下拉下方顯示該模板的簡介，並附「能力摘要」——讀表單目前的五項配點與性向預覽（改配點就跟著變），不在文案裡寫效果。人物卡：名字下方顯示同一份簡介；能力仍是原本讀 `p.stats` 的欄位。
4. **不進世界**：簡介只在介面；`createWorld` 的參數、點數預算、問卷與存檔都不變。不加可選角色、不生成新圖、不採 PR #370。

## 事前驗收

1. 四個開局在開局對話框可切換、各自顯示簡介與能力摘要；改配點後摘要跟著表單變。
2. 開局後人物卡顯示同一份短介與背景；小禾、阿木各有自己的簡介；林青、沈禾等其他人沒有簡介也正常顯示。
3. 綁定：自創改名「郭靖」→仍是自創簡介；`guo` 開局的主角拿郭靖簡介；成熟作客的訪客郭靖不拿主角簡介；舊檔（M16、M23 示範存檔、journey-03）讀入後主角簡介依模板。
4. 安全：`sanitizeProfile` 丟掉非公開欄位；名字含 `<script>` 等字元時被轉義；長名字（16 字）與長背景不撐破版面；缺簡介、缺圖時有合法回退。
5. 不改世界：同 seed、同表單送出的世界 hash 與 M33 相同流程一致（簡介不影響 `createWorld` 參數）；讀簡介前後世界 hash 不變；存檔內容沒有簡介文字。
6. 正常 UI（1440×900、1280×800）走一遍上面 1–3；回歸全過。
