# M43 接正式遊戲導覽：實作前規格

base `8cf3b8a`（M42 交付）；規劃 GPT / Codex（M41-M44-PLAN），實作主筆 Claude Opus 5.5（Anthropic），單一作者。本節先 commit，結果另列。

## 玩家問題

大場景裡找不到阿木在哪、鏡頭在看哪裡；跟隨一個野外人物時，人走出視線後鏡頭還會跟著原始位置走（`render.mjs` 的跟隨直接讀 `w.people[follow]`，沒有看可見性）。

## 修改範圍（同一 `index.html` 入口）

1. **入口**：鏡頭列加「導覽」按鈕（`aria-expanded`／`aria-controls`），開收場景左上的紙墨面板（公版 `createNavigationRenderer`，樣式用 `vendor/public/00f4dbe/navigation-view/style.css`，本地只改位置與高度讓它在 1440×900、1280×800 不蓋住側欄、人物卡、鏡頭列）。面板有標題、圖層、名單、地點下拉、圖例與「實際路線未提供」。水彩 Canvas、拖曳、縮放、地點按鈕、跟隨、剖屋頂全部照舊。
2. **同源更新**：每一幀在 `render(canvas,world,view)` 更新完相機（含跟隨）之後，用同一個 `view.camera` 與 Canvas CSS 尺寸更新導覽；暫停時拖曳、縮放、選人、定位、側欄開收都在下一幀就反映。不加 timer、不加 step。面板收起時不更新。
3. **點人物**：先用 `isPublicNow` 重核；不可見就不動作。可見就沿原有選人與「跟隨」：`view.selected`＝該人、`view.follow`＝該人、切到人物頁（與點畫布上的人看同一張卡）。
4. **點地點**（圖上或下拉）：沿既有「在地圖上看」公式（rect 中心、span 520、清跟隨），並把建設頁的設施卡切到該設施；不派工、不開資源、不切分頁。
5. **跟隨的可見性護欄**（最小共用）：每幀 render 之前，若 `view.follow` 的人已不在場景公開名單（離開視線、inactive、departed），清掉跟隨；被選的若是野外人物也不再可見，選取回到掌門（人物頁原本的預設）。只影響跟隨與這種選取，不改視線規則。
6. **不穿透**：面板內的 pointer／wheel／鍵盤由公版 renderer 攔下（不會變成點地走路、縮放場景或空白鍵播放）；Escape 收起面板並把焦點還給「導覽」按鈕。沒有從面板點空地移動、攻擊、傳送的捷徑。
7. **換局**：world 換掉時（新局、成功讀檔）導覽 epoch 變，renderer 清掉全部舊 marker／名單／下拉；開收偏好只在本頁，不進存檔。

## 事前驗收（正常 UI，1440×900、1280×800）

1. M36 展示檔：開導覽 → 名單是場景上的人、三個地點 → 點阿木 → 人物頁是阿木、跟隨中；播放時阿木在圖上的點跟著動、鏡頭框跟著跟隨移動；暫停時拖曳場景、縮放、按「家園」，框在下一幀就變（tick 不變）。
2. 點「膳房」→ 鏡頭到膳房、跟隨清掉、建設頁設施卡是膳房、沒有新命令（命令紀錄數不變）；派阿木做飯後在設施卡看在途。
3. 關人物圖層 → 圖上與名單都沒有人、鍵盤 Tab 走不到人；再開回來。面板內按空白鍵不暫停、滾輪不縮放場景、點面板空白不在場景下令；Escape 收起、焦點回到按鈕。
4. 失去可見：跟隨一位野外可見的人物，讓他離開視線（遠征頁的正常出發／返院，或觀察者離開）→ 名單與圖上消失、跟隨清掉、鏡頭不再跟原始位置（以快照比對）。若正常流程做不到野外可見人物，改以 M44 的遠征路線驗，並在此註明。
5. 換局：讀入另一個存檔後名單、下拉、marker 都換成新世界的；舊 marker 不可點。
6. 暫停時所有導覽操作前後 world 不變（snapshot JSON 相同）；播放中同命令 twin 用模型驗（導覽讀取不改世界，M42 已驗）。
7. 回歸全過；M29、M35、M39 正常 UI 驅動重跑（鍵盤與焦點、立繪沒被蓋住）。
