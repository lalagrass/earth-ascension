# M19 人物與武學面板接入：實作前規格

base `c93c212`（M18 交付）；規劃 GPT / Codex（M17-M23-PLAN、PUBLIC-PANELS-ADOPTION），實作主筆 Claude Opus 5.5（Anthropic），單一作者。本節先 commit，結果另列。

## 玩家問題

點一名門人時，人物頁是一長串分組；現在在做什麼、為何受阻、練成什麼、下一個真正可做的選擇分散在人物頁、武學頁與內容頁三處，而且武學三軌只寫「下一步：完整練習至90」，看不到下一招的真前置與這一刻能否出手。

## 修改範圍

1. **卡首**：選人列表保留；頭像沿用現有色塊＋姓氏字（中性回退，不搬 #339 素材，actorId 與外觀分開），姓名、身份、成年與否、現在行動、地圖徽記與重要狀態（最多兩則）。「跟隨」與收起面板沿用原控制，不另造入口。
2. **兩個入口**：卡首下方兩顆切換鈕「生活總覽／武學成長」，換人時保留目前入口。
   - 生活總覽：現在／原因／下一步（M8 情境卡）、身體與生活（精力、生命、傷勢、今日用餐、步速、背負，取自 M18 快照）、日常按鈕、勞作與修行、性情與相處（性情兩軸照 M18 可見性；相處分組；師徒）、職務方針。
   - 武學成長：稟賦與身體能力（五項，照 M18 可見性與「本版規則沒有讀取」說明；無雷達圖）、練成的本領（每門一顆，顯示階段與 U/F/I）、選中那門的詳情、試招／同堂／器械分組（只對成年人顯示；未成年改寫一行原因）。
3. **武學詳情**（全部讀 M18 投影與核心純查詢）：定義（分類、階段門檻、九劍入門說明「不是完整九式」）、此人的理解／熟練／體悟與已有情境、成長紀錄（最近 5 筆來源與總筆數，標「自學會起完整保存」；建角時的基礎拳寫明沒有來源）、招式清單（已學會／可研讀／未達前置＋真前置文字／未學；這一刻可否出手與核心原因）。選中一招時顯示規則值（起手、收勢、距離、耗能，原單位換成秒與 DU）與此人當下時序。
4. **操作只接現有指令**：練這門（task train art）、到靜室研讀（studyContent）、交手偏好（preferContent）、朝空地試招（attack，無目標不給成長），器械原因時顯示現有的製作／學習／換裝鈕。按鈕在畫面當下以核心預判停用並寫原因；按下時一律重新送核心，不憑畫面 enabled 執行。
5. **合法回退**：記住的選中武學或招式若在此人或此局不存在（換人、匯入沒有內容包的存檔），改看此人的第一門武學並寫一行說明，不報錯、不顯示舊資料。
6. 原「武學三軌」分組由武學詳情取代；其餘分組的 data-section 不改名。

## 事前驗收

1. 正常 UI 主線（1440×900、1280×800，各一次）：M16 示範存檔 → 林青「武學成長」→ 基礎拳 → 短打快拳顯示「未達前置」與真前置文字 → 按「練這門」實際練到熟練 30（看到成長紀錄筆數與熟練值上升）→ 招式變成「可研讀」→ 按研讀，走到靜室 20 秒後「已學會」，成長紀錄多一筆 content-study → 按朝空地試招，地圖上林青真的以短打快拳起手（紀事有 action-start）。
2. 覆蓋情境（同一回合正常 UI）：忙碌（阿木與沈切磋中，研讀鈕停用並寫核心原因）、缺器械（掌門九劍入門的辨隙截擊寫「九劍需實際領用並裝備木劍」，並出現換裝鈕）、未知資料（阿木屬性「未揭露」、掌門起始快照「未知」）、角色切換（林青→小禾：小禾武學成長沒有試招／同堂／器械分組，練拳鈕停用並寫原因；再切回林青選中狀態仍合法）、合法回退（選中進階招後匯入沒有內容包的舊存檔，畫面寫回退說明且無錯誤）。
3. 成長紀錄截斷：GPT 的來源陣列從不截斷，所以「已截斷」在本版不會出現；畫面固定標保存範圍，此項照實記為不適用，不造假資料。
4. 不洩漏：阿木、小禾隱藏列的 HTML 無數字；沒有雷達或六角圖。
5. 只看不改：暫停中切換兩個入口、換人、選武學與招式，前後世界相同。
6. 模型測試：武學詳情的招式狀態與 M18 投影一致；回退函式對不存在的武學／招式給出第一門武學；既有回歸全過。

## 不做

不新增屬性、成長、命令或權限；不做立繪素材、雷達、手機版；不改存檔格式。

## 實作紀錄

人物頁改為卡首（色塊頭像、姓名、身份、地圖徽記＋現在行動＋最多兩則重要狀態）＋「生活總覽／武學成長」兩顆入口鈕（換人保留入口）。生活總覽：情境卡、今日用餐與步速、日常按鈕、勞作與修行、「性情與相處」（性情兩軸依 M18 可見性）、師徒、職務。武學成長：五項能力（無雷達）、每門武學一顆鈕、選中那門的定義／U·F·I／實戰情境／下一步／成長紀錄（最近 5 筆＋總數＋保存範圍）／招式清單；選中招式顯示規則值、此人時序、研讀／偏好／朝空地試招，器械原因時出現製作／學習／換裝鈕；試招、同堂、器械分組只對成年人顯示。全部資料讀 `public-view.mjs`；新增 `pickArt`／`pickMove` 回退。原「武學三軌」分組與 M18 的預覽區由此取代（`m18-ui.mjs` 是 M18 當時的證據，不再對新版面重跑）。新按鈕只送既有指令：task train、studyContent、preferContent、attack。
