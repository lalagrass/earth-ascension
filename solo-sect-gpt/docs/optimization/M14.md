# M14 學成之後在同圖交手看得出來：實作前規格

base `243373c`；Claude Opus 5.5（Anthropic），單一作者。本節先 commit，結果另列。

## 盤點

- M6 內容包能表達的招式：只沿拳（punch）／棍掃（sweep）／劍刺（thrust）三家族；可調起手 8–40、作用 1–4、收勢 7–40 tick，距離（拳 12–24、棍劍 24–38）、寬度 4–36、傷害 1–10、耗能 200–1000、前置理解 U 5–10 與熟練 F 0–30。沒有多段命中、擊倒、反擊或特殊狀態，本階段也不加。
- 幾何：拳與劍刺用「前方距離＋寬度」判定；棍掃只看距離、最多打三人，但兩側各 16 DU 要淨空，窄橋口（x 1854–1956、y 415–465）一律不能棍掃，起不了手時 AI 改出拳（M13 已觀察到）。
- 熟練分級影響時序：直拳在 F≥18 起手 12／收勢 10、深修（F≥90 且 I≥10）起手 10／收勢 7；其他招收勢依分級乘 1／0.9／0.8。
- 學習：內容招式要在靜室研讀 20 秒（`studyContent`）、器械招式要實際裝備；交手偏好用 `preferContent`。

## 事前驗收

1. 三招可從正常 UI 預覽、安裝、研讀；前置不足時顯示原因（例如熟練不足、未裝備器械），不能研讀或偏好。
2. 研讀前不能出手；空揮不給成長；缺器械、短期疲勞（精力不足）、重送指令都按核心規則拒絕。
3. 比較四格完整跑完，方向逐一判定，不符照實記錄。
4. 存讀：裝了兩個包、交手途中存讀雙軌 hash 相同；包快照與未知 ID 的既有反例照常拒絕。
5. 師徒路線列出方向對應的進階招與前置狀態。
6. 回歸全部通過；九劍原窗口與失敗條件不變。
7. 正常 UI（1440×900、1280×800）：showcase 匯入→內容頁安裝進階三式→普通弟子阿木在靜室研讀貼身短拳並設為交手偏好→與沈禾安全切磋，紀事出現貼身短拳的出手與命中；林青的面板顯示貼身短拳前置不足的原因。
