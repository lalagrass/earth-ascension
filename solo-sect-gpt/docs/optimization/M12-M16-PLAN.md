## M12：讓經營與出發選擇說得清楚

**玩家結果：** 看懂現在為何該修屋、備糧或修行，也知道多帶乾糧何時有用、何時只佔空間。

工作先以既有 M9／M10 為主，不增加新的生存需求或方針數量：

1. 使用真正不同的情境比較方針：有已下令工地且材料可取得、餐食短缺且生產可接續、供給穩定且有修行站位。起點與差異落檔；同一情境各安排從同一保存／fixture 分叉。
2. 保留原始資源單位，分別看施工工量、供餐中斷時間、實際修行、乾糧儲備、受阻與精力。不要把餐、水、乾糧加成一個「食物分數」來判勝。
3. 對帶糧選項明說容量與作用條件：已滿精力不保證額外收益；實際使用還要符合營地／抵達用餐規則；帶回物空間會減少。預估與實際差異保留，不包裝成戰鬥勝率。
4. 只補直接服務選擇的經營／遠征說明、條件與警示，保留現有人物面板。既有選擇若在指定情境無可見差異，先查真正原因，再作最小修補，不任意加懲罰湊差距。

**出口：** 三種情境的完整比較表；至少一段正常 UI 從下令工地／選方針到真施工，以及一段帶糧選擇到返院的連續證據。玩家看得到自己選項改了什麼、付出什麼。缺料／滿包／滿精力反例、取消與中途存讀不回歸。

**規模：中。** 主要成本是正確的比較起點、來源說明與既有策略缺口修補。先收尾這段，再擴成長內容。

## M13：讓一名普通弟子有完整成長段落

**玩家結果：** 阿木或另一名符合條件的普通同門，從「幫忙的人」成為有共同經歷、看得見進步的弟子。

1. 選一名普通成年人物走完整流程；沿同一 actorId、物品、傷勢與記憶，串接共作／入門、真指點、本人接受師徒、練習、一起完成一件事、回院後續。
2. 用既有 U/F/I 與已知武學，提供「把基礎練深」或「學一種器械」兩個可追求方向。先沿用現有目標，不在此階段新增身體成長值或龐大武學樹。
3. 有限編寫最多三段新銜接／後續，或改進既有段落，優先填缺口。條件讀真記憶、實際練習／教學和返院結果；不能靠對話一次跳等級。
4. 讓性格與相處歷史改變邀約理由、演出或選項；不以隱藏值直接寫進說明。不強迫已成年角色接受，保留婉拒、延期、取消、再約。
5. 在現有師徒／紀事區提供簡明的目標與已完成來源，避免玩家在數頁間猜下一步；不開公版卡重構。

**出口：** 正常 UI 完成一名普通弟子的上述段落；另一方向至少驗到有效學習與不同後續條件。開局五 stats 保持原義，修練進步有事件／前後值，師徒成立前經歷不追認。雙方任一人叫停、同時外出或受傷都有合法出口；讀回後不重領結果。

**規模：中。** 主要是內容條件、既有教學／關係的接線與可達性。每人各自獨立多套故事引擎不在範圍。

## M14：學成之後在同圖交手看得出來

**玩家結果：** 更期待下一招，並能從距離、節奏與用途看懂深修／器械的回報。

1. 只做三個進階招式候選，各沿既有拳、棍、劍家族；例如短距離快收勢的貼身拳、適合攔側路的棍招、要求前向站位的劍招。名稱由 Claude 依最終規則定，不能先用名字宣稱連擊、反擊或擊倒。
2. 優先用現有有界內容包、學習前置、真研讀／練習、器械領用、幾何與起手／作用／收勢。逐招先盤點此格式能表達什麼；無法表達的效果先縮減，不偷偷以圖像演出冒充新規則。
3. 接續 M13 的兩種學習方向，顯示已滿足與尚缺條件。低悟性仍可深修基礎；高悟性也能走同一路。保留九劍的原窗口及失敗，不做零冷卻必中。
4. 同一角色在公平條件下，比較原招／新招，覆蓋貼身快攻、長距離／側移、狹窄站位等三種既有可達情境。至少看動作與收勢、有效命中／落空、受擊、耗能與用時；不用總傷害一欄下結論。
5. 沿用程序人物、兵器與原特效；可加有明確作用的姿態／軌跡區別，不引入公版 motion 契約、跨版人物圖或全員骨架重做。

**出口：** 三招能從正常學習到實際出手，前置不符時有原因；至少有一種用途與一種限制可觀察。至少一條普通弟子的學成→交手回報流程。不能讓單純換名字／放大光效成為通過證據。取消、空揮、重送、缺器械、短期疲勞與存讀仍按核心規則。

**規模：中。** 若提出多段命中、全新腿法或肢體損傷，已超過這個三招包，應另列候選而不是擴大本階段。

## M15：一次有分工的門派聯合演練

**玩家結果：** 看見弟子平日的訓練與分工，在同一張地圖一起派上用場。

1. 增加一個玩家明確選擇啟動的有限聯合演練，沿用現有家園外圍／林緣／溪橋及同圖戰鬥。目標選「護送到一個既有安全站位」或「守住一處既有站位」其中一種，先完成一種，不同時做兩個任務引擎。
2. 上限三名成年門人、兩波有限演練對手；來源明確，使用現有安全演武後果。沒有日常自動入侵、不讓自然獸群無限重生，家園可恢復平靜。
3. 至少兩種有效安排可嘗試，例如前點攔截／側路保護，或少人出手／留人照護。角色使用真位置、武器、精力與當前學會的招式，不以隊伍戰力公式替代。
4. 指令與取消走 M7 所有權；途中召回、傷員處理、橋口互讓、結束清理都可恢復。小禾不成為戰鬥目標、誘餌或戰鬥支援單位。
5. 結果只回顧實際發生的護送／漏過／交手／受照料事件；同參與的師徒可留下符合原規則的記憶。沒有參與者不能領共同成長或師徒履約。

**出口：** 一次正常 UI 完成、一個失敗或主動撤回且能恢復生活的流程；兩種安排的收益與代價照實落檔，不要求都勝利。M14 至少一招在此有可見用途。共享安排、有限對手與實物守恆不回歸。

**規模：中至大。** 這是本輪最大包，優先重用既有演武／站位；如需新導航／新敵人引擎才成立，先收斂成既有場地上的有限演練。
