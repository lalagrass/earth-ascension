# M13 一名普通弟子的成長段落：實作前規格

base `469cb1f`；Claude Opus 5.5（Anthropic），單一作者。本節先 commit，結果另列。

## 盤點

- 已有：共作記憶、邀請入門（阿木／一般同門）、真實指點與交談、M11 一師一徒（兩步同意、約定、成立後的共同記憶、五個一次性後續）、M3 武學三目標（深修拳／器械／體悟）、U/F/I 只由真實練習／授課／攻防增加、遠行 v2 與 `expedition.usedArts`（遠行中實際出手用過的武學）。
- 缺：這些步驟散在人物、江湖、遠征、武學四頁，玩家看不出一名普通同門「走到哪一步、下一步是什麼、每一步是哪次真實事件達成的」；師徒成立後沒有「往哪個方向練」的約定，後續也不讀練習與遠行中是否真的用上。

## 有限實作

1. **成長路線（唯讀）**：師徒分組顯示八步，每步列完成與否和來源（tick、記憶／事件／遠行 ID 或前後數值）：共作 → 入門 → 真實指點 → 拜師成立 → 選定方向 → 練出進度 → 一同遠行 → 返院後續。下一步寫出還缺什麼。入門紀錄若早於目前紀事保留範圍，照實寫「早於紀事保留範圍」，不補造。
2. **兩個方向**（沿現有 U/F/I 與武學，不新增身體成長值）：
   - 深修：基礎拳；進度＝自選定後拳的熟練 F 實際增加至少 10。
   - 器械：棍或劍（師父需已理解該器械 U ≥ 5）；進度＝自選定後弟子實際學會該器械（技能出現）且其熟練 F 增加至少 6。
   方向由師父提出、弟子本人答應或婉拒；婉拒後 1 日內不能再提同一方向；可改提另一方向。
3. **三段新銜接**（沿 M11 的到場相處 10 秒、一次領取、1200 tick 冷卻、雙方空閒）：
   - 定向之約：方向答應後可約；完成時記下基準值（選定當下的 U/F/I）。
   - 練成驗收：進度達成後才可約；文字寫出前後數值與成立後真實練習次數（讀技能來源紀錄）。
   - 歸來相談：需定向之後的一次共同遠行；內容依弟子那趟是否真的出手用上該方向的武學、是否受傷撤退而不同。
   三段都只加互信、寫紀事與共同記憶，不加任何武學數值。
4. **性格與歷史改變演出**：邀約理由與對白依弟子的勤勉／顧人性向與實際相處次數改寫（例如勤勉者「今晚就去練」）；面板只寫看得到的理由，不寫隱藏數值。
5. **保存版本**：方向與基準是新持久狀態。第一次提出方向時，把師徒約定由 v1 明示升為 v2（事件記錄），標記 `chapter1-mentor-2`；v2 驗證方向種類、器械、狀態、基準值範圍、婉拒冷卻、新事件 ID；v1 舊檔照 v1 讀入不默改，舊 reader 拒絕 v2。

## 事前驗收

1. 成長路線：普通同門（非經典人物）從共作到返院後續的每一步，來源都能對到真實紀錄；師徒成立前的遠行與記憶不算進成立後的步驟（沿用 M11 修補後規則）。
2. 方向：提出／答應／婉拒／冷卻／改提另一方向；條件不足（師父沒學過該器械、弟子是未成年或訪客、雙方忙碌或遠行）都拒絕且不改世界。
3. 進度只由真實練習產生：沒有練習時「練成驗收」不可約；練到門檻後可約；對話完成前後武學數值不變。
4. 歸來相談的不同後續：同一起點配對——弟子在共同遠行中真的出手 vs 沒出手（或受傷撤退），文字與互信變化不同。
5. 去重與中止：三段各只能領一次；任一方叫停不結算、可重約；冷卻內不能約下一段；讀回後不重領。
6. 保存：v1→v2 升級後中途存讀雙軌 hash 相同；方向／基準／事件引用不合法或未知版本拒絕；v1 舊檔照常讀入。
7. 既有 M7–M12 與審查修補測試照常通過；小禾不可拜師或被定方向。
8. 正常 UI（1440×900、1280×800）：showcase 匯入 → 林青（普通外門）走完整段：真實指點與交談 → 拜師 → 初次指點 → 定「深修」→ 定向之約 → 實際練拳到門檻 → 練成驗收 → 與師父一同遠行並返院 → 歸來相談；路線面板逐步打勾並顯示來源。器械方向以模型測試驗證有效學習與不同條件。
