# M28 可追溯的近期門派紀事：實作前規格

base `f9114f2`（M27 交付）；規劃 GPT / Codex（M24-M30-PLAN），實作主筆 Claude Opus 5.5（Anthropic），單一作者。本節先 commit，結果另列。

## 玩家問題、真實來源與缺口

紀事頁只把最近 70 筆 journal 直接印成一行文字（類型＋原文＋人名），點不回人物或設施；換局、讀檔時這份清單直接換成新世界的內容，看不出哪些是本局剛發生的。

- 本核心 `w.journal`：每筆有原生 `id`（`event.N`，N 單調遞增）、`tick`（20Hz）、`type`、`actors`，部分帶 `text`、`kind`、`art`、`facility`、`outcome` 等；只保留最後 500 筆（環形）。不是可見性歷史，也沒有通用的「原因」欄位。
- 公版（ef823ac）`event-view/contract.mjs`：`eventView()` 在保留前就遮掉 hidden；`createRecentEvents()` 有界快取（120）、每次最多列 24、以來源＋epoch 為身份，hidden 只消費游標不留任何列、數量或時間。`render.mjs` 的 `recentHtml()` 呈現列表與人物／設施按鈕。`adapters.mjs` 的 GPT 轉接綁 6cbd3e6，且用「本輪讀到的物件集合」比對環形 journal——不採用，本地改用原生 `event.N` 序號當游標。

## 本地採用

`vendor/public/ef823ac/event-view/contract.mjs`（不改）、`render.mjs`（只改 import 到本地 `text.mjs`），更新 `SOURCES.md`。

## 修改範圍

1. 新增 `src/event-feed.mjs`：`createGptEventFeed({getWorld})`，只讀 journal：
   - 游標＝`event.N` 的 N（每串流單調），環形捲動或重複讀取都不重收；epoch 在換成另一個世界物件或 tick 倒退時加一，快取跟著清空。
   - 支援目錄：列出 M20–M22 與既有常見事件（活動完成、成長、採集、建物完成、回復原安排、做飯、聯合演練開始／集合／回顧、師徒事件與作廢、方向各階段、後續、研讀招式、切磋結束、記憶、入門、義學完成、用餐、喝藥茶、體悟）；目錄內的事件只取該筆自身的欄位當結果與原因（`text`、`reason`、`outcome`、`kind`、`art`、`U/F/I`、`item`、`n`、`stage` 等），不讀人物現況、不看相鄰事件。目錄外的類型照列類型，但結果與原因都是「未知」。
   - 可見性：任一參與者不存在、已離開、在野外／古洞、未啟用時整筆 hidden；`command`、`transfer` 是內部帳目，也當 hidden 不列。hidden 只推進游標。
   - 連結：參與者連到人物卡；設施只取事件自身欄位（建物完成的 `facility`、做飯／練功／採集完成的 `kind`）對應到 M27 的三張設施卡，對不上就不給連結。
2. 介面：紀事頁上方新增「近期紀事」（全部／工作／武學／生活篩選），人物卡生活總覽新增此人的近期紀事；按人名回人物卡、按設施開設施卡。快取放在畫面，不進存檔；開關與篩選不改世界。
3. 讀檔：成功載入（換成新世界物件）→ epoch 加一、清空；載入失敗（世界沒換）→ 快取原封不動。

## 事前驗收

1. 過量：連續產生 300 筆以上事件，快取不超過 120、列表不超過 24；同一 tick 多筆事件都分開保留；journal 捲動與重複讀取不重收、不漏收（以 N 比對）。
2. 讀檔：成功讀檔後 epoch 加一、清單只剩新世界的事件；壞檔被拒時快取與世界都不變；新局同理。
3. 隱藏：離開的人、野外動物、內部帳目不出現在任何列、篩選、數量與 id 中。
4. 不推因果：目錄外類型結果「未知」；原因只來自事件本身。
5. 不改世界：開關紀事、篩選、按連結前後 hash 不變。
6. 正常 UI（1440×900、1280×800）：開近期紀事 → 一筆做飯完成 → 按人名到人物卡 → 按設施到膳房卡；另做一次壞檔匯入（被拒）確認清單不變、一次成功匯入確認清單重來。
7. 回歸全過。

## 實作紀錄

- `vendor/public/ef823ac/event-view/{contract,render}.mjs` 採用（render 只改 import），`SOURCES.md` 補兩列與不採用 `adapters.mjs` 的理由。
- `src/event-feed.mjs`：`createGptEventFeed`，游標是原生 `event.N`；`SUPPORTED` 目錄 26 種事件只取自身欄位，活動完成的標題用 `TASKNAME`（例如「烹調完成」）；目錄外類型結果與原因未知；內部帳目與參與者已離開／野外／古洞／未啟用的事件 hidden。
- `ui.mjs`：紀事頁頂端「近期紀事」（公版 `recentHtml`），人物卡生活總覽「此人的近期紀事」（展開才讀）；人名→人物卡、相關設施→M27 設施卡。快取只在頁面。
