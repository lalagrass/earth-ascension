## S02 單一 World 與固定時間

權威資料只能有一份 `World`；列表、人物卡、鏡頭、戰報都是投影。家園與遠征不得各自複製人物／HP／庫存。最小資料契約如下（欄位名稱可等義實作，語義不可省略）：

| 區塊 | 必存事實 |
|---|---|
| meta | `schemaVersion=1`、`rulesVersion="chapter1-1"`、`mapVersion="gpt-world-1"`、seed、worldId、nextId、tick |
| random | 分流 `world/events/npc` 的 uint32 狀態及每流 drawCount；戰鬥幾何不抽幸運必中 |
| people[id] | 穩定 ID、姓名／canonicalIdentity、成人／親屬資料、常住／日訪狀態、職位、五屬性／性向、真座標與朝向、精力／傷勢、攜物、武學、目前活動／玩家意圖、床與家庭引用、已知事實 |
| facilities[id] | 獨立 stage、施工單與已投入／待搬／已消耗材料、已完成工量、床／站位 availability；不存全圖 S2 作免費升級開關 |
| inventories[id] | 所在世界座標或人物／設施引用、逐物品整數數量、容量、owner、保留量；包括地面、手上、工地、營地、糧袋、原料與餐盤 |
| activities[id] | kind、actors、target、step、progressTicks、起訖／中斷原因、玩家 intent revision、交易與預約 token、已完成單位 |
| reservations | source quantity、destination capacity、station／paired slot、door／bridge token、候位及取得順序 |
| combat | 每個實體 health／move phase／actionId／已命中集合／觀察記錄；沒有遠征隊共用血條 |
| ecology | 3鼠2豬的固定個體 ID、棲地、模式、傷勢／恢復時刻／已驅離與擊倒狀態；洞口兩名守路人固定身份 |
| relationships | 有向互信／意願、事件引用、親屬／結伴／同住狀態；不從頭像位置推斷關係 |
| stories | 16 手寫節點的狀態／綁定人物、可見 choice、承諾與履行事實、各身份模式／來訪狀態 |
| expeditions/drills | 隊員 ID、目標／守點／追擊界線、路標／回程、逐次事件引用、實際物資 owner、去重報告 ID |
| journal/tutorial | 單調 eventId、tick、actorIds、因果／數量變更、顯示模板 key；教學已見狀態、立匾事實 |

所有引用 ID 必須存在，離去人物保留歷史記錄且標 `departed`，不刪再建同名人。ID 由 World 計數器產生，禁止姓名作 key。物資、人物、事件禁止重複計數；`people[id].rank` 改變不能重置活動、傷勢、技能或關係。

表內people與combat的health／action是同一component引用，不能各存可寫副本。常住／日訪容量只計人類居留身份；自然獸、兩守路人與演武訓練實體另有有限來源，不占床。周行未被發現時屬洞中story actor；開始護送前原子預留1日訪名額，滿額先約現有訪客正常離開或暫緩護送，不讓到家才憑空超過2訪客。此預留要在洞口顯示，途中取消釋放，轉常住另按招募條件。

一 tick=50ms，20Hz；一天 12000 tick=600 模擬秒。所有作業、移動、傷勢、睡眠與事件只消耗整數 tick。座標採 1/256 DU 定點整數，精力採 1/100 點整數；移動除法餘數入 state。需要距離時用整數平方根與固定捨入，避免渲染浮點回寫權威。1 DU=2 WU 只供原參考速度換算，runtime 統一 DU。

每 tick 的固定順序：

1. 依 `(executeTick, commandSeq)` 收命令，驗證並套用控制／中斷；拒絕亦回穩定 reasonCode。暫停時可即時套用控制命令／預約清理，tick、資源作業與角色位置不前進。
2. 釋放失效活動預約，處理安全／倒地；每人每 20 tick 評估一次自主（以穩定 ID 分散相位），有危險或有效新命令立即評估。
3. 依 `(requestTick, actorId, activityId)` 決定資源／站位交易與候位，先驗全部條件再原子提交。
4. 所有人提出移動，依通道 token／候位規則裁定，再同步移動；移動後快照供戰鬥使用。
5. 推進招式，先算可觀察資訊與截擊，再算未被中斷招式同 tick 命中集合，集中套用傷害／推離；同時合法命中可互中，不由陣列先後免傷。
6. 完成作業、成長、用餐／恢復及故事條件；同 tick 新產出下一 tick 才可預約，依事件 ID 寫紀事／去重標記，檢查不變量。

`step(world, commandBatch)` 與 `view(world, viewer)` 可分離；render 只讀 snapshot，音效只讀事件。1/2/4 倍速分別每牆鐘秒推 20/40/80 tick，不放大 dt、不跳動畫後直接給戰果。frame accumulator 保留 backlog，每 frame 最多 8 tick；落後顯示實際模擬變慢，不丟 tick。分頁隱藏／恢復時自動暫停，不追趕離線時間。相同 seed＋同 tick 命令，播放倍率、鏡頭、靜音、低動態不得改 canonical World。

PRNG 採明定 xorshift32（`x ^= x<<13; x ^= x>>>17; x ^= x<<5; x >>>=0`），流初值由 seed 與固定流常數 XOR，零值換 `0x6d2b79f5`。整數 seed 接受 1..4294967295，預設 11；非法拒絕。禁止模擬使用 Date.now／Math.random。隨機只用有限人物偏好、事件同級候選和個體起始巡行差，不抽是否能結尾；每次 draw 有固定呼叫順序。

## S04 活動、預約、取消與守恆

活動模板宣告 `{requirements, participants, source, destination, stations, duration, commitPoint, outputs, interruption}`。人物只持一個活動，可保留一個被自理／避險打斷的意圖；不要堆無限工作佇列。主要狀態是 `proposed→reserved→approach→perform→deliver→complete`，分支 `waiting/blocked/paused/cancelled`；任一步 target 失效都走 cleanup。

預約是 token（activityId、actorId、kind、key、quantity、phase），不轉移物品所有權。原子取得順序為 source→destination capacity→participant agreement→station；失敗全部回滾，不讓一人抱著原料鎖等另一人永久擁有的座位。長程搬運只保 source／destination，不保未到達工作站；到接近區再排站。雙人活動兩人及兩槽同批接受，任一人拒絕／離開／新令／受傷，兩邊 token 同步釋放，不產生完成收益。

| 取消時點 | 必須保留／退回的事實 |
|---|---|
| 尚未取料 | 釋 source、destination、station；數量未變 |
| 已取料、在路上 | source已扣、人物 inventory持有；只釋舊目的地容量。新目標若不接收，先到最近合法地面堆放或回倉；不遠端退款、不瞬移丟物 |
| 已投工地／已完成作業單位 | 工地已收料／工量保留；取消不把同料再退倉；續工只補缺口 |
| 配方 perform已達commitPoint | 原料→在製品一次轉換；取消留下可見在製品供後續續做。不得再退完整原料又保留產物 |
| 被擊倒 | 物品留該人／原地包裹，owner變更有事件；被救援取回才回倉 |
| 截擊／攻擊途中 | 起手取消無命中；已結算命中不倒扣，剩餘收勢限制仍在；新工作等最短合法恢復，不因重送清冷卻 |

守恆逐物品核 `初始＋採集／配方／事件有來源產出－配方／食用／施工消耗－明記損失＝所有inventory總量`；預約不算持有。容量也包含已保留未到貨量。木／石／菜／藥／水不允許負數與小數，配方轉換在 ledger 有明細。採集不是無來源加倉：資源節點先產到採集者手上，再負重走回。相同 commandId／activity completionId 重送無第二次效果。

玩家意圖帶 revision：新令取代舊令；休息後只續仍有效 revision。`停工` 設manualStop直到玩家解除，只自理／避險；`叫回` 設return且回安全點後manualStop，途中不接新採集；`暫停工作` 保留工地與活動可續資料但釋排他鎖。畫面分清「整局暫停」與「此人停工」。

## S07 同圖武學與成長

戰鬥與普通活動共用位置／時間；不必逐招操作。玩家指定主修、守點、保護對象、追擊上限，AI依已知敵人距離／朝向／精力選合法招。目標感知需120 DU內且LOS，觀察到才顯示；牆後不能知道敵人move。旋轉朝向最大每tick15度（身法每高於4加1度，最低10度），active期間朝向鎖定；最後起手4tick亦鎖定，不瞬時追蹤側移。

每個action唯一ID，`windup→active→recover`；每target每action最多一次命中。起手時扣招式精力，非足額不出；命中按移動後快照幾何與LOS，落空照樣收勢。HP歸零倒地；野外傷害另加 `ceil(damage/2)` 傷勢。一般受擊僵直4tick，可打斷windup；active已合法發生的同tick互中保留。推離沿可走路徑最多指定距離，碰牆／人／水前停止，不穿牆、不額外碰撞傷害。

受擊一律清當前連續觀察；已辨識模式的完整觀察次數扣 `max(0,2-floor(定力/3))`，不低於0。身法對短步recover每高於4減1tick、最低12tick，低於4每點加1；其餘表列規則不暗改。定力不能使未知／遮擋模式自動識破。

演武兩組配置：甲「正面守線」兩波各2訓練人，乙「側路協作」第一波2、第二波2（分左右邊路），同時至多4對手；每人有訓練ID及真準備位／入場路，玩家開始才走入。訓練沿同moves、LOS與AI，只把倒地後果改為HP不低於50%、不加永久傷勢、到界停止；結束實走退準備位再復原，無物資獎勵。對練與演武不耗自然獸，不洗自然HP。結束需所有波完成／玩家終止／全部隊員退出；報告列各action、漏線／落空／受擊及時長。

安全模式命中本會令HP≤上限50%時，先夾在50%，標該session的 `trainingDefeated` 並停手／退出，不能等永遠到不了的HP0。訓練對手被判負或真的越過守線都移出當波active集合；當波全退出且間隔10s才進下一波。門人判負即沿撤退路退出本次演武，不自動滿血重入。對練同樣以判負或30s時限結束；武學命中規則未變，只是非致命結束後果不同。

成長比較用正常存檔在自然遊玩取得練前／練後兩時點，同配置、同角色、同初始精力／負重／裝備、其他角色不介入；AI或規則更動不得混在同一配對。工程fixture另可精確鎖其他屬性，正常UI比較不要求假裝腳力未在長局成長，須列出實際控制值與剩餘差異。

## S09 遠征、自然個體、撤回與救援

隊員來自people引用，不能派小女孩、日訪宗師、失能者或重複ID。派遣前檢驗一隊限制、1..3成人、路可達、目前intent可中斷、健康與補給，顯示缺項；先走到倉領乾糧並集合，再按真路出北門。沒有把人標away後清path的背景模式。遠征各段用同S07；玩家可跟鏡、切家園且家園繼續同tick。營地最多2格補給（每格4乾糧），搬到才有；外出包仍按人物carry容量，休整不能憑空補滿。

回程預留每20tick／傷勢或路變化時重算：沿可走路徑到內院長度L，用本人當前負重／傷勢速度求ceil ticks，精力成本採負重行走率，另加10精力與20s候橋（若已知橋待用）；有扶助按扶助速度。出發至少滿足去程＋回程＋10戰鬥餘裕；不足拒絕並指出可減負／備糧／休息。途中剩餘精力≤回程預留立即回頭，若需補給先到已知安全營地；不假設未知洞內必有補給。改派叫回立即取消進攻追擊，保護／自衛仍可；優先搬自己手上物回家，不沿路新採集。

自然3鼠2豬在newWorld一次建ID及棲地。鼠迴避、豬巡行覓食；初日一次野豬沿北來路接近外帶作有限護家遭遇，之後回棲地，不每晚刷波。被驅離／逃回者原ID進恢復，至少一日後才再次巡行；擊倒者本章持續inactive，不刷新補滿。戰報分辨driven/escaped/down/avoided/unknown，用逐個體事件去重，不把沒遇到的獸算清場。洞守路人脫戰回側位，不無限堵橋或回家追到臥室。

首版敵方資料基準：鼠HP16、速度24DU/s、咬20/2/24tick、距14／基傷4；豬HP48、速度22、拱28/2/28、距18／基傷8；洞守路人HP60、速度26，沿直拳／直刺規則（基傷6）且每三次起手可取消一次佯攻。全部經同action／LOS／受擊引擎，無另一套DPS。自然五ID `rat.1..3/boar.1..2`，起始位置以 `(1490,630),(1550,600),(1580,560),(1510,720),(1640,540)` 為基準，runtime各放於已驗林緣開敞可走區；若需投影到最近合法點，newWorld只做一次固定投影並記map資料，不每次重進區洗位置。訓練對手HP40、速度26、同拳／劍基傷6，先弱後強靠進場方位，不隱藏增傷。獸被推離棲地外或HP≤50%且無近身威脅可選逃回，3s追擊未再近身則完成驅離，非自動擊倒。

人物HP≤0設downed，保持位置／物品，不永久死亡；同伴接近且安全後8s扶起，恢復HP10、傷勢至少70，速度受傷勢與扶助乘數，禁重返戰鬥。全隊失能／精力無法回程時顯示「請求救援」，120模擬秒後由家園可用成人或村路救援者步行出發；先派可行本地成人，否則最多兩位具名有限服務訪客（占日訪槽，現有可離開訪客先沿正常路離去、新約訪暫停）。若周行已預留1槽，先派另1槽的一名救援者分趟即可，不必等兩槽全空；只保留尚在使用的主線護送預留，取消的活動立即釋槽。救援者在可見南邊界入圖、沿已通路前往，每次可攙扶1人，3人隊分趟，不瞬移、不改橋容量；救援者只護送不代清洞口，救援期間對已倒地隊伍停戰並退讓安全走廊，有明確停戰事件。地圖不可達是工程失敗，不以救援傳送補洞。

救援記錄實際耗時；每次村路救援最多收5錢，錢不足記一次欠情事件、禁止負庫存；損失僅原地包中最多一半非任務食物（向下取整，事件明列），周行與主線物不消失。可以付代價失敗再玩，不自動全HP滿糧。返院以每隊員抵內院安全槽為準，交貨按實際完成，戰報至多一次，可有未履約事項，不用返程倒數結束就算到家。

## S10 UI、呈現、教學與可見證據

桌面基準1440×900與1280×800，100%縮放；全圖適配、滑鼠縮放／拖曳、家園／E1／E2／E3定位、人物跟隨／取消跟隨。鏡頭只改view，不把出圖者藏進away清單。選人、發令、設方針、暫停／倍率、叫回、停工、取消、存讀全有可見控制；Space暫停、Escape關面板，輸入欄內快捷鍵不搶文字。按鈕disabled要有缺料／路阻／對象拒絕理由，不能靜默不動。

HUD顯示日／時段、seed、倍率、暫停、常住／訪客／床數、缺餐提醒與物資；詳情固定「現在／原因／下一步／受阻」，人物武學三軌與最近因果事件可展開。建設顯示每stage需求／已在途／投入／工量；派遣面板顯示每人負重與回程預留，不只總戰力。遊戲畫面不放資源加滿、設level、固定戰果、跳結尾按鈕；開發fixture與測試入口不能出現在正式index。

教學只引導正常流程：配點／問卷→認人／暫停→取木與搬運→修dorm／真床→練拳→護家→招募與備糧→演武→出門／叫回→古洞分歧→立匾與存檔。可略過／重開，不給略過獎勵，不自動派任改存檔。缺材料展示合法取得路，低精力指出休息，不能把教程順序當不可逆鎖。

動作與圖層依 [ASSET_CONTRACT](ASSET_CONTRACT.md)。工作、負重、拳棍劍、起手與收勢在小人上可辨；樹／屋頂遮擋按腳底排序，選中人物輪廓不授穿牆視線。音效由腳步／施工／出招／完成事件觸發，使用者首次互動才啟動；提供靜音／音量與低動態，設定不進規則hash。無音訊時仍能完整辨識時機，不自動全屏搶鏡。

## S11 保存、驗證、版本與資料保護

新key前綴 `solo-sect-gpt.chapter1.v1.`，一手動槽、三輪替auto槽、獨立settings；不讀寫舊Earth／SG／LIFE01／Grok鍵，不掃localStorage全域清除。自動存每1200tick（60模擬秒）於完整tick尾，失敗可繼續局並顯示；同tick不重存輪替。手動、匯出、匯入都在一致tick邊界；保存不中斷作業，不用清空預約來掩飾難存狀態。

envelope `{format:"solo-sect-gpt", schemaVersion:1, rulesVersion, mapVersion, savedAt, payload, checksum}`。checksum採SHA-256(canonical payload)防意外損毀，不宣稱防作弊；savedAt與UI偏好不在canonical World。canonical遞迴排序object keys、以ID排序具名集合、保留佇列既定順序、排除view／cache／牆鐘；不排除會影響行為的commandSeq、活動進度、RNG、冷卻、token、物資餘數。保留所有第一章關鍵記憶／故事／個體結果，render journal可限最近500條但必存已去重ID與彙總依據，不從UI截短資料猜前史。

載入先在獨立暫存解析與驗：檔案≤8MiB、format／版本、checksum、有限安全整數與範圍、全引用存在、8＋2容量、床／槽唯一、source預約≤持量、dest已保＋實量≤容量、活動／token owner一致、actor位置合法、物資ledger／nextId／tick／RNG一致。原型不接受 `__proto__`／未知型別注入，不把匯入字串當HTML。合法才原子替換當局；讀回停在暫停態，按繼續才走下一tick，不追牆鐘。

不把nav cache／貼圖存入payload；load從mapVersion重建圖，校驗保存的route edge索引／位置／token，再保留相同可行活動、候位順序與剩餘tick。若不可驗而會改後續行為則拒絕，不靜默丟掉手上木／中途招式。每個tick尾可存，包含橋上、多人對話、收勢、工地在途、傷員護送、分歧承諾尚未履約。

先寫暫存字串、重讀驗證成功後才輪換正式槽，保留前一份有效快照；localStorage quota／disabled／checksum失敗不得覆寫最後有效槽。原子單key替換失敗仍保留舊值；啟動只讀本前綴有效槽。匯入需預覽版本／seed／日與確認「替換當局」，不自動覆寫手動檔；取消與壞檔不改World／槽。只支持本新schema1；未知／其他分支格式明拒絕，無自動遷移承諾。日後規則／map改變若需載舊檔，先補明確遷移與fixture；不得只改版本號把舊檔當新檔。
