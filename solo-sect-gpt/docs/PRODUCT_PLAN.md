## 1. 要完成的體驗

玩家讓一間破道館變成有人願意留下的小門派：看見取水、扛木、修房、吃飯、聊天與練功；下達方針後角色自行完成，遇到問題能解釋、能叫回。帶同一批人走出家門，看到練過的拳、棍、劍在同一張連續世界裡有不同作用；返回後留下物資、傷勢、關係和一段可追溯的故事。

完整願景的廣度是「生活 → 建設 → 識人／收徒 → 練功／深修 → 守點／遠征 → 回家／關係 → 開宗立派」。第一版讓這一圈完整轉一遍；不以全部名俠、全部武學或無限地圖作完成條件。

| 支柱 | 第一版肉眼可驗的承諾 |
|---|---|
| 門派生活 | 三人起步，同一人物可由具名雇工轉外門，再到內門；不換 ID 或憑空替換立繪 |
| 同圖武學 | 起手、有效時點、收勢、落空與破招都發生在真實位置；切鏡頭不結算一場戰果 |
| 人際與成家 | 一次共同施工、照料或護送造成可回看的關係事件；成年互相願意者可結伴、共住房間 |
| 塔防式演武 | 選守點與方針，角色自主迎敵；同一配置可重複比較練功前後；家園沒有強迫無限獸潮 |
| 逐步擴建 | 材料從資源點到手上、料堆，再成為工地；完工才開放床位與活動 |

## 3. 玩家的一天與可靠自主

起床後先看「今日門派方針」：修屋／備糧／修行三選一，不是隱藏的無限指令佇列。掌門依能力、已知缺口與性向選事；其他人依職務、作息、目前承諾決定。面板固定顯示「正在做／原因／接下來／受阻原因」，例如「扛木到側舍：已接施工；送完先用餐」。

優先序為立即避險與保命 → 玩家有效指令／叫回 → 必要自理 → 已承諾的工作單位 → 作息／方針 → 自由活動。危險暫時打斷時保留玩家目標及原因；玩家明確停工後只自理與避險，不自動復工。改派從當前位置合法轉路，手上物資仍屬該人；滿倉、堵路、對方離開、資源用完都要釋放預約並有可讀出口。

一日候選 600 模擬秒：睡眠 180、雜務／生產 180、練功 120、用餐／自由 120；不要求每人整齊同時排隊。外門每日貢獻為目標而非欠債：候選 2 個完整工作單位或 120 秒有效工作，以先達者為準；另保留至少一個 60 秒練功窗口。缺料、傷病、必要照顧與危機免除未完成目標，不跨日加倍。內門平日偏修行／教學，物資斷供或護家時可幫忙；掌門沒有永久免勞動特權。

水與木路程長，吃飯與床位短。腳力由真走路／負重成長；更快仍走同一路，不縮路或穿牆。物資充足後確實停止補貨，角色能聊天、看山或練習，避免自主變成永不停工。

## 4. 識人、招募與家庭

初始雇工暫名「阿木」（成年），義學候選「林青」、慕名候選「沈禾」、古洞旅人「周行」皆為成年原創角色；姓名可在 spec 自行調整，不增事件數量。具名雇工有工作契約、既有能力與未揭露偏好；共作或交談後逐步認識。邀入門需空床、可負擔的供餐與本人意願；拒絕不重生另一個同名人。職位變更保留記憶、工作途中物資、傷勢、武學與人際。晉升內門由一次真對練／教學與貢獻紀錄支持，不以換標籤免除全部責任。

另外三條入口做成有限事件：下山免費義學（授課者沿南路走到村路接待空地，村民也真走到場；本版不另做村莊地圖）、慕名來訪（立有接待條件後抵達）、古洞奇遇／救助（與主分歧共用）。義學不強迫授課者或候選者加入，不用開選單直接加人口。

關係記錄「誰在何時為誰做了什麼」，事件分開記互信與相處意願。短時間重複同句話不刷進度；沒有任何關係事件的好感直升不算交付。成年、非親屬、互有結伴意願者可建立家庭並挑相鄰床位；同房不是瞬移或消失，拒絕／解除不抹掉歷史。小女孩只有親情、陪伴、受照顧事件；無戀愛選項或成人事件 target。

## 5. 武學的廣度、深度與可見差異

理解＝知道條件與原理，熟練＝動作穩定和銜接，體悟＝在實際情境發現一種新用法。三者分別有來源；只有反覆點按按鈕不能增加。低悟性學理較慢，但有效練習累積仍可把基礎拳練深；高悟性也能走同一路。候選成長階段只有「入門／熟練／深修」，沒有十階龐大樹或悟性互斥門檻。

| 動作 | 玩家能分辨的用途 | 必須存在的限制 |
|---|---|---|
| 直拳 | 短距離、收勢快，深修後步伐更穩、失手後接續更快 | 仍有非零起手／收勢；空揮與重送不刷完整練習 |
| 推掌 | 蓄力明顯、推離守點；洪七公授課可使掌門理解它 | 太早出手可被躲開；距離／牆體限制，不全屏擊退 |
| 棍掃 | 能攔側翼、同一弧面有限多目標 | 窄橋會被空間限制；收勢較長，不固定克制全部拳法 |
| 直刺 | 明確前向、距離較長 | 側移或遮擋會落空，轉向非瞬間必中 |
| 辨隙截擊 | 先看到對方起手、識別已學模式，再在距離／時機內截擊 | 視線遮擋、沒看過、太晚、疲勞、對手佯攻或短起手都可失敗；無 0 秒自動必中 |
| 短步 | 在短距離換位／撤退，能避開明顯攻擊線 | 消耗精力、需要落腳點，不能穿人牆或越溪捷徑 |

演武和遠征讀相同動作與命中規則；安全演武只改傷害後果與對手來源。深修比較用同一可重複演武配置、同一角色、同負重／精力，記錄有效出招、落空、用時、受擊、守點漏過，而不是只比 DPS。自然獸不為測試重生；敵人逃離、驅離、擊倒、繞避分開計。

## 6. 自創與少量經典人物

自創採固定 20 點分配到體魄、臂力、身法、悟性、定力（每項 1–7，起始各 4），4 題情境問卷導出勤勉／自由、顧人／自持兩軸與可見偏好；不宣稱心理測驗真實有效。不賣點數、不靠故意低悟獲得額外預算。允許預覽選擇理由，改一次方針後依合法時點生效。

可選開局模板只有郭靖、令狐沖、岳不群；固定相同總預算與入門實力，與自創走同一經濟和成長流程。每一經典身份全局唯一，開局選中者從候選池移除。未選角色的「未成名招募」與「成熟作客」由新局模式固定，同一局不出現年輕版與宗師版雙重身份。新局預設未成名世界；成熟作客模式保留同樣弱起步模板（明示為成長改寫），NPC 則作有限客人，不能直接永久加入碾過第一章。

| 人物 | 兩個有限事件節點與特色 | 成長／招募與作客邊界 |
|---|---|---|
| 洪七公 | 招待一餐→真授課推掌；重飲食、俠義與分享 | 未成名模式可結識邀請，成熟模式授課後離開；沒有全部十八掌 |
| 令狐沖 | 自由切磋→觀察一種招式並學截擊；不愛被排滿 | 未成名可招募或選主角，成熟只陪練；九劍只交一種可失敗辨隙 |
| 喬峰 | 共同行走護人→承擔一次護衛；優先護住落後者 | 未成名可邀入門，成熟客人護送一趟後離開；不硬派民族／原作悲劇 |
| 郭靖 | 一起練樁→同條件深修展示；勤勉有過程 | 未成名可招募或選主角，成熟有限指點；高悟角色不被排除同種深修 |
| 岳不群 | 接待與門派名望→主分歧後回應；顧門派與承諾 | 未成名可招募或選主角，成熟只來訪；不強迫走黑化或自傷宿命 |

只使用私人原型文字與自製／已核可素材，不搬外部 IP 遊戲的立繪、聲音、台詞。公開授權或原創化是發布前另案，不阻止此次本機設計與開發，也不由本規劃聲稱已解決。

主分歧只有「古洞救人／先保糧」：E3 洞口先看見受困旅人與有限糧袋，玩家或已啟用自主掌門依性向選擇。救人帶傷者走回、少帶糧，留下互助／未來招募機會；保糧先運糧返家，救人承諾留在記錄並可後續回去履行。兩者均能開宗立派；有負擔與人際回呼，不把其中一個寫成必然邪惡。第三節點在返院後核實實際結果，若中途改令／撤退則不冒充已履約。旅人只在真的安全回院後計入訪客或候選，糧袋不進全局空間倉。

## 7. 畫面、控制與結尾

桌面第一版以全圖、人物跟隨、家園／遠征定位三種鏡頭操作即可。人物清單與同一張角色詳情側欄持續可用；建設與遠征各一個簡短面板，內容隨已具備條件逐步顯露。玩家可暫停讀原因、改派、叫回、切守點與追擊界線；不要求逐招微操。

外出時家園繼續按同一模擬時鐘生活；未觀看區可降低渲染量，不能批次計算另一套戰鬥。所有人物頭頂只顯示短動作與必要原因，完整事件進回顧；預設不自動搶鏡，少量音效可關，減少動態選項不改規則。看不見的 NPC 不顯示玩家未取得的敵方意圖。

立匾畫面只回顧真的發生過的建設、收徒、練成與分歧結果。完整保存最後收尾，但單一權威狀態、穩定 ID、版本界線先訂；不能先以多套人物世界接 UI，最後才補資料一致性。
