## 3. 五種路線、距離與容量

## 4. 外圍演武與唯一遠征

演武區是家園局部 `[1280,250,290,210]`，與外功區相鄰但不重疊。兩個守點 A `(1340,420)`、B `(1430,350)`，前方一條主來路與可側移空地；西南 `(1260,450)` 是可撤出口。牆、石塊阻擋視線，樹冠只遮畫面不自動擋招；spec 分別定 LOS／碰撞標記。對手最多4、每配置2波，玩家按開始才有；結束後回準備位，沒有素材獎勵刷取或自然個體復活。

世界家園北界 `(1480,800)`＝家園局部 `(1480,0)`＝E1 起點。北門位於家園內 `(1480,880)` 世界座標；角色先走到邊界再進遠區，座標與身份不重設。遠征總主路 1072.3 DU（2144.5 WU，未含院內出門），正常步速單程約35.7s；觀察、戰鬥、補給與護送另外計時。

| 路段／世界座標 | 資源、風險與操作意義 | 返回／視線／容量 |
|---|---|---|
| E1 林緣 `(1480,800)→(1660,520)` | 野藥少量、3鼠與2豬的有限棲地；可觀察、繞避或驅離，擊倒不是唯一目標 | 植被間有較寬空地；首次遇見才揭露個體；棲地恢復留原ID，不能每次出隊刷滿 |
| 休整 `(1660,520)` | 2格便攜糧袋存放位；先運來才有；受傷者可休息與被接回 | 主路外側，3隊員可集合；不成無限回血泉或免費回家傳送 |
| E2 溪谷 `(1660,520)→(2000,400)` | 藥草和碎石；側路由 `(1740,480)` 經 `(1860,320)` 再到 `(1870,440)`，可避獸、較長 | 岩塊遮視線；側路不跨溪、不繞過橋，繞避不記清場 |
| 窄橋 `[1870,425,70,30]` | 共用地形瓶頸，短步不能越溪；棍掃受站位限制 | 一人／單方向占用，西候位 `(1840,440)`、東 `(1970,420)`；傷員／撤退優先，正常隊伍有限批次，避免永久餓死另一邊 |
| E3 古洞 `(2000,400)→(2200,150)` | 兩名守路人、受困旅人、有限糧袋；救人／保糧主分歧 | 岩角遮視線，不可隔岩截擊；守路人不在橋上無限卡路，退回登陸空地可脫戰；原路回營／回家 |

1–3 隊員由同一人物世界出發，預留負重與傷勢下的回程精力，依目前可走的實際路長計算；玩家隨時叫回。碰到未預計的傷勢／堵路可在休整點等救援，清楚說明缺什麼。第一章沒有永久死亡，倒地者留原位置、可被隊員攙扶慢走；如全隊失能，啟動一段可見的有限救援返程並記損失（具體耗時／損失由 spec 定），不能偷偷瞬移後宣稱完美返院。

全部區域同一時鐘和規則。渲染可只畫鏡頭附近，移動／出招仍按相同權威 tick；不存在遠征 DPS 批次、另一套 HP、在地圖與報告各自更新的人物副本。戰報由真事件整理：最遠路標、走路／交手／回程用時、每個對手的逃脫／驅離／擊倒、帶回糧、人是否平安。

已檢視的 SCENE04 水彩圖足以界定氣氛，本階段不另生一張相同用途概念圖，亦未使用 imagegen。工程圖優先用原創 SVG 讓位置、門與路線可編輯。開發需要新水彩地面／建築／角色時依 imagegen 技能使用 OpenAI 圖像工具；不能以生圖替代可用碰撞或將本圖當最終遊戲美術。

## 6. 自校界線與下一步

本次做靜態路長、footprint／路線中心線、資料及連結自校，檢視 HTML 切階段與疊圖；證據在 [SELF_REVIEW](../evidence/planning/SELF_REVIEW.md)。沒有運行新遊戲，所以不聲稱尋路、LOS、排隊、戰鬥、公平性或效能驗收通過。下一階段先將缺的室內／候位／資源支線補成 spec，再實作可走幾何；發現不通可局部調整本候選尺寸，保留原因，不需再次問每個座標。
