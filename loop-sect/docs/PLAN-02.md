# 規劃 2：M11–M20（loop 11，2026-10-30）

規劃輪沒有程式碼可以擋住，所以這份文件要讓每個 milestone 都對得到三樣東西：擁有人原話裡的哪一段、哪一條 openIssue 或 retro 風險、一句可以在 soak 或 report 裡量的主張。

## 依據

- 擁有人 2026-10-30 開這個變體時的願景：模擬市民式需求與社交、世紀帝國式採集建設、塔防式侵擾、天下霸圖式學武領悟、遠征換長久安寧、人格問卷與天賦點數。
- [NORTH_STAR](../../sect-chronicle/docs/vision/NORTH_STAR.md) 的五支柱與擁有人 2026-10-24 原話：大廳、外功區、宿舍、膳房、藥園、菜園、後山打獵；從破道館慢慢擴建；親密夠了拉進一個家庭；練完出去打怪的感受；同一張地圖上看到不同武功。
- 第一批的現況（M10 report）：十日經濟穩、看生平猜得出個性。但門派長不過 5 人（床位）；生活技能第 3 日後幾乎不長（沒有持續需求）；防禦是「衝出去打」，不是守點；招式只有一種出招弧線；沒有受傷，遠征的風險只有精力；地圖只有一屏，M9 說的「東側區域一路打過去」沒有做。

## 排序的想法

1. **先解人數上限**，因為塔防、作息、成家都要人。人數上去之前先量效能（retro 1 起就掛著的 openIssue）。
2. **再補持續需求**，讓第一批的技能、搬運、採集在十日長跑裡一直有事做。
3. **然後是武學與防禦的三步**：先讓招式看得出不同（P2），再讓人守在柵欄後（P4 塔防），最後是主動的演武波次（P4「練了有沒有用」）。
4. **風險跟著來**：受傷與藥園，讓遠征與守點有代價，也接上藥園。
5. **生活感的兩步**：成家（P3）、作息與門規（P1 天下霸圖式的一天）。
6. **最後擴地圖**（後山與東側），再做第二次觀察與平衡。

擁有人選定的觀看樂趣是「長通勤、負重與腳力造成的速度差、成長即速度」，所以走路占 45% 不當成要壓低的數字；擴建時不把設施全擠在一起。
