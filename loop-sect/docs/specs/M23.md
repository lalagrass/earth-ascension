# M23 後期侵擾

Loop 27。支柱 P4。PLAN-03。

## 目標

M20：敵人每 2 日多 1 隻、沒有上限，第 19 日一次 10 隻；打退率還在升。拆了巢之後那一類敵人就再也不來，故事到這裡斷了。這輪做兩件事：一次來的敵人有上限；拆了巢，過幾日那一窩的頭目會帶人來報仇，頭目有名字、血多，紀事記下。

## 前置條件（v5、v9）

- `raidSchedule` 用自己的種子亂數，一日一筆：`1 + floor((d − 1) / 2)` 隻（d 從 0 起算），十日內最多 5 隻；第 11 日（d 10）起才會 ≥ 6。上限設 6，**前 12 日的排程跟以前一模一樣**，5 日 soak、10 日 report 的 base 不變。
- 拆巢只在 exp 情境（第 3–4 日拆野豬窩）。報仇在拆後第 3 日，落在第 6–7 日，10 日 report 的 exp 會變。
- 這條規則不是針對飢餓，v9 第 18 條不適用；但 exp 的飢餓照舊判。

## 玩家會感受到的主張

「拆了野豬窩不是故事的結尾：幾日後野豬王帶著兩頭野豬來報仇，大家一起圍上去打；敵人不會多到永遠打不完」。

## 規則與資料（`data.mjs` 的 `RAID.CAP`、`BOSS`；`raid.mjs`）

- `RAID.CAP = 6`：一次最多 6 隻（排程時就截）。
- `BOSS = { DELAY: 3, HOUR: 10, HP_MUL: 3, ESCORT: 2, NAMES: { boar: [...], bandit: [...] } }`。
- 拆巢時排一筆報仇：拆後第 `DELAY` 日 `HOUR` 時，頭目（那一窩的種類、血 ×3、名字照種子挑）加 `ESCORT` 隻同類從南邊來。紀事「野豬王〇〇帶著兩頭野豬來報仇」；打退時「〇〇、〇〇打退了野豬王〇〇」。頭目頭上有名字、血條較粗。
- 報仇的敵人不受「拆了巢就不再來」影響；打退後那一類照舊不再來。
