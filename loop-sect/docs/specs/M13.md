# M13 外功場與招式演出

Loop 15。支柱 P2（武學在同一張地圖上看得到）。

## 目標

M6 起練功、切磋、迎敵都畫成同一種弧線，看不出練的是哪一招，也看不出練得好不好。這輪讓每一門招式在地圖上有自己的形狀，熟練越高出手越快、範圍越大；再加一座外功場，讓練功有一個看得到的地方。

## 前置條件（v5）

- 已有：六招（長拳、開山掌、流雲手、破岳勢、飛燕腿、太初拳），`drawStrikes` 每 12 tick 換角度畫一道弧（`render.mjs`）。練功 `drill` 50 tick、切磋 `spar` 40 tick；迎敵每 tick 扣血。
- 外功場的空地：道館東邊、東茅屋南邊 `[40..47, 21..23]` 目前是空地（地圖固定版型），在河（49 欄）西邊。
- 不動既有平衡：出招只是演出，不改傷害、熟練、領悟。只有在外功場練功時熟練多長一點（`MARTIAL.YARD_MUL`）。base、exp、grow、farm 情境不放外功場，雜湊不變。

## 玩家會感受到的主張

「只看出招的形狀，就分得出是哪一門；練得越久，出手越快越大」。

## 玩家看到什麼

- 練功、切磋、迎敵時，人旁邊畫出那一招的形狀：
  - 拳（長拳、太初拳）：朝前一道直線，末端一個拳印。
  - 掌（開山掌、破岳勢）：朝前一片扇形。
  - 手（流雲手）：繞身一圈的圓弧。
  - 腿（飛燕腿）：遠處一道窄弧，人往前踏一小步。
- 熟練高的人一招接一招比較密，形狀比較大。
- 人物卡「武學」分頁每一招旁邊有一個小圖，畫這一招的形狀與現在的大小。
- 營造面板多一張「外功場」藍圖（木 8 石 4，工時 100）：道館東邊一塊夯土地、三個木人。在那裡練功，熟練多長兩成五。

## 規則與資料（`data.mjs` 的 `MOVES[].form`、`STRIKE`；`src/forms.mjs`）

- 每招一個 `form`：`fist`、`palm`、`hand`、`kick`。形狀描述 `shapeOf(form, size)`：
  - `fist`：直線，伸出 1.6 × size 格，寬 0.2 格。
  - `palm`：扇形，半徑 1.3 × size 格，張角 100°。
  - `hand`：圓環，半徑 1.0 × size 格，張角 300°。
  - `kick`：窄弧，半徑 2.2 × size 格，張角 50°，人前踏 0.3 格（只畫，不改座標）。
- 出手間隔 `period(v) = round(STRIKE.BASE × (1 − STRIKE.FAST × v/100))`，`BASE = 16`、`FAST = 0.5`。熟練 20 → 14 tick、80 → 10 tick。
- 大小 `size(v) = STRIKE.SIZE0 + STRIKE.SIZE_GAIN × v/100`，`SIZE0 = 0.8`、`SIZE_GAIN = 0.6`。
- 練功、切磋時出的是 `task.move`；迎敵時出的是會的招裡「威力 × 熟練」最大的那招。
- 每次出手記在 `p.strike = { move, form, at, ang, size }`，畫面依 `at` 淡出（`STRIKE.LIFE = 8` tick）。不用亂數，不進 `stateHash`。
- 外功場藍圖 `yard`（kind `yard`）：`[40..47, 21..23]` 變成可走的夯土格 `w`；完工加三個木人（站位 `[41,22]`、`[43,22]`、`[45,22]`，`yard: true`）。在外功場木人練完，熟練 × `MARTIAL.YARD_MUL = 1.25`。

## 不做

輕功位移（真的改座標）、招式的範圍傷害、出招音效、多人合擊、外功場升級。
