# M1 世界骨架與人物模板

Loop 1。支柱 P1（看得到人物在地圖上照自己的個性生活）。

## 目標

建立之後九個 milestone 都會用到的底座：可決定論重播的模擬、格子地圖與尋路、人物模板（16 型人格＋天賦點數＋特質），以及一個最小但真的由個性驅動的走動 AI。

## 玩家看到什麼

1. 開局畫面：回答 8 題問卷得到人格類型（四軸即時預覽），用 25 點分配根骨／悟性／身法／膂力／定力（每項 1–10），或一鍵套用六位武俠人物模板之一；可改名。
2. 進入地圖：64×40 格的荒山——中間是破道館（牆有破口）與院子，西邊林地，北邊石坡，東邊一條溪與橋，南邊野莓叢，東緣有一條山徑通往圖外（之後遠征用）。
3. 主角與兩位同住者（由種子從模板產生）在地圖上走動。外向的人往院子、往人多處；內向的人去溪邊、林邊；直覺型愛去遠處沒去過的地方；感覺型留在熟悉的道館附近；判斷型按固定路線輪流；感知型隨性。
4. 點人物，右側顯示人物卡：類型、四軸、五項天賦、特質，以及「現在做什麼、為什麼」（前三名候選與分數拆解）。
5. 上方時鐘（第幾日、時辰），暫停／1×／2×／4×。

## 規則

- 時間：1 tick＝1 遊戲分鐘，一日 1440 tick。1× 每真實秒 20 tick。
- RNG：mulberry32，狀態存在 `state.rng`，所以同種子同輸入完全重播。
- 地圖：格子 `T`（樹，擋路）、`R`（石，擋路）、`W`（水，擋路）、`#`（牆）、`B`（莓叢，擋路）、`.` 草、`:` 土路、`_` 地板、`=` 橋。
- 尋路：8 方向 A*，不能切角穿過擋路格；目標是擋路物件時走到相鄰可站格。
- 移動：每 tick 朝下一路點前進 `speed = 0.12 × (0.8 + 0.04 × 身法)` 格。
- 人格：四軸 E/N/F/P 各在 −1..1；類型字母取正負號（0 視為 E/N/F/P 以外的那邊：I/S/T/J）。問卷每題推一軸 ±0.5，最後夾到 −1..1。
- 天賦：五項，新角色總和 25、每項 1–10；不合法拒絕。
- 特質：由軸值（|值| ≥ 0.4）與天賦（≥ 8 或 ≤ 2）推出，固定規則，畫面用中文標籤。
- 走動 AI：候選是地圖上的去處（POI），分數 ＝ 基礎 ＋ 個性加權（社交性、安靜、遠近、熟悉、輪替、隨機）＋ 小雜訊；選最高者，走到後停留一段（感知型停短、判斷型停固定）。把前三名與各因子存在 `person.why`。

## 驗收

| 編號 | 條件 | 檢查 |
|---|---|---|
| A1 | 同種子同角色，跑 3 日後狀態雜湊相同；不同種子不同 | test `sim.test.mjs`、soak |
| A2 | A* 繞過障礙、不經過擋路格、不切角；到不了回 null | test `path.test.mjs` |
| A3 | 問卷答案決定類型，例如全選外向／直覺／情感／感知 → ENFP | test `person.test.mjs` |
| A4 | 天賦總和必須 25、每項 1–10，否則拒絕；六個模板都合法 | test `person.test.mjs` |
| A5 | 特質由軸與天賦決定，相同輸入相同輸出 | test `person.test.mjs` |
| A6 | 每 tick 位移 ≤ 速度上限＋誤差；人物永遠站在可站格；沒人卡住超過半日不動 | soak |
| A7 | 個性有差：多種子下，外向者平均離最近他人的距離小於內向者 | soak |
| A8 | 瀏覽器正常流程：答問卷、配點、開始；三人可見且在動；點人物出現人物卡含類型與理由；無 console error | headless |
