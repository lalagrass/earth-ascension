# M20 觀察與平衡 2（二十日長跑）

Loop 22。支柱：全部。PLAN-02：「M11–M19 的主張在二十日內都還成立；最差種子不崩」。

## 目標

到目前為止的量測都是 5 日（soak）或 10 日（report）。這輪把 base 與 exp 跑到二十日，看每個支柱完成的主張在後十日還在不在、有沒有種子在後半段崩掉，並整理一張平衡參數表。不改規則。

## 前置條件（v5、v8）

- `report.mjs` 已有 `--days`；但 M12 的「第 6–10 日」等是寫死的，長跑另寫 `tools/long.mjs`，只跑 base 與 exp，前十日、後十日分開記。
- 樹木與石頭不會長回來（`takeResource` 用完變空地）：地圖上 193 格樹、32 格石。base 十日每個種子砍約 45 份木。
- 十日的參考值（loop 21 report，種子 1–12 base）：每人每日進食 1.94–2.32；有朋友的種子 10/12；成家 4/12（13–24：7/12）。
- 暫停中的 milestone（M11、M12、M14、M16、M18、M19a）不在這輪驗；它們的情境不跑。
- 飢餓的門檻（M10-A5）在擁有人回重定卡之前只量不判。

## 玩家會感受到的主張

（給開發迴圈的）「門派放著跑二十日，前十日看到的東西後十日還在，沒有哪個種子慢慢垮掉」。
