# M25 門派史

Loop 29。支柱 P1。PLAN-03。只動畫面與紀事整理，不動模擬。

## 目標

紀事簿只列最近 12 筆，二十日下來早年的事都沉下去了。擁有人想回頭看「這個門派這些日子過得怎樣」。這輪在紀事簿多一頁「門派史」：

1. **大事**：每種要緊的事第一次發生（第一處完工、第一位留下的人、立派、第一次打退來犯、第一次領悟新招、第一次拜師、第一次成家、第一次拆巢……），再加上每一次頭目來報仇。照時間排。
2. **生平**：每位同門一句話：怎麼上山的、師父、學會的招、家人、跟同門比的習性。
3. **走勢**：每日一列：完工、來犯、打退、領悟、留下的人數，用小條畫。

## 前置條件（v10）

- 不動 `sim.mjs`、`ai.mjs` 與任何常數：5 日雜湊一定不變（`hashes.mjs` 照查）。
- 大事、生平、走勢都只從 `state.events`、`state.people` 讀，`sectHistory(state)` 是純函式。
- 先數過 base 二十日 12 個種子出現的紀事種類：built、visit、raid、repel、leave、skill、rel、join、found、move、master 每個種子都有；stolen、breach、repair、family 11/12。

## 玩家會感受到的主張

「打開門派史，就看得到這個門派從開山到現在的幾件大事，和每個人是什麼樣的人」。

## 驗收

門檻在第一次量之前寫定。

| 編號 | 條件 | 檢查 | 可行性粗估 |
|---|---|---|---|
| A1 | 規則：大事每種只取第一次（頭目報仇每次都取）、照時間排；生平每位同門一句、訪客不寫；走勢每日一列、各欄等於那日紀事數 | test `history.test.mjs` | 純整理 |
| A2 | 主張：48 個種子 base 二十日，每個種子的大事 ≥ 5 種 | test（48 種子） | 前置條件數過 11 種每個種子都有 |
| A3 | 看生平猜個性：48 個種子 base 十日，開局三人；生平裡提到「聊天切磋」多或少的人，照它猜外內向，對的 ≥ 75%；提到的人 ≥ 30% | `diag/history` | 不知道；習性只寫差最多的兩類 |
| A4 | 舊量測：5 日雜湊不變 | `hashes.mjs` | 不動模擬 |
| A5 | 瀏覽器：紀事簿有「門派史」頁，看得到大事、生平、走勢；字框不重疊 | headless `m25-history` | 畫面 |
