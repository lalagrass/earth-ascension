# M17 親密與成家

Loop 20。支柱 P3（人際走到家人）。

## 目標

M5 起關係有四階：陌生、相識、朋友、知己，但到知己就停了，也很少有人走到知己。這輪讓朋友之間的聊天變成「談心」（長得快），知己可以結為道侶或結義（金蘭）；成了家的人會一起吃飯、睡在相鄰的床，紀事記下。

## 前置條件（v5）

- 現況（`tools/diag/bonds.mjs`，base 十日）：種子 1–12 只有 1 個種子有一對到知己（最好一對中位約 37）；種子 13–24 有 3 個。120 對的平均好感中位 6、p90 33（兩組相近）。
- 聊天一次好感 `CHAT_GAIN 4 × 相合 × (1 + 0.3 外向)`，同桌吃飯每次 0.6、一起幹活 0.8。
- 探測（不留）：朋友以上聊天的好感 ×3 時，十日內有一對到知己的種子 1–12 是 4 個、13–24 是 7 個；×2 時 2 個、7 個。
- 現在沒有性別，所以「道侶」或「結義」看兩人的心軟軸（F）：兩人都偏心軟就結為道侶，否則結義為金蘭。
- 會改到 base：雜湊會變。舊指標照現有門檻判（NOISE-01 的重定還在等擁有人）；只在雜訊帶裡翻的，寫出四組裡的位置。

## 玩家會感受到的主張

「朋友常聊就會走成知己；知己會結成一家，之後吃飯睡覺都在一起」。

## 玩家看到什麼

- 朋友之間的聊天頭上寫「談心」。
- 兩人成了知己而且都還沒成家，就結為道侶或結義，泡泡寫「結為道侶」，紀事記「甲與乙結為道侶」。
- 名冊名字後面加一個「家」字，人物卡人際分頁第一行寫「道侶：乙」或「金蘭：乙」。
- 家人在吃飯時更想坐同一桌；睡覺時更想睡在家人旁邊的床。

## 規則與資料（`data.mjs` 的 `FAMILY`；`social.mjs`）

- `FAMILY = { DEEP: 3, EAT: 0.8, BED: 0.6, BED_R: 3 }`。
- 談心：聊天完成時，若兩人已是朋友以上，好感 × `DEEP`。
- 成家：`withStage` 看到某對升到知己，而且兩人都是同門（不是訪客）、都還沒有家人，就成家：`p.kin = o.id`，記 `kind: 'family'` 的紀事。兩人都是 F > 0 叫道侶，否則叫金蘭。
- 吃飯：家人正在同一張桌吃飯或正走去那張桌時，吃飯候選的個性分加 `EAT`。
- 睡覺：家人睡著或正走去的床，距離 `BED_R` 格內的空床，睡覺候選的個性分加 `BED`。
