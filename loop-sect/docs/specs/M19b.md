# M19b 東側山路

Loop 26。支柱 P4。PLAN-03；PLAN-02 的 M19 拆出來的後半。

## 目標

地圖往東加寬半屏：溪的東邊多一片山林，野豬窩與山寨搬到更遠的東邊，遠征要走一段山路。畫面可以左右捲動。

## 前置條件（v5、v9）

- 地圖 64 × 40 格，畫面 1280 × 800（一格 20 px）。`buildMap` 的亂數只在固定範圍（x < 15 的林、石坡、莓叢）用，跟 `MAP_W` 無關；往東加的格子不用亂數，舊的 64 欄就跟以前一樣。
- 巢：野豬窩 (58, 36)、山寨 (58, 6)。`diag/march`：exp 情境走到野豬窩平均 156 tick（種子 1–12，10 次）、159 tick（13–24，15 次）；拆掉 9/12、9/12；撤退多半是精力不支與天黑。
- 訪客從 (63, 30) 進來，侵擾從南邊 x 18–46 來，這兩個都不動。
- 會改到的：exp 情境（巢更遠）。巢的守衛在 base 也在（站在巢邊），所以 base 的雜湊可能也會變；變了就照舊指標判。

## 玩家會感受到的主張

「討伐要走一段山路：出發後要過一陣子才看到隊伍到巢邊，路上精力與天色都是風險」。

## 規則與資料

- `MAP_W` 64 → 80。新的 16 欄（x 64–79）：x ≥ 66 的地方，用格子座標算的固定花紋撒樹（不用亂數）；y 25 的大路、y 30 的東山徑一路通到東邊。
- `NESTS`：野豬窩 (58, 36) → (76, 36)、山寨 (58, 6) → (76, 6)。巢附近空出 3 格。
- 畫面：`#view` 仍是 1280 × 800（64 格寬），鏡頭左右捲動：頂列「◀ 西」「東 ▶」按鈕、鍵盤左右鍵；點名冊時鏡頭移到那個人。點地圖選人照鏡頭位置算。
