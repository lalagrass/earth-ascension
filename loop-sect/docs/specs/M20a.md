# M20a 舊門檻雜訊帶

Loop 19。retro 6 從 M20 提前的一部分。支柱：全部（量測工具）。

## 目標

五個 milestone 暫停，其中三個卡在 M10-A5「最差日飢餓 ≤ 2%」。retro 6 看到這條門檻離雜訊太近：只放一座沒有作用的藥園，herb 情境的最差日就到 3.0%／3.7%；種子 13–24 的 exp 不動任何東西也是 3.3%。這輪不改任何規則，只量出每條舊門檻換種子時會不會翻盤，讓擁有人一次決定要怎麼重定。

## 前置條件（v5）

- soak（5 日，7 情境）與 report（10 日，6 情境）已有 `--from`，可以換種子組。
- 舊門檻都在種子 1–12 上定，種子 13–24 只在 loop 14 之後量過幾條。
- 不改規則：這輪不動 `src/`，雜湊與 report 輸出不變。

## 玩家會感受到的主張

（這輪是給開發迴圈的）「新功能不會因為換了一組種子就被判退步」。

## 做法

- `tools/noise.mjs`：同一份程式，四組種子（1–12、13–24、25–36、37–48）各跑一次 soak 與 report，逐條列出過／不過與數字，判成「穩過」（四組都過）、「雜訊帶」（有過有不過）、「穩不過」（四組都不過）。
- 對照：herb 情境在受傷關著時，除了兩畦沒人用的藥畦，跟 base 一樣。它的飢餓跟 base 差多少，就是「只換一點情境」的擾動大小。

## 不做

改門檻（等擁有人）、恢復暫停的 milestone、二十日長跑（M20 本體）。
