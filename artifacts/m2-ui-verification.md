# M2／M1 Chrome 介面驗收

日期：2026-10-17。以 Chrome 擴充的實際瀏覽器操作本機服務，資料庫均置於 `/tmp`。這輪不部署，也未更改正式存檔。先前 IAB／桌面擷取不可用的紀錄已由本次 Chrome 驗證取代。HTTP 腳本 `python3 artifacts/run_m2_http_demo.py` 仍作獨立端到端檢查。

| 路徑 | 實際操作與比對 |
|---|---|
| M2 建人與推進 | 全新 M2 資料庫，Chrome 創造「M2驗收人物」ID 101，填完 16 題，從第 0 月逐次點到第 12 月；第 0 月無記憶／關係有明確空狀態。 |
| M2 觀察與回放 | 第 12 月觀察頁顯示長期目標「穩定生活」、進度 0/6、定向關係、決策分數／波動、引用記憶與來源。點 `m2:12:1383` 進入第 12 月歷史，找到「完成階段目標」及其原因；另點過第 1 月來源事件。組織與生命歷程頁也在 Chrome 開啟。 |
| 與儲存快照核對 | `/tmp/earth-ascension-m2-chrome-validation.sqlite3` 第 12 月保存快照的玩家目標、進度、關係信任 42／33／3、記憶 `m2:12:1383` 等四筆及決策結果 `m2:12:1382`／`m2:12:1383`，均與頁面顯示一致。 |
| M2 已故人物 | 獨立 fixture 把人物年齡設高後透過**真正 M2 月結算**觸發死亡；Chrome 觀察頁與生命歷程可看到死亡事件來源 `m2:1:0`。測試暴露「已故人物仍顯示目標 active／下次檢查」的誤導標籤，待貢獻者 PR 修正。高齡值只存在測試資料庫。 |
| M2 人格變化 | seed 7 的真實 M2 第 60 月世界，人物 14 的外向已由資料核對較創角 +3 點；目前正式 UI 未呈現差值與變化來源，列入 [#5](https://github.com/lalagrass/earth-ascension/issues/5) 的 PR 審核場景。 |
| M1 六頁與續玩 | 以真實 `initial_world(2026)` 建 M1 暫存 SQLite，Chrome 逐點世界總覽、創造人物、人物觀察、組織、世界編年史、生命歷程，均顯示 M1。從第 0 月點推進至第 12 月，選第 1 月歷史後確認事件切換，返回現況。 |
