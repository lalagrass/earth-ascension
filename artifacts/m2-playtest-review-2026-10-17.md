# M2 0.2.2 階段試玩：單一玩家人物的 1–60 月路徑

這是供貢獻者審查的**合成 QA 樣本**，不是玩家存檔，也不是 M2 驗收。基準為 `dev` commit [`e92cee6b`](https://github.com/lalagrass/earth-ascension/commit/e92cee6b889f49b0ccbddf6881b32bed8637086c)、規則 `0.2.2`、schema 2、seed `2026`。完整的逐月決策、目標評估與事件 ID 在 [`m2-playtest-seed2026.json`](m2-playtest-seed2026.json)；[`run_m2_playtest_review.py`](run_m2_playtest_review.py) 只建立暫存 SQLite，不讀寫任何既有存檔。

## 重現方式與樣本邊界

在上述 commit 的 repo 根目錄執行：

```sh
PYTHONPATH=. python3 artifacts/run_m2_playtest_review.py --out /tmp/m2-playtest-seed2026.json
cmp /tmp/m2-playtest-seed2026.json artifacts/m2-playtest-seed2026.json
```

已獨立比對本次 QA 資料庫的第 0／60 月 canonical hash 與 60 筆行動、月末目標；全數相同。第 60 月 hash 為 `c973d08e6bf239d6c374649332c88c1f3115ce4113d8265c683b785e56db4692`。樣本世界開始時有 100 名 NPC，另投放 1 名 QA 玩家人物（ID 101，虛構代號「測試旅人」）：學園、30 點，根骨／悟性／意志／感知／社交各 6，16 題情境答案皆 3，初始目標「探索靈氣」，八項初始人格／價值分數皆 0.6。無自由文字目標、LLM 或付費服務。

## 瀏覽器實測：入口、創角、推進

在使用者 Mac 上的 **Google Chrome 155** 開啟隔離 QA 的 `127.0.0.1` 服務，確認頁面標題「Earth Ascension · 靈氣紀元」、六個導覽分頁、世界第 0 月與 100 名具名 NPC。透過該 Chrome 頁面的「創造人物」表單填入上述 QA 輸入並按「投放世界」；服務回應 `POST /api/characters` 201，頁面轉到「人物觀察」，顯示 ID 101 的測試旅人和「探索靈氣」。在頁面按「推進一個月」；`POST /api/advance` 回應 200，頁面顯示第 1 月、103 件事件，人物仍在世、當月自行選擇「工作」。這些操作發生在**獨立 QA 資料庫**。另一本空白開局未用來測試或推進。

瀏覽器只直接操作到第 1 月；下方第 2–60 月是另一份相同輸入的**獨立、可重跑 Store 樣本**。沒有把 60 個月稱為瀏覽器點擊驗證，也沒有用成功跑完推論體驗良好。Chrome 的 macOS 螢幕擷取與輔助操作當時遭系統拒絕；已用本機 Chrome 的頁面 DOM、HTTP 回應與資料庫核對操作結果，沒有螢幕截圖。

## 值得請貢獻者審查的現象

1. **轉向可追溯，但玩家端理由不足（[#8](https://github.com/lalagrass/earth-ascension/issues/8)）。** 第 12 月由探索休整轉財富時，記錄只有 `review_month` 與分數；為何此時不能繼續同類探索，需從排除清單推回去。請判斷是否能從 UI 看懂角色的下一步，並提出只顯示現有 trace 的最小改善；不要用新增古武／仙俠階段填補說明。
2. **持續工作還是重複行為（[#4](https://github.com/lalagrass/earth-ascension/issues/4)、[#9](https://github.com/lalagrass/earth-ascension/issues/9)）？** 第 29–41 月連續 **13 月研究**，跨越第 36 月的休整與第 40 月的服務社群目標；財富由第 29 月的 210 降至第 41 月的 66。休整時計畫步驟顯示「維持工作與生計」，但第 37–40 月仍每月研究；第 41 月服務社群也研究。這不一定是規則錯誤：行動評分仍可能有理由持續研究。但應檢查玩家能否理解、資源風險是否合理，以及不同 seed 是否同樣卡在研究迴圈。#9 原議題是**受挫後**短計畫不一致，本樣本沒有證明該 bug 的重現，請勿混稱。
3. **進度與記憶對長期目標的意義（[#4](https://github.com/lalagrass/earth-ascension/issues/4)、[#2](https://github.com/lalagrass/earth-ascension/issues/2)）。** 第 23／35 月是 7/6，直到第 24／36 月檢查才完成，UI 仍用「進度」顯示分數；請判斷是否要把它表達為待檢查的累積，而非已完成。四次轉向都沒有決定性記憶來源，雖然行動在其他月份有引用記憶；請在多 seed 配對下檢查這是個案還是 M2 目標記憶影響偏弱。已合入的 #2 衰減**僅是實驗**，本樣本沒有啟用它。

**最短審查路徑：** 先讀 JSON 的 `months[7]`、`months[11]`、`months[22]`、`months[28:41]`、`goal_reviews`；再執行上面的暫存重跑命令與 `cmp`。若主張是普遍平衡問題，請另附至少數個**開發 seed**與配對對照；不要拿這一位人物宣稱 A3/A4 過關或失敗。請在同一個試玩 review issue 回報「看到的月份／事件 ID → 玩家可見的困惑 → 建議的最小修正或量測」，避免重複拆出既有 #8／#4／#9／#2 的問題。

## 界線

這是**單一 seed、單一中性人格**的合成 QA 人物，不能代表不同人格、不同經歷、100 NPC×60 月統計或保留組驗收。第 60 月仍在世（健康 76、財富 133），只證明可推進，不證明節奏有趣。60 月是 Store／規則重跑，不是手動點擊 60 次。沒有使用或發布任何真實玩家的遊戲存檔，也沒有改正式規則、對外部署或進入 M3。
