## 實驗設計

- **配對：** 四組用相同 seed，所以初始資源、人格、目標與所有外生抽樣（aura、發現抽籤、社交對象、選擇雜訊）的 key 都相同；差異只來自記憶權重造成的行為分歧。
- **替換正確性：** 腳本把 `_intent` 的四處記憶加分改成「乘以權重 w」，0.2.2 起也把 `_goal_review_scores`（休整後的目標重評）讀記憶的同一個 12 個月截斷換成 w，讓候選的「記憶作用期」在兩處一致。截斷組的 w 是 1.0（age ≤ 12）或 0；腳本先斷言截斷組在 30 個 seed 上的最終 canonical hash **逐一等於同一規則版的正式模組**，否則中止。0.2.1 與 0.2.2 都通過，所以替換方式本身不改變行為。
- **權重從 age 1 起算：** 第 m 月觀察到的記憶，最早在第 m+1 月的決策生效（age 1）。

9.1 是讓離散權重和最接近現況 12 的半衰期（9.0 為 11.821，9.2 為 12.102）。

## 0.2.2 讀法

1. **0.2.2 下的結論和 0.2.1 一致：** 整體行動分布差距在 1 個百分點內，研究正回饋沒有被明顯放大，代價仍是近期記憶變弱。
2. **新觀察：** 衰減讓目標重評更常「因記憶轉向」，目標分布本身沒有變差。
3. **雜訊變大：** 0.2.2 的配對差距標準差約 2 pp，判斷要看全期或多 seed 的中位，不看單一 seed 的單一年。

### 0.2.1 讀法

1. **整體行為接近現況。** 兩個候選的行動分布與截斷組差距都在 1 個百分點內，第 5 年研究占比的逐 seed 中位差是 −0.8（8.3）與 −0.1（9.1）個百分點。無記憶消融則差 −6.6，說明記憶確實在起作用，量測有分辨力。
2. **代價是近期記憶變弱。** 衰減把影響從近期挪到遠期：age 6 的記憶讓實際選擇改變的比例從 12.8% 降到 8.2–8.7%，age 12 從 11.3% 降到 4.8–5.3%；換到的是 age 18／24 從 0 變成約 2.6%／1.7%。如果「重大經歷在一年內要明顯影響行為」是產品要求，這兩個候選都會削弱它。一個可能的下一輪候選是「前幾個月全權重、之後才衰減」，但本次**沒有量測**。
3. **研究正回饋沒有被放大。** 引用發現記憶的研究選擇多了 18–22%，但研究占比與發現數沒有上升。兩個候選在 seed 18、19 都偏高，值得在規則 PR 前看清楚原因。
4. **8.3 與 9.1 差異很小。** 9.1 讓權重和回到 12、各年研究占比貼近截斷組，但多出兩個超過參考線的 seed；8.3 總影響少約 9.5%，研究略低。選哪一個不能只靠這 30 個開發 seed 決定，需在 #8 合併後重跑，再封存門檻、看保留組。

## `expiry_or_review_month`

只有 `earth_ascension/m2.py` 寫入它（`_remember`，事件月 + 24）。`earth_ascension/` 下的 Python 與 JS **沒有任何規則或 UI 讀取它**（`grep -rn expiry_or_review_month earth_ascension/`）。現行截斷下記憶在 age 12 後就沒有作用，9.1 候選則到 age 39 才失效，兩者都不是 +24。所以它目前只能當「複查月」，不是失效月；規則 PR 若採衰減，應明確命名或移除，避免 UI／trace 誤讀。是否改欄位留待規則 PR 與 PO 決定，本實驗不改。

## 限制與未驗證

- 只用開發 seed 0–29、60 月；沒有跑保留 seed 30–39，也沒有更長月數。
- 0.2.2 的候選把衰減同時套到行動分數與目標重評；沒有量「只衰減其中一處」的拆分。
- probe 一次只拿掉一筆記憶，不量多筆同類記憶的疊加；也沒有量 A3 驗收指標或 UI 上的可讀性。
- 沒有做相同能力／不同人格、相同人格／不同經歷的 fixture；那屬於規則 PR 的驗收。
- 候選權重在 Python 3.12／3.13／3.14 的浮點一致性沒有進 golden 測試；本報告的數字只在本機 Python 3.13 跑過。
