## 六項有限驗收與成本

1. **可比較／可重製**：同鏡頭、人物站位、工作狀態與尺寸的改前／改後各一張，標新舊來源SHA／坐標；可編輯來源、生成／繪製方法、素材授權與可重製輸出說明齊。局部確有材質差異，不只調色或加紙紋。
2. **圖層與角色保留**：一處人物在物件前、另一處在後的代表情境；原腳底排序、陰影、選取圈、翻面／工具掛點無跳動或重影。角色與地點仍可辨，不需重驗每棵樹／每個動作。
3. **同入口真生活**：自然新局看到兩人沿原路挑水／採藥並交付；只核此次背景接線沒有移動工作點、遮住鼠或名牌／掌法疊圖。LP11／LP12整套行為由接受後證據復用，不再把全清鼠／長恢復重演一遍。
4. **桌面＋390一次操作**：桌面點人、工作點與既有暫停／倍率／平移縮放；390只補局部可讀與點選、掌法／自主控制仍可到達。暫停前後唯讀snapshot顯示tick／位置／精力與產出不因畫面更新變動，無render寫回。開少量實圖，不能以靜態合成稱操作已驗。
5. **畫面成本與回退**：同瀏覽器／viewport／裝置像素比／鏡頭下配對記素材尺寸／下載bytes／紋理數與初屏時間、短段畫面節奏；未有既定FPS門檻則報實值與差異／限制，不自行發明保證或降門檻。明顯退化先修；保留舊資產／上一已接受commit與啟動方式，不新增存檔相容問題或大benchmark框架。
6. **範圍與必要檢查**：保護檔diff為零，必要語法、`git diff --check`、根`python3 -m unittest discover -s tests -v`、`node --check earth_ascension/static/m2.js`、SG快驗`node --test sect-chronicle/test/*.test.js`及適用CI保留。沒有模型變更時復用已核對的LP12等模型／時間／政策證據，不加新世界seed、長RT矩陣、全命令×人物×時相、存讀／RNG測試或鏡像測試。

完整log留檔，只回命令／真exit摘要、差異、失敗與少量圖；GPU／CDP／素材工具限制照實。圖稿階段只驗圖、來源、連結與可讀性，動態／操作僅在接線後補受影響部分。未跑或失敗不能寫通過；與本片無關的#215舊locator不拿來追綠或加整套驗收前置。
