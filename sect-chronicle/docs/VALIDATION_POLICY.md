# 遊戲局部驗證政策：必要、直接、可復用

依[D30](DECISIONS_AND_SOURCES.md#d30桌面生活優先平台末位與精簡驗證2026-10-23)，由擁有人要求精簡遊戲開發的冗餘驗證。適用生活版切片、畫稿與PO review；根[貢獻契約](../../CONTRIBUTING.md)／[測試政策](../../docs/testing-policy.md)的必要CI、Earth高風險與正式發布驗收保留。本文件不修改workflow、分支保護、根測試或既有驗收結論。

## 每類改動只驗直接風險

| 改動 | 本地最小證據 | 不逐包重做 |
|---|---|---|
| 純Markdown／排序／prompt | 改動段落的連結、批准／前置／白名單一致、diff空白；必要CI照跑 | 不另跑遊戲行為／瀏覽器／root53或世界seed；未變程式證據復用 |
| 靜態畫稿／分鏡 | 真正看過完整桌面圖、尺寸／來源／示意標註、與接受場景及要求相符 | 不為每張圖寫存在性測試，不要求手機稿、播放器或遊戲矩陣 |
| 設計專用互動頁 | 變更JS語法＋一段桌面點選流程；有播放器才核暫停／到期／重播 | 不將未連模型的熱區當世界驗收，不測不存在的遊戲行為 |
| 純UI／鏡頭／局部動畫 | 變更JS語法／diff；一段桌面真操作覆蓋所改控制、資料／拒絕理由、暫停與選人；只補會重現具體缺陷的必要回歸 | 模型／路線／RNG／存讀未變就復用原證據，不重跑全工作×人物×等級×政策、手機或世界seed |
| 模型／結算／RNG／存讀 | 受影響單測／原失敗反例、必要相容／回放證據；按原風險與既定樣本升級 | 不事後縮減原定正式樣本、不改閾值追綠；高風險不套純UI豁免 |

純UI的短流程通常可同時回答：玩家看到什麼→操作原指令→真結果／等待原因→暫停純UI無額外命令→返回觀察。只驗這次變更涉及的步驟；不用每輪把所有舊功能重演，也不硬造2～5分鐘等待或固定截圖數量。

## 刪除重複與自證要求

- 不新增只斷言初始常數、檔案／截圖存在、測試自建布林切換或複製實作公式的測試作為驗收。已有這類測試記為低價值候選，原作者有空可局部移除／合併；不另開大拆前置，也不以「測試數增加」衡量完成。
- 141／365等總數是執行資訊，不是每個UI包必須本地重跑的目標；Node模型測試不稱DOM／按鈕／鏡頭真驗收。反例無法以合理成本自動化時，一次可重現桌面流程與少量圖足夠，不強制新runner。
- 同一head／實際合併結果的CI已覆蓋未變SG／root時，可引用當前run與結果；作者、遊戲PO、Earth不各自再本地重跑相同套件。必要CI本身照原設定執行，SG dev快驗／root jobs不刪；只有差異／失敗／風險理由才擴本地驗證。
- 審查者仍讀受影響diff、真作者／範圍、實際head與合併結果；五check狀態一次核對，明確CI／tree風險才查詳細checkout log，不逐輪重複下載整份綠燈log。合併後CI成功與接受結果仍由queue確認，不要求每位PO重新取同份全log。
- 交付只留命令／exit／摘要、失敗重現、必要少量完整圖／URL與已知限制。未變證據附來源；不製造大型輸出、冗長「全綠」報告或為湊時間新增任務。

## 手機與平台適配延後

手機390／平板響應式、觸控專用、全裝置／瀏覽器組合與像素矩陣移至[FUTURE_BACKLOG末位BL-P01](FUTURE_BACKLOG.md#bl-p01平台適配與全面驗證末位)。當前不作開工、完成或合dev門檻；已有適配保留，不為了延後而刪程式。桌面普通視窗的可讀／可操作、錯誤資料與暫停等實質問題仍要修。手機數字若只是設計假設就標示意／未驗，不能繼續冒充實測保證。

## 什麼時候擴驗

只因新差異、重現失敗、邊界／相容風險或實際支持平台決策擴驗，記一句原因。#215只做有限健康回訪，不逐包全架構audit；#113的跨產品CI優化另走根契約單一作者，不混進生活切片。新功能批准、非作者review、Earth唯一dev queue與main發布權限不變。
