# 仙俠人物屬性候選：先補作用，再選欄位

2026-10-26，擁有人詢問「武俠主要就根骨、悟性、福緣嗎？參考仙俠模板有什麼可加」。這是追加研究／建議，不是批准新增屬性／功法／成長／需求。主[#340](https://github.com/lalagrass/earth-ascension/issues/340)，文件PR #341；沿[公版人物卡](CHARACTER_CARD_PUBLIC_PROPOSAL.md)既有分類，MBTI候選另見[人格v0.1](CHARACTER_MBTI_CANDIDATES.md)。

## 1. 武俠與仙俠都沒有唯一標準三項

根骨、悟性、福緣只是本案目前稟賦候選的主要三項，不是全部人物屬性，更不是所有武俠遊戲通用規格。力量／身法／耐力、所學、內力／修為、狀態、心性與關係本來就分層；「資質」一詞也可能是根骨／悟性的總稱，不能見一個名字就多建一個可重複加成的數字。

仙俠的新增價值在於解釋**怎麼感到靈氣、親近哪種力量、能感知或控制多遠、為何選這條修行路**，並把靈氣復甦同日常生活連起來。不必一開始就加滿境界、法力、心魔、壽元等條。

## 3. 可以加什麼：候選與歸屬

下表用途均為P本案設計建議，非上述遊戲共同規則，亦非本作已實裝效果。優先序是研究順序，不是開工順序。

| 候選 | 放哪一層 | 能帶來的可見差異候選 | 取捨／研究優先序 |
|---|---|---|---|
| **氣感／靈氣感應** | 稟賦可記初始敏感度；感氣／引氣／收放是可練技術 | 先察覺藥草、山泉或某段環境的變化，師父示範後逐漸學會感應 | **優先研究**；感到不等吸得快／能安全用，不能同時加血量、修行、攻擊 |
| **神識／感知能力** | 可成長能力；感知範圍與精細操控如真有不同作用再細分 | 巡山察覺蹤跡、辨藥細節，後期操控法器；靈氣感應與外界觀察有邊界 | **優先研究**，與既有感知／武感／定力查重；不給人物全知地圖／隱藏敵人資訊 |
| **靈根／五行親和** | 稟賦或親和輪廓／路線標籤，依本作選定規則 | 同等悟性可走不同功法、藥園／煉器方向；風格與練習環境有所不同 | **優先做紙上研究**；先不強制五條分數或單靈根絕對優於多靈根，不把水親和變喝水需求 |
| **特殊體質** | 有來源的traits／身體狀況 | 耐寒、經脈適應、特定功法承載差異 | 優先用少量特性，**不另建通用「體質值」**；天生、後天塑體、傷病分開 |
| **經脈／內息承載** | 身體狀況＋功法／練習成果 | 理解已足卻暫不能全力施展，經正確鍛鍊再改善 | 有武學安全／內息玩法時再做；與根骨、力量、控制查重，不先建全身經絡網 |
| **心境** | 當下或較長期狀態，需與心情／疲累分辨 | 環境、休息、關係與經歷讓修行時感受不同 | 有可見生活因果再選；不新增一條頻繁中斷工作的生存需求、不視同MBTI或定力 |
| **道心／修行志向** | 價值、目標、承諾與可追經歷 | 同樣有天賦，一人護家、一人求知、一人求長生，投入不同生活 | 先用敘事／志向表達；不等善惡／服從／通用突破加成，也不因一次問答永久鎖路 |
| **靈元／真氣／靈力** | 當前資源current/max；功力上限與回復由修行／核心決定 | 招式有真消耗與回復，能看懂連續施展與力竭返院 | 等消耗玩法明確後再選一套主要語義，不與修為、精力混同或同義三條並行 |
| **境界／修為／道行** | 修行進度、所學或有定義的經歷成果 | 階段成長與新能力；不能只換更大的戰力數字 | 先核既有境界與修為，不再造重複進度；本次不訂下一境或突破處置 |
| **壽元／年齡** | 身份時間＋生命歷程／上限資訊 | 日後世代、長生、師徒傳承有意義 | 長期世界／時間尺度成立後評；不為模板加死亡倒數、保存升版或打斷生活試玩 |
| **魅力／親和** | 外觀氣質、社交技巧、性情／關係分別核 | 與人相處的方式不同，不同對象反應不同 | 不是新增一個萬用社交值；外向／漂亮不保證被喜歡，也不強迫高魅力全勝 |
| **氣運／因果／功德** | 若選用，屬事件／敘事紀錄或特殊世界規則 | 做過什麼影響誰願幫忙，或何種事件可遇 | 後排；先和福緣／聲望／關係查重，不把道德兌換傷害、不保證好人必勝 |

氣感敏感度與後天引氣技術若最後沒有各自獨立用途，就合成一項技藝即可；神識若只是感知的仙俠名稱，也沿原值加稱呼，不複製加成。候選需要經典／原創角色與具體流程才能決定，不從MBTI、八卦或福緣反推靈根。

## 4. 對我們生活方向的最小建議

暫保留根骨／悟性／福緣原語義；只將**氣感、神識、靈根／五行親和**提升為優先紙上候選。可拿同一段採藥／巡山比較：一人辨藥熟練，一人先察覺靈氣異常，一人善察蹤跡；三者各有用途，而不是同一人堆高所有收益。這是未來流程假設，不改現有採集概率、路線或自主AI。

人物卡仍生活總覽＋武學成長；以靈氣復甦／師父指導／真發現逐步提供線索，不開局畫滿所有未知軸。沒決定／沒實作就缺項；修煉期條目可在未來有真來源時出現，普通村民不必填全表。

本次不為研究增三方作業：各agent若已有相關欄位，在原一張差異短表順帶指出是同義／異義／缺項即可，不做新仙俠矩陣或prototype。另選可見工程前需擁有人確認第一候選與實際效果；沒有本次批准的效果、數值／硬前提、神識探圖、五行環境與新需求，一律先不實作。D45撤口渴、D53親情／鼓勵無buff、單一入口、保存升版／手機末位照舊。
