## 建議：生活基地＋有邊界的外圍掃蕩

可行，而且能同時呈現長路奔波、腳力差、掌法節奏與角色知道何時收手。塔防適合提供「守護對象、來路、隘口、威脅預警」；外出用巡防與沿路迎敵，先保留可暫停觀察的生活節奏，不把所有野獸改成固定倒數刷新的攻城波。

一趟的可見流程是：**院內準備→沿柵欄出口上山→感知／辨識→接近交手或繞避→逐隻處理／有限追擊→提前返院→恢復與簡短戰報**。野獸也有目的、精力／威脅及離開條件；不要求站著等死或一定被殺。

## BL-D07：一次外圍掃蕩與實戰紀錄

沿BL-D03／Q01／Q02／D05／D06整成**一個玩家目標**，不按鼠種、計數卡或返程按鈕拆issue。D03保留完整巡防／安全控制研究，D06保留巢穴；D07聚焦「這個人這次能走多遠、處理哪些對手、為何回來」。

| 問題 | 建議與取捨（未定正式數值） |
|---|---|
| 路線與地形 | 從既有騷擾方向接一條有限山徑，有容易記住的路標、可視隘口／掩蔽物與返院方向；延伸新支路，不暗改目前挑水／採藥長路及端點。遠方可有不同棲地、混合獸種；不是越遠每隻都按角色等級變強 |
| 野獸為何在那裡 | 先用少量有身份、位置／棲地與活動理由的個體；覓食、守巢、受驚、恢復後再出沒可研究。示意配置須標fixture；完整繁殖不是首片前置。返回、讀檔、跨過柵欄不能把已遇個體重生／複製、清除威脅或重新發戰果 |
| 不同對手的用途 | 最小候選用鼠類與野豬兩種可辨對象：弱鼠沿既有掌法／真接觸，野豬沿既有精力／威脅驅離或因風險繞避。小型警覺鼠讓人看追不追得上，野豬讓人看是否值得交手；新攻擊／人傷／新血量另定，不能默認同一掌全部擊殺。侵略鼠、成群圍攻、棲地繁殖後擴 |
| 何時出手 | 只對合理已知、可到達且在本次允許範圍的目標判斷；真走近→出手→收勢→再選目標，沿既有單tick移動預算。未看見的精確敵數／戰力不進角色大腦；未知痕跡可讓謹慎者停止深入，情報不是全知戰力雷達 |
| 何時返回 | 每次深入／交手前，比較當前可用精力、下一步成本、**沿可走路線的回程估算＋遭遇餘裕**；缺餘裕就返程，不等精力歸零。途中威脅變大、目標逃遠、路被堵或玩家召回亦可收手。估算不是保證：退路改變時重評，無路明示受阻／求援候選，不瞬移回家或永不失敗 |
| 如何避免反覆折返 | 已決定返程便以回家為本次目標，不因剛恢復少量精力／看到弱鼠又深入；必要近身自保不變成追擊。恢復後若要再出發須有明確持續巡防政策；玩家明確叫停不自動重啟，也不搶回新工作 |
| 玩家怎麼管 | 首片以「掃蕩這一段／召回」和少量可見限制為主，範圍／追不追可在正式包選定；守院、一次外出與持續巡防不混用。個性先影響已知風險偏好，返程底線不被熱心覆蓋；不要求先做完整人格、所有角色指揮或新Utility AI框架 |
| 掃蕩有什麼價值 | 一段時間內減少已處理路段騷擾／取得可見情報可成未來收益，需另定有效範圍與恢復原因。清過一遍不宣稱永久安全，驅離不等根除；人在山外時不能同時守院／工作。沿現有LP06可忽略、非功能損痕基線，不能藉此偷加家園倒數崩潰或真損失 |

## 戰報：戰果與成長分開

平時只顯示當前路段、動作／對手、精力與返程理由；返回後給一張短報告，可點開種類明細，不常駐十幾條數值。以下為**欄位／文案示意，沒有假造已實測成績或正式單位**：

| 欄位 | 意義與防誤讀 |
|---|---|
| 最遠抵達 | 沿固定院門錨點／路線的最遠位置或路標；若尚未訂世界尺度，用路段／世界單位，不假稱公尺。往返與追逐繞路不累加成「最遠距離」 |
| 已清理路段 | 只有完成觀察／處理條件的路段才記；跑過一段、最遠抵達或只見過一隻，不等於整段已安全。清理判準、未觀測支路／剩餘威脅另標，不顯示全知百分比 |
| 遭遇與結果 | 依真實個體ID，分鼠／豬等**種類**及擊倒、驅離、逃脫、繞避；同一豬重遇不算兩隻，擊中數不是擊倒數，down不自動寫死亡。每趟最終結果互斥，重遇次數可另列，後來打倒不能又把同個體留在逃脫總數裡 |
| 時間與代價 | 分旅行／搜尋／交手／返回的遊戲時間、精力消耗／恢復與離家時間；後續真傷勢／損耗有批准才加。播放倍率與真實等待時間另識別，不能當作腳力成績 |
| 返回原因 | 例如返程精力不足以再打一場、發現未明威脅、目標逃出範圍、已完成路段或玩家召回；「回家」有可見過程，安全到院／受阻／未完成分開 |

「這次走更遠／清更多」是現場表現，不直接等於武學成長。野獸分布、逃跑、負重、補給與派遣政策不同會改成績；目前初學／熟練是fixture，不稱自動練成。

要確認角色變強，另用同路線／同配置或seed、同規則版本、裝備／負重／補給、起始狀態與策略做可比較記錄，僅改要比較的身體素質或招式熟練，顯示兩者差異；不要求每次日常出遊都跑配對實驗。可看同一段處理所需精力／時間、面對同種目標的處理結果與返程餘裕；總路程還包括搜索與追逐，不能全歸功於輕功，也不急著做單一總戰力排名。

**生活世界與能力驗證分開**：真世界沿用個體狀態，不能為戰報每趟刷新一波。若日後需要可重複演武／比較fixture，須明示與日常世界隔離、無物資／XP複製；不復活世界中的同一群野獸。有效練習與戰鬥是否增熟練沿[武學候選A](MARTIAL_ARTS_RESEARCH.md#武學候選a一式掌法的學會練習與熟練)另定，擊倒數不自動發XP，弱鼠不是無限成長燃料。

## 後續取捨與最小可見出口

| 方案 | 評估與回訪條件 |
|---|---|
| **推薦：一條有限路線、兩類對手、自主進退＋返院戰報整包** | 中至大；可沿現有掌法／野豬／真移動做有限差異，不必先有真熟練、輕功、完整巢穴或新HP。若先完成武學候選A，長期練功對照更有意義；兩者不是強制串行前置。第一版後與生活候選擇一批准，不現在插隊 |
| 再擴：多段巡防、棲地線索與暫時安全控制 | 接#104／219，實際玩過一趟再看是否需要支路、發現巢穴／清除失敗、侵略／警覺、恢復與再來的合理原因；不要每個路段另派作者 |
| 遠期：建塔／陷阱、多路獸潮、完整鼠群繁殖遷徙 | 會同時引入建造、材料、碰撞改路、多人防守、真損失與族群狀態，成本大；先確認守護目標與損失模式，不能當首條掃蕩路的共同前置 |
| 可選獨立玩法：無盡掃蕩／試煉榜 | 易展示極限但會改成追分與刷怪循環。若日常巡山不足以滿足觀賞性再評，明示與世界生態／獎勵隔離，不暗把生活入口改為生存競速 |

候選後續正式包只需四組驗收方向：①沿真路遭遇兩類對手、接觸／驅離／逃脫可辨，長通勤與身體速度差保留；②預留返程與未知威脅／失去目標能收手，召回／停工有效且不反覆接戰；③最遠抵達、已清路段及個體種類／結果記錄真實，不重遇重算／重生刷取；④同條件對照能解釋差異，日常返回後生活／必要恢復成立。這是候選驗證問題，不是本輪新增測試或第一版DoD。

實裝前僅需在所選整包定案：路線邊界／出發與返程成本、已知威脅與中斷／失敗處置、各獸可用動作及損失模式、成果是否影響區域壓力／熟練、持久個體／戰報與存檔相容。不要現在預建schema／通用戰鬥引擎或把所有遠期生態先凍結。沿現有model／palm／routes／render責任，只有本包出現實際重複成本才局部整理，#215不是全面重構gate。

交付沿一位主筆完整開發、一主PR集中review與Earth唯一queue；改動若選中才做一段桌面真流程、直接風險反例，持久狀態有變才補代表存讀／版本證據。復用未變模型／CI，不全敵種×角色×倍率×平台矩陣、不為紀錄欄位寫鏡像測試。純研究只查來源、連結／錨點與diff，本輪不開遊戲瀏覽器／服務、不改單一8800。
