## B1／H2-1：木料工作，真走路與一次有效成長

- 同一1600×1350權威世界加一個林緣枯木作業點與必要短支路／站位；保持原水路、採藥路、巡山geo與院內既有端點，不為新圖縮長路、改移速或以瞬移／分路投影代替移動。木料有合理來源，不實作逐樹砍倒、有限森林再生或完整生態。
- **木料初始0、容量12；到位有效砍柴8遊戲秒產木1，作業耗1精力／遊戲秒。** 行走／負重成本沿既有同類搬運契約，不另調舊工作或以木數倍增速度懲罰。8秒在模型tick推進，暫停零進度，播放倍率不改每遊戲秒規則。
- 一個完成作業單位才得一份在途木，真搬回院倉才入庫；既有腳力成長只在有效交付結算一次，不新增力量／工藝屬性條或因取消／空揮／重送刷成長。未完成砍柴不給木，已耗精力不退。
- 原人工持續工作／當趟先交付／必要自理／改派停工語義沿用。庫存＋在途容量預留不可超12；滿庫不新增出發，已攜貨合法交付不丟料。畫面呈庫存、可用／已預約、在途與庫滿原因，不再造一種暗扣物資維持忙碌的方針。

## B2／H2-2：單一固定寢舍修繕案

HOME01側屋預留處使用同一基座／門口，破損→施工→可用；不搬既有功能點或重畫整張成熟地圖。只一間固定屋、兩張固定床位，沒有自由擺建／拆屋／擴房／施工優先佇列。

**全案需木6、有效施工18遊戲秒，施工耗1精力／遊戲秒；一個施工工作位。** 玩家選一人修屋，另一人照常生活；本包不加自主建造政策。可讀缺料／工位忙碌原因，不在背後反覆搶位／重試。

材料與工時分開：

1. 同tick重核可用木及唯一工位，原子預約所缺木料，兩人不雙花最後6份。院倉→在途→工地分清，只有一份真正材料；搬一捆木料的真去回程和攜帶姿勢可見，不以UI遠端扣木換完工圖。
2. 未領料取消即全釋放；已領在途則沿合法返程歸還再全釋放，不丟貨、瞬移歸還或讓其他人同時使用該捆。交工地後材料留工地，不自動退款／二次扣料；後續接手只補缺額，已備足不重新領6份。
3. 人到施工站位、有效工作才累計工時；中斷保留本局已交料及有效工時，未做部分不算。低精力按原自理／當趟交付規則接續，較新改派或停工優先，不被舊施工旗標搶回。
4. 全料到位且有效工時達18秒才完成一次、開放兩床；重送修屋／同tick完成不重複扣料或生成房屋／床。工地已完只顯已完成，不繼續刷施工成長；本包無新工藝經驗。

## B3／H2-3：床位認領、自主歸處與玩家優先

| 契約 | 正式行為 |
|---|---|
| 身份 | 一間穩定房ID＋兩個穩定床ID；床主、當前使用者、短期預約者分開，各床最多一人。不存在第三AI／招新或家庭關係系統 |
| 自主認床 | 屋完工後，人物第一次需要歇息時優先自己的合法床，否則按穩定順序認領未有主／未占用的空床；不按動畫幀率／畫面遍歷搶床，不偷他人床 |
| 玩家操作 | 可查看床牌，在床閒置且無使用／預約時指派／解除；不能直接把正在躺的人或在途有效預約床移除。改派已擁一床者需原子解除舊歸屬，不能一人多床或同床多主。選屋／選人／開床牌不推tick／派工作令 |
| 恢復 | **沿原+5精力／秒、30啟動自理／80續工、上限100**；真到床位才躺下恢復，走路不遠端補精力，不疊石凳／茶恢復。無獨立睡眠／舒適需求、日夜排程、buff或更強恢復倍率 |
| 續工與停工 | 低精力自理後只續仍有效目標；明確停工仍可自理但不續工。有效新指令沿原交付／合法返程生效，舊床／施工／茶返程不能覆蓋新意圖。不能每幀換床或床一認領就搶走原工作 |
| 備案 | 屋未完、無可用床或不可達時，沿原石凳恢復／明示原因，不新增缺床懲罰或無限等待。使用取消／改令按階段釋放短期預約，正常離床保留床主 |

床側入口、走道及人物腳底可達，兩人不穿牆／重疊同床。可用同畫面局部屋內／切屋頂呈現，但不能烘固定人物到背景或另開第二遊戲入口。
