# LP-17：道館場景與雙人美術整合

追蹤 [#274](https://github.com/lalagrass/earth-ascension/issues/274)；[Gemini兩小時提示詞](LP17_GEMINI_PROMPT.md)。目標是同一生活入口的主要場景與活動小人都更接近 [Grok D32](../experiments/water-carry/design/art184-scene-trio/README.md)，保留長通勤、真速度差與現有生活。依 [D31整包交付](PARALLEL_HANDOFF.md#d31單一主筆完整工作包與集中審查)，Gemini一位主筆完成素材、接線與必要文件，一個工程PR集中review，不逐張簽核／分成場景、人物、烘焙三次交接。

## 評估：這批一起做什麼

LP16已改善採藥細節，但大面積道館／環境仍偏簡單色塊，人物也沿舊輪廓。再只加小道具，整體改變有限；直接換整張Grok圖則會帶入固定三人、新地勢與錯誤可走區。**本包採同幾何的場景重繪＋兩位活動人物外觀**：擴大視覺變化，保持現有玩法與動作資料。

| 批次項目 | 本包要做 | 取捨／不一起做 |
|---|---|---|
| 道館與院落主體 | 原位置的灰瓦、木柱窗格、石基／石階／院坪，降低舊紅白塊面感，採Grok暖灰木竹與山居生活細節 | 保留建築占地／出入口／水缸、藥架、座位；不搬成三層台地，不新增可進房間或建築功能 |
| 長路環境連續 | 院落→竹林／坡路→溪橋／泉眼，改善植被組團、石木與水岸材質、前中後景；與LP16藥圃／竹架協調 | 路仍長，不新增捷徑、障礙／巡山通道；保留1700.9水路、515.2藥路、世界1600×1350與橋遮擋幾何 |
| 兩位真正活動的人物 | 主角圓潤少年、藍衣紅結、努力但初學；熟手少年較瘦長、橄欖褐村衣與整潔髮型。改善頭髮／臉型、衣褶明暗、腰帶與鞋，實際走路／工作時都用新造型 | 沿原角色id與UI稱呼、身體尺度／腳底與原姿勢。不是只做立繪／頭像；不把Grok人物裁下當靜態小人，不改數值／成長體態，不新增第三人AI |
| 動作與工具視覺一致 | 新外觀套用兩人現有動作，衣袖／背部、桶簍與掌法借用手臂色彩一致，沿LP16採摘→裝簍→背回→交藥 | 不新增動作、骨架、姿勢狀態或步頻；女孩表情／完整NPC、全員角色與全朝向動畫留後續 |

Grok原圖的細密筆觸不是兩小時可保證逐像素重現的標準；本包要求可辨的屋舍結構、植被層次、兩人輪廓與服裝改善。不能只套紙紋、全畫面調色或換HUD就宣稱達標。一般材質／構圖小選擇由同主筆決定，先在本地看完整構圖再整包接線，不要求先交另一份設計PR。

## 技術採用：復用現有工具，隔離新素材

1. 先盤點現有 `spikes/shared/scene.json`、背景／props、`template/actions.json`、`template/tools/bake.js`與兩人sheet。背景已包含道館／舊泉池／地面，props另排序；替換時不能新舊雙屋頂、雙樹或畫死人物。可重繪同坐標背景／局部替換物件，圖層與原尺寸／錨點要明列，不以新增建築遮住原路。
2. 新可編輯SVG／程序繪圖來源、烘焙圖與manifest放 `demo/assets/lp17/**`；原圖稿、歷史spikes／template輸出只讀。Grok全景與三人稿只作風格／造型參考，不直接鋪成導航或不動的人物。優先既有SVG／Pixi與本機已可用匯出工具，不採購／加依賴或要求新圖像服務。
3. 沿既有POSE、動作名／幀數／stride、fallback／omit與動畫選擇；本包只換畫法。可讓現有bake工具接受可選新painter／輸出目錄，預設歷史行為保留；不要複製一整套動畫引擎。新兩人sheet落在lp17子目錄，runtime改讀新來源，沒有舊新版選擇按鈕。
4. 現有hero 30幀／cousin 27幀，共用幀框190×214像素、腳底anchor(90,184)，各自原hitbox與桶掛點契約保留；不靠把sprite整體拉高或放大來代替造型。新畫法在原框內適配，不截頭／桶繩，不丟任何原動作。掌法疊手肩點與新衣袖對齊，採藥簍仍沿LP16原腳底掛點。必要的工具擴充須維持同一份姿勢來源與輸出真相。
5. 新靜態景物預建／快取，沿原腳底y排序；不在每幀烘圖、增加第二個時鐘或借畫面座標改世界。UI、路線、模型、精力／成長／帳目不隨換裝改變。
