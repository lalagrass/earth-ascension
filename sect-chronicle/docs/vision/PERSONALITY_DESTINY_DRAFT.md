# 人格、命譜與卦象：長期系統草案

狀態：**保存與評估／待討論／未批准實作**。整理：Codex（遊戲 PO），2026-10-20。[完整原稿](sources/2026-10-20-personality-destiny-original.md)／[願景](SHANJIANDAO_DRAFT.md)／[Proposal #152](https://github.com/lalagrass/earth-ascension/issues/152)。共用人格核心／分類研究仍以 Earth PO 主責 [#106](https://github.com/lalagrass/earth-ascension/issues/106) 為主單；本稿提供遊戲使用情境，不另造共用核心。

## 原意與推薦方向

希望主角不是白板：玩家可直接設定或回答少量問題，得到容易談論的現代人格分析、古風心性稱號、命譜與判詞；無人介入時看見角色差異，外出、修行與奇遇也有天時意象。這可以補強人物記憶點，但「玩家一定有代入感」「每次抽卦會更好玩」仍是體驗假說。

PO 建議先把三件事分開：**人格偏好解釋角色選擇；命譜描述身世與經歷；卦象提供情境意象或有限資訊。** 命格被動、人格驅動行為、占卜改變事件因果是更大的玩法選擇，各自評估，不以一套玄學 RNG 包辦。

| 層次 | 原稿構想 | PO 建議與取捨 |
|---|---|---|
| 人格核心與輸入 | MBTI／短問答決定現代人格，自主 Utility AI 據此行動 | 先由 #106 比較既有核心／分類投影；玩家可校正設定，不把少量自創問答稱為官方量表或已驗證測量 |
| 古風心性呈現 | 玄同澄照、仁心、抱樸守拙、狂狷任誕 | 可作原創稱號候選，映射需解釋且容許多樣。原稿僅舉八種型，未覆蓋十六型；分組名稱不當作官方完整分類 |
| 自主偏好 | 探索、研究、幫人、維護等傾向與危機反應 | 未來只在合法、有資源且需求允許的行動中影響偏好；飢疲／安全／明確玩家指令與當前承諾先處理。相同人格也能有不同價值、能力與選擇 |
| 命譜與判詞 | 八字、五行、神煞／星宿、詩句、人生氣質 | 出生設定、當前人格、已發生經歷與象徵意象分開。自創混合體系明標遊戲設定，不聲稱各術數天然等價；真曆法排盤與生成虛構命譜是不同成本 |
| 命格天賦 | 瀕死悟性翻倍、貴人救援、效率加成／材料減半 | 保存為候選；這會改經濟、戰鬥與救援規則。先比較敘事命譜與獨立可選天賦，避免人格直接決定強弱，或為符合判詞強迫成功 |
| 卦象與歷練 | 本卦、動爻、變卦影響收益／奇遇；出發前擇路 | 優先比較純敘事與有資訊的占斷。改收益、生成災禍／奇遇是第三條獨立規則路線，不能偷偷混入呈現層 |

「INTP 必不近戰」「某型必冒險嗜血」等絕對行為不作規格。官方 MBTI 說明區分偏好與能力／品格，並不以類型規定行為；本稿採此限制，不據官方宣傳推論遊戲映射已具科學效度。[Myers & Briggs Foundation 概覽](https://www.myersbriggs.org/my-mbti-personality-type/myers-briggs-overview/)

## 占卜到底做什麼：三條候選路線

| 路線 | 玩家得到什麼 | 主要代價／限制 |
|---|---|---|
| A：結算後的意象敘事 | 既有事件發生後，顯示相符的卦意與原創批註；不改世界或抽世界 RNG | 整合最小，但不提供出發前的策略資訊；必須說清這是對已發生結果的詮釋 |
| B：出發前的有限占斷 | 讀取角色有權知道或正式獲取的局部資訊，顯示時效、可信度與範圍；玩家決定是否採納 | 需先定角色的資訊來源與占斷能力，不保證北方必有靈鶴、逆卦必遇三狼；真正超常預知需另批規則，不能偷看未來 RNG |
| C：卦象本身參與世界事件 | 某次正式儀式產生卦象，權威規則按條件決定事件／收益 | 是命運玩法，會改分布、成本、存讀與 RNG；需定重複起卦、事件資格與資源來源，不是 UI 包裝 |

PO 優先推薦先做 A 的紙上樣例，再研究 B 是否帶來有意義的選擇；C 留後續。若選 B，占斷可以錯、過時或資訊不全，但原因需可理解；不以隱藏懲罰強迫玩家照卦行事。若選 C，就坦白說是儀式改變局勢，不同時宣稱只在預測獨立未來。

占卜不應成為每次挑水／採集都必點的稅。候選為出發前可選儀式、每日／階段性回顧，或長任務結算後一條可展開批註；實際頻率與成本未定，保留玩家不占卜仍能生活的路線。原稿十秒、五成加成、三成獨修收益、必遇救援等都未凍結。

## 判詞應如何有神秘感又保留玩家空間

候選命譜分「初命」與「行跡」：初命呈現創角設定與象徵；行跡依已發生選擇形成回顧。判詞可含模糊的可能性，不把尚未發生的突破、救援、背叛或結局寫成事實。若未來有真正預言玩法，需明示可改變的條件與權威來源。

紙上示意：同一位偏獨立、重研究、曾兩次援村的角色，可顯示心性「靜思而不絕人情」，原創判詞「松窗問理燈猶在，山路逢人亦解囊」。它描述已有設定／行為，不增加效率、不保證遇難獲救。未來是否讓選擇改變人格、只改行跡或兩者皆變，留 #106／#105 研究，不先做型別漂移。

題庫、類型文案、命理資料、現代譯注、套件程式各查來源與授權；先用原創問答／文案及可核對古籍片段，不把名稱流行或程式開源當成整包內容可用。這不是已進行量表授權／法律審查；正式採用時沿 #106 調查。

## 原稿需校正的卦象與程式例子

以下是本輪文件核對與位元推導，不是新增正式演算法。採明示慣例：**bit 0 為初爻、bit 5 為上爻，陽 1／陰 0，字串由左至右寫上爻到初爻**；卦序編號不是二進位整數的值。

| 原稿例子 | 核對／推導與處理 |
|---|---|
| 水火既濟，上六動變未濟 | 既濟 `010101` 只翻上爻得到 `110101`，為風火家人。未濟是火水未濟 `101010`，與既濟六爻全反，不能說單一上六動得到；原稿「水火未濟」名稱也須改。依[既濟](https://zh.wikisource.org/zh-hant/周易/既濟)、[家人](https://zh.wikisource.org/zh-hant/周易/家人)、[未濟](https://zh.wikisource.org/zh-hant/周易/未濟)各原文的上下卦推導 |
| 風水渙，九二動變風澤中孚 | 渙 `110010` 翻 bit 1 得 `110000`，為風地觀；不是中孚。渙九二爻辭應對該爻，不將不同卦辭拼接成逐爻引文；遊戲自創斷語另標。依[渙](https://zh.wikisource.org/zh-hant/周易/渙)與[觀](https://zh.wikisource.org/zh-hant/周易/觀)推導 |
| `0b001000` 標升、`0b100010` 標屯 | 在本約定前者為震上坤下，對應[豫](https://zh.wikisource.org/zh-hant/周易/豫)；[升](https://zh.wikisource.org/zh-hant/周易/升)應坤上巽下 `000110`。後者為艮上坎下，對應[蒙](https://zh.wikisource.org/zh-hant/周易/蒙)；[屯](https://zh.wikisource.org/zh-hant/周易/屯)應坎上震下 `010001`。若改位序要整張表一致重核，不能只改一筆名稱；採用前需有完整六十四卦資料來源 |
| 固定抽一個動爻，稱為三枚銅錢法 | 六次公平陰陽加強制一動是遊戲自訂分布，不是逐爻擲三枚錢。若每枚賦值 2／3，三枚和為 6／7／8／9 的機率由八種組合推得 1／8、3／8、3／8、1／8；若 6／9 為動，每爻動率 1／4，六爻可有零至六動。本輪只作組合推導，未選起卦法或多動爻解法 |
| GDScript 隨機與結算 | `randf`／`randi_range` 未使用本作可序列化 RNG；沒有實際算變卦／動爻集合，只有五筆表；查表結果直接加欄位有共用字典污染風險。原稿只作示意，不移植或依它改本 JS 引擎 |

來源查核日 2026-10-20。古籍數位原文用於核對上下卦／爻序，不聲稱上述遊戲事件是古籍本義。CText 頁面本輪讀取受阻，未拿它當已讀證據；以可讀的《周易》數位原文及明示位元計算交叉對照。沒有建立可執行占卜程式或驗證完整六十四卦。

## 若未來採用，必須先決定的技術語義

- 共用人格、遊戲偏好、天賦、命譜與占斷各自責任／版本。行為只產生意圖，仍走同一資源與名額仲裁；玩家覆寫不因性格被暗中取消。
- 一次正式起卦／事件的識別、適用範圍、何時扣費／抽籤／鎖結果，以及取消／重送／讀檔後處理。查看面板、動畫、暫停不能刷新結果；不同 UI／倍率不能改抽取順序。
- 若另設 RNG stream／事件鍵，需先提相容與分布方案，不自行新增。固定結果的敘事模板也不應消耗權威世界 RNG；採用前測同 seed／指令／存讀一致。
- 偶發稀有物、救援、突破與新配方要有世界資格、來源、消耗與上限；目前 D7 修為／突破契約不能被「大吉直接突破」繞過。不存在的靈獸、崖路或物品不可只靠判詞生成事實。
