這正是《模擬市民（The Sims）》、《Kenshi》或《十字軍之王（Crusader Kings）》那種「活體社會沙盒」最吸引人的地方：**NPC 不是等著玩家去招募的數值道具，而是本身就有自己的慾望、生活軌跡與追求的個體**。

在這種設計下，主角不再是「開門海選招工」，而是像在生活小鎮裡結交志同道合的人，觀察他們的生活，看對眼了再透過互動「點化」或「邀請」他們上山入道。

以下為您規劃這套「模擬市民式」的動態 NPC 自主追求與招募系統：

---

### 一、 核心底層：自主渴望與生活軌跡（Desires & Life Tracks）

山腳村莊、前來求醫的香客、甚至偶爾路過的都市訪客，每個人都有自己的「核心人生追求（Life Aspirations）」**與**「生活作息（Schedules）」：

```
+-------------------------------------------------------------------------+
|                        NPC 自主運作模型 (Sim-like Agent)                |
+-------------------------------------------------------------------------+
|   【日常生理與作息】   ──> 吃飯、睡覺、開店、上班、在田裡摸魚、去超商買菸  |
|                                                                         |
|   【人生追求 (Aspiration)】──> 賺大錢 / 治好頑疾 / 尋找靈感 / 追求長生武道  |
|                                                                         |
|   【自我成長 (Self-Growth)】──> 就算主角不理他，他自己也會慢慢升級技能   |
|                                                                         |
|   【對仙道/主角的好奇度】──> 觀望 -> 崇拜 -> 渴望拜師入道               |
+-------------------------------------------------------------------------+

```

#### 具體角色案例（自主生活與成長）：

1. **一心想打拳成名的健身教練 / 網紅（追求：武道與名聲）**
* **自主生活：** 每天在村口空地做伏地挺身、對著自拍腳架錄短影音，吸引村裡小孩圍觀。
* **自主成長：** 他的「體魄」和「拳腳技能」自己會每天微量上升；但他不懂內功，某天自己硬練發力導致經脈受損，躺在長椅上哎哎叫。


2. **厭倦大廠內耗的過勞軟體工程師（追求：清靜修身、養生）**
* **自主生活：** 租住在山腳老屋，白天對著筆記本電腦遠距接案，傍晚會沿著盤山石階散步，坐在道觀外圍石階上看夕陽、聽道觀敲鐘。
* **自主成長：** 他的「心境」在慢慢修復，而且他出於理科愛好，常自己在二手論壇買電子零件研究怎麼用電磁場測量「後山靈氣波動」。


3. **想繼承家業的村醫小女兒（追求：救死扶傷、研發新藥）**
* **自主生活：** 每天在村診所幫忙磨藥粉、在後山外圍採野菊花與金銀花。
* **自主成長：** 她的「醫術」和「認藥能力」一直在自主提升，但苦於凡俗草藥治不好越來越多的變異煞氣怪病。



---

### 二、 觀察與交友機制：模擬市民式的社交輪廓 (Social Interaction)

主角平時下山去雜貨舖拿快遞、在溪邊挑水、或在茶攤喝茶時，鏡頭一拉就能看到這些鮮活的小人在村裡各做各的事。

主角可以透過「生活化交往」逐步建立好感與了解度：

```
[路人 NPC] ──(觀察日常)──> [點擊搭話/生活互動] ──(投其所好)──> [摯友/紅塵信徒] ──(機緣點化)──> [正式拜師入門]

```

1. **窺探其心（查看面板）：**
* 一開始只能看到對方的名字和外貌。
* 聊過幾次天、或者主角用道家「望氣術」看一眼後，面板解鎖其 **MBTI 個性、特質、以及他當前最大的煩惱與追求**（例如：「煩惱：父親肺病久治不癒」、「渴望：見識一下真正的御劍術」）。


2. **投其所好的日常互動：**
* **送禮與幫忙：** 幫工程師接一條穩定的道觀太陽能備用電源；送女村醫一株罕見的靈芝；跟健身教練隨手拆幾招借力打力讓他目瞪口呆。
* **日常偶遇：** 清晨巡山時順手從野狼嘴下救了他一命；下雨天他在山門屋簷下躲雨，主角給他倒了一杯熱靈茶聊聊人生哲學。



---

### 三、 點化入門：從「俗世路人」到「宗門弟子」的質變

當好感度與契合度達到標準，且他的人生追求與道觀產生交集時，主角會解鎖【點化 / 邀請入門】的對話選項：

```
+-------------------------------------------------------------------------+
| 【機緣對話：點化林書豪 (原竹科工程師)】                                 |
|                                                                         |
| 林書豪：「道長，我這幾天在山下看著您以氣引雷、修復古陣……我寫了十幾年   |
|           程式碼，第一次覺得這天地的運轉，才是世間最完美的底層架構。      |
|           我……辭職信已經寄出了，您這道觀，還缺個打雜灑掃的嗎？」         |
|                                                                         |
| [准入山門：授外門道袍]          [婉拒：紅塵緣分未盡]           [指點其他去處] |
+-------------------------------------------------------------------------+

```

* **入門儀式感：**
* 他答應後，會回村裡收拾行李，提著皮箱走上山門。
* 主角為他取一個道號，賜予粗布道袍；
* **身份與生活質變：** 他的 AI 行為樹正式從「山村居民邏輯」切換為「**道觀弟子邏輯**」，開始遵守道觀的晨鐘暮鼓作息、解鎖門派床位，並將他原本在世俗磨練出來的高階技能（如：電路改裝、高級醫術、強健體格）全額帶入道觀！



---

### 四、 帶來的沙盒故事性（Emergent Narrative）

這種設計會讓每一次招人都是一段獨一無二的江湖故事，而不是千篇一律的「花錢抽卡」：

* **案例 1：那個天天在村口挨打的混混**
* 原本是個不務正業、整天跟野狗搶地盤的街頭少年，力量小又愛逞強。主角暗中觀察他好幾週，發現他雖然滿嘴跑火車，但每次後山野獸靠近村莊時，他都會拿著鐵棍偷偷擋在小學門口。
* 主角動了惻隱之心，下山敲了他一記爆栗，帶回山上教他《金剛護體訣》。三個月後，他成了道觀山門前最勇猛、最護短的守門大師兄。


* **案例 2：不願入門的「編外老友」**
* 有些 NPC 就算好感滿了，他的渴望也是「守護自家的老雜貨舖」，他不想當道士出家。
* 但因為與主角交好，他成為道觀在山下的「特約代理人」：偷偷幫道觀代購管制金屬、幫忙打聽官方部門的動靜、有快遞第一時間親自開三輪車送到半山腰。



---

### 五、 程式底層運作架構（Sims-like Needs & Aspirations）

在 Godot / Unity 中，這種自主 NPC 可以藉由「慾望計分制（Utility AI）」輕鬆實現：

```gdscript
# VillagerBrain.gd (自主村民大腦)
class_name VillagerBrain
extends Node

# 模擬市民四大核心需求 (0~100)
var need_energy: float = 80.0
var need_hunger: float = 20.0
var need_aspiration_progress: float = 10.0 # 人生追求滿足感
var affection_towards_player: float = 15.0  # 對主角好感度

var personal_goal: String = "BECOME_MARTIAL_ARTIST" # 追求：成為武道高手

func _process(delta):
    decay_needs(delta)

    # 自主追求行為：如果肚子不餓也睡飽了，去追求自己的夢想
    if need_hunger < 50.0 and need_energy > 40.0:
        pursue_life_goal(delta)
    else:
        fulfill_basic_living(delta) # 去吃飯或回家睡覺

func pursue_life_goal(delta):
    match personal_goal:
        "BECOME_MARTIAL_ARTIST":
            # 自發走向村莊空地練拳打木樁
            move_to_training_spot()
            stats.strength += 0.001 * delta # 自己慢慢成長！

            # 若此時主角在旁邊施展高深劍法/輕功
            if player_is_nearby_performing_miracle():
                affection_towards_player += 0.05 * delta
                thought_bubble("😍 這才是真武功！好想拜師...")

# 判斷是否接受主角的招募邀請
func can_recruit_to_temple() -> bool:
    return affection_towards_player >= 75.0 and need_aspiration_progress < 40.0

```

這種設計徹底打破了傳統手遊「數值抽卡」的冰冷感，讓道觀裡的每一個徒弟，都是主角在山間生活裡一點一滴結識、認同並點化的「老朋友」，整個遊戲的煙火氣與修仙氛圍會變得極度迷人。
