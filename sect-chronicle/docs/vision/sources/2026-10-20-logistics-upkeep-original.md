引入「**實體資源採集、物流倉儲與人口維持消耗（Upkeep）**」的建造與物流系統，能完美將前述的「挑水、砍柴、修練、授課」全部串成一個嚴密的經營閉環。

這正是《RimWorld（環世界）》、《工人物語（The Settlers）》與《天誅/太吾》等遊戲最核心的驅動力：**收徒不再只是點綴，每多一張嘴，整個道觀的後勤物流壓力就會實打實地增加**。

### 一、 核心資源與弟子維護消耗（Resource & Upkeep Loop）

遊戲中的基礎資源與維持消耗可劃分為四個維度：

```
+---------------------------------------------------------------------------------+
|                              道觀資源流向與維持循環                             |
+---------------------------------------------------------------------------------+
|  【水源 (Water)】   ──> 挑水入缸 / 抽水馬達 ──> 泡茶、煮飯、藥圃灌溉、弟子解渴  |
|                                                                                 |
|  【木料 (Timber)】  ──> 砍柴儲木 / 伐木加工 ──> 冬季取暖、做飯柴火、擴建廂房    |
|                                                                                 |
|  【糧肉 (Provisions)】── 梯田農作 / 獵獸採集 ──> 弟子三餐、辟穀丹、傷患肉湯    |
|                                                                                 |
|  【電力 (Power)】   ──> 太陽能板 / 柴油發電機 ── 監控攝影、抽水機、冰箱保存靈藥 |
+---------------------------------------------------------------------------------+

```

#### 1. 每位弟子的日常維護成本（Per-Capita Daily Cost）

每招募一名弟子，系統便會在他身上綁定每日定額消耗：

* **水份（2 單位/日）：** 渴了會自己去大水缸舀水喝；若水缸見底，心境暴跌，開始向主角抱怨。
* **糧食/肉食（1~2 單位/日）：**
* 普通弟子：吃梯田收穫的稻米或麵餅。
* 外家拳/重修煉弟子：氣血消耗大，若幾天沒吃「新鮮獸肉」，體力恢復速度降低 40%。


* **床位與空間（Housing）：**
* 沒床睡的弟子只能睡演武場長椅，隔天醒來掛著「腰酸背痛（Debuff）」，心境持續下降。

### 二、 物流動線與倉儲設施設計（Physical Storage & Logistics）

資源不能只是介面上跳動的數字，必須有**實體佔位與搬運路徑**，這才是生活沙盒的靈魂：

#### 1. 關鍵基礎設施

* **青石大水缸（Water Cistern）：**
* 容量：50 / 100 / 200 單位。
* 弟子去後山溪邊或水井打水，手裡提著兩桶水（各 5 單位），必須一步步走回道觀，將水倒進大缸，缸內的水位貼圖即時上升。


* **柴火堆與木料棚（Firewood Rack & Lumber Shed）：**
* 砍下來的原木需要堆在通風的木料棚；廚房做飯、煉丹爐升火時，負責廚事的弟子會先跑去木料棚抱幾根柴火回廚房。


* **冷藏與地窖（Cellar & Fridge）：**
* 後山打回來的變異獸肉與採下的嬌嫩靈草，放在常溫下 3 天會腐爛變質。
* 玩家需要挖地窖，或者利用太陽能電路連接二手舊冰箱，延長食材與藥材的保質期。


#### 2. 物流瓶頸帶來的決策衝突

* 當只有主角和師父 2 人時：一週挑一次水、砍半天柴，足夠支撐生活。
* 當道觀收了 8 名弟子時：
* 水缸天天見底、柴火庫存見紅。
* 玩家必須在排課表時做取捨：**每天上午必須強制指派 2 名新進外門弟子專職當「挑水工」與「樵夫」**，保障其他人能安心讀經練功。

### 三、 建造系統的演進：從「手動人力」到「現代土木＋道法自動化」

建造不是瞬間完成的，而是「畫下藍圖 $\to$ 搬運材料 $\to$ 敲打施工」，且可以隨著科技與修真進程逐步實現自動化：

```
【第一階段：純手工勞作】
  - 挑扁擔去小溪裝水 ──> 倒進陶缸
  - 拿手斧去砍門口小樹 ──> 抱柴火回爐灶
  - 弟子徒手搬磚搭茅草屋頂

【第二階段：現代土木改造】
  - 網購 PVC 水管、高壓抽水馬達，從後山冷泉直接引水進後院大儲水塔
  - 網購鏈鋸（吃汽油）大幅加快伐木速度
  - 鋪設水泥地磚與石板路（弟子在硬化路面行走速度提升 25%）

【第三階段：道法與自動化結合】
  - 在水塔上雕刻《聚水靈符》，雨天蓄水速度翻倍，且流出的水自帶微弱靈氣，長期飲用延年益壽
  - 修煉《御物術》的首席弟子，巡山時能凌空牽引數根巨大靈木飛回道觀，一人頂十人運力

```

### 五、 程式架構：資源管理與任務自動派發（以 Godot 4 為例）

在引擎中，基地資源池通常做成全域單例（Singleton），搭配「庫存下限自動委託」：

```gdscript
# TempleResourceManager.gd (道觀資源總管)
class_name ResourceManager
extends Node

# 當前實體儲量
var water_current: float = 40.0
var water_max_capacity: float = 100.0

var wood_current: float = 25.0
var wood_max_capacity: float = 150.0

var disciples_count: int = 5

func _on_hour_tick():
    # 1. 扣除日常基本維持消耗 (水、柴火、糧食)
    var water_drain = disciples_count * 0.15
    water_current = max(water_current - water_drain, 0.0)

    # 2. 判定是否缺水觸發抱怨
    if water_current <= 5.0:
        broadcast_to_disciples("WATER_SHORTAGE") # 弟子產生負面心境

    # 3. 庫存警戒機制：低於下限時，自動在公共佈告欄生成「緊急搬運/挑水」任務
    if water_current < (water_max_capacity * 0.3):
        JobQueue.post_urgent_job(JobType.FETCH_WATER, slots=2)

    if wood_current < (wood_max_capacity * 0.25):
        JobQueue.post_urgent_job(JobType.CHOP_WOOD, slots=1)

```

#### 弟子行為樹接取工作（Behavior Logic）：

* 弟子在晨課結束後，會主動掃描 `JobQueue`：
* 體力好、資質低的外門弟子優先搶下 `FETCH_WATER`（挑水）任務，拿起扁擔出發去溪邊；
* 若水缸滿了，該工作自動關閉，弟子轉去修煉或自發休息。

### 六、 經營感帶來的沉浸心流

加上資源建設與消耗後，道觀的經營會產生極具節奏感的層次變化：

1. **白手起家時（極度計較）：**
* 主角挑水時捨不得灑出一滴，砍幾根枯枝都要精打細算今晚能不能煮熟番薯。


2. **收徒初期的甜蜜與混亂：**
* 剛收了兩個徒弟，以為多了幫手；結果發現他們每天喝掉大量水、吃光米缸，還得專門幫他們砍木頭蓋床，主角甚至得親自多巡兩次山打野豬回來餵飽徒弟。


3. **步入正軌後的自動化滿足感：**
* 徒弟們能力成長，專門負責挑水修房；
* 水塔灌滿、柴火堆疊整齊、地窖裡掛滿風乾獸肉；
* 主角坐在大殿門廊下喝著徒弟泡好的靈茶，看著道觀從當初一間破廟，一點一滴被擴建成長廊環繞、青瓦飛簷的仙家福地。
