### 三、 易經爻動：動態行動收益與歷練占斷系統 (I Ching Engine)

如果採集、練功、巡山只是一成不變的「讀條 $\to$ 獲得固定物品」，遊戲會非常單調。將**易經六十四卦與六爻變動**封裝成底層隨機亂數引擎（RNG），每次主要生活行動都相當於「起一卦」：

```
[玩家/主角發起行動] ──> [消耗少許精氣/時間起卦] ──> [產出本卦與變卦] ──> [結算奇遇/收益/風險]

```

#### 1. 生活與採集：天時卦象反饋（採藥、伐木、挑水）

在執行較長週期的生活任務時，結算介面不只彈出「獲得木材 x5」，而是伴隨微小的卦爻批註：

* **案例 A：後山採藥，起得【地火明夷】卦（初九爻動）**
* *爻辭：*「明夷于飛，垂其翼。君子于行，三日不食。」
* *遊戲反饋：* 晦暗受阻之象。主角在採藥時不慎踩空滑落山坡，扭傷腳踝（獲得輕傷 Debuff），但慌亂中抓住崖邊一株百年何首烏（獲得稀有材料，因禍得福）。


* **案例 B：靜室閉關，起得【乾為天】卦（九五爻動）**
* *爻辭：*「飛龍在天，利見大人。」
* *遊戲反饋：* 大吉大順。打坐時心靈澄澈，天地靈氣如醍醐灌頂，直接突破當前功法層數，且引來師父讚許，贈予貼身隨身道玉一枚。


* **案例 C：煉丹熬藥，起得【水火既濟】變【水火未濟】（上六爻動）**
* *爻辭：*「濡其首，厲。」
* *遊戲反饋：* 爐火原本極穩，但最後關頭火候太盛，丹藥險些報廢，出爐的丹藥變成了「焦黑的爆炎散」（獲得特殊消耗性投擲道具，非原本預期的療傷丹）。

### 四、 程式架構實作：輕量級易經隨機生成器 (GDScript 範例)

不需要硬背六十四卦的全部內容，在程式中可將其抽象為二進制數值（陰爻為 0，陽爻為 1）與事件查表：

```gdscript
# IChingEngine.gd (易經占斷核心)
class_name IChingEngine
extends Node

# 六十四卦簡易資料庫 (由二進制 0~63 映射)
const HEXAGRAM_DATA = {
    0b111111: { "name": "乾為天", "nature": "大吉/剛健", "efficiency_bonus": 1.5, "danger_level": 0.1 },
    0b000000: { "name": "坤為地", "nature": "厚重/包容", "efficiency_bonus": 1.2, "danger_level": 0.0 },
    0b100010: { "name": "水雷屯", "nature": "初始艱難", "efficiency_bonus": 0.8, "danger_level": 0.4 },
    0b010101: { "name": "水火既濟", "nature": "圓滿成功", "efficiency_bonus": 1.4, "danger_level": 0.05 },
    0b001000: { "name": "地中生木 (升)", "nature": "漸進成長", "efficiency_bonus": 1.3, "danger_level": 0.1 }
}

# 為某個動作起卦 (例如：採集、閉關、出門)
func cast_action_hexagram(actor: Disciple, action_type: String) -> Dictionary:
    var hex_val: int = 0
    var changing_line: int = randi_range(1, 6) # 哪一爻發動

    # 搖六次銅錢生成六爻 (三正面為老陽，三背面為老陰...)
    for i in range(6):
        var is_yang = (randf() > 0.5)
        if is_yang:
            hex_val |= (1 << i)

    # 查詢卦名，若不在精簡表中則給予基礎平卦
    var result = HEXAGRAM_DATA.get(hex_val, { "name": "尋常之卦", "efficiency_bonus": 1.0, "danger_level": 0.2 })
    result["changing_line"] = changing_line
    result["hex_code"] = hex_val
    return result

# 套用至採集或修煉結算
func apply_hexagram_outcome(base_exp: float, base_loot: Array, hex_result: Dictionary) -> Dictionary:
    var final_exp = base_exp * hex_result["efficiency_bonus"]
    var triggered_incident = (randf() < hex_result["danger_level"])

    return {
        "final_exp": final_exp,
        "loot": base_loot,
        "hex_name": hex_result["name"],
        "has_incident": triggered_incident,
        "incident_type": "beast_ambush" if triggered_incident else "none"
    }

```
