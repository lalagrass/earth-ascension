# 北極星：門派生活的五個支柱

狀態：**願景錨點／不是開發契約**。2026-10-25，Claude 整理；來源是擁有人 2026-10-24 在專案聊天的原話與 [#314](https://github.com/lalagrass/earth-ascension/issues/314) 的討論。本頁不批准任何玩法、數值、排程或工程；目前唯一執行排序仍以 [VISIBLE_DELIVERY_PLAN](../VISIBLE_DELIVERY_PLAN.md) 與各正式工作包為準。

用途：之後每個提案或正式包開頭可標明「推進哪個支柱」，review 時對照本頁判斷有沒有偏題。

## 擁有人原話（2026-10-24，原樣保存）

> 我覺得做了那麼久，好像慢慢知道自己想要的是什麼。我喜歡老遊戲天下霸圖的生活部分，就是可以看到弟子們在地圖上跑來跑去，練功變強學到新武學，但我不喜歡它的戰鬥系統。比較喜歡在同一個地圖直接看到角色施展不同武功的感覺。然後我也喜歡模擬市民的生活感，可以練習不同的技能、可以跟人聊天、甚至親密夠時拉進一個家庭。最後是武學演練部分，才想到說可能可以結合塔防的感覺，實地體會角色練完，出去打怪會是怎麼樣的感受。所以預計如果是門派生活場景的話可能有大廳、鍊外功區、宿舍、膳房、藥園、菜園、後山打獵等等的地區，然後把時間點往前退的話，一開始門派尚未成立，可能只有一個破道館，每個功能點需要慢慢擴建。

## 五個支柱

| # | 支柱 | 玩家看到什麼 | 刻意不要什麼 |
|---|---|---|---|
| P1 | **天下霸圖式門派生活** | 弟子們在同一張地圖上跑來跑去、照作息做事、練功變強、學到新武學 | 只看選單與數字的經營 |
| P2 | **同圖武學** | 不切戰鬥畫面；在同一張地圖直接看到角色施展不同武功，練熟了肉眼看得出差 | 另開回合制／戰鬥場景 |
| P3 | **模擬市民式生活感** | 練不同技能、跟人聊天，親密夠了可以成為一個家庭 | 只有隱藏好感數字、沒有可讀原因 |
| P4 | **塔防式武學演練** | 練完出去打怪，實地感受「練了有沒有用」 | 無限刷波、玩家手動出每一招 |
| P5 | **從破道館擴建** | 開局只有一間破道館；大廳、外功區、宿舍、膳房、藥園、菜園、後山獵場一處一處蓋起來 | 一開始就是完整門派 |

已選定且貫穿五支柱的觀看樂趣：**長通勤、負重與腳力造成的速度差、成長即速度**（見 [D26–D27](../DECISIONS_AND_SOURCES.md)、[D41](../DECISIONS_AND_SOURCES.md#d41新山居場景整合批准2026-10-24)）。

## Claude review 的加強建議（候選，未批准）

來源：[#314 review 留言](https://github.com/lalagrass/earth-ascension/issues/314#issuecomment-6387677473)。以下只是建議，由擁有人與遊戲 PO 決定是否採用、何時排入。

1. **人數進主線（P1／P3／P4）**：把「第三位弟子入門」併入 BL-S01 少量床位那包；三人兩床才有認領的意義，也順勢把按人物 id 寫死的設定改成資料（#317 的最小觸發點）。
2. **新活動掛在設施站位上（全部）**：HOME01 交出 `fac.*` 設施表後，之後每包新活動都掛在設施站位，不再新增按人物 id 分支的路線或設定。用規則代替大重構。
3. **提早一個演武小切片（P2／P4）**：在 `fac.yard` 演練場放一波木傀儡，沿用已交的掌法、練掌進度與戰報欄位，先驗證「練熟的人站得住、新手要退」；可與 #318 第二式合成一包。
4. **先定後山空間（P4／P5）**：排到 #320 之前，決定是擴大世界邊界還是由山道接一塊相鄰區域；並在 HOME01「概念→實裝」對照表中寫明巡山方向以現行西坡或母版東北山門為準。
5. **擴建與保存一起決定（P5）**：選第一個修繕包（#321）時，同時決定「設施階段」要保存（一個欄位、最小升版）或明說只限本局，不等多個設施後才補。這是 [D40／BL-P02](../FUTURE_BACKLOG.md#bl-p02新增存讀升版與遷移最後) 的一個已知例外風險，不是推翻它。
