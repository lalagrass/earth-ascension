# 北極星：門派生活的五個支柱

狀態：**願景錨點／不是開發契約**。2026-10-25，Claude 原稿與 review 校正，Codex／遊戲 PO 依 D52 增補現況與順序；來源是擁有人 2026-10-24 在專案聊天的原話與 [#314](https://github.com/lalagrass/earth-ascension/issues/314) 的討論。本頁不批准任何玩法、數值、排程或工程；目前唯一執行排序仍以 [VISIBLE_DELIVERY_PLAN](../VISIBLE_DELIVERY_PLAN.md) 與各正式工作包為準。

用途：之後每個提案或正式包開頭可標明「推進哪個支柱」，review 時對照本頁判斷有沒有偏題。

## 擁有人原話（2026-10-24，原樣保存）

> 我覺得做了那麼久，好像慢慢知道自己想要的是什麼。我喜歡老遊戲天下霸圖的生活部分，就是可以看到弟子們在地圖上跑來跑去，練功變強學到新武學，但我不喜歡它的戰鬥系統。比較喜歡在同一個地圖直接看到角色施展不同武功的感覺。然後我也喜歡模擬市民的生活感，可以練習不同的技能、可以跟人聊天、甚至親密夠時拉進一個家庭。最後是武學演練部分，才想到說可能可以結合塔防的感覺，實地體會角色練完，出去打怪會是怎麼樣的感受。所以預計如果是門派生活場景的話可能有大廳、鍊外功區、宿舍、膳房、藥園、菜園、後山打獵等等的地區，然後把時間點往前退的話，一開始門派尚未成立，可能只有一個破道館，每個功能點需要慢慢擴建。

## 五個支柱

| # | 支柱 | 玩家看到什麼 | 刻意不要什麼 |
|---|---|---|---|
| P1 | **天下霸圖式門派生活** | 弟子們在同一張地圖上跑來跑去、照作息做事、練功變強、學到新武學 | 只看選單與數字的經營 |
| P2 | **同圖武學** | 不切戰鬥畫面；在同一張地圖直接看到角色施展不同武功，練熟了肉眼看得出差 | 另開回合制／戰鬥場景 |
| P3 | **模擬市民式生活感** | 練不同技能、跟人聊天，親密夠了可以成為一個家庭 | 只有隱藏好感數字、沒有可讀原因 |
| P4 | **塔防式武學演練** | 練完出去打怪，實地感受「練了有沒有用」 | 無限刷波、玩家手動出每一招 |
| P5 | **從破道館擴建** | 開局只有一間破道館；大廳、外功區、宿舍、膳房、藥園、菜園、後山獵場一處一處蓋起來 | 一開始就是完整門派 |

已選定且貫穿五支柱的觀看樂趣：**長通勤、負重與腳力造成的速度差、成長即速度**（見 [D26–D27](../DECISIONS_AND_SOURCES.md)、[D41](../DECISIONS_AND_SOURCES.md#d41新山居場景整合批准2026-10-24)）。

## 近期落地順序（D52方向已確認，工程待定）

1. **下一里程碑先SOCIAL01**：主角與小女孩有內容交談、溫柔鼓勵與可回看相處事件，先讓現有兩人更有生活感。S1–S4建議與取捨見正式規劃，不以文案批准代替機制／數值定案。
2. **隨功能漸進維護**：設施活動／站位／預約核真ID與需求，不先重寫核心、另開入口或建立通用關係引擎。
3. **後續各自評估**：第三人與安置／加入原因另包；演武與第二式先擇一最小成果；後山先畫路網與空間差異，不以「沒有空間」直接授權擴圖。
4. **最後**：新增保存升版／遷移與手機適配。HOME02已選只本局，不因修繕／關係要累積就自動重開保存例外。

原快照中的空間不足為當時假說，並非已量測結論；候選數值／介面與更多支柱不因本順序自動批准。

## Claude review 的加強建議（候選，未批准）

來源：[#314 review 留言](https://github.com/lalagrass/earth-ascension/issues/314#issuecomment-6387677473)。以下候選依上方D52校正去向；其中先兩人互動的規劃方向已選，其餘具體功能／數值與工程尚未批准。

1. **增加人數是獨立候選（P1／P3／P4）**：多數支柱終究需要兩人以上，但不併回已完成的 HOME02 床位包；兩人兩床已能呈現歸屬與預約。第三位弟子會帶來容量不足、安置與加入原因等新語義，選定時要和可讀互動、入門理由一起設計驗證。遊戲 PO 建議先讓現有兩人有內容地交談／鼓勵、關係可讀，再談新增人口。「家庭」也可包含師徒、親情與共同生活，不自動等於道侶。
2. **設施活動／站位與預約方向漸進沿用（全部）**：在真的需要的包裡落地，不要求先重寫核心或換入口。SCENE04 的 `fac.*` 是母版候選命名，目前 runtime 沒有對應 ID；採用前要先核實裝的權威 ID 與入口，不當成既有穩定 API。
3. **選一個「看懂訓練成效」的最小切片（P2／P4）**：演武木傀儡與 #318 第二式各有學習目標，先挑一項最能讓玩家看出「練熟了有差」的，不必綁在一起。
4. **後山空間先量再選（P4／P5）**：排到 #320 之前，先畫出路網、功能區與連接方式的差異，再選擴大世界邊界或山道接相鄰區域；巡山方向以現行實裝為準，母版東北山門只是候選。
5. **長期擴建與保存（P5）**：HOME02 已依 D49 選定木料／工地／床位只限本局。擴建累積多了之後，保存何時排入仍依 [D40／BL-P02](../FUTURE_BACKLOG.md#bl-p02新增存讀升版與遷移最後) 由擁有人另定；本頁不把任何「最小升版」視為已批准例外。
