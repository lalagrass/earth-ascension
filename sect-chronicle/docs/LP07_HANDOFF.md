## 意願、名額與正式執行

本片局部狀態只需能分允許／傾向、本訪意願、本訪人工抑制、本訪自主已嘗試、正式派遣auto/manual來源與最近結果；命名／API由作者選，不先建通用任務佇列、人格系統或另一個時鐘。

1. 主動者在可察覺`sniff／approach／prep`且來訪有效時願意處理，畫外`out`不先讀心；受擾者須**本訪`hits ≥ 1`**，不讀全局`marks`當碰撞事件。損痕已3時，新訪仍有自己的hits。
2. 先過允許、當人本訪抑制、手動停工／待停工、LP05叫回來源、目標有效與他人已派遣等硬限制；不能靠性格越過。低精力／必要恢復者可顯示「有意願，恢復到80後再候補」，但不清恢復、不占名額。
3. 工作中只記意願，完整交付一次產出／成長／釋約；休閒去程走完當前腿、活動點下一合法tick返院、返程不重啟。候補可促使沿既有合法路徑返院，但不瞬移、不半途丟工作。目標失效／同伴先正式接手時清意願與保留原因，當前腿仍走完，再回生活；未出發只記意願過期／同伴處理，不假稱到場晚到。
4. 候補不寫正式`guardOrder`、不拿目標名額、不呈現已派遣。人在共同院中端點、交付與必要恢復已完成、確實能走上防守路，再查最新命令／目標／名額後，沿既有guard執行路徑受理並立即出發。**決策要在合法院中邊界、原工作／休閒再出發之前**，不是模型外step後輪詢，避免已自動接下一趟而永遠不能護院。
5. 多位同tick都準備好，以明列的穩定人物ID順序打平，不能由每人更新先後／render遍歷決定雙派；不宣稱最短ETA或公平排班。每個人每訪最多一次自主正式受理，記已嘗試；只表達意願不算已受理。任何時刻一個訪次最多一位正式指派者。已出發auto或任何已受理manual不被候補搶單；人工明派仍可在工作／必要恢復中預約，沿D16交付／恢復後才走。
6. 正式受理後沿D16移動／等待／喝止／同tick判效／晚到／返回。退走即目標失效，不接下次來訪，不遠端成功、不重複收益；返回重查最新工作、LP05來源、容量／公平預約與必要恢復。關自主不影響本來就由玩家明派者。

單一時間下，候補／名額的讀寫須確定性，同tick只取一位；喝止與自然退走、資源誘因消失／接觸的成效優先沿D16，不能對已失效目標補成功。可在現有模型做正確性必要的最小抽取，保持自主關閉時原LP06可觀察行為。#215只收具體非阻擋發現，三片回訪不是本片大重構gate。

|---|---|
| 改工作／開始／停工 | 清候補、記該人本訪抑制；未完成正式guard的取消及目前腿／最新返回工作沿D16。停工／待停工跨訪仍優先，不能靠新訪解除 |
| 取消待執行 | 可取消本片候補意願；在原pending／尚未出發正式guard之外，只薄擴到有候補時可用，UI提供可用入口。受理後清候補、記本訪抑制；不清手動停工、不取消已在走的腿／已在喝止的效果。若要取消進行中guard，沿既有改工作／停工；不造萬用取消 |
| LP05叫回工作 | 只在原本可叫回的休閒狀態受理，清候補／記本訪抑制；保留叫回直到返院後新工作趟次完成或明確恢復自主，不為本片擴叫回可用狀態 |
| LP05恢復自主 | 仍只清LP05叫回來源，不清停工／必要恢復；**不清本訪抑制或已嘗試，也不代啟護院開關**。不把這項既有操作當成P3清單外的新強制取消 |
| 手動guard | 沿D16合法性／目標名額，允許護院關閉或本訪被自主抑制的人由玩家明派；成功後標manual來源，不被候補／關自主取消。拒絕或重送不改來源／重啟路程，已由同一人處理的既有拒絕語義保持 |
| 關掉護院允許 | 清該人的候補；若正式guard為auto來源，取消其尚未完成效果、走完當前腿返院套最新生活意圖；manual來源保留。其他人不受此人的開關直接操控 |
| 改傾向／重開護院允許 | 更新設定供下一合法判斷；不清本訪抑制／已嘗試，不重啟腿或已正式受理的guard；玩家可另手動guard處理本訪 |
| 拒絕指令 | 不清候補／來源，不新增或清抑制；P3只作用於真正有效受理的指定操作，不讓無效點擊改政策 |
| 新來訪／重來 | 新visit只重置前訪的意願／抑制／自主已嘗試，不能清停工／叫回／必要恢復；新局重置兩人允許關閉、預選傾向、所有本片局部狀態與LP06原初值 |

本訪抑制是**每人、指定visit**，不是全隊停防或任意秒數冷卻；抑制一人不自動禁止另一個合法候補。沒有進行中來訪的手動操作不把抑制延伸到未來新訪。清意願不憑空釋放他人名額；取消／過期和名額釋放只一次。

暫停時允許改設定／合法指令及零進度意圖，但不推動位置、工作、精力、獸狀態、喝止／候補時間；恢復播放才沿權威tick決策。仍無生活存檔／舊RT自動轉檔，不寫新存檔版本。

## UI、檔案與有限驗收

同一`sect-chronicle/index.html → experiments/water-carry/demo/`與PixiJS／HTML生活入口。每人有允許設定、可交換反應選擇及可讀原因；「尚未允許／觀察中／已有意願待交付或恢復／本訪由玩家改派／同伴處理／已出發／喝止成功／意願過期／到場晚到」各如實，別用單一「護院中」掩蓋。原因更新才記事件，不每tick刷log；窄畫面可選人、設定／取消／讀原因，不增不必要面板。

只改`experiments/water-carry/demo/**`、必要`checks/**`、實驗README交付列；優先復用原素材，不需template／atlas改造或背景重畫。保留人物選取、鏡頭、暫停／1／2／4×、背景不補時、重來、挑水採藥成長、LP04恢復與LP05偏好。不要改舊`js/`、`viewer/`、storage、Earth、root依賴CI／RNG／golden、他人服務埠；不預留修護／鼠群schema。

必要驗收分六組，選少量代表反例，不做全指令／人格×全時相矩陣：

1. **允許／反應**：預設全關不自主派遣；同身體／路線局部配對中，早反應於可見靠近、本訪hits≥1才晚反應；交換傾向後意願時機隨之變。封頂marks後新訪仍可觸發，不把傾向當速度／能力buff。
2. **候補與名額**：忙碌主動者有意願但無guardOrder，另一合法可出發者可正式接手；同tick兩個ready只一個受理，已出發／手動工作中預占不被搶單。院中合法邊界先決策再接工作，非一直錯過端點；本訪每人正式受理最多一次，候補取消／目標過期與釋放不重複。
3. **玩家覆寫／恢復**：少量配對核有效改工／停工／候補取消與拒絕操作、本訪抑制、下訪重評仍不解停工或LP05叫回；恢復自主不清抑制／必要恢復。保留LP05停工→開始／改工→恢復自主不跳80／不死鎖反例；關允許只清auto、保manual。
4. **交付／過期／位置**：先完整交付一次產出／XP／釋約、必要恢復至80、最新返回工作與容量公平不丟；工作中候補不占工作容量。真的往返／喝止，目標退走不補成功，不換下一訪；未出發過期與到場晚到有別，喝止與同tick接觸／退走沿D16。無新精力／收益／趟次／XP。
5. **時間／新局**：暫停設定／命令零進度、同固定遊戲時間1／2／4×與分幀局部等值、背景不推進不補時；重來清本片局部狀態與預選重置。無新RNG，不造seed矩陣；自主全關復用LP06接受基線／相關局部回歸。
6. **一次桌面＋390px真操作並開圖**：自然新局開熟手自主、看見意願→實際出發／喝止或晚到→回生活；下一訪只開受擾者或交換傾向，看本訪碰撞後意願及晚到／過期原因；玩家有效取消後本訪不搶回。可正式4×，不改D16、縮路／注入精力或強迫受擾成功。390px只補新增設定／原因／覆寫可用，不重演完整桌面；長恢復／名額競爭／封頂後回訪用局部模型驗。
