# 公版人物簡介（第一包）

玩家結果：開局選出身時看得到一句短介和可展開的背景；生活人物卡在名字下顯示同樣的短介與背景。研究用的經典人物可以在展示頁切換對照，不能拿來開局。

## 名單與欄位

已接上的選人入口是既有三個出身：採藥童、農家子、道館學徒。短介沿用 `story-data` 的 `blurb`，背景寫在同一模板，不進存檔。能力、配點仍只讀規則。

生活卡綁定：`hero` 主角、`cousin` 熟手同伴、`girl` 道館收養的小女孩。前兩人已在生活名冊；女孩只備好介紹，名冊不新增她。

研究展示：十二人，以及功夫的阿星、包租婆、包租公、苦力強、裁縫、油炸鬼、火雲邪神、天殘、地缺。每人保留作品、階段、`designId`，`actorId` 空著。`templateId` 不進規則模板。

公開欄位只有短介、背景、作品／版本／階段、來源、可見性與立繪引用。隱藏身分不進資料。功夫裡尚未在公開介紹說破的高手身分，只寫街坊生活。

`character-card/profiles.mjs`、`render.mjs`、`gemini.mjs`、`style.css`、`showcase.html`、測試與本說明。出身文字在 `js/story-data.js`，選人畫面在 `viewer/actions.js` 與 `viewer/app.js`。

不改生活 `demo/app.mjs`。人物卡本來就呼叫 `identityHtml`，簡介從那裡出現。
