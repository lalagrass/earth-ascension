## 風險與停止擴充條件

- 多人課表淪為瑣碎操作：先用三格與範本；真人仍困惑就縮減可編角色或行動，不增加自動化面板掩蓋。
- 五行成為一次擺好即無決策：先測建設成本與工作位是否形成取捨；無影響則簡化，不堆第二層風水。
- 多系統重複懲罰：先讓體力／心境各有用途；若玩家分不清，合併或延後其一。
- 手動操作成為免費產出漏洞：統一時段預約與一次扣費，禁止 UI 直接改世界。
- 拆引擎成本低估：先完成 14 天切片；M3 試玩不支持時停止 M4。
- 多 agent 契約漂移：先合併 schema／規則；共用 engine 檔案串行，跨模組更動交 Tech Lead 協調。
