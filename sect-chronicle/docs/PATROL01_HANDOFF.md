## PF1：一條可辨的西坡山徑

- 世界維持1600×1350；不改既有挑水1700.9／採藥515.2、護院／修繕／院內清鼠與休息原路。新增由HOME經西院通道、**繞竹護欄端點**往西坡林緣的有限折線，不穿牆／欄杆或瞬移；可調新路與非功能裝飾避障，不搬原功能端點、不另建鄰接地圖／無限生成。
- 設S0柵欄外巡山口、S1竹坡、S2石坳、S3林緣四個路標，院中至S0是前導路。S0→S3單程以**800～1200世界單位為配置目標**，實際折線量距為準，不是已量測路長，不蛇行湊數。可用西坡x約100～620、y約300～850安排彎路與棲地；Grok同PR定稿記點／距離，不另外先交圖等簽。
- 一份純幾何來源供model／render共用，距離與工期用世界單位／權威遊戲時間。主路不自交，深入進度取真走過的主路段；離路追逐只增加總路程，不以近道投影跳過未走路段。新路、路標、鼠／獸與動作沿第一版水彩資產先用，缺少才局部補，不重繪整張圖或烘入固定人物。
- 本片前導路／主路／有限離路追擊的回程始終可走，不加動態堵路、敵人阻擋或突發移速減益。遠期封路／受傷／救援不混入本片，也不能宣稱未來任何情況都保證安全。

## PF3：巡山耗能、返程預算與人工意圖

下表為PO按本次委託選定的**本片示意值，待真人校準，非已測平衡**。集中一份巡山規則，只套新巡山狀態，原生活耗能／恢復不改。

| 項目 | 示意值／語義 |
|---|---|
| 精力／速度 | 原0～100、腳力空手速度與上限不改；本趟不加腳力XP／掌法熟練或收益。出發鎖本趟腳力／掌法fixture，活動中不能切成另一能力 |
| 出發 | 院中合法邊界且**精力≥40**；已在必要自動恢復流程者仍先完成原80門檻。待出發不足40則走原座位恢復至80，不免費加滿／解除手動停工 |
| 巡山走路 | **0.8精力／遊戲秒**，含前導路、深入、追逐與返程，按權威tick真移動工期扣；不按render幀或同tick雙扣 |
| 停步觀察／出招 | 路標首次觀察**1遊戲秒**；觀察、起手／收勢、喝止工期均**0.2精力／遊戲秒**。與該tick走路費互斥；出掌／喝止起手2另計一次 |
| 返程餘裕 | **8精力**是保留量，不另扣／補給；不能用固定低精力門檻代替實際退路計算 |
| 返程鎖定 | 決定返回後不再選敵／觀察／出掌／喝止／離路追逐，僅真退路移動耗能；不因出現弱鼠又深入，到院才結束 |

每次走下一個**≤40世界單位短段前**，必須滿足：目前精力 ≥ 該段耗能 ＋ 從該段終點原路返院耗能 ＋ 8。離路時把回離路起點的折線及院內前導路也算入，不用直線穿山／距院中心半徑代替。

每次起手前另滿足：目前精力 ≥ 起手2 ＋ 完整起手／收勢或喝止工期的0.2/s耗能 ＋ 當前返院耗能 ＋ 8。路標觀察也先留工期成本；出發先核下一短段可行，不足不發起／走原恢復流程，不原地占名額掛住。

返程連續近似＝**0.8 × 剩餘真退路長 / 鎖定本趟空手速度**；實際預算按返程**每段真整數tick工期保守向上取整後加總**，不是僅全程末尾取整，並計入尚待完成短段／出招。已返回不再接戰，本片又無封路／人傷／減速，因此合法狀態有足夠精力回家；精力不負，不靠0精力免費走或戶外回滿兜底。存讀驗返程可行不變量，壞檔不得塞入退路足夠明確卻無能量返回的活動狀態；明列小浮點公差，不用補值掩蓋缺額。

紙上例（非路長承諾／實測）：退路600、速度60，回程約耗8，另留8；精力17不能再起手扣2，應返回。相同退路速度84，回程約5.72，約多2.28餘裕；快者可能多完成一個合法動作。真對照另計動作工期／tick取整，不拿示例數字寫公式鏡像測試。

### 接單、名額、取消與生活續接

- 「巡山一趟」是明確派遣，**不定期自動重派**；途中進退自主，不先做完整人格／Utility AI。
- 巡山名額全場1，受理／等待至真返院均占，同一人與護院／整理／院內清鼠互斥，重送不重開。其他人照常生活，外出者不兼算生產／守院。
- 搬運先交付原趟、休閒真回院、必要恢復完成，再從HOME出發，不丟桶／撤收入／預約或瞬移。手動停工／已排本趟後停工者，按鈕不暗解除，先明確恢復原活動再派。原人工抑制保留，巡山不偷偷重新允許自主清鼠。
- 有效新工作／停工／叫回／取消走原正式指令入口：未出發撤名額，原工作照舊；途中最多完成當前≤40短段、起手未命中可收手（已扣不退），已成結果保留，再真返院。新工作存待辦，不在山外開工；到院釋名額並照最新人工意圖。**明確停工仍停工、不再巡山**；召回／改工沿原語義，不另造停工真相。
- 返回原因包含終點、返程預算、近距豬威脅／無合法驅離、失目標且無下一合法路段、玩家召回／改工／停工。逃一鼠不必終止整趟：回主路後仍有合法路段／預算可繼續；返回決定一旦成立不翻轉。

## PF4：返院戰報與同條件能力觀察

沿原人物卡加派遣／等待理由／召回與短進度，能點選／跟隨，保留1×觀看。活動中只顯示路標、行為／對象、精力、返程需求與理由。到院產生**最近一份戰報**，下一份完整返回才覆蓋；活動摘要另存且有界，不以診斷log作唯一戰果來源。不加另一入口／排行榜／完整技能面板。

| 欄位 | 定義 |
|---|---|
| 最遠掃蕩距離 | 固定S0為0，沿主路投影的最遠位置／路標；前導路、折返／離路不灌成深入距離，用世界單位而非公尺 |
| 巡查／確認處理路段 | 完成路標觀察才記巡查；已知目標均處理／離開才另記「已知威脅已處理」。逃脫／繞避／未確認支點明示，不讀隱藏fixture宣布全段清空／永久安全 |
| 總移動／時間 | 含前導、沿路、追逐、返回的真移動長；遊戲時間以移動／觀察／交手的互斥分類加總，另標「其中返程」子集，不能重複加返回。倍率／真實等待不冒充能力 |
| 種類／結果 | 只記真看過的個體；同ID重遇不算多隻。最終結果互斥：擊倒、本人造成驅離、逃脫／失目標、繞避，或已見未處理；後來擊倒覆蓋先前逃脫，擊中不是擊倒，down不寫死亡 |
| 成本／返回 | 精力起終／實耗、遊戲耗時、返回理由、是否真到院及最新待辦；到院前不發完成報／釋名額。無人傷／掉落／收益不造假欄位 |

再巡可能沒鼠／沒遇豬，如實記錄，不強迫遭遇／重生。驅離需本人合法喝止因果及模型逃離結果，自然疲累／同伴驅離不算自己。現場成績不是成長或單一戰力；本包用既有兩人／初熟fixture觀察，不新增真學習／XP。

需要比較時用**同配置明示新局fixture或純模型配對**，固定路線／敵初態／出發精力／負重／策略／規則版本，分移動與出招耗時。不在正常世界加「重生這群鼠」／複製獎勵／第二試玩入口；日常每趟不必跑實驗。

## 保存、版本與必要架構

- 以第一版最終model／scene／save為基底，不搬282舊修法。仍同一JS tick，用局部巡山模組／純幾何串既有公開API，render只讀view；不另開時鐘／引擎、全站ECS／BT。
- 新增持久活動採**同生活專用key升saveVersion 2，明確支援已接受v1→v2最小無損遷移**。先按第一版v1驗完整舊資料／原幾何，保留人物／當趟／庫存預約／人工意圖／豬與院鼠，只補尚未巡山、新局林鼠初態等新增欄位。遷移後是v2狀態，手動存檔寫v2；載入不自動覆寫舊檔，不重複補鼠。不接受未知版本／錯誤v1／不符幾何，不讀RT key。
- v2存名額／來源、待出發／進退階段、真位置／路段／短段進度／離路退路、鎖定能力、扣費進度／返回決定、已觀察個體／結果、林鼠狀態／豬因果引用、活動摘要與最近戰報。新幾何有相容識別，不重新出發／清進度／重結算出掌喝止或戰果。
- **按各mode**驗必要座標／queue與每路點、ID／enum／數值／持有者／返程可行；新局模板加LOOSE或一步試跑不是活動結構驗證。候選先驗再原子替換，失敗現世界／舊檔不變且仍可step／view，成功載入暫停、clock.clear，不多走一步。
