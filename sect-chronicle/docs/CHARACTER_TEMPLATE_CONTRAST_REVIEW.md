# 經典角色對照：先驗角色差異，再選天賦欄位

狀態：2026-10-26，擁有人要求的**紙上研究／三方差異評估**，不是新增角色、數值平衡或系統實作授權。主[#340](https://github.com/lalagrass/earth-ascension/issues/340)，文件PR #341。前次R2分類仍是評估基準；感知、武感、氣感、專注、親和／共感、工巧均先列備選，沒有全部採用。

後續追加研究：東方不敗／黃藥師／周伯通等與個性、價值、經歷見[心性設計](CHARACTER_PERSONA_TRAITS_DESIGN.md)。擁有人進一步提出開局問答可給有感甚至較強的隱藏特性，再經歷練分支，並以九劍／降龍的不同偏好檢查學習條件；詳[天賦支系與武學清單](CHARACTER_TRAIT_PATHS_PROPOSAL.md)及[公版武學模板](MARTIAL_ART_PUBLIC_TEMPLATE_PROPOSAL.md)。本文件v0數字仍只是紙上假設，新增隱藏特性不自動回寫先天值。

## 1. 本輪方法與結論

先問「希望這兩人在同一件事上有什麼不同」，再找可解釋差異的最少欄位。人物模板分為：

1. 稟賦：學習傾向／身體發展潛力；與起始力量、現在跑速不同。
2. 開局經歷：年齡階段、已學技術、知識、師承、傷勢與已有功力。
3. 性格與目標：願不願意練、喜歡哪種生活、對人的態度。
4. 劇情／特性：覺醒、傳功、奇遇、特定學習方式等；說清是潛質還是事件所得。

**現有數字能區分郭靖式與令狐沖式的大類，尚不能證明足以區分所有天才。** 最先處理悟性是否混入交際機靈、定力是否混入守規矩，以及根骨是否只是體魄別名。這些語義未清，多加一列分數只會複製混淆。允許同型天才有相近甚至相同的先天值；不同技術、經歷、性格仍能形成不同人物。不得為猜出名字而硬拉開分數。

「先天數值能否區分」本輪只完成靜態辨識與紙上反例，沒有同條件運行三版、也沒有確定新公式。原著沒有本表的官方數值；以下人物特徵是遊戲設計假設，不是文學定論。

### 4.1 候選量尺與小型紙上數值探針

先用兩個**待評學習維度**驗證是否有必要，不新增六角：理悟（理解／類推原理）與武感（在交手中察覺、適應變化）。量尺只供紙上比較：**1偏弱、2較慢、3一般、4突出、5頂尖**；未知用「？」而非0。

以下數字是為測機制設的**假設性對照設定v0**，不是原著官方評分、不是三版原值換算，也不是批准新模板。沒有依據的項不強填；後續作者可以有理由地推翻，不能先拿它們改系統。

| 同段講解／同種新套路 | 時間、教師、起始知識、體力 | 理悟候選 | 理解進度不同；不是立即獲得熟練或傷害 |
| 同種陌生交手變化 | 已學招式、速度、傷害、對手 | 武感候選 | 能否較早認出變化／選適當已會招式；不直接保證命中／勝利 |
| 同篇招式回憶 | 閱讀量、理解、背景知識 | 強記候選 | 回憶細節不同，不直接提高力量 |
| 同基線前後傳功 | 稟賦、人格、身份 | 已有功力 | 虛竹型結果變強但先天不變，驗證沒有把成長倒寫 |
| 同人兩條創建路徑 | 角色身份與階段 | 主角／客卿初始化來源 | Grok韋小寶wu3／1差異要能解釋；若作者有意分階段就保留註記 |
| 同悟性、不同意願 | 學習率、技能、資源 | 自主練習時間／志向 | 日常進度不同，證明不用把勤勉再塞入悟性 |

只做這些紙上反例與來源檢查，不建立每角色×所有武學的巨量矩陣。真正工程另授權後，先對採用欄位驗一個正例及一個容易混淆的反例，復用既有測試，不為研究啟遊戲／瀏覽器或跑整套seed。

## 5. 社群／開源可借鑑的做法

核讀2026-10-26；這裡借設計分工，沒有選作依賴、移植程式或素材。

- [Dungeon Crawl Stone Soup官方手冊](https://github.com/crawl/crawl/blob/master/crawl-ref/docs/crawl_manual.rst)：species的學習aptitude與background的開局已學技能分開。可借「擅長學什麼」與「已經學過什麼」兩份資料，不把其種族規則原樣套到人類或強迫用多種族。
- [Battle for Wesnoth官方traits定義](https://github.com/wesnoth/wesnoth/blob/master/data/core/macros/traits.cfg)：quick改機動、intelligent改升級經驗需求、resilient改生命承受，少量具體特性就能產生用途差異。可借「可說明的效果＋條件」，不必人人一套十幾項雷達；不搬回合制數值或認定天才都必有代價。
- 原先[經典研究](CHARACTER_CARD_CLASSIC_REVIEW.md)已核《天下霸圖》／《金庸群俠傳》的原手冊與實作參考；本輪沿用，不重找截圖／重跑遊戲。借分層，不能因傳統遊戲一個資質門檻，就把本案所有學習、性格、知識塞成同一資質。

本案推論：**少量核心資質＋有條件的學法特性＋開局經歷＋可成長本領**，比持續增加泛用屬性更值得先驗。這是本PO的設計建議，非開源作者替本遊戲定案。

## 6. 備選清單與下一輪交付

| 候選 | 狀態／啟動條件 |
|---|---|
| 武感／動作領悟 | 優先紙上驗：原悟性與既有技巧無法表現的理路／臨戰差異；不等同生活感知 |
| 記識／強記 | 新增研究備選：王語嫣型反例；先評特性是否足夠 |
| 感知 | 備選：巡山／採藥情境有獨立效果時再驗，不因本輪順帶實作 |
| 定性／專注 | 備選：先與既有定力／勤勉去重 |
| 氣感 | 備選：有靈氣觀察／引氣玩法與不同結果才討論 |
| 親和／共感 | 備選：先區分說服技巧、意願、情緒辨識與關係 |
| 工巧 | 備選：先區分動作協調、已有製作技術及成品品質 |

下一輪順序：①核根骨／體魄→②核悟性→③核定力→④回看力量／身法／耐力起點→⑤檢查福緣與劇情→⑥只對仍解不開的角色差異選新增特性／維度。可逐項與擁有人確認，不為一次研究全部批准。

GPT／Grok的#340舊報告保留，僅補本輪角色對照；Gemini核未回部分。每方最多挑三組有用的角色反例，附固定HEAD、原值／真用途、可沿用／歧義／缺項、建議不加／改標籤／加特性／加維度及原因。禁止直接改模板、加入新角色、創造共同成長公式或互合分支。新[差異提示詞](CHARACTER_CARD_AGENT_PROMPTS.md)供擁有人手動貼，沒有代送／啟動agent。

存檔升版、手機適配繼續最後；本研究不是任何已批准開發包的新阻擋條件。共用素材仍歸#339未排程，不在本輪搬圖。
