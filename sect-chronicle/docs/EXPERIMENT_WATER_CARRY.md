## 要讓玩家看到什麼

一條 2.5D 山路連著道觀與泉水，一個人帶兩個水桶：**空桶下山 → 停下裝水 → 滿桶負重上山 → 倒入水缸 → 完成一趟並成長 → 下一趟更輕快**。不用逐趟派工。先讓人看出「勞動累積成長，成長回饋下一次生活」的樂趣，驗證畫面與節奏，沒有先證明好玩或完成正式平衡。

預設 1×，展示約一至兩分鐘內能看到數趟與清楚差異。這是原型體驗目標，不是正式遊戲日長、開發工期或人物能力定值。第一個可開頁面就交短展示，不必先完成整組世界驗收。

## 五個小任務，一個原型 PR

| 任務 | 最小內容 | 驗收出口 |
|---|---|---|
| T1 場景與循環 | 一人、一本道路、泉水、水缸／道觀；真實走路、取水、負重、倒水並自動重複 | 觀看一趟即可說出誰在做什麼，沒有瞬間取水／到站前收成 |
| T2 工作帶來腳力 | 只用一個腳力／挑水熟練維度，整趟完成時入帳／成長一次，有速度上限 | 下一趟同距離／同載重實際用時縮短，沒有重複入帳或無限加速 |
| T3 生活表現與對照 | 有腿部步態、肩擔／桶擺動、空滿水差、取／倒水動作與少量成長回饋；初始能力對照影子 | 不看數字也能辨認前後差異，並能在同播放倍率比較；對照不產出 |
| T4 控制與簡潔資訊 | 開始／暫停／繼續、重來；目前動作、腳力、累計水量／趟數、趟耗時、個人速度倍率、播放倍率 | 暫停零進度；重來還原；速度變快的原因可分辨，按鈕鍵盤可用 |
| T5 展示與交付 | 可直接開的頁面、短步驟、真實截圖、實際耗時比較、少量必要測試、README／來源 | 遊戲 PO 能用約一分鐘看懂核心；擁有人看過再決定調整、延後或正式採用 |

先做到 T1～T3 的可見效果就交中途 URL／截圖與缺項，再收尾 T4／T5。這些是實作步驟，不必拆成五張 issue 或五個 PR，也不要因此預占五個作者租期。

## 極小原型規則

- 一條固定路線、相同距離，不做 A*、避障或多人交通；坡道可以畫出高低，但不在本包增加另一套地形公式。
- 空桶與滿桶分開顯示；滿桶套固定、正值的速度折減，水量每趟固定。腳力只影響移動速度，先不增加容量、裝水／倒水速度、品質或所有工作收益。
- 只在回到水缸並倒完本趟後增加水量與成長，各一次。新速度從下一趟使用；一趟內不突然跳位置或修改已走路程。初期可明顯進步，之後封頂／減緩，不實作凡人瓶頸、突破或正式經驗系統。
- 初速、距離、負重係數、裝／倒水時間、每趟成長與上限集中在一個清楚的小設定；作者選合理展示值、在 README 明標並說明。速度必須有限且大於零，不能負速／除零。數字僅 demo 值，不回寫正式規則表。
- 每趟記實際出發／裝水／返回／倒完時間。報告初始與成長後的**整趟耗時及移動段耗時**，兩者不同，固定裝倒水時間仍有成本。不要把理論速度倍率直接當整趟產量倍率。
- 初始對照以當前趟的同一出發時點、路線、載重與裝倒水條件，用初始能力推算淡色影子；標「初始能力對照」，到終點停等，不生產、不成長、不占工作位。影子只供比較，不是新增 NPC 或第二套世界。
- 單一原型模擬時間／固定步進驅動位置與工作；render／步態只呈現該狀態。暫停時模擬、入帳、成長及對照都停止；頁面在背景時自動暫停，返回保持暫停、不補時間。重來清空模型與對照，不受舊 callback 影響。
- 2×播放可選，預設與主要比較用 1×；畫面分別標示播放倍率與個人速度倍率。先不加慢速／快轉控制器的全套抽象。

## 測試與交付成本

局部測試合併情境即可：抵達／裝水／倒水先後及每趟只入帳／成長一次；相同路線與載重的前後耗時／速度上限；暫停／重來不殘留；不同 render 頻率在同固定步進下結果一致。沒有隨機就不增加 seed 矩陣。測試放原型資料夾，以 README 的 `node --test sect-chronicle/experiments/water-carry/model.test.mjs` 重跑，不改主線 test runner 或 CI。

真實瀏覽器看一輪初期與成長後、初始對照、暫停／繼續、重來、背景返回、主要按鈕鍵盤與 console。選一個代表性窄視窗確認可操作即可，不另立完整跨裝置矩陣；自動檢查若有，失敗需非零退出。保留根目錄要求的基本檢查與必要 CI，不重跑長 RT 世界矩陣、不做逐幀 snapshot 大包。輸出落檔，回報 head/base、命令 exit、實際比較與限制。

啟動方式：從 repo 根目錄 `python3 -m http.server 8770 --directory sect-chronicle`，開 `http://127.0.0.1:8770/experiments/water-carry/`；作者先確認埠未占用，占用就選其他空埠並回報，不停止既有 viewer 服務。純靜態展示，沒有新增 build 或模型服務。

交付至少包含本機入口、30～60 秒看法、初始與成長後的真實畫面、同條件往返／移動耗時、小量驗證摘要、素材來源與未完成限制；不能只交測試綠燈或錄製動畫。效果由擁有人看過後評價，不以產量增加宣稱已好玩。
