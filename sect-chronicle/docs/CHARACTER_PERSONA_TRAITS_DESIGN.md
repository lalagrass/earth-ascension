# 心性、價值與隱藏特性：共用人物卡補充提案

狀態：2026-10-26，擁有人授權的**研究／設計與紙上評估**，主[#340](https://github.com/lalagrass/earth-ascension/issues/340)，延續PR #341。不改系統、模板、數值、問答、UI、存檔或既有開發包。新角色是對照樣本，不是runtime新增。前述新能力仍列候選；本文件的路線／特性名稱都是待評例子，不是已批准玩法。擁有人後續追加的「開局問答給較強隱藏特性→歷練分支」已納入研究，詳細角色與支系見[支系提案](CHARACTER_TRAIT_PATHS_PROPOSAL.md)，不沿用「開局只能給弱提示」的限制。

## 1. 建議：同一張人物卡，加入可共用的心性子面板

人物差異由「稟賦＋開局所學／身體狀況＋心性與價值＋經歷／當前目標」共同形成，不能要求先天分數辨認所有人物。建議維持公版既有兩主入口：

| 主入口 | 子區塊 |
|---|---|
| 生活總覽 | 正在做什麼／原因／下一步、身心狀態、**心性與志向**、已知相處事件 |
| 武學成長 | 稟賦與身體能力、已學技術、實戰紀錄、**已發現／已獲得的特性** |

「心性與志向」可作獨立呈現元件，供創角預覽、遊戲中人物卡、兩人比較重用；不是另建一套角色核心或強迫三版統一人格公式。先約定唯讀資料語義，再另選工程。立繪、頭像與地圖sprite沿[素材提案](CHARACTER_SHARED_ASSETS_PLAN.md)，不再建第四個素材庫。

精簡卡首顯示兩項已知性情、最重視的一至兩項價值、目前志向；展開才看細分、來源與改變。不是再加一張人格六角戰力圖。陌生NPC只顯示已知部分，不能讓共用面板洩漏真性格、稟賦或尚未發現的特性。

## 2. 東方不敗與其他經典角色：擴充對照，不補滿天賦數字

東方不敗已在Gemini傳奇登錄與Grok劇情中，這次提升為主要研究對照；周伯通、小龍女、喬峰、林平之等也已有部分登錄，不寫成「新實裝」。黃藥師、歐陽鋒、任我行、程靈素在本輪核讀池中未確認完整可選模板；先作新增紙上樣本，不以名字／圖片存在判斷已實作。

以下是遊戲設計用的角色解讀假設，需固定作品版本與故事階段；不冒充原著官方人格／數值，未知可保留。

| 對照角色／階段 | 用來檢查什麼 | 不能靠一個數字／標籤帶過 |
|---|---|---|
| 東方不敗：修煉有成、已掌教之後 | 高速招式／精密施展、當前牽掛與教主職責可分離 | 葵花武學造成的快是已學能力，不能直接倒推先天身法滿值；不同時期不必一直追求掌權 |
| 黃藥師：成熟多藝者 | 學習興趣、創造／跨領域知識、重視自主或自身準則 | 琴棋醫藥陣法多為累積技能，不全塞高悟性；不按是否守禮判善惡 |
| 周伯通：習武遊戲化的階段 | 貪玩／好奇與高武學成就能否共存 | 貪玩不等於學不會；左右互搏是特定學法／已學武學，不由「低智力」自動獲得 |
| 喬峰／蕭峰：承擔群體責任的階段 | 臨戰表現、重情／責任與身份衝突 | 忠於群體與救具體的人可能衝突，不是一個俠義總分解決；喬／蕭同一身份沿階段記，不複製兩人 |
| 小龍女：古墓生活至建立牽掛的階段 | 社交主動低與深厚特定關係能否共存 | 內向不等於無情、低同理或低悟性；雙劍／步法是所學 |
| 林平之：遭遇前／後兩張快照 | 經歷如何改變目標、風險取捨與對人的信任 | 復仇志向不是出生人格；辟邪所得不倒填根骨，改變不默認永久不可逆 |
| 程靈素：醫藥／照護對照 | 細察、醫藥知識、關懷動機與非正面戰鬥貢獻 | 不用武力低判整體資質差；醫術與已學毒理不是同一個善惡屬性 |
| 歐陽鋒：求武階段與受創後分開 | 武道目標、承擔風險、特殊經歷與失常狀態 | 暫時／事件狀態不當作生來人格，不把強迫求勝或傷病混成悟性低 |
| 任我行：掌權／復位目標的階段 | 權勢控制、組織目標、親疏關係 | 「門派」價值不必等於服從現任掌門；權勢可作未來價值擴充，不默默替所有角色新增必填軸 |

性別認同、情感對象、身體經歷與武學代價分開記，不從其中一項推出人格、善惡或天資。東方不敗的案例尤其用來測這個分類邊界，而非建立身份到戰鬥加成的對應。

與前輪王語嫣、虛竹、石破天、張三豐合看：同型天才可同分，角色仍因所學／關係／目標不同。不同天才如「廣泛知識」「臨戰應變」「特殊學法」能用有來源的不同資料表示，不要求每人一項專屬隱藏天賦。

## 3. 除了數值，哪些資料值得共用

| 層 | 回答的問題 | 候選內容與變化方式 |
|---|---|---|
| aptitude／capability | 擅長學什麼、身體做得到什麼？ | 根骨、原悟性、身體能力，沿各版真規則／原量尺；不因答題自動提高 |
| personality／性情 | 習慣怎樣回應？ | 社交主動、審慎／冒險、規整／隨興、情緒反應、嘗新偏好是研究候選，不要求五軸全加；可有長期基線與短期狀態 |
| values／價值 | 衝突時較重視什麼？ | 可先參考Grok已有俠義、門派、情義、自在、武道、名望；不訂共用總和100，保留負值與原義；關懷／求知／權勢僅擴充候選 |
| aspirations／志向 | 這段人生想完成什麼？ | 修成一門、守護家人、重建道館、復仇等；可由事件與選擇改變，不等同所有時候的固定行動 |
| experience／relations／culture | 為何現在是這樣？ | 師承、已學、承諾、親情、事件與文化參照；文化可給背景／初始傾向，不替每個人定性 |
| traits／特性 | 有什麼穩定而具體的規則或敘事差異？ | 強記、特定學法、已獲稱號、身體潛質等分來源；另記僅文案或有真效果，避免標籤看似有buff |
| state | 現在受什麼影響？ | 疲累、受傷、情緒、威脅；不能當一生定論 |

「性向測驗」在本提案解作**角色性格／志向情境問答**，不是對現實玩家的心理判定。MBTI、八卦、心印／判詞可作可選摘要或敘事外觀，從同一組資料投影，不能再生一套祕密戰力。內向不降低勇敢、善良不自動增加根骨，類型不鎖職業／戀愛或武學。

同一個「武」要分清：Grok stats.wu是悟性，values.wu是重視武道；共用資料必須用不同語義ID，不能依中文相近或同key對接。

## 5. 問答怎麼設計才有生活感

建議先用少量不同情境的問答，既有五／九題可保留再評，不要求三版同題同長。題數／權重／門檻未批准。

1. 每題呈現兩種合理但有成本的優先順序，例如「先補破護欄／先照料受傷同伴／先確認危險再求援」；不要一個好選項對一個明顯壞選項。
2. 題目可形成性情、價值、初始志向，並作開局隱藏特性生成的條件之一。特性可有感甚至較強；原稟賦配點／既有角色基線另記，不能把特性效果偷偷改寫成高根骨。
3. 相近主題在不同情境再次出現；保留回答是混合或不明確的可能，一題不能決定整個人格。這不是經驗驗證過的心理量表。
4. 結果先給可讀預覽，例如「偏好先觀察、重視家人、想把道館修好」；允許玩家調整或改用直接設定，不把測驗變成最佳答案猜謎。
5. 同等稟賦的人可因價值不同而選不同生活；玩家指令是具體選擇，不能被人格硬擋。安全／精力／可用資源與明確叫停仍服從既有規則。
6. 後續真正行為／關鍵事件可提供人物改變的證據；不因一次取消、一次危機選擇就翻轉人格，也不每日重算類型。若要改長期價值，另定規則與可回看原因。
7. 問答結果需在生活中被看見，例如有人先巡視、有人先照護、有人先觀察；不能創角完只剩一張貼紙。相同需求下的行動差異先沿核心權重評估，不在UI私自排程。

## 6. 根骨＋心性能否開出隱藏屬性？

可以設計，但建議叫**潛質發現／特性養成**，分清三種狀態：

| 類別 | 是否原先就存在 | 如何呈現／何時生效 |
|---|---|---|
| 未知的稟賦 | 若核心原本已生成，發現只增加認識 | 發現前就有的效果不能在揭露時再加一次；發現條件不能倒改出生值 |
| 達成條件才獲得的特性 | 沒有；是新獲得 | 經歷／學習／選擇滿足後才取得，記來源與時間；叫後天特性，不偽稱先天 |
| 暫時觸發的狀態 | 依當下情境而有 | 例如受威脅時警覺；不寫成永久解鎖，亦不每tick重複授予 |

可以讓稟賦／學法影響適應條件或成長方式，讓價值觀影響願不願意投入，再由實際經歷取得成果。依擁有人追加構想，**問答可以給有感甚至較強的開局特性，再經歷練分支**；具體方案見[天賦支系提案](CHARACTER_TRAIT_PATHS_PROPOSAL.md)。不設唯一最強答案路線；不同性格應有可行途徑，且能透過明確行動另尋路線。原分支已有門檻如實記，不以本提案擅自取消或新增硬門檻。

### 紙上路線例（名稱、條件與效果均待評）

| 例子 | 可能的條件與資料角色 | 類別／取捨 |
|---|---|---|
| 抱樸厚積 | 適合反覆學習的稟賦／學法＋多次有效練同套路＋師承指導；勤勉傾向只讓自主投入較常發生 | 後天學法特性候選；不因低悟性直接送補償buff，不把按鈕重複點擊當有效練習 |
| 觀變知機 | 武感候選／既有理解＋真實接觸不同變化＋有紀錄的領會 | 後天特性候選；不是社交外向獎勵。若原悟性／熟練已能表達，就不另造一份加成 |
| 潛質初見 | 核心已有未知根骨／潛質，在安全修行或師長觀察後獲得線索 | 只揭露既有資料；不要求瀕死刷天賦，也不將推測說成確定值 |
| 守望相助 | 重視照護使人較常幫忙，真照護／守護事件累積形成稱號或熟練 | 後天事蹟／技能，不新增「天生善良＝高戰力」；D53女孩鼓勵仍無buff，本例不擴其工程 |

若未來要用機率，只由各版權威核心在有效事件處處理，並記結果；開人物卡、重畫UI或重複讀快照不重擲。種子與正式保存規則屬後續工程範圍，本輪不新增。

解鎖規則要能表達前置、可替代路徑、互斥與效果來源，但**先交三個紙上例就好，不建完整天賦樹／條件語言**。同一事件只認一次，重複觸發不疊加；多個buff若影響同一學習率，須另定疊加順序，不能先假設全相乘。

未知、未發現、尚未獲得、已獲但未啟動是不同狀態。完全未知的祕密不因空卡數／問號輪廓暴露；獲線索才顯示提示，已發現特性才顯示用途與證據。隱藏資料在送UI前遮罩，不能放tooltip／DOM假裝沒顯示；透露哪些前置須由核心可見資料決定。

## 7. 公用面板與資料邊界

共用的是**人物資料的唯讀投影與呈現元件**。人物核心、問答評分、行動決策、條件判定仍由各分支負責。

| 資料 | 共用面板需要什麼 | 邊界 |
|---|---|---|
| 身份 | actorId、來源分支／HEAD、人物與故事階段 | 同名、同圖不等於同一人；年少與成熟以來源說清 |
| 性情／價值 | semanticId、原標籤／量尺、已知值或描述、來源／已知程度 | 同名不同義不強合；不把缺值補中間值，不把persona.current當當下情緒 |
| 志向與行動 | 當前目標、核心提供的現在／原因／下一步 | 面板不另算人格AI／風險選擇 |
| 特性 | ID、來源類別、已知／獲得／啟動狀態、效果說明／僅敘事、真事件來源 | 展示「發現」與「獲得」不同；不在渲染時grant或判隱藏條件 |
| 問答預覽 | 答案結果摘要、可調整的公開項 | 創角確認前只改草稿，確認由核心正式創角；不改已運作世界 |
| 經歷／變化 | 可公開的事件與時間；沒有歷史就顯示資料不足 | 不用當前數字反推人生，不為研究新增存檔格式 |

創角與遊戲中人物卡可重用小卡／條形／標籤元件，但編輯權不同：創角可調公開草稿，遊戲中按正式可用指令；NPC不因共用元件獲得任意編輯。先作三版各一份adapter評估，**沒有決定現在發布共用套件或強合三個核心**。MBTI／卦象／判詞只是可插拔敘事區，隨來源標註，不能冒充已驗的人格心理測定。

## 8. 社群／開源參考與限制

核讀2026-10-26，借資料分工與設計方法，未安裝／移植：

| 來源 | 核實內容與可借用處 | 本案邊界 |
|---|---|---|
| [ScummVM Ultima IV創角實作](https://github.com/scummvm/scummvm/blob/master/engines/ultima/ultima4/controllers/intro_controller.cpp) | startQuestions／doQuestion以德目取捨形成questionTree，initPlayers讀結果決定職業 | 支持情境問答可形成角色方向；不照搬職業鎖定或八德成勝利條件，不把問答當真實心理測驗 |
| [DFHack人格編輯](https://github.com/DFHack/scripts/blob/master/internal/gm-unit/editor_personality.lua)與[價值／信念編輯](https://github.com/DFHack/scripts/blob/master/internal/gm-unit/editor_beliefs.lua) | facets與values分開；信念編輯可標示文化預設來源；set-personality另分基線與當下修飾值 | DFHack為開源工具，Dwarf Fortress本體不是本案可直接搬用的開源引擎。借分層，不搬數十軸或把文化決定個人 |
| [CDDA特性資料文件](https://docs.cataclysmdda.org/JSON/MUTATIONS.html) | 定義前置、互斥、後續變化與角色畫面是否顯示等欄位 | 支持規則與顯示分開；不搬變異玩法，player_display也不等於本案已完成資訊遮罩 |
| [Project Horseshoe 2009設計討論](https://www.projecthorseshoe.com/reports/featured/ph09r3.htm) | 分析價值衝突題與Ultima IV，指出答題若只剩職業／能力最佳解，可能失去倫理取捨的意義 | 借兩種有道理選擇的設計與後續行為回應，不聲稱是適用所有遊戲的實證結論 |

設計推論：數值回答能力、性情回答回應方式、價值回答優先順序、經歷回答如何改變；少量具體特性連接它們。資料可共用呈現，但不要把開源系統整套搬來才開始生活玩法。

## 9. 評估交付與未決事項

三方僅補本輪差異，不重做舊報告，各至多三組對照：

- 能力接近、價值不同：例如令狐沖與另一高悟性者，行動／選擇怎樣不同？
- 性情接近、經歷不同：例如內向角色與小龍女的不同所學；不能都變成不關心人。
- 一個隱藏特性例：先說是發現、獲得還是暫時觸發，資料主權／效果／可見程度與成本，不新增程式。

紙上只核六個反例：同根骨不同價值、同價值不同能力、未知潛質揭露不重加效果、經歷改目標不改出生、重複事件不重發特性、UI遮罩不漏祕密。不跑九角色×所有屬性×所有問答的矩陣，不啟瀏覽器／服務。

待擁有人逐項確認：首批性情／價值語義；問答是否允許預覽調整；優先做發現或後天學法；首批三條路線與顯示程度。**本文件不批准數值門檻、特性效果、稟賦重寫或新人格AI工程**。存檔升版、手機適配繼續最後，既有D53親情／無鼓勵buff與單一試玩入口保持。
