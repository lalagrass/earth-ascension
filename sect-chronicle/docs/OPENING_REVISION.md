## 2. 開局與人物模板

- `newWorld` 接受可序列化 characterOptions：templateId、三屬性配點、兩軸性格；預設配置可直接開始。
- 所有模板採同一總預算與上下限；服務端不是本版前提，但純引擎也必須驗證，不能只靠 UI 擋超額／負點／未知模板。
- 相同 seed、相同角色設定、相同有效指令才保證相同結果。角色設定是回放輸入，換模板不是同一實驗。
- 模板預算、加點上限與性格枚舉的分工：SG-01 驗證結構、型別及暫定常數約束，常數先在 `js/state.js` 以「先宣告的暫定常數」（`CHARACTER_OPTION_LIMITS`）提供；SG-02 才凍結數值、移入 `js/rules.js` 並升 ruleVersion，凍結後的變化須在 PR 說明。SG-02A 負責性格對應的事件文案資料，不改數值。
- 謹慎／果敢影響事件建議與台詞，獨立／重情影響求助或合作表達；玩家仍可選任何合法行動。切片不把人格綁成隱藏勝率加成或強制行為。
- 舊模板欄位尚未逐項核對。SG-02 先盤點可取得的舊模板來源；有來源則列映射與不採用項，無來源則清楚標為本版新模板，不因缺檔停止已批准的骨架開發。

## 3. 復甦、援助、招募與立派契約

世界候選階段：日 1 起微弱、日 4 起初兆、日 7 起顯化、日 11 起獸患升溫；切換發生在該日第一格開始前。階段表與倍率由 SG-02 記錄，首次實驗前凍結。階段只隨 slotIndex 決定，不因點擊、倍率、建築或主角成長而倒退／跳級。第 1 天修行仍有可見進步，不能因「尚未復甦」完全停滯。

每階段至少一項可核對效果：修行係數變化、草藥點解鎖靈草產出、獸患資訊更新。山川草木／野獸的變化用有限事件與資料表表現，不模擬完整食物鏈。地圖不因劇情隨機洗牌；未解鎖靈草時 UI 說明缺口，必需材料須有可達取得路徑。

援村是同一時段引擎中的有限工作，例如協助村民建立防護：占一人一格，無額外戰鬥系統；完成時記錄來源、日期與一次性村民物資，不得透過重選事件重複領取。確切材料成本／獎勵由 SG-02 決定，保留零材料也可完成的援助入口，避免招募前置形成資源死鎖。

招募條件：已完成援助且進入日 7 後，依穩定事件 ID 依序提供兩名固定學徒。每次邀請只觸發一次；可接受或稍後，延後候選可再從候選面板接受，不每天強制重彈。招募通知若進入 awaitingChoice，先以 chooseEvent 確認／稍後並返回 planning，再由候選面板接受。不做招募抽卡、人口生成或好感門檻。入隊時點採單一規則：`acceptCandidate` 只在 planning 階段接受，記錄 `joinSlotIndex` ＝ 接受當下的 `world.slotIndex`（尚未結算、下一次 advance 要結算的那一格）；該角色從 `joinSlotIndex` 起可排課並被結算，不補發 `joinSlotIndex` 之前任何格的產出。待選危機（slotIndex = 42）時不能再接受，最終獸患優先。候選在接受前不能排課、支援或被計入戰力。未收滿四人仍能完成結局。

第 14 天晚的最後一格結算完後停在待選危機，slotIndex = 42；選布陣後結算獸患並進 ending，不再多走第 43 格。此前 UI 是道館／村莊；勝利後記錄正式立派及村民支持，主角為首席弟子。失敗則記錄保全／撤離、立派暫緩，不偷偷把 phase 或組織狀態改成成功。結局選擇與 RNG 都只結算一次；師父不死於腳本交棒。
