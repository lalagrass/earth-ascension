路線由作者在既有畫面院外選一條短且可讀的固定折線，防守點在護欄內側、野豬接觸點在外側，位置清楚相鄰。可先以約250單位的人路、240單位的獸路估算：Lv1約4.17秒／Lv3約3.36秒到點，野豬靠近約3.33秒；**這是紙上路長估算，非必須湊足的幾何／效能驗收值**。最終記實際座標／路長，模型與畫面共用；不改舊採集／石凳／休閒路線，不加A*／剛體／門禁或另一張戰場。

同tick優先語義：先完成已發生的工作交付／角色移動及其一次結算，再判野豬誘因／逃離門檻；已應逃離／退走的目標不能被喝止補算成功。否則有效喝止若同tick完成，先加威脅並逃離，取消尚未接觸的本次衝撞；再否則處理到期接觸一次並扣精力／加損痕，接觸後再查逃離。精確程式可沿既有單一tick薄整合，但不得因人物遍歷／render順序重複撞擊、雙成功或漏交付。

不另加血條：首片沒有真攻擊／傷害來源，血量降到某值逃跑留給LD03。此處用精力與威脅實現擁有人要的進退；不能宣稱已受傷、可擊殺或完整生態。新局預設有水、無介入且無其他變化時，60→80約需40遊戲秒；這只是條件成立的推算，不把40秒寫成首訪觸發。野豬恢復滿但資源已空／威脅未消退，仍不回來；相同條件可能有規律，不假稱隨機自然史。

## 指令與生活交接

只一個有限驅離意圖、來訪識別與最新返回工作；不建通用工作佇列／戰鬥AI。同一來訪最多一位指派者；另一人可照常生活。重複派同一人不重啟路程／1秒動作，第二人申請明示已由誰處理；需先改令取消原指派再派別人，不搶跑雙重結算。

| 情境 | 已定行為 |
|---|---|
| 工作中派遣 | 本趟完整交付→一次收益／成長／釋約→必要恢復優先→目標仍有效才出發；不半途丟包。已接受的最新工作保留為返回工作，例如挑水中先改採藥再派遣，原挑水仍完整交付，驅離後回採藥，不吞先前改令 |
| 休閒／其去返途中派遣 | 活動點下一tick返院；已在去程先走完本腿，返程只更新意圖，不重啟。返院後再查有效目標／精力；驅離不算完成LP05叫回後的新工作趟次 |
| 精力／玩家停工 | ≤30或已有必要恢復時先走LP04至80；驅離／恢復自主不能清恢復來源。已手動停工或有待停工指令時派遣拒絕並明示原因；依現有明確開始／取消待停工解除後再派，不暗中徵召 |
| 較新改工作／開始／停工 | 取消尚未完成的驅離意圖／目標綁定；已在防守去返途中走完當前腿再回共同院中端點，套最新工作或LP04恢復／停工。正在喝止則取消未完成效果，不能又驅離成功又執行舊命令 |
| 取消待執行／恢復自主 | 取消待執行可清尚未生效的驅離預約，不取消已在走的路或解除停工。恢復自主仍只清LP05叫回，不取消有限驅離、不清manual／必要恢復。不為防守擴大「叫回工作」可用狀態；進行中可用改工作／停工結束 |
| 目標過期／誘因消失／自行逃離 | 退走開始即不再接受該來訪派遣／成功；未離開工作／恢復者清過期意圖照原流程。已在返院或防守路上者走完當前腿、再返院，不等下一次、不瞬移、不追獸。嗅探去程尚未結束者清意圖後沿原LP05合法轉場，不憑空生成新路腿 |
| 完成／晚到／返回 | 成功或目標已走均有結果文字；從防守點實際返院，重查最新工作、在途／容量／公平輪替、必要恢復與LP05叫回來源；不保證原工作有空位。未被新令覆蓋的原工作／叫回仍有效，不把驅離當免費解除待命的方法 |

出發／返回分別鎖人物當下既有空手速度與實際路長；防守者不持工作容量。目標過期後新來訪不能承接舊指令；同一隻野豬可以有新來訪識別，但不能被當成新生成的個體。暫停下令只改意圖或零進度狀態，位置／精力／威脅／收益／動作進度全不推進。

## 畫面、範圍與交付

同一入口顯示野豬的「棲地恢復／觀察／靠近／撞護欄／逃離」、精力與威脅記憶、當前原因（資源誘因、累了、害怕、院內已空）；不用倒數「下次襲擊」。棲地可用小狀態卡顯示，不把畫外恢復當成角色消失重生。精力／威脅條與非功能損痕區分，不標獸血量／房屋耐久。

## 六組必要驗收與成本

1. **狀態決策**：棲地恢復與邊界80／20、誘因實存而非在途；精力夠但害怕／兩庫皆空不出發。從預設新局自然形成一次來訪；無固定首訪／回訪計時器。攻擊耗18、移動每秒−1、回棲地才恢復；攻擊前／後≤30或威脅≥60能離開，逃離不中途折返。高低到場精力導致可做次數不同，不硬寫撞三下。
2. **有限損失／收益守恆**：一個體一來訪一指派者，事件冪等；損痕最高3、無功能／人傷。不介入多次狀態循環仍可工作／恢復／閒暇；驅離往返等待無精力與資源／XP／趟次收益。工作照完整交付一次與正確釋約，不因跨狀態漏算或重算。
3. **意圖／過期**：少量代表組合涵蓋工作後派遣、必要恢復／停工拒絕、休閒叫回交接、途中新令取消、獸已退走的晚到與重送／第二人；保留最新工作／LP05叫回來源，新來訪不承接過期令。重點保留LP05「停工→開始／改工→恢復自主」不跳過80、不死鎖的反例，不做所有指令全排列。
4. **真移動與同tick**：人受出發空手速度、獸按72／120與實際路長連續位移；暫停下令不移動、無遠端驅離／畫外命中。喝止與到期接觸、自然退走相遇時按上表只結正確一次；到防守點不等於成功。返回重查容量／公平輪替，不能瞬移、超額或負預約。
5. **單一時間／新局**：同固定遊戲時間的分幀與1／2／4×狀態等值，暫停／背景不推進也不補時；重來清來訪／目標／指派／路程／損痕／預約，野豬回棲地E60／威脅0、兩人E100／Lv1與Lv3、水3／8藥0／8。無新RNG不造seed矩陣，未變背景handler證據復用。
6. **一次桌面＋390px真操作並開圖**：同入口看到自然靠近→未及處理、精力下降後逃離→棲地恢復與原因→下一次指派→實際抵達／喝止或晚到→返回生活。看得出不同速度與兩種結果，清楚不是血量或耐久；窄畫面只驗受影響可選／原因／操作，不重演全部桌面流程。長恢復與誘因空缺的邊界用局部模型驗，不縮恢復速率／改資源造展示。

約2～3分鐘真人展示可用正式4×，不保證每次剛好趕得上；可遊戲內先讓一人採藥或在休閒時派遣，記實際條件，不能注入精力／縮路假稱自然。Lv1與Lv3速度差可用同一實際路線局部配對，不要求真人重跑完整兩局。

必要局部模型／受影響素材、主線快驗 `node --test sect-chronicle/test/*.test.js`、根Python／m2語法／diff與適用CI保留；未變舊RT長矩陣、atlas及背景證據復用。完整log落檔只報摘要／失敗／少量實圖，保留strict真exit、ReadPixels GPU／CDP限制與未驗項，不過濾警告、降門檻或反覆追綠。紙上估算不當已實測或玩家接受。
