## 規則與指令交接（P1–P4 已採用）

### 單一決策順序

完整交付與一次入帳／成長／釋約 → 套最新待執行意圖 → 玩家停工沿 LP04 → 精力≤30沿 LP04 → 若有合法容量按既有公平輪替出發 → 若玩家叫回待命則明示等空位 → 若**實存量**已滿則去偏好活動 → 其餘仍院中等待（例如空位已被在途預約）。不自動切換另一份工作。

工作在途中照 LP04 完整交付，不能因另一人填滿庫存而截斷／吃掉已預約收益；只有院中決策點才選閒暇。休閒全程不持有工作容量預約，回院後依當時庫存／在途與公平規則重新競爭，不能預留空位或保證叫回必搶到工作。

最少區分「去偏好活動」「進行偏好活動」「從休閒返院」「院中叫回待命」；保留原工作與一份最新指令，不建立通用 JobQueue、第二份 AI 時鐘或多層意圖堆疊。叫回待命獨立於 LP04 的玩家停工；不能用同一個 `rest` 原因混寫。

| 情境 | 行為／指令結果 |
|---|---|
| 進行休閒，原工作出現可用容量（實存＋在途<容量） | 下一權威 tick 開始返院，不等一整輪動作；到院再重查。途中被別人取得空位，抵達後明示等待，不能超額預約；僅在途占滿時不馬上又去休閒 |
| 走去偏好點途中出現容量／叫回／改工作 | 只更新最新返院意圖，走完目前去程腿再返回，不瞬移、不反覆掉頭或重設路程。原工作機會不在途中預留 |
| 在偏好活動點叫回／明確改工作，或返院途中改工作 | 保留原／最新工作與叫回意圖；**已在活動點**才於下一 tick 開始返院，**已在返院途中**只更新意圖、不重啟本腿；**去程**一律依上一列走完本腿再返院。返院可做就做，滿庫待命；至少完成下一趟**返院後新開始的**合法工作才解除叫回，不是到院或改令就解除 |
| 叫回後仍無空位 | 顯示「玩家叫回，等藥架空位」；不另去玩、不自動換工作。玩家可改派另一份工作、按「恢復自主」或停工。無法強制倒水／交藥到滿庫 |
| 「恢復自主」 | 只解除未完成的叫回／待命約束，保留工作種類，下一決策點依目前容量行動；去／返途中不瞬移或立刻掉頭。當下在工作則完成當趟。玩家停工時此功能不可解除停工，仍需明確開始工作 |
| 休閒往返／活動中叫停 | 最新意圖轉為玩家停工；走完當前腿、返院，再走 LP04 手動休息路線。已在院中直接走去座位。不能從休閒點跳到石凳；只有實際坐下才恢復精力，到100仍停 |
| 停工後開始、精力恢復途中改令 | 完全沿 LP04 的80門檻與路程交接；本片叫回不能跳過恢復或提前解除停工。較新的明確指令覆蓋較舊意圖，已接受的工作種類不丟失 |
| 取消待執行 | 只取消尚未生效的既有 pending，不清掉已生效叫回／玩家停工；叫回用「恢復自主」，停工用明確開始，避免一鍵含糊解鎖 |
| 暫停／背景／重來 | 下令只改意圖／零進度狀態，位置、精力、工作／休閒進度、收入與成長不動。重來清所有休閒路程／來源、叫回及 pending／預約，兩人沿原 Lv1／Lv3、精力100、水3／8、藥0／8挑水 |

恢復自主發生在去程中且當前仍滿庫：可以走完到偏好點留下；發生在返院中：先走完返院，再依容量選擇。不同按鍵不能生成回頭路或清掉別人的意圖。沒有中途丟包、社交邀約或無路情境，若新發現無法沿此表完成的產品歧義，僅回報受影響分支，不自行擴系統。

## 可見畫面與實作邊界

同一場景加一個小型閒暇區、兩個不與精力石凳混淆的活動位置：主角朝山看景、熟手在旁空地伸展。固定折線從共同院中端點往返，沿出發時空手速度鎖定、模型 tick 計時；renderer只能把進度換成位置／姿態。不得改舊工作路線、加長通勤來湊效果或先加 A*／門禁／碰撞。

人物的目光／姿態或手臂伸展至少看得出不同活動，不能只把同一待機貼兩個文字標籤。優先復用既有畫法／動畫模板，必要只添少量姿勢；若新增幀，舊幀、錨點／掛點及桶簍工作動作保持並驗差異，不整套重畫或採購。純動作循環可依模型活動 tick 呈現，不能用 render 更新世界或工作收益；腳底位置仍由模型決定。臨時素材／fallback 如實標明，不宣稱整體畫風已升級。

面板／名冊顯示：偏好、目前活動、原工作、原因（實存已滿／有人在補位／玩家叫回／玩家停工分清）、下一步與可用介入。活動中解釋「有空位會回去；這是閒暇，不回精力」；滿庫叫回時解釋等什麼、如何恢復自主。兩人都可選，操作保留暫停、1／2／4×、鏡頭、背景不補時、重來；390px原因／按鈕可讀且不遮住所選人物。

## 短展示與六組必要驗收

展示建議：原新局可4×自然跑到滿庫、必要時先完成LP04恢復再看閒暇；或在遊戲內把兩人改採藥，藥架滿後較易停留觀察兩種偏好。點選看原因→暫停叫回主角→返院後滿庫仍待命、同伴繼續活動→恢復自主可再去活動→再叫回／改挑水可用時出發→停工不被休閒解除→重來。自主因水容量開放而返院可用同條流程的一次新局觀察，無需測試專用寫入 API、加速世界或調容量造展示。目標約2～3分鐘看懂，非必須真人等滿所有成長。

1. **啟動與優先**：實存滿／僅在途滿分開；低精力先恢復、玩家停工不去玩、可工作不休閒。既有輪替與兩人不同偏好，無每 tick 重啟活動／路程。
2. **守恆**：休閒往返／活動不改精力、產出、XP、趟次或工作預約；只有工作完整交付與LP04坐下各做原本效果。局部配對跑到相同工作／休息時段查差異，不造新隨機樣本。
3. **意圖與控制**：叫回滿庫待命直到返院後下一趟完成；改工作只留最新、恢復自主只解叫回、停工仍需明確開始；兩人互不串狀態。少量交錯情境涵蓋去程／活動／返院，不列全命令笛卡兒積。
4. **路程與容量**：逐 tick 座標連續、位移受出發鎖定空手速度上限；暫停改令位置不動；去程中叫回走完腿、返回重查被別人取得的空位，無超額／負預約與瞬移。
5. **單一時間與新局**：同固定遊戲時間的分幀／1、2、4×等值；暫停／背景沒有活動或精力旁路、恢復不補時；新局清來源／叫回／路程與預約。背景handler未改可復用既有證據，清楚列本輪未實測項。
