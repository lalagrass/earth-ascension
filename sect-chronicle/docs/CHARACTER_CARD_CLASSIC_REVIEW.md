# 公版人物卡第二輪 review：起點、腿法與經典參考

2026-10-26，主 [#340](https://github.com/lalagrass/earth-ascension/issues/340)／PR #341 的設計修訂。只授文件研究與三位 agent 評估，不授實作／平衡。讀 [修訂公版](CHARACTER_CARD_PUBLIC_PROPOSAL.md)、[分支對照](CHARACTER_CARD_BRANCH_MAPPING.md)、[提示詞](CHARACTER_CARD_AGENT_PROMPTS.md)。

## 1. Review 結論：起點是時間維度

原稿把 startingBaseline 列為與能力／技能並排的類別，容易誤讀成「力氣是後天，所以開局沒有力氣」，或「放在起點就永遠不能練」。修正為兩個獨立維度：

- **這是什麼**：稟賦／身體能力／生活或武學技能／當下狀態／性情關係／衍生表現。
- **這是哪個時點或來源**：開局快照、目前常態值、短期修正後有效值，以及能證明的成長事件。

力量、耐力、身法均可有開局值，也可在某版規則下成長；具體是否可練仍由該版證明。悟性／根骨也不能只因名叫天賦就假定絕不改變。真正天生的值與創角前已有鍛鍊不強行分解。

公版先用一個能力語義ID，例如 capability.strength；initial可選，base代表目前常態（可已含永久成長），effective代表本時點有效表現。精力這種資源另外提供current/max。不把initial與current建立成兩套各自成長的系統，也不一律加算修正；公式歸核心。

若沒有保存過開局值或成長事件，卡片只顯示目前已知值；不能從後來的力氣反推先天、不補一份存檔升版或假造「成長＋0」。

## 2. 名詞應拆清楚

| 名詞 | 建議語義 | 能否有起始值／成長 | 不等同於 |
|---|---|---|---|
| 力道／力量 | 身體出力能力；最小方案先用整體力量 | 可以；依本版規則 | 傷害結果／武功熟練 |
| 臂力／腿力 | 上肢／下肢出力的可選細分 | 可以；本版已存在才投影 | 手上／腳上還剩多少精力 |
| 身法 | 協調、平衡、變向與閃避等控制能力；本版若只管跑速需標原義 | 可以 | 長跑耐力／腿法等級 |
| 耐力 | 持續活動的能力；可能影響消耗／容量／恢復之一，作者明說 | 可以 | 當前精力剩餘 |
| 行走／跑步速度 | 某模式、負重、地形與狀態下的即時結果 | 可有參照值；是衍生表現 | 單獨一個「先天速度天賦」 |
| 腿法 | 踢、掃、蹬等武學技術與所學招式 | 可開局已會，之後練習 | 跑得快／腿肌力強 |
| 輕功／步法 | 所學的移動武學或專門技法 | 可開局已會，之後練習 | 所有移動一律加速 |

「腳力」保留為原分支的原標籤，**不再當公版已定義的統一屬性**。作者需說它是行走速度、長途行走本領、下肢出力，還是混合值。混合值先保留來源擴充，不能一份原值同時映射成身法、腿力與耐力再三重計分。

## 3. 建議的最小能力集合與取捨（待選，不是要求補系統）

A：力量、身法、耐力三類身體能力；腿力／臂力可選細分，體魄若另有健康／承傷作用就獨立保留。跑速與出招結果另外顯示。這是PO建議的低成本起步，讓日常成長與武學共用身體基礎。

B：直接分臂力、腿力、身法、耐力，另留體魄／內功等。好處是砍柴和踢擊各有成長特色；代價是多項訓練來源、平衡、卡片與重複計算的負擔。

**先採能容納A與B的公版，三版回覆後再選是否統一。** B僅在想做「上肢很強、下肢薄弱」等可見差異且已有獨立效果時值得增加。不能為腿法存在，就要求新增腿力；通用力量也能驅動腿招。既有版不合此命名可提出理由，不為貼卡重做體系。

「體魄」與「耐力」如果在某版始終只有相同作用，就先不要兩者都加；如果一個影響健康承受、一個影響持久，才有獨立價值。尚未有耐力規則的版本顯示未支援，不能拿energy百分比充當耐力。

## 4. 腿法如何套公版武學

拆成身體基礎、門類／套路、招式、目前效果四層。角色有力道不代表懂腿法；腿法熟練也不保證長跑最快。

紙上示例（無新數值／未授實作）：

| 層 | 「掃堂腿」候選呈現 |
|---|---|
| 身體能力 | 使用該核心已有的力量；若真有獨立腿力再引用腿力，不重複加一次力量 |
| 技術／套路 | 腿法相關理解／熟練／體悟或本版XP；只展示本版真有的維度 |
| 招式規則 | 踢／掃的攻擊載體、站位與目標條件、作用範圍、起手／作用／收勢、耗能、命中／落空／打斷 |
| 效果解釋 | 哪些既有能力影響威力、時序或穩定性；不是全部同時加成，更不默認固定必中／多段／擊倒 |
| 呈現模板 | 掃腿motion、足部或兵器錨點、接觸／落空特效；核心phase驅動，動作不送額外位移／命中 |
| 人物卡 | 已會哪招、練到哪、何時能用、現在有效耗能／範圍；有真紀錄才顯示命中與成果 |

日常搬運、上坡與採藥可改善已有身體能力；**不自動教會掃堂腿或給腿法熟練**。本版若已有「勞動增身體、練招增技術」的規則，只讓卡片讀它；本輪不修改成長率。腿法訓練可能同時有身體與技術成長，但需核心分別定義，不讓UI或素材模板另給經驗。

內功、輕功、拳掌／腿法、兵器不必全放同一互斥樹：呈現可用「用途／門類＋套路＋招式」；若某版只允許主修掌／腿，原限制保持。新複合技／輕功跨河／連續清鼠仍須另行授權。

## 5. 與經典人物面板比較

### 《天下霸圖》一代：已查原廠手冊與圖

[Steam官方手冊](https://store.steampowered.com/manual/2304030) 第23–26頁；本輪下載原PDF、閱讀並render第23／26頁。圖中卡首保留身份／行動／精力；分基本、武術、行程、裝備。五角圖是拳腳、刀劍、槍棍、奇術、暗器的**學習力**。四力包含可消耗回復的腿力，輕功與武功經驗另列；因此腿力不等於腿法或跑速。第24頁文字的第五項列法與圖不一致，這裡依圖標籤並保留此差異。

本案借鑑：固定卡首、學習傾向與練成的技術分開、招式可直接看作用範圍。公版保持即時同圖生活，**不引入其回合制、四力消耗或硬套五角數值**。

### 《金庸群俠傳》DOS原版：已查操作手冊掃描

[智冠原版操作手冊存檔](https://archive.org/details/heroes-of-jin-yong)，PDF頁20–23／25（印刷18–21／23）。區分生命／內力／體力、攻防／輕功、拳掌御劍等專項及隱藏資質。修練頁把「學新武功／提升武功等級」與「只增屬性的秘笈」分開，也保留低資質可學特殊功夫的例外。

本案借鑑：人物能力、技術背景、單門熟練和學習條件分層；資質不等於眼前戰力。卡片宜讓玩家知道「為何可學／不可學、下一步如何練」，也可容納不同成長路線。**不把其隱藏資質數值、武器分類或等級上限直接複製成公版規則**。

手冊含模糊影印圖／OCR誤字，本輪核讀相關頁面；不以OCR拼字精確推出數值公式、隱藏算法或原版腿法分類。1996原版與網路重製／MOD分開，沒有查到的細節不拿玩家表格補成官方結論。

### 《Morrowind》與OpenMW：能力、技能與當下資源分離

[Bethesda官方能力說明](https://help.bethesda.net/app/answers/detail/a_id/17557/~/what-do-the-primary-and-derived-attributes-in-morrowind-do)將Agility、Speed、Endurance分別解釋，Fatigue是會消耗的狀態；[技能說明](https://help.bethesda.net/app/answers/detail/a_id/17546/~/what-do-the-skills-in-morrowind-do%253F)另有Athletics、Acrobatics與Hand-to-Hand。[OpenMW的API](https://github.com/OpenMW/openmw/blob/master/files/lua_api/openmw/types.lua)也分AttributeStat／SkillStat／DynamicStat，能力含base與modified等欄位。

本案借鑑：常態能力與短期有效值有區別；base並不等於出生／開局值。移動表現與格鬥技術可各有來源。保留這個分層，不搬其等級倍率或技能清單。

### CDDA：武學、技法與攻擊載體分離

[官方Martial Arts JSON說明](https://docs.cataclysmdda.org/JSON/MARTIALART_JSON.html)分武學style、technique與attack vector；技法可按技能／狀態要求選用，vector描述使用的肢體與接觸面。這提供腿招的資料架構參考，不必為每招新加一個人物能力。

本案建議：以「這招用足／小腿」連結身體條件、規則與動作；不把腳力當學習、威力、速度、耐力四用值。只借概念，不搬完整肢體損傷、裝備覆蓋與大量buff模擬。

### jynew／群俠傳，啟動！：開源重製另列

[專案README](https://github.com/jynew/jynew)與[人物UI程式](https://github.com/jynew/jynew/blob/main/jyx2/Assets/Scripts/UI/XiakeUIPanel.cs)可研究人物資料與技能清單的投影。這是Unity框架／重製，不是原版規則的直接證據。README對程式／素材用途有明確限制，本輪只讀設計，不採用其圖像或把它列為可自由嵌入的MIT人物卡庫。

## 6. 回到我們三版，先問什麼

沿原盤點固定SHA，不因本輪研究重跑三版全功能；agent補自己較新HEAD的相關差異：

| 分支 | 本輪新增重點 |
|---|---|
| GPT | 五項stats哪些只是起始常態、哪些真可鍛鍊；punch／staff／sword／step的能力與招式分工。未有腿法就報擴充位置，不把step自動當腿法 |
| Gemini | innateStats與skills.legStrength／physique哪些是起點、哪些是目前能力；people.level與persona如何映射真速度。legStrength名稱不能直接證明是踢擊力量 |
| Grok | MOVES有kick／掃堂腿且skill='leg'，STYLES有掌／腿，arts另有腿法XP；skills.agility用於speedOf。leg是技術、agility是移動相關值，不能都叫腿力；力量是否影響腿招傷害由作者核函式 |

對照表只維持來源事實；「共同力量是否足夠／要不要獨立腿力、身法如何與速度分開、耐力是否值得新增」列待選，不借研究批准新屬性。三方多交一段：同一人從開局→勞作→學腿招→疲累後，各欄應如何顯示；缺規則就標不支援。

## 7. 建議下一步

保留一張人物卡、兩主入口。先把「先天／來源」放詳細標籤，把能力用「起始→目前常態→當下效果」解釋；練功頁再展示武學門類、所學套路／招式、實際進度與限制。雷達優先是可選的同類學習傾向圖或能力圖，不再拿所有好看的數字拼一個戰力六角。

先收三位agent評估，再由PO合併語義／由擁有人選新增玩法；現階段沒有新runtime、存檔升版或手機前置。文件review只核分類、來源、映射與提示詞，原未變的分支／證據不重跑。
