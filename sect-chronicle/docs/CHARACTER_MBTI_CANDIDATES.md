# 人物MBTI候選版 v0.1：經典角色與《功夫》

2026-10-26，擁有人同意「先加一版，感覺比較有趣」。這次批准加入**紙上候選與人物卡敘事位置**，不是批准新問答、人格AI／加成、人物數值、畫面或存檔工程。主[#340](https://github.com/lalagrass/earth-ascension/issues/340)，文件PR #341。原[十二人](CLASSIC_TWELVE_TEMPLATE_COMPARISON.md)與[電影案例](KUNGFU_HUSTLE_TEMPLATE_COMPARISON.md)的版本／階段／武學／立繪來源保持。

## 1. 公版先加在哪裡

放在生活總覽→**心性與志向**的可選摘要，同角色性情、價值、志向並列。面板研究可以表達「候選ENFP｜重情義、喜嘗新｜一行人物語氣」，先有辨識樂趣，不把四碼當整個人的決策模型。

| 可選研究資料 | v0.1用途 |
|---|---|
| displayType／alternatives | 一個暫用四碼＋有真來源或明確P假設的其他解讀；空白／未定與零值無關 |
| referenceWork／storyStage | 指回既有角色窗口；社群頁未分版次／階段就標缺，不假稱符合窗口 |
| sourceKind／source／reviewedAt | S社群標示、P本PO暫擬、B原分支原值分開；保留核讀範圍、日期與連結 |
| rationale／counterEvidence | 用具體情境解釋候選與不合處；型號不能反過來當人物行為證據 |
| flavorLine／visibility | 一行本作原創語氣；是否玩家知道沿原核心，不洩漏未相識NPC真性格 |

這是可選文件欄位，不建立可執行schema。**沒有0–100四軸分數、百分比、投票率或精確可信度**；沒有原資料就不從四碼反推權重、認知功能或Big Five。可表達完整16型：ISTJ、ISFJ、INFJ、INTJ、ISTP、ISFP、INFP、INTP、ESTP、ESFP、ENFP、ENTP、ESTJ、ESFJ、ENFJ、ENTJ；不要求本批角色湊滿16型。

MBTI不直接改悟性／根骨／學習率、傷害、武學前提、親情／好感，也不把F當善良、T當聰明、I當冷漠、P當懶散。兩人同型仍可因價值、志向、文化、關係與所學而不同。問答與類型互相如何對應留後續設計，不追溯重算三版人物；D53女孩無鼓勵buff保持。

## 6. 三方回覆與接受界限

原最多三組案例／原碼至多兩門上限不變。各agent沿舊報告只用一個既有案例，補「類型摘要能否表達、哪些原值不得從四碼反推、同型如何呈現不同人物、未知或分歧怎麼留白」；可替換原案例，不加21人×16型矩陣，不要求填完所有角色人格或問答。

MBTI候選文件完成不代表新AI／buff／世界真值。既有runtime、三分支人格權威與隱藏遮罩不改；D45不重開口渴，單一入口、保存升版／手機末位保持。三份prompt由擁有人手貼，未代送／啟動；後續可見工程另定。
