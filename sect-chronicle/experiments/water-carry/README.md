# 生活開發版與挑水切片素材（SG-EXP-01）

原始工作單 [#155](https://github.com/lalagrass/earth-ascension/issues/155) 的 UI／2.5D 原型與素材保留在這裡。D13／[#197](https://github.com/lalagrass/earth-ascension/issues/197) 已將同一 `demo/` runtime 接續為主遊戲生活開發版；設計候選與技術小樣仍各自保留，不自動採用。

**生活主入口**：repo 根目錄跑 `python3 -m http.server 8765 --directory sect-chronicle`，開 <http://localhost:8765/>，會導向同一生活 runtime。亦可在本目錄跑 `python3 -m http.server 8798`，開 `/demo/`。兩人各自挑水或採藥（LP-03）／成長／精力低時自己去石凳恢復再回原工作（LP-04）／存放處實存滿時各去喜好處（主角看山、熟手舒展筋骨），有空位自己回、可叫回或恢復自主（LP-05）／一隻野豬依精力／威脅記憶與院內水或藥草實存進退、撞西坡竹護欄（損痕最多 3，只是外觀），可派一人去防守點喝止（LP-06）／可允許某人自主護院，有意願後回到院中才自己去（LP-07）／護欄有損痕且看不見野豬時可單次派一人去整理一階（LP-08）／可允許某人自主整理護欄，真碰撞後每輪全隊最多自己去一次（LP-09）／可允許某人自主清鼠，院內有有效鼠且無全場清理時由合法院中出發（LP-12）／本趟後停工，主角 Lv1、熟手 Lv3，水缸與藥架都含在途預約；共用一個60Hz時鐘。名冊可切換兩人，窄畫面跟隨所選人物。

SG-LIFE-01 起有**手動**存檔／讀檔（只有一格，按鈕才動；無自動存讀、雲端或離線收益），重整後未讀檔即新局；存檔用自己的 key，不承接或覆寫舊RT資料，舊修行／目標／招募等尚未移植，[舊viewer](../../viewer/)可保留原功能與存檔。體態是既有外觀；LP-04 起有精力與自主休息（精力低自己去石凳、恢復後回原工作），玩家「停工」則一直停著；仍沒有減重／社交系統。LP-01已發布單人基線 commit `c51615648b6f38151ffdcb36e8b2b1a0362fe857` 的同一路徑可回訪。
