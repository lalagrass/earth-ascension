## 3. 四段動作質感詳細規範 (LP15-B)

### 3.1 四段分鏡動作拆解與模型事實

原模型 `model.mjs` 採藥包含 4 個原生階段：`herbOut` → `herbGather` → `herbBack` → `herbDeliver`。原模型無獨立之 `herbStow` 階段，採摘與裝簍動作完全容納於 `herbGather`（整整 4.0 秒，常數 `RULES.dipMs = 4000`）內部，以進度 `k` 作為視覺切換依據：

```text
去程 (herbOut) ────────► 採摘 (herbGather 前段) ──► 裝簍 (herbGather 後段) ──► 背回 (herbBack) ────────► 交藥 (herbDeliver)
• 空身速度：            • 停於路底 (1398, 772)    • 直身整理、束草入簍    • 負重速度：            • 停於路頭 (962, 512)
  Lv1 60.0 / Lv3 74.4    • 俯身微蹲前傾 15°       • 綠草尖自簍口冒出      Lv1 40.0 / Lv3 52.0    • 面向藥架 (896, 474)
• 空簍背於身後          • 撥土探尋草藥根莖        • load = 0.5 → 1.0      • 軀幹前傾 8° 沉著步態   • 雙手捧草置入架中竹篩
• zIndex: z - 0.03     • 手部提案 (+14, -8)      • 簍具置身前 (-18, 0)   • 背簍在身後上方可見     • 藥架 herbs + 1
• 耗時：Lv1 8.59s       • 耗時：2.0s (k: 0.0~0.5) • 耗時：2.0s (k: 0.5~1.0) • 耗時：Lv1 12.88s     • 耗時：整整 4.0 秒
        Lv3 6.92s      └──────── 整整 4.0 秒 (RULES.dipMs) ────────┘        Lv3 9.91s        (RULES.pourMs)
```

1. **① 採摘 (Gather · `herbGather` 前段 `k = 0.0 ~ 0.5`)**：
   - **姿態重心**：人物面向藥圃右側（`face = 1`），俯身微蹲，重心微傾約 15°。
   - **手部動作**：手腕微幅起伏撥動泥土，自土畦中探尋草藥根莖（視覺提案手部掛點 `(+14, -8)`，因涉及人物全新骨架幀，接線階段標記為延後至 BL-P02）。
   - **簍具狀態**：竹簍取下自然置於人物身前腳邊 `(-18, 0)`，`zIndex = p.y + 0.03`（在人物身前清晰可見）。
   - **進度表現**：簍中草藥從無到有逐漸顯現（`load = k`，0.0 → 0.5）。
   - **時長**：2.0 秒（前段）。

2. **② 裝簍 (Stow · `herbGather` 後段 `k = 0.5 ~ 1.0`)**：
   - **姿態重心**：人物直身、微轉向身側，雙手整理剛採集之靈草束，準備置入竹簍。
   - **手部動作**：雙手捧草向簍口收納置入，手部掛點 `(+6, -12)`。
   - **簍具狀態**：竹簍微向人物傾斜，簍口冒出深淺兩色青翠靈草葉尖，`load = 1.0`（滿載）。
   - **時長**：2.0 秒（採摘與裝簍合計整整 4.0 秒，完全對齊原模型時鐘）。

3. **③ 背回 (Carry Back · `herbBack` 整段)**：
   - **姿態重心**：人物負重返程，身後背負滿滿草藥竹簍，視覺提案身軀自然前傾（Lv 1 前傾 8°、Lv 3 平穩 5°）保持平衡，步態沉穩著實。
   - **背簍掛點**：背部上方中心 `(-2 * face, -20)`，雙肩背帶斜跨胸前。
   - **圖層遮擋**：`zIndex = p.y + 0.03`，背簍於人物身後上方完整可見，不被軀幹錯誤吞沒。
   - **速度與時長**：完全依模型真值，實路 515.2。主角負重 40.0 單位/秒（耗時 12.88 秒）；堂哥負重 52.0 單位/秒（耗時 9.91 秒）。

4. **④ 交藥 (Deliver · `herbDeliver` 整段)**：
   - **姿態重心**：抵達院中端點 `[962, 512]`，面向藥架 `[896, 474]`（面向左方，`face = -1`）。
   - **動作呈現**：將身後背簍卸置於腳邊身後/側邊 `(+16 * face, 0)`；雙手捧出新鮮草藥束，平穩放置入藥架之圓形竹篩中（視覺提案交付掛點 `(-22 * face, -26)`，標記延後至 BL-P02）。
   - **結算與回饋**：交付那一 tick，藥架竹篩即時增加一束草藥實存（`herbs: 0 → 1`，上限 8），人物 `trips + 1`，並彈出綠色浮字 `+1 份藥`。依據 `tripsToNext[0] = 1`，主角完成 1 趟採藥即可升至 Lv 2。
   - **時長**：整整 4.0 秒（對齊原模型常數 `RULES.pourMs = 4000`）。
