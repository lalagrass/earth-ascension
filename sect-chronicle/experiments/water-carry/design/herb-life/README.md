## 3. 四段動作質感詳細規範 (LP15-B)

### 3.1 四段分鏡動作拆解

```text
去程 (herbOut) ────────► 採摘 (herbGather) ──────► 裝簍 (herbStow) ──────► 背回 (herbBack) ────────► 交藥 (herbDeliver)
• 空身速度 7.5 單位/秒   • 停於路底 (1398, 772)    • 直身收鋤、束草入簍    • 負重速度 4.2 單位/秒   • 停於路頭 (962, 512)
• 空簍背於身後          • 俯身微蹲前傾 15°       • 綠草尖自簍口冒出      • 軀幹前傾 8° 沉著步態   • 卸簍於架旁，雙手入篩
• zIndex: z - 0.03     • 手持藥鋤撥土細拔        • load = 1.0 (裝滿)     • 背簍在身後上方可見     • 藥架 herbs + 1 份
• 步伐輕盈開展          • load: 0.0 → 0.5 漸增    • 時長約 2.5 秒         • zIndex: z + 0.03       • 浮字「+1 份藥」(1.6s)
```

1. **① 採摘 (Gather · herbGather 前段 `k = 0.0 ~ 0.5`)**：
   - **姿態重心**：人物微蹲、軀幹前傾約 15°，重心壓低，腳底 Anchor 鎖定於地表 `(0, 0)`。
   - **手部動作**：手持採藥木鋤向下撥動畦泥，手部掛點 `(+16, -8)`。草藥自土畦被拔出時，有 2px 微幅向上彈起回饋。
   - **簍具狀態**：竹簍取下自然置於人物身前腳邊 `(-20, 0)`，`zIndex = p.y + 0.03`（在人物前下方清晰可見）。
   - **進度表現**：簍中草藥從無到有逐漸顯現（`load = k`）。
   - **時長**：約 2.5 秒。

2. **② 裝簍 (Stow · herbGather 後段 `k = 0.5 ~ 1.0`)**：
   - **姿態重心**：人物直身、微轉向身側，雙手整理剛採集之靈草束，準備置入竹簍。
   - **手部動作**：雙手捧草向簍口置入，手部掛點 `(-15, -20)`。
   - **簍具狀態**：竹簍微向人物傾斜，簍口冒出深淺兩色青翠靈草葉尖，`load = 1.0`（滿載）。
   - **時長**：約 2.5 秒（採摘＋裝簍整段固定 5.0 秒，完全對齊原模型時鐘）。

3. **③ 背回 (Carry Back · herbBack 整段)**：
   - **姿態重心**：人物負重返程，身後背負滿滿草藥竹簍，身軀自然前傾 8° 保持平衡，步態沉穩著實。
   - **背簍掛點**：背部中心 `(+10, -26)`，雙肩背帶斜跨胸前。
   - **圖層遮擋**：`zIndex = p.y + 0.03`，背簍於人物身後上方完整可見，不被軀幹錯誤吞沒。
   - **速度對比**：主角負重速度 4.2 單位/秒（去程為 7.5 單位/秒），明顯呈現負重跋涉之厚重感。

4. **④ 交藥 (Deliver · herbDeliver 整段)**：
   - **姿態重心**：抵達院中端點 `[962, 512]`，面向藥架 `[896, 474]`（面向左方，`face = -1`）。
   - **動作呈現**：將身後背簍卸置於腳邊身後 `(+18, 0)`；雙手捧出新鮮草藥束，平穩放置入藥架之圓形竹篩中，交付掛點 `(-22, -26)`。
   - **結算與回饋**：交付那一 tick，藥架竹篩即時增加一束草藥實存（`herbs: 0 → 1`，上限 8），人物 `trips + 1`，並彈出綠色浮字 `+1 份藥`（持續 1600ms 淡出）。

## 4. 最小接線差異表與素材規格 (LP15-C)

### 4.1 核心掛點偏移量 (Attach Offsets)

所有座標皆以角色腳底地表原點 `(p.x, p.y)` 為基準：

| 物件 / 掛點 | 所屬階段 | 建議座標偏移 `(dx, dy)` | zIndex 層級 | 視覺遮擋關係 |
|---|---|---|---|---|
| **角色腳底 Anchor** | 全階段 | `(0, 0)` | `p.y` | 對齊路線節點，地面排序基準 |
| **空身背簍** | `herbOut` (去程) | `(-8 * face, -19)` | `p.y - 0.03` | 背於身後，大部分被身軀遮擋 |
| **腳邊採藥簍** | `herbGather` (採摘) | `(-20, 0)` | `p.y + 0.03` | 置於人物前下方，簍中草藥隨 `k` 增加 |
| **採藥木鋤/手部** | `herbGather` (採摘) | `(+16, -8)` | `p.y + 0.02` | 手持藥鋤撥土，動作微幅起伏 |
| **滿載背簍** | `herbBack` (負重回程) | `(+10 * face, -26)` | `p.y + 0.03` | 背於身後上方，綠草尖清晰外露 |
| **交藥捧草手部** | `herbDeliver` (交藥) | `(-22 * face, -26)` | `p.y + 0.02` | 雙手捧草向前伸入竹篩 |
| **曬藥架竹篩** | 常駐 | `(places.rack.x, places.rack.y)` | `places.rack.y + 8` | 三層竹篩，依 `herbs` 數量逐份渲染草藥 |

### 4.2 最小接線修改清單 (接線階段授權實施)

在後續接線階段，僅需修改極少量程式即可完整呈現本設計：
- **`demo/app.mjs`**：
  - 加強 `drawBasket(g, load)`：支援滿載時更精緻的葉片多重輪廓與背帶線條。
  - 加強 `drawRack(n)`：支援立體雙層/三層圓形竹篩，草藥束錯落排布。
  - 調整 `placeBasket(id, p, person)`：使用上述掛點偏移量與 zIndex 層級。
- **`demo/style.css`**：
  - 微調藥架標籤與交付浮字樣式（保持與挑水浮字一致）。
- **`checks/water15.test.mjs`**：
  - 新增輔助單測，驗證 `herbOut`、`herbGather`、`herbBack`、`herbDeliver` 階段流轉與交付結算帳目。
- **只讀保持**：`model.mjs`、`routes.mjs`、`water-layout.mjs`、幾何座標、精力扣耗等**完全不修改**。
