## 水系：由畫面成立

1. **新水源**：山壁泉口（岩縫出水、濕痕苔、石槽匯水後溢流成溪），取代「孤石接截平河」。泉口≠取水處。
2. 林溪連續河床、小階落差 → 竹林坡 → **溪橋**（跨真河道、兩端落在土路）→ 主溪出圖。
3. **谷底取水潭**（現遊戲名「泉眼」）：潭東石階岸台為取水站位，桶到水面、腳不入水；上游取用、潭出水下游洗滌／排水。
4. 高低靠崖、坡、階地與落差讀出；院落位在山肩台地，高於橋。不做水文／污染／雨季模擬。
