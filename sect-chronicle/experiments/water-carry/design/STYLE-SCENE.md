## 參考

- 《活俠傳》官方 Steam 頁：<https://store.steampowered.com/app/1859910/>
- 本機環境連不到 Steam 與圖片 CDN，**這次沒有對著官方畫面比對**。下面的「取向」是我對該作畫面的印象整理，不是逐張驗證過的原作風格清單，請擁有人與遊戲 PO 對照官方畫面判斷方向對不對。
- 取向：場景偏手繪、暈染、色彩收斂的山水；人物線條乾淨、比背景清楚；介面偏紙、卷軸與印章的質感。
- 全部原創 SVG，沒有描摹或取用原作素材。

## 新風格做了什麼

| 部分 | 處理 | 和現況的關係 |
|---|---|---|
| 遠山、雲霧 | 重畫：兩層上濃下淡、山腳沒入雲霧的暈染峰，加皴線；朱色淡日 | 新畫 |
| 草地、草坡 | 青瓷綠與赭黃暈染，邊緣不規則；乾筆草痕取代一撮撮的草 | 同形狀，新畫法 |
| 松、楓、梅、灌木、竹、石、前景枝葉 | 重畫：暈染團塊加墨線，松針、苔點、墨竹 | 同位置，新畫法 |
| 道館、石階路、泉水、水缸、石燈 | 沿用 #179 幾何，換色盤，再套輕微暈染 | 沿用 |
| 人物 | 同一個 `figure()`，略收飽和度，外加一圈淡墨描邊 | 沿用＋描邊 |
| 全畫面 | 最上層一層紙紋 | 新增 |
| HUD、地點牌、對話框 | 紙底雙墨框、朱印名牌、標題用襯線字 | 同位置、同內容，換樣式 |

## 成本盤點：保留／調整／延後

| 項目 | 建議 | 理由與成本 |
|---|---|---|
| 色盤與紙紋 | **保留** | 一組色票加一個濾鏡，成本最低，效果最大 |
| 遠山、雲霧 | **保留** | 只畫一次的背景層，換掉就有山水感 |
| 植被、石頭 | **調整** | 方向可以，但團塊偏大、墨線偏重，要再收；每種一兩個變體就夠 |
| 道館、石階、泉水、水缸 | **調整** | 目前只是換色加暈染，還有向量感；要補手繪線條與材質，是最花工的一塊 |
| 人物描邊 | **保留** | 在暈染背景上辨識度明顯變好，小尺寸尤其需要 |
| 人物本身 | **延後** | 換畫風不必重畫小人；#181 模板的 sprite 換色或加描邊後要重烘 |
| HUD、對話框 | **調整** | 樣式能用；按鈕、選取框、捲動面板、名冊卡還沒畫 |
| 390px | **調整** | 暈染背景較暗、細節多，地點牌要有紙底才讀得清；選取框對比要另驗 |

接進展示時要注意：

- 濾鏡（暈染、紙紋、描邊）在 SVG 上方便，但在 Pixi 每幀即時算很貴。
- 正式做法應該是把背景先烘成分層 PNG（遠景、中景、地面、前景），人物 sprite 在烘焙時加描邊。
- 這是第 3 步之後的工作，這裡沒做。
