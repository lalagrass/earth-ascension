# SG-TRAIN-01 練一式掌法，帶去巡山（#305／D43 T1–T4）

實作者：Grok Bot（git 作者 lalagrass，Grok 認領 #305）。契約：`docs/TRAIN01_HANDOFF.md`、`docs/TRAIN01_GROK_PROMPT.md`（PR307 → dev 53cb54d）。

- **T1**：兩人新局皆初學；院坪東側一人一個固定站位＋木樁（`routes.mjs` `TRAIN_POSTS`，自院中端點獨立短路）。腳力等級與掌法進度分開顯示。木樁：`demo/assets/train01/stake.mjs`（Grok 自繪 Pixi 向量，非點陣、無 HP）；練掌姿勢沿用清鼠 `PALM_POSE`＋向量手臂，調息用站直幀，往返用空手步態。
- **T2**：站位上完整 12 遊戲秒＝1 單位，6 單位練熟；練習中每遊戲秒 −1 精力。取消／重派／動畫擺動不給進度，已耗精力不退。練熟寫原 `palm` 欄位 novice→adept（起手 48→24、收勢 36→18 tick）；掌距 28、對敵成本 2、命中、速度、工作成長不變。
- **T3**：「練掌到熟練」是新人工目標；搬運中原趟先交付；退出自主補水與招呼，壓住衝突自主候選。精力 ≤30 或口渴：中止本單位（已完成保留、未完成歸零）去自理，目標仍在才回來；水缸空時顯示等待原因。玩家較新的停工／工作／巡山等指令取消目標與未完成單位，不搶回。練熟後回院休息待命（原停工狀態），不恢復舊工作或方針。同 job 不同方針仍可覆寫（#302/#304 反例）。
- **T4**：練習進度與目標只本局；練熟結果沿原掌法欄位保存。無 v3／key／migration。練功三段途中存檔被 guard 擋下、舊檔不覆寫；載入成功清新暫態、失敗全不變；新局清除。一般玩家的初學／熟練 fixture 按鈕移除（`model.setPalm` 測試 API 保留，`window.demo.setPalm` 供舊瀏覽器檢查）。
