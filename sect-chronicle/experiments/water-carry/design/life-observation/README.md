# LP-14 生活觀察介面設計與流程規劃

本文件為 **LP-14 生活觀察介面**（O1–O4，依據 [D28 決策](../../docs/DECISIONS_AND_SOURCES.md#d28lp-14-生活觀察介面-o1o4批准2026-10-23) 及 [LP14_HANDOFF.md](../../docs/LP14_HANDOFF.md)）之設計說明、版面架構與控制項對照。

---

## 1. 設計目標與問題診斷

### 現狀痛點
1. **頂部 HUD 與卡片堆疊**：原有頂部 HUD 塞入 10 餘個標籤與按鈕，野豬卡（`#boar`）無論是否有危機均固定展開並橫跨頂部（在 390px 手機上高達 126px），嚴重壓縮垂直觀察空間。
2. **人物狀態缺乏下一步與因果**：人物面板只呈現 raw mode，玩家無法直接看出「為何停在座位上」（是手動停工、還是回滿 80 準備出發？）以及「路中改令後下一刻會做什麼」。
3. **鏡頭控制依賴鍵盤**：拖曳進入自由觀察後，原介面依賴鍵盤 `'0'` 鍵恢復跟隨，在手機或觸控裝置上缺乏直觀恢復入口。
4. **進階自主政策干擾日常觀看**：自主整理、自主清鼠、自主護院及掌法 fixture 等設定直接鋪平在面板上，造成日常觀察雜亂。

### O1–O4 解決方案
- **O1 觀察優先**：HUD 精簡聚焦於時鐘、倍率、存量與角色快捷；野豬／鼠群／護欄收納為**可展開的「院落近況」摘要卡片**，平時僅佔一行精簡摘要，點擊展開完整明細與派遣。
- **O2 人物小卡**：選人時小卡優先呈現「工作、精力、**下一步與停止原因**、腳力與成長」，常用切工／本趟後停工一鍵可達。
- **O3 進階按需**：自主政策與掌法 fixture 收納於「進階設定」折疊區；新增清楚可見的「跟隨 / 自由視野（點擊恢復跟隨）」按鈕。
- **O4 單純 UI 切片**：100% 保留原模型、路線、命令語義與時鐘，UI 折疊操作零模型副作用。

## 4. UI 操作純粹性保證

1. **零世界副作用**：
   - 點擊「展開/收起院落近況」僅切換 DOM class（如 `.boarcard.collapsed`），不呼叫 `model.dispatch()`，不推進世界 tick。
   - 點擊「展開/收起進階設定」僅切換 DOM class（如 `.advanced-panel.open`），不改變任何政策數值或觸發 `change` 事件。
   - 暫停狀態下進行上述 UI 展開/收起操作，世界狀態快照前後 100% 相同。
2. **相機可視區動態適配**：
   - `follow()` 自動偵測 `#boar` 與 `#panel` 的即時 `getBoundingClientRect()`。
   - 當院落近況收起時，頂部有效下界大幅縮減至 HUD 附近（~50px），相機居中範圍擴展至更寬闊的場景視野。
   - 當展開時，相機自動避讓展開高度，人物全身嚴格維持在淨可視區間內。
