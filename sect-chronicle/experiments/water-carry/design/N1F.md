## 流程一：做完再玩

主角照玩家的交辦挑完三擔，接著依序：

1. **倒下第三擔，交辦完成**：紀錄寫「完成交辦」。只完成一擔不算，不會提早去玩。
2. **回到自己作主**：手動鎖照 [RT00 §2.5](../../../docs/RT00_CONTRACT.md#25-手動命令暫停或執行中皆可) 結束，產生現有的 `autonomyResumed`。
3. **走到石凳邊坐下聊**：看得到動作，走過去、坐下，兩人輪流冒聊天泡泡，不是只跳一行字。
4. **點他看原因**：卡片回答三件事，剛做完什麼、為何在這裡、接下來何時回去。休閒有上限，不會一直閒逛。

**對象在忙時**：

- 堂親正在翻曬時，主角不打斷他，改去石凳自己歇一下，原因寫「堂親在忙」。
- 路不通、對象不在時，也一樣說明原因和改去哪裡，不瞬移，也不原地乾等。
- 正式做時，兩人是否「有空」要在權威仲裁裡決定，畫面不能自己配對。

## 流程二：工作沒做完就分心

主角在沒有玩家交辦的情況下，自己作主挑水。

1. **倒完一擔**：這是單位邊界，只在這種時候考慮分心。走在路上或倒水途中，不會丟下桶走掉。
2. **遇見師兄，放下桶去聊**：頭上寫「閒聊中・水缸還差 2 擔」。已倒進缸裡的那擔照算，不倒帶。
3. **玩家暫停、點他**：卡片寫原本在做什麼、為什麼停下，有「允許這次」「叫他回去挑水」兩個按鈕。只有主角有按鈕，其他人物點了只看得到原因。
4. **叫回之後**：等於對主角下手動指令。在指令做完之前，他不會再分心（手動鎖不被個性覆寫）。

**回去前先重新確認**：

| 情況 | 結果 |
|---|---|
| A 還需要 | 照常繼續剩下的 2 擔 |
| B 已經不需要（聊天時堂親把水缸挑滿了） | 不補做舊任務；說「水缸已滿」，改做下一件或歇 |
| C 玩家按「允許這次」 | 聊完（有上限）自己回去；不會每擔都停一次 |

## 一個簡化建議：剩多少用推算，不另存

#189 把「分心時保留還想做什麼／剩多少的意圖」列為待定。對照現行程式後，我建議第一片先不要另存：

- **現況**：[`autonomy.js`](../../../js/autonomy.js) 的自主請求，除了建造與煉丹，都是一次一單位。採集、修行、援村、突破、休養的 `units` 都是 1。
- 建造與煉丹是承諾型，本來就不能分心。
- 所以在未鎖定的自主工作者身上，現在沒有一份「剩幾擔」可以保存。

**建議**：圖上的「水缸還差 2 擔」定義成**目標需求的剩餘量**，每次決策由 R2 從當下世界重新算。

- 聊天結束後，下一次決策自然重評，不用新增 schema。
- 流程二的情況 B 也不需要額外的「過期」規則：缸滿了，需求就沒了。
- 代價：不能表達「他本來打算挑三擔」這種個人意圖。若之後真的需要，再另比較「另存意圖」的版本。

## 建議表（待評估）

[n1f/prefs.png](n1f/prefs.png) 下半部的表：

| 問題 | 建議 | 要擁有人選的 |
|---|---|---|
| 叫回後會不會又立刻跑掉？ | 沿用手動鎖，保護這次指令的剩餘擔數，做完才回到自主 | 要不要允許人物違抗玩家 |
| 分心時原工作怎麼辦？ | 已完成的擔照算；剩下的不另存，回來時由需求重新算 | 若要另存意圖，舊意圖何時過期 |
| 什麼時候考慮分心？ | 只在單位邊界：倒完一擔、採完一份 | 要不要加「走一半就停」 |
| 什麼時候回去？ | 一次有上限的休閒；聊完或被叫回就重新看需求 | 一次多長、多久才能再分心 |
| 誰可以被叫回？ | 首輪只有主角，其他人物只看原因 | 是否開放全隊手動 |
| 做完的單位與目標 | 分開顯示：這一擔、這次交辦、長期目標 | 休閒插在決策順序的哪一層 |

## 畫面與規則分開

這組分鏡只定**玩家要看到什麼**。下面每一項都會改到遊戲結果，要另定小範圍規則與相容驗證：

| 項目 | 現況 | 若要做 | 需要另定 |
|---|---|---|---|
| 休閒活動 | 沒有；等待（`goals_done`）不移動、不改體力心境 | 新增一種活動，不是改寫等待 | 插在 R2 之後、R4 之前或別處；會不會回體力或心境 |
| 雙人聊天 | 沒有 | 兩人同時占用 | 像工作位一樣預約；對象忙就落選並寫原因 |
| 分心觸發 | 沒有 | 固定條件或亂數 | 用亂數就要決定用哪條亂數串流，並更新既有種子的回放基準（#118） |
| 剩餘量 | R2 每次從世界推算需求 | 沿用推算（上節建議） | 若改成另存意圖，要定存檔欄位與過期 |
| 叫回 | 主角手動指令＋手動鎖 | 沿用 | 不需要新規則；開放全隊另批 |
| 存檔與回放 | 不受影響 | 休閒若是活動，就進活動與事件紀錄 | 版本與舊檔相容另定 |
