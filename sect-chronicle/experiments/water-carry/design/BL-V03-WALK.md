## 改前的問題

改前是 V1 姿勢表的 `emptyA–D`、`loadA–D`，V3 展示和 [#181 模板](../template/actions.json)現在都用這組。兩個問題：

- **腳在地上滑**：兩步實際跨出的距離（空桶約 28 場景單位）比每循環前進的距離（4 幀 × 6.6 = 26.4，兩步）大很多，著地那隻腳每循環滑約 15（空桶）、9（負重）。
- **負重看不出重**：負重循環的髖部起伏只有 0.8，比空桶（4.5）還平；步幅、雙腳著地時間和空桶差不多。

## 改後怎麼做

腳的位置先定在地面，再用大腿、小腿各 21 的兩段腿反推膝蓋角度（`walk-boards.js` 的 `ik()`）。站著的那隻腳跟著地面一起往後退，所以不滑。

| | 空桶下山 | 負重上山 |
|---|---|---|
| 幀數 | 8 | 8 |
| 每幀前進（場景單位） | 5.85（原 6.6） | 4.14（原 5.2） |
| 一隻腳著地佔循環 | 60% | 66%（雙腳著地更久） |
| 膝蓋 | 幾乎伸直 | 多彎、落地時再沉一點 |
| 抬腳高度 | 5.5 | 3.4（拖著走） |
| 髖部起伏 | 3.6（原 4.5） | 3.0（原 0.8） |
| 桶子擺動 | 大、比身體慢半拍 | 小、比身體慢半拍 |
| 扁擔 | 幾乎不彎 | 落地時往下彎、左右肩換邊時傾斜 |
| 著地腳滑動／循環 | 0（原 14.8） | 0（原 8.7） |

數字都是 `render-walk.js` 跑完印出的量測。

## 不變的東西

- 移動速度（空桶 60、負重 45 場景單位／秒）、路程、到達時間、何時入帳，都照 V3 與 #181 的權威狀態；換幀只看走了多遠。
- 正面下山、背面上山的朝向，人物畫法（#179 的 `figure()`）。
- 沒有改 `demo/`、`spikes/`、`scene.json`、`template/actions.json` 或已烘焙的 sprite，也沒改正式 js／viewer／存檔／RNG／根依賴／CI。
