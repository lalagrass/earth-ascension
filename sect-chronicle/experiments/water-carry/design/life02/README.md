# SG-LIFE-02「夠用就歇，與同門打個招呼」設計與證據

依據：[LIFE02_HANDOFF](../../../../docs/LIFE02_HANDOFF.md)／D42（PO 文件 head `640269a`，PR #301 已 squash 入 dev `b3cef9e`）。

- **P1 自主補水**：人物卡／地點選單新增「自主補水（夠用就歇）」。實存 ≤3 開一輪、實存 6 收輪；輪外或實存＋在途 ≥6 不新增自主出發（方針者 `slotFor` 只看上限 6，仍走原公平輪替預約）。收輪後要等實存再掉到 ≤3（不在 5、4 立刻重啟）。未選方針的人工持續搬運照原規則補到 8；容量 8 不變。改派只在原合法邊界生效（搬運中待交付）。
- **P2 招呼**：只有本局選了自主補水、且輪到他發起（完成一趟新工作後才有一次機會）的人，在自己的休閒點、雙方都無必要自理／人工／護院巡山承諾／待執行時，兩人沿「休閒路反走→院中端點→院坪站位」真走近、面對面，發起 2 秒＋回應 2 秒＝4 遊戲秒，記一筆短事件（最多 8 筆）後各自從所在處走回院中續生活。對方忙＝本次放棄，留在原地，原因只在改變時記一次；中途有人要喝水／工作輪到／玩家下令＝雙方同時釋放走回。無 buff、好感、第三 AI 或亂數。
- **P3 人物卡**：只補「現在／來源／原因／下一步」小區塊、方針按鈕與「取消招呼」。玩家改派／停工／巡山／護院／整理／清理都退出方針，下一 tick 不搶回；停工後只自理，再選自主補水才恢復。
- **P4 保存**：方針、招呼暫態在 `life02.mjs` 閉包，不進 `s`、不進 v2 快照、不升版；招呼路長度從 `createModel` 的 `sense` 傳入，不改 `lengths`（存檔幾何識別）。招呼或其返程中按存檔＝說明並不覆寫舊檔；回到院中後可存並明說方針不保存。讀檔成功才重設暫態，失敗時連暫態也還原（`guardedSave／guardedLoad`）。
- **素材**：無新圖檔；招呼姿勢借用「舒展筋骨」前彎幀／站直幀（人物卡如實標示借用），對白用 HUD 文字氣泡。
