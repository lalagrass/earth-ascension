# LP-16 採藥視覺整合素材與局部渲染模組

本目錄包含 LP-16（#271）「美術與採藥視覺整合」之可編輯向量渲染模組與小素材。

## 模組說明

- [`herb-decor.mjs`](herb-decor.mjs)：
  - `drawRefinedHerbPatch(ground, patch, herbPoints)`：精修東坡藥圃（坐標 `1440, 788`），包含梯田腐殖土台地基底、暖灰包邊石塊與苔蘚點綴、三道耕作土畦溝壑、18 組三層立體藥草植株（含金黃與素白藥花草穗）、帶竹節與橫綁繩的竹籬、西側灌溉陶甕（`1388, 778`）與東側靠放木鋤（`1490, 804`）。
  - `drawRefinedRack(rack, n)`：精修院中曬藥架（坐標 `896, 482`，嚴格維持 2 層竹篩、上限 8 份），包含雙粗竹柱、竹節凹槽、人字斜撐加固、雙層大竹篩經緯篾條編織紋理，以及 1～8 束清晰可辨的捆紮草藥束。
  - `drawRefinedBasket(g, load)`：精修採藥竹簍，呈現雙肩背帶、梯形簍身、多道經緯交錯篾條竹編紋理、厚竹圈口沿與深邃簍內陰影；當 `load > 0` 時呈現挺拔翠綠與深綠交錯的靈草嫩芽與葉片。
  - `getRefinedBasketPlacement(phName, px, py, face, scale, k)`：純視覺掛點換算，對齊 LP-15 規範：
    - `herbOut`：`(-face * 8 * s, -19 * s)`，`zIndex = py - 0.03`，`load = 0`
    - `herbGather`：`(-18, 0)`，`zIndex = py + 0.03`，`load = k`
    - `herbBack`：`(-face * 2 * s, -20 * s)`，`zIndex = py + 0.03`，`load = 1`
    - `herbDeliver`：`(+16 * face, 0)`，`zIndex = py + 0.03`，`load = 1 - k`

## 來源、工具與授權

- **主筆**：Gemini (Antigravity)
- **工具**：PixiJS Graphics API 原創代碼繪製（代碼即向量來源，零點陣相依）
- **風格與色系**：採納 Grok #270 / D32 提案之暖灰石 (`#767468` ~ `#868478`)、木竹 (`#9a7544` ~ `#dac48e`)、苔綠 (`#5a6e42` ~ `#64a648`) 與深土色 (`#52402c` ~ `#8a6c46`) 方向，實現現有坐標之精緻局部重繪。
- **授權**：專案內部原創代碼，與專案主體一致（MIT）。
- **依賴**：零第三方外部套件或外部圖片，直接調用工程現有 PixiJS 繪製接口。
