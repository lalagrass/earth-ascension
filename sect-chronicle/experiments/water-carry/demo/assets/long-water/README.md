# LP-13 長挑水路素材與分層設計

本目錄存放 LP-13 長挑水路（道館院落向南延伸至 1600×1350、水路折線長 1700.9）之必需乾淨素材、分層規格與幾何對齊。

## 來源、工具與授權記錄

- **實際主筆**：Gemini（Antigravity，非 PO／非審查者）
- **工具／方法**：向量程式渲染（PixiJS Graphics / SVG 原生向量）；完全由程式參數化繪製，不取用商業素材，未直接拉伸 PR #250 概念底圖。
- **參考與概念來源**：
  - PR #250 生活盆地地圖設計（commit `dbb0070`，僅作動線、氣氛與相對位置參考；原圖含烘焙人物與距離壓縮，不作底圖）。
  - 《活俠傳》唐門後山林野氣候（僅作氛圍色彩參考，無取用素材）。
  - 《天下霸圖》門派弟子日常走動感（僅作動線與勞動觀察參考）。
- **授權與歸屬**：原創程式碼與向量幾何，保留專案內 Grok（#182/#248 原圖稿與分鏡）及 Gemini 原作者紀錄。

## 分層與掛點結構

| 圖層 / 物件 | 坐標範圍 (x, y) | 排序層級 (zIndex) | 說明與遮擋關係 |
|---|---|---|---|
| **南段地面基底** | `x: 0–1600, y: 880–1350` | `ground` 層（底層） | 與舊 1600×900 院落接縫於 y=890–910，草坡與泥土斜坡自然過渡 |

## 檢驗與限制

1. **同源性**：水路折線 `WATER_POINTS` 經 `pathTool` 計算為 1700.9 場景單位，供模型耗時、畫面位置取樣與腳底對齊百分之百同一來源。
2. **無重疊人物**：素材無任何預烘焙人物影子或二度重影。
3. **景觀保留**：舊院中泉池（北面谷底泉池）保留純景觀，移除舊取水熱區標記，全場僅新泉眼 (352, 1245) 為有效取水點。
