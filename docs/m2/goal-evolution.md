# M2 #8 設計提案：目標延伸、深化與轉向

狀態：2026-10-17 產品語義提案，待 #8 討論與驗收基線確認；本文件不代表規則已實作或 M3 已開工。關聯：[#8 目標塌縮](https://github.com/lalagrass/earth-ascension/issues/8)、[#9 受挫後計畫](https://github.com/lalagrass/earth-ascension/issues/9)、[M3 開放方向](../m3/creator-briefs.md)。

## 玩家想看到的角色發展

同一個人可以從「探索靈氣與古武的關聯」開始，學到方法後深化問題；若後續世界確有可驗證的新知與行動，才可能提出更遠的修行方向。這是**可能的角色弧線**，不是所有角色必經的「古武→仙俠」劇情，也不預設現有世界有古武或仙俠的效果規則。另一人可以因生計、健康、反證或人際關係轉向；也有人能長期專注一個未完成的問題。

目標應區分三層：玩家給的**方向**（M3 候選，原文可開放）、人物當下承諾的**一個活躍長期目標**（M2），以及該目標下可檢驗的**短步驟／研究工作**。完成工作量、獲得證據、相信假說、解鎖能力是四種不同狀態；進度達 100% 不能自行證明靈氣假說或開啟新能力。沒有相應世界規則時，合格結果是「尚無方法驗證」，而非換一段更玄奇的敘事。

## #8 的有限規則選擇

1. 到檢查月、達到既有完成條件、遭遇重大事件或明確停滯時，才評估目標。保留完成或受挫事件，避免每月任意抽新目標。**本月結算產生的事件最早在下月共同決策快照供人物使用**；當月不能因此重選行動或告知其他人物。
2. 評估四種後繼：**延續**（尚有合理進度或新證據，保留目標並修短計畫）、**深化／延伸**（在同一脈絡中提出有規則支持的新問題或更高階目標）、**轉向**（其他已知且可行的目標更符合需求與人格）、**休整／結案**（生計、健康、證據不足或暫無可行後繼）。休整使用現有「穩定生活」作**唯一活躍目標**，設定下一檢查月；結案只屬已完成目標的歷史狀態，不能使人物變成零個活躍目標。休整不是永久吸收態；「繼續穩定生活」仍可有理由地勝出，不為分布指標強迫換目標。
3. 每個候選需列出人物**當時已知**的事件、前置、可行行動、預期成本、人格／價值與當前需求。不得讀全域目標占比、未來事件或角色未知情報；有限候選的分數和 tie-break 均由版本化規則與獨立 RNG purpose 決定。
4. 活躍目標仍恰好一個，與現有 `validate()` 一致。#8 的最小候選池只從現有五類目標中選；同類深化若沒有機械上不同的前置與完成條件，就保留同一活躍目標、只修短計畫，不把新標籤當升階，並以獨立 trace 原因碼計數，不混入新 `goal_id` 切換。若要加入新目標類型或階段參數，須另列規則版與驗收，不在小修 PR 暗加。若確實切換，舊目標留在歷史；`parent_goal_id` 指向**直接前任目標**，完整脈絡由鏈追溯，後繼另記 `transition_kind`、檢查月、可為空的來源事件 ID、決策原因。例行檢查無觸發事件時以檢查月作原因；不轉換也記錄檢查及留任理由。這些是待 #10／#11 存檔契約核准的**資料需求**，不是已存在的欄位。
5. #8 先修「完成後必入穩定生活」的漏斗與切換因果；[#9](https://github.com/lalagrass/earth-ascension/issues/9) 再修挫折時短計畫與目標之間的恢復／轉向。兩個 PR 不同時重寫相同規則。M2 只允許現有行動與可驗證前置組成有限後繼；自由文字理解、玩家方向輸入、多個同時活躍目標及全新修行體系留在 M3 候選或更後續，不塞入 #8。

例：角色完成「探索靈氣」階段，若本人已知 `practice_basis`（親自發現或合理獲分享），且現有 `修習` 前置成立，可以評估繼續探索並調整短步驟；現有五類目標並沒有獨立的「古武／仙俠」目標或階段，因此 #8 不把修習直接包裝成新長期目標。若沒有該知識，不能只因目標滿格就宣稱學會武術或仙法。M3 的「研究靈氣與中國古武學關聯」即使被人物採納，仍須先有題目對應的可觀察機制；現有通用研究不能冒充古武效果證據。

## 驗收設計與停止條件

- 對照現行 M2 與候選規則，以相同初始世界和配對 seed 跑 30 個開發 seed、10 個保留 seed，每組 100 NPC×60 月。每月最大目標占比的分母是**該月存活人物**；目標段長度按同一 `goal_id` 連續活躍月數；切換率以每存活人物月為分母；休整退出率以到期且有可行候選的休整檢查為分母。逐 seed 報最大占比、段長分布、延續／深化／轉向／休整比例、切換原因及失敗 seed。先在開發組量測，再於保留 seed 前封存候選門檻；目前沒有經試驗證實的 60% 配額。吸收態、震盪與深化有效性都須有事前量化門檻，不能看完保留 seed 後才改。
- 固定能力、seed 和外生環境，對照不同人格；再固定人格對照不同親歷事件／可知情報。每個後繼必須有決策 trace 與真實來源，且當移除相關資訊時其選擇或候選可行性有可解釋差異。涵蓋有證據可深化、反證／挫折後轉向、資源不足而休整、持續收益而延續、完全沒有可行後繼等 fixture，另驗證月末新事件不能在同月被用於目標評估。
- 比較舊 0.2.0 存檔在原規則下的回放 hash、M1 遷移複本，以及新規則同 seed 同版本的 hash；新增 RNG 抽樣不可改洗無關人物或同月公平結算。Dashboard 須能從現目標回看父目標、完成／轉向事件與當月留任或切換原因。
- 失敗：另一個目標變成新吸收態；無理由快速來回切換；角色靠未知事件升階；進度條滿格即宣告世界事實／解鎖；舊版存檔被靜默套新規則；只靠漂亮文字而沒有實際可行行動差異。若現有行動原語不足以表達階段，先記為 M3 需求，不替 #8 虛構機械效果。

上述是設計選擇，不是已驗證的行為效果。[#25 的現況量測](https://github.com/lalagrass/earth-ascension/pull/25)只證明漏斗：30 seed 的第 60 月有 92–99% 人物處於「穩定生活」，2,287 次切換均朝向它；尚未證明哪一個後繼規則較好。
