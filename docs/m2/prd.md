# M2 PRD — Living Characters

狀態：供決策的規劃稿，未實作。M2 不進入 M3。依據 [M1 現況](../review-retro.md)及[研究](research.md)。

## 產品假設與成功定義

玩家創造人物後觀察其人生。M2 要讓人物在相同能力與環境下因人格而有不同取向，在人格相同但經歷不同時有可解釋的分岔；其後數月仍可看見重大事件的影響。人物可以持續工作或研究，前提是生計、進度、承諾或技能回報足以解釋該選擇。平淡人生亦是有效結果。

這是遊戲內部行為一致性假設，不宣稱模擬真實心理或社會。M1 的 20 seed、12 月實驗已見社交／探索偏好差異（102 對 0 個社交月；37 對 138 個研究月），但兩組同時改了多項偏好，未測長期目標、經歷效應或因果品質；40 點優勢也尚不能解讀為平衡結果。[原數據](../../artifacts/experiments.md)。

## M2 必備能力（P0）

1. **持續目標與短計畫。** 每人至多一個活躍長期目標及一個短期步驟，另可記錄候選目標。目標有類型、起因、開始月、預期檢查月、進度、狀態及停止條件；短計畫從有限行動集合選下一步，通常在 3–6 月檢查。生計／健康可暫時打斷。重規劃須由進度、限制或重要事件觸發，不能每月任意換目標。容許有理由的連續工作；無進度且無新理由的長期單一行動須可被觀測和調整。
2. **重要記憶與有限情報。** 只有已觀察、親歷或由有來源的交流取得之事件，才能進入人物知識與記憶。重要記憶採結構化事件引用及顯著性，不再只保留最近 12 條文字。死亡、重要發現、重大關係變化、長期目標的成功或失敗可成為候選；普通工作不必永久記憶。記憶影響目標或行動時，原因必須指回事件 ID。全局知識不等於個人已知。
3. **關係與人格演化。** 關係是定向的信任／態度與最近互動原因；單次交流不保證互惠。人格、價值偏好與先天能力分離。只允許經可定義的重複或重大經歷，以有界幅度緩慢改變人格／價值；不能由一次隨機擲骰重寫性格，亦不能以事件文字作推斷。長期穩定與可塑性都須測量。
4. **公平同月結算。** 所有人基於同一決策快照提出意圖；衝突及互動在固定規則下解決，月底才提交新狀態。同月新情報原則上次月可用；顯式雙方互動在結算後同時記錄。人物 ID／建立順序不得給予系統性優勢。
5. **可觀察、可回放。** Dashboard 的人物觀察顯示活躍長期目標、短步驟、進度、關鍵記憶、關係、決策原因與來源；歷史快照可看當月當時所知。固定 seed 與規則版本可重現純規則結果；M1 舊存檔有可驗證的讀取或明確遷移途徑。

## 使用流程

玩家在現有六頁 Dashboard 創角、投放、按月推進，在人物觀察中查看「此月目標／下步／關鍵記憶／關係／為何行動」，並由原因連到生命歷程中的來源事件。切換歷史月時顯示該月快照，不以未來情報改寫過去。沒有合格記憶或關係時明示「尚無」，不補造故事。

## 優先級與邊界

P0 使用無 LLM 的規則策略，保留 M1 六種月行動及既有建人、點數與月推進流程。可擴充少量目標及事件種類，但每項需能在現有月結算中產生可驗證狀態變化。P1 是離線、無付費呼叫的影子方案設計與手動評估；不介入正式世界狀態，通過[驗收](acceptance.md)才討論啟用。

非目標：完整 BDI 解譯器、自然語言聊天、家庭／婚育與完整職涯、知識網路、動態背景人口、組織策略、戰爭、跨世代、小說生成、臨床人格推論、全員 LLM、付費 API、公開部署及 M3。這些不作為 M2 驗收前置。

## 交付判準

各 P0 能力須通過[實驗與回歸](acceptance.md)，並對比 M1 與 M2 消融組；門檻中的候選數值先跑 M1 基線和小樣本後校準，未校準前不得宣稱達標。若只產生更多事件文字，卻不能證明事件影響後續選擇，視為失敗。
