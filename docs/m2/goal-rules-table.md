補充（同一份程式碼的共同機制）：

- 行動選擇＝每個行動分數＋均勻噪音 ±0.9 取最大（`_intent` L215–220）；`休息`在健康低時加分，`研究`／`修習`在健康 < 35 時 −1（L194–196）；財富 < 75 時 `工作` +1（L182）。
- 行動層的記憶修正（L203–214）：發現 → 研究 +0.35；關係 → 社交 +0.25；關係挫折 → 社交 −0.6；目標受挫 → 研究 −0.4。這四項**不看目前的目標**，所以不論目標是什麼，社交挫折都會壓低社交，而目標受挫只壓低研究。
- 進度只看「這個月選了預期行動」，不看結果：研究月未必有發現，社交月沒有同區同伴（`target is None`）也算進度（L329–332）。
- 完成與轉向只在 `review_month`（每 4 月）判定（L337）：進度滿 6 後最長要再等到下個檢查月，所以非休整目標的最短完成時間是第 8 月，耗時必為 4 的倍數（量測中位數 8、p90 12–32）。
- 規則 0.2.0／0.2.1 不走 `_review_rest`：休整進度由「工作」推動，滿了後 `target += 6` 永遠留在休整（L341–345）。本表只描述 0.2.2。
- `legacy_custom`（舊檔自訂目標，L61–66）：沒有預期行動、不計進度、不會完成，只有檢查月推遲 `review_month`。

## 3. 容許偏離的候選清單（供維護者評估，未採用）

維護者在 #4 要求表中標出「容許偏離理由」。現行規則**沒有**明確的容許偏離清單；偏離只是分數加噪音的自然結果。下列是從現行機制可以讀出的、可能值得明文化的候選，是否採用、各自算偏離還是正常，請維護者決定：

1. **健康保護**：健康低時選休息（現行有分數路徑）。量測：偏去休息的月份平均月初健康約 67–72，並非主要在低健康時發生，意味「休息」多半來自噪音／人格而非健康。
2. **生計保護**：財富 < 75 時工作 +1（L182）。對預期行動不是工作的目標，這是**逆向**壓力；量測顯示該壓力下仍偏離的占比（建立關係 25.6%、探索靈氣 19.4%、服務社群 18.2%）。
3. **無同伴的社交**：社交預期行動在同區沒有同伴時仍計進度（不合理的候選？）。本 PR 未量測此項的頻率，列為待查。
4. **能力與人格匹配**：高悟性者的研究在任何目標下都有較高分（L186），是否算「合理偏離」取決於產品意圖。
