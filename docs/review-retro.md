# M1 Review 與 Retro

## Review

- 模型：`engine.py` 純規則結算，`store.py` 以單一 SQLite 交易保存月快照與事件；前端不能直接改寫世界事實。
- 可重現：每人每月 RNG 由 seed、月份、人物 ID、規則版本決定。測試涵蓋相同初始狀態 12 個月完全一致。
- 一致性：每月檢查點數、健康、財富、靈氣與組織資源範圍；歷史快照與死亡人物保留。
- 風險：跨人物即時社交會依固定遍歷順序影響關係；規則改版後應為舊存檔加上遷移策略。HTTP 介面設計供本機單人使用。
- 安全：無外部依賴、憑證或金流；僅綁定 localhost。姓名在 HTML 輸出有逸出處理。
- 研究：20 seed 的偏好與點數測試已執行，見 `artifacts/experiments.md`。60 月無玩家測試已通過；結果尚未校準真實統計。

## Retro

有效：用標準函式庫避免大型下載，快速取得完整月度閉環；保存決策依據讓結果可以追溯。測試先發現死亡案例測試設定不穩定、SQLite 連線未明確關閉，均已修正。

待改進：模型目前過於抽象，靈氣研究速度、經濟與角色關係需更嚴謹的指標與校準。Chrome 實際介面驗證與截圖已完成，並修正歷史選單的現況月份顯示；詳見 `artifacts/ui-verification.md`。其他瀏覽器與長期平衡仍未驗證。

## M2 建議，未開工

1. 校準研究速度、知識傳播、職業與資源收支，使人物長期選擇更可信。
2. 完成多 seed 人格與點數平衡實驗，調整付費點數可能造成的優勢。
3. 加入更完整的人際、家庭與組織變遷，並建立可選的 Tier 1／2 決策介面。
