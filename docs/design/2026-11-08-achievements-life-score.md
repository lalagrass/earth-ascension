# 山門紀成就表與一生評分

Nov 8, 2026 · @Yuying Chen

## 結論

可以，而且大部分材料遊戲裡已經有了。建議分三層，都從同一份「事件紀錄」算出來，不另寫判斷：

1. **里程碑**：第一次做到某件事是第幾日（第一次學會一招、第一次打退野狗、第一次收徒、第一次上崖）。可玩性工具現在算的就是這個，改成遊戲和工具共用同一張表。
2. **成就表**：寫成資料列的條件，例如「白身開局，不靠師父讀懂第一卷」「門派沒收徒也撐過 90 日」。只記錄、不給遊戲內獎勵。
3. **一生評分**：不合成一個總分。分成三張分數卡：**個人心願**（照這個人自己的價值觀加權）、**門派**、**江湖眼中**（傳聞）。分數用「同樣開局、同樣天賦的人，模擬一百次裡排第幾」表示，所以天賦差的人走得遠，分數一樣高。

閒雲野鶴型的人物因此不會吃虧：他的「個人心願」主要看自在與情義，門派分數低是事實，但不拿來扣他的分。

## 遊戲裡已經有的材料

| 現有機制 | 位置 | 可以怎麼用 |

## 第一層：里程碑

- 一張表 `MILESTONES`，每列一個事件 id、名稱、要記「誰」還是「門派」。例：第一次學會一招、第一門整套武學、第一次打退野狗／野豬／山賊、第一次上崖、第一卷讀懂、立匾、第一個徒弟、第一次有人因傳聞上門、第一次修好一座設施、第一個徒弟出師。
- 記錄只寫日數與當時的人，不耗亂數、不改模擬，所以 golden 不變。
- 畫面：大事記旁一欄「門派年表」，每個人的卡片有「個人年表」。
- 可玩性工具改讀這張表，報告裡的里程碑首達日就和玩家看到的一致。

## 第二層：成就表

成就是資料列：`{ id, 名稱, 條件, 類別, 隱藏? }`，條件只引用事件統計（計數、首次日、最大值、某段時間內有沒有發生）。分四類：

| 類別 | 例子 |
| --- | --- |
| 進程 | 第一門整套武學；一門武學練到大成；三代同門 |
| 挑戰 | 白身開局，30 日內不靠師父讀懂第一卷；沒蓋大廳就收到第五個徒弟；90 日沒有山賊上門（因為窮，或因為名聲讓他們不敢來） |
| 人生 | 一生沒收徒、走遍三座崖、與一人好感達知己（閒雲野鶴也拿得到） |
| 隱藏 | 達成才顯示，例如讀到奇書卻沒有自宮 |

- 不給獎勵、不影響模擬。
- 每條成就的條件要能在遊戲內做到；用可玩性工具跑 12 個種子，列出每條的達成率（C 類，只報告）。從來沒人達成的條件要檢查是不是走不通。

## 第三層：一生評分

### 六軸事蹟

每個價值觀一個軸，只用可量的事蹟：

| 軸 | 事蹟（舉例） |
| --- | --- |
| 武道 | 最高武學層數、會的整套武學數、悟出的招 |
| 門派 | 弟子數、出師的徒弟、修好的設施、傳了幾代 |
| 俠義 | 打退山賊、護住村民、救人 |
| 情義 | 知己數、家人、徒弟對師父的好感 |
| 自在 | 去過的地方、上過的崖、不受職責綁的日數、休閒時間 |
| 名望 | 外面流傳的不同傳聞數、傳到多遠（村路、市集、茶攤） |

### 分數怎麼算（不設權重常數）

- **相對於同條件的人**：用可玩性工具，對同一個開局、同樣先天屬性的人跑一批模擬（自然玩法），得到每一軸的分布。玩家這一局的分數＝在這個分布裡排第幾（百分位）。天賦差的人只跟天賦差的人比，所以答案就是「這個人以他的條件，發展得如何」。
- **個人心願分**：六軸百分位，用這個人自己的 `d.values` 加權平均，再扣違心。閒雲野鶴的人重自在與情義，所以分數主要看這兩軸。
- **門派分**：門派軸的百分位，加上門派層級的事蹟（傳承、設施、弟子出師），只在有立匾時顯示。
- **江湖眼中**：名望軸，只看傳聞。可能跟實際差很多，這正是 R8 的意思（做了好事沒人知道，江湖就不知道）。
- 三張卡並列，不合成總分。

### 什麼時候看

- 任何時候都能打開「生平」頁，看到目前的三張卡與年表。
- 人物過世或退隱時，寫出一份生平（像 Stone Soup 的結局檔），列年表、成就、三張卡。之後若做「傳承三代」志向，這份生平就是傳給下一代的依據。

## 怎麼排

| 步驟 | 內容 | 改模擬？ | 建議時機 |
| --- | --- | --- | --- |
| A1 | 事件統計 + 里程碑表；可玩性工具改讀表；年表畫面 | 否，golden 不變 | 可以馬上插隊，不衝突 |
| A2 | 成就資料列 + 成就頁；工具列出每條達成率 | 否 | 第二十五輪之後 |
| A3 | 同條件分布基準檔 + 生平頁的三張卡 | 否（基準是工具產生的檔案） | 第二十六輪之後，因為時間與尺度會改分布 |

驗收（A 類）：里程碑與成就不耗亂數，加上之後 golden 不變；每條成就條件在固定情境能觸發也能不觸發；同一份紀錄，工具與畫面算出相同的首達日。
