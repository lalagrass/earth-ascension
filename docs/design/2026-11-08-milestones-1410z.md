## 第二十五輪：中期活得下去

照提示玩到 90 日，每一局從第 30–45 日起心情低落佔比升到接近 100%，人口停在 4–7 人，90 日內山賊來 8–15 次。追到三個原因：

| 現象 | 原因 | 修法 |
| --- | --- | --- |
| 倉裡有 64 份菜，煮好的飯是 0，全員餓 | 「餓」只讓人想吃，不會讓人想去煮；煮飯分數輸給睡覺和偷閒 | 25b：沒有現成的飯、又有菜時，煮飯承接吃的急迫度，不加新常數 |
| 沒名聲也一堆人來拜師 | 人選的現況預設「沒飯沒床」，入門永遠划算，聽到一則傳聞就來 | 25c：每個人選的吃、住、安全照實寫；功夫只看傳聞裡說的門派本事；新弟子繳錢或做雜務抵食宿 |
| 窮門派也每 5–6 日來一次山賊 | 行商每 5 日固定付 15 錢並放出「存糧」傳聞，不管有沒有賣東西；房子也算成財富 | 25d：真的成交才有傳聞；山賊只算聽到的、搬得走的錢糧，再對比聽說的守方本事，划算才來 |

- 25a 工具先跑 90 日，每 15 日一段，存成 `base-90d.json`。
- 25e 三項合併後重跑，若心情低落仍密集，再追回復與連戰的成因。
- coding agent 問行商的菜價：市集沒有菜價，他用「一畦收成抵一日雇工工錢」推出來。我認為這個讀法合理，會在 review 時確認標成「推導」。
- 參考：RimWorld 的來犯看財富（這裡改成只算聽到的、搬得走的）；Kenshi 的強盜挑看起來弱的目標；Banished 與 Dwarf Fortress 的饑荒來自人口成長快過產能。
- 驗收：每條規則一個 A 類測試；90 日的心情與來犯次數列 C 類，不為 C 改常數。
