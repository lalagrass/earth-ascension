你的思路，整理成五句話

  1. 同一張地圖。村民挑水、種田、打獵，和打架是同一個世界，不切戰鬥畫面。打起來旁邊的人照常過日子。
  2. 先寫實，後浪漫。入門到小成像真的練武：羅漢拳、太極劍、八卦掌一招一式，招對招、腳步進退、拳拳到肉，沒有光。大成以後才開始有內力的痕跡，絕學才有特效、字章和林克時間。
  3. 一招一式慢慢學會。每一招有「形、用、戰」三層熟練，從站樁、套路、喂招、對練、切磋到實戰，在門派生活裡一層層練上去。「有鳳來儀」「力劈華山」是一招一招解鎖、第一次在實戰用出來時記入紀事。
  4. 戲劇來自差距，不來自特別規則。同一套判定（前搖、四種接法、架勢）：兩邊都弱就是菜雞互啄、拖很久沒人受傷；兩邊都強就是久戰，等一個破綻一擊定勝負；差距很大就是高手錯身、隨手一掌，一路走過去倒一地。三種場面都不用另外寫。
  5. 成長看得見。一次應付得了幾個人（應接 1、2、3、5、10），一波波魔教殺上來時闖得過幾人；和小龍女並肩、背靠背、合擊、陣法，把一個人的成長變成一群人的打法。

新加兩段示意：「拳拳到肉」（整勁的發力鏈、八卦掌走圈換掌）和「高手穿行」（差距大時的碾壓）。下面的章節是每一句話的細節。

拳拳到肉：力學感怎麼做

  • 勁是一條鏈。蹬地、擰腰、送肩、出拳，每一節是一個熟練度。入門只動手臂，打中了對方也幾乎不動；練熟了四節連成一條，同一拳能把人推退半步。這是傳統武術講「整勁」「力從地起」的意思，正好能變成數值。
  • 打中的那一下要有重量。畫面停一兩格（打擊停頓）、被打的人退步、腳下起塵、兵器相碰有火花。勁越整，停得越久、退得越遠。這些都不用光效。
  • 不同拳種打法不同。羅漢拳、長拳正面直進；太極以柔帶開再反擊；八卦掌繞著對方走圈，從側面換掌；腿法要距離；擒拿要貼身。差異寫在每一招的「法、盤、距離、步法」裡。

先回答你這次的兩個問題

閃避太遠、走過去才打，確實不合理。已經改了：離得遠就用輕功直接縱過去；比對方強的人只錯開一步就立刻反擊（後發先至）；只有比對方弱的人才往後退，被纏上就往同伴身邊逃。示意「迎戰魔教」裡加了一個入門弟子，可以看到強弱兩種閃法的差別。

前面的設計確實偏電玩。林克時間、應接小圈、字章都是為了讓小人看得懂而加的「遊戲層」。這次把順序反過來：寫實的武術是底子，遊戲層只留給高手和絕學。入門、小成的人打起來應該像真的練武的人：腳步進退、一招一式、多半落空或被擋，不放特效、不放慢。到大成以後才開始有光，絕學才有字章和林克時間。下面兩節是新加的寫實部分。

練武是日常：站樁、套路、喂招、對練、切磋、實戰

傳統的練法大致是先練基本功（站樁、馬步、壓腿），再練套路，然後由師父或師兄喂招、學每一招怎麼用，再練兩人固定的對練，最後才自由切磋和實戰。老話說「練拳不練功，到老一場空」。這個次序本身就是門派生活，可以直接搬上地圖：

階段地圖上看到漲的是
站樁清晨外功場，孩子蹲馬步，旁邊燒一炷香；腿酸站起來會被叫回去根基（內力、架勢上限）
走套路一招一式走，招名浮在頭上；師父在旁糾正「馬步再低一點」每一招的「形」
喂招師兄慢慢餵一招，師弟練怎麼拆、怎麼反擊每一招的「用」
對練兩人照固定順序你來我往「用」，以及兩人的默契（關係）
切磋弟子之間自由過招，點到為止，會影響關係「用」轉成「戰」
實戰獸襲、山賊、魔教「戰」

每一招有三層熟練：形、用、戰。只練套路的人「形」很熟，打起來卻只用得出一兩招，因為其他招的「用」還沒練；被圍、架勢低的時候，更是只剩「戰」熟的招用得出來。這就是菜雞互啄最真實的樣子，也讓「慢慢學會一招一式」變成看得見的事：某一天，弟子第一次在實戰裡用出「獨立反刺」，記進紀事。

入門套路可以用真實的套路，例如五步拳（弓步衝拳、彈踢衝拳、馬步架打、歇步蓋打、提膝仆步穿掌、虛步挑掌）；少林一系從羅漢拳起步，動作簡樸直接、多用掌，攻防藏在姿勢裡；太極劍可以用常見的三十二式（起勢、並步點劍、獨立反刺、仆步橫掃、向右平帶、向左平帶、獨立掄劈、退步回抽……，各派名稱和順序略有不同，正式採用前要再對一次）。示意「練功場」。

寫實過招：招對招，而不是互扣血

  • 每一招是一筆資料：什麼「法」（劍有刺、劈、點、撩、掛、截、抹、帶、抽；刀有劈、砍、掃、撩；拳有衝、劈、架、蓋），打哪一盤（上、中、下），要多遠，怎麼走步（進、退、側、轉）。
  • 拆招就是找對的招：被攻擊的人從自己「用」得出來的招裡，找能拆這一招的那一招。上盤劈可以用「平帶」帶開、用「架」頂住，或側身讓過；橫掃可以退步回抽讓過，或提膝；直刺可以截、可以帶。拆完順勢接一招反擊，就是見招拆招。
  • 距離是真的：腿和長兵要遠一點，拳掌刀劍在中間，貼身才用肘、膝、摔、拿。兩個人一直在調距離，進一步、退半步，這比任何特效都更有武術的味道。
  • 戰報寫成小說：每一回合寫成一句話，「山賊一招『力劈華山』當頭劈下，主角側身『向右平帶』把刀帶開，順勢『獨立反刺』」。中文 MUD 就是靠這個讓人覺得自己在練武。
  • 低段沒有特效：只有腳步、兵器相碰的火花和招名。示意「寫實過招」。

一段話說完整套設計

戰鬥就發生在門派生活的同一張地圖上，不切畫面。真正分勝負的不是血量，而是架勢。每一招都有前搖、出手、收招三段，被攻擊的人在前搖時有四種接法：看破、閃、招架、中招。接住了，雙方掉架勢；架勢先空的人露出破綻，下一招就是重傷（打瞎、傷手、內傷）甚至一擊致命。敵人三三五五一波波來，角色不站樁，用輕功周旋、拉開、繞側面，被圍時最多四人貼身，外圈的人繞著游走等空位；貼身的人超過自己應付得來的人數（應接），多出來的招就接不住。練功變強就是招式變多、前搖變短、能應付的人變多，最後學會改寫規則的絕學。

四個目標：好看（輕功、殘影、字章、局部慢動作）、看得懂（先預兆、後結果，顏色固定意思）、好玩（以少打多要靠走位和看破，不是數值碾壓）、看得見成長（每個弟子都有「一次應付幾人、闖過幾人」的紀錄）。

一、核心：三條資源、三段出招、四種接法

資源意思什麼時候會動
架勢還撐不撐得住。真正的勝負條每次招被接住，雙方都掉一點；不打時慢慢回
氣血真實傷勢，打完會帶回生活（養傷、內傷）只有「中招」和「破綻重擊」才掉
內力本錢。閃避、輕功、反震、絕招都要花打坐、休息回；內力見底就只能硬接

每一招分前搖 → 出手 → 收招。前搖是預兆（地上的紅色扇形），長短看熟練度；收招是空檔，對方可以趁這時反擊。用遊戲的固定時間步長來跑，不用計時器，結果可以重播。

菜雞互啄和高手久戰都從這裡自然長出來：兩邊都弱，招常常揮空、互擋，架勢慢慢掉又慢慢回，打半天沒人受傷；兩邊都強，招招被拆、架勢一點點見底，誰先空誰就被一擊定勝負。不用為這兩種情況另寫規則。

二、周旋：一波波來，邊走邊打

塔防只借「一波一波來」的節奏，角色不站樁。魔教三五成群從不同方向來，角色要決定先打哪一股、怎麼不被包夾。

  • 交戰圈：最多四人貼身。被圍時只有內圈四個位置能出手，外圈的人握著兵器繞圈游走、叫陣、等空位補上，畫面不會疊成一團（Kenshi 的 attack slots 就是這樣，玩家討論常把它調在 3 到 5）。
  • 應接：一次應付得來的人數。入門 1 人、小成 2、大成 3、化境 5、絕學再往上。貼身的人超過這個數，多出來的招就沒機會看破或閃，直接中。頭上一排小圈顯示：金色是正在應付，冒紅圈就是被圍太多。交戰圈固定四個位置，所以應接到 4 以後內圈怎麼圍都不怕，剩下的是靠群攻招把外圈也一起清掉。
  • 輕功是周旋的工具。快被包夾時縱躍到人少的一側，挑落單的、繞到側面打。這是角色自己判斷的（不用玩家操作），玩家看到的是一個人在敵群裡穿梭。
  • 林克時間。在敵人前搖的最後一刻閃開（完美閃避），身邊一圈敵人放慢約一秒，自己照常出手連打幾下。身法和看破夠高才觸發得到，是高手才有的爽感。只放慢那一圈，圈外的生活照常。預設全自動；以後可以讓玩家在林克時間裡點一下，選要打哪個破綻或放哪招絕學，這是唯一需要操作的地方。
  • 輕功交錯。兩個身法都高的人對上，會變成來回突進、互相穿過、半空交擊的打法，像忍者對決。兩人同時突進撞在一起就是「交擊」，火花一閃、雙方架勢都掉。
  • 成長看人數。每個弟子有兩個紀錄：一次最多應付過幾人、在木人巷或魔教來犯時闖過幾人。練出新招、身法變高，這兩個數字就往上爬，從「只能闖過兩人」到「一人迎戰一整波」。

三、一招一式變強

每門武學是一串有名字的招，熟練度到了才會下一招，地圖上只用已學會的招，招名浮在頭上（入門的「力劈華山」、小成的「有鳳來儀」），第一次使出新招記進門派紀事（中文 MUD 的老做法，換成畫面）。每升一境多一種能力，而不是只加傷害：

五、群戰：結伴、合擊、陣法

  • 結伴背靠背：兩人靠近時，背後來的招改由同伴接，兩人的應接互補。和小龍女一起打上門時，一人一邊，就不怕被包夾。
  • 合擊招：兩人都學會、站得近、關係夠深才打得出來（程式裡已有楊過與小龍女、郭靖與黃蓉等配對加成，可直接當門檻），例如玉女素心劍的雙劍合璧，蓋「合」。
  • 陣法：陣中的人共用一條陣勢，打任何一人，力道沿連線分給全部人；要先看破陣眼才破得了。我方弟子學了陣法，守山門時也能用。
  • 一招破眾：一次出手對範圍內每人各判定一次看破，看破幾個就打中幾個，所以同一招在高手手上才變成令狐沖一劍刺瞎一圈人。
  • 打上門：現在的討伐是在面板上算結果，改成隊伍上地圖、走到敵寨，門口一波波出人，換我方闖關。

六、讓小人物也看得懂

  1. 先預兆，後結果：紅色扇形是對方要出的招，越滿越近。
  2. 顏色固定意思：紅是威脅、金是你看穿了什麼、白藍是內力相撞。
  3. 局部慢動作：看破、反震、林克時間只放慢那一圈，加 0.1 到 0.2 秒停格；圈外照常。
  4. 字章代替細節：破、震、現、合、勝。人只有四十像素高，字比手勢清楚。
  5. 強度跟著境界：低段只有連線，大成才有光，絕學才有字章；平時不掛光環。
  6. 長戰快轉：高手對拆幾百招用快轉加招數計數，只有決勝那一下放慢。

七、Gemini、Argon 與 Gemini Flash 的建議，我怎麼取捨

建議判斷理由
架勢與破綻、前搖／出手／收招採用和我的架勢條同一個想法，前搖三段讓看破有了明確的時機。我把「破綻值」併進架勢，少一條數值
局部時滯、林克時間採用和交手圈同一個做法，加上完美閃避觸發
太極借力、獨孤自動截招、葵花延遲倒地採用這三個比我原本寫的更有畫面，已併進第四節
四階成長（入門到絕學）合併和我的五境合在一起，每境多一種能力
九陽常態熱浪改只在圓滿才有，不然一院子人都在冒氣，看不出誰強
陣法攻擊力「指數疊加」不採用七人等於幾十位高手會把平衡打爆，改成共用陣勢、分擔傷害
虛擬碼裡用 setTimeout 出招不採用遊戲是固定步長、可重播的模擬，計時器會讓結果每次不同。改成每一步扣前搖時間
Matter.js 物理不採用擊退、縱躍只要幾行位移就夠，物理引擎會讓重播不穩定
pixi-spine 骨骼動畫先不要Spine 執行庫的授權要求使用者持有付費的 Spine 編輯器授權（依我所知的條款，網頁全文這次沒抓到）；我們的人物是程式畫的，先用分格動作就夠
Yuka.js（行為與轉向）借概念MIT、不綁 three.js，追逐、躲避、保持隊形都有。但我們的人數少，自己寫幾十行轉向就夠，不必加相依套件
RBush、四叉樹以後再說畫面上同時幾十人時，逐一比對距離完全夠快；上百人時再加
部落與彎刀參考一部分主角帶兵、技能清場的爽感值得學，但它進戰鬥會切到戰場，和我們同一張圖的做法不同
交戰圈：內圈有限位置、外圈游走等位（Argon）採用畫面不再疊成一團，也讓「被圍」有清楚的樣子。Kenshi 確實有這個機制（玩家討論的 attack slots）。我設四個位置，配合應接
部位傷（Argon 列了頭、胸、腹、四肢、雙目）簡化採用只留目、手、身三處，只在破綻重擊和精準武學時發生。六處以上在四十像素的小人身上看不出來
兵器分工、烈毒與奇毒、暗器在圈外採用讓不同弟子有不同用處，併進第四節
太極氣場減速、累積後甩開採用比單純借力更有畫面
全局慢動作 0.5 秒改成局部全局會打斷村民的生活，和同一張地圖的初衷衝突
玩家在林克時間點破綻介入以後可選是個好的操作點，但先讓全自動好看，再決定要不要加
Your Only Move Is HUSTLE 的關鍵幀預覽不採用它是雙方同時下指令的回合制，和我們全自動的即時模擬不合
GAS 標籤式狀態（金鐘罩、失明、劍意）借概念用標籤管狀態是對的，我們用一個簡單的標籤集合就夠
Flexi、Gamesmiths.Forge、godot-open-rts用不上查過都存在、都是 MIT，但 Flexi 是 Unity、Forge 是 C#／.NET、open-rts 是 Godot 4。我們是瀏覽器 JavaScript，接不進來
「Stillwater（雨歇）」無法查證給的連結是 GitHub 的 wuxia 主題列表頁，不是某個專案
七人陣「宛若六十四位一流高手」、九陽內力回覆「指數級」不採用倍數失控會讓平衡爆掉；陣法改成共用陣勢，九陽改成回得快但有上限
後期雜兵破不了護體採用就是護體門檻：低段武學打不進，給「一人挑翻分舵」的爽感；但有罩門、毒、暗器可以破
第二份（Gemini Flash）
架勢歸零才致命、新手互啄、宗師繞步試探採用和現有設計一致，已經有示意
高手自動側身、走位中順勢出掌採用這是這次新加的「高手穿行」：腳步不停、錯身、隨手一掌
打擊停頓、剛體位移的重量感採用併進「拳拳到肉」，停頓長短和退步距離跟著整勁走
內力高一個境界就震飛、繳械改改成內力差越大反震越強，不是跨境界一刀切，避免同境界之間完全沒變化
九陽「抵消前 N 點傷害」、金鐘罩「完全免疫硬直」改九陽維持自動反震；金鐘罩維持傷害門檻加罩門，完全免疫會沒有剋法
令狐沖一瞬刺盲十五人合併就是「一招破眾」：對每個人各判定一次看破，看破幾個就打中幾個
小龍女「情網護體」互補後搖合併併進合擊：兩人都學會、站得近、關係夠深才觸發
《絕世好武功》招式部位克制（拳破掌、腿破拳）不採用這個說法查了 Steam 頁面：它是自創武功、組招式牌組的回合戰鬥，頁面沒有提到拳破掌這類克制，這點我查不到依據。我們用「法、盤、距離」決定能不能拆，不用兵種相剋表
RimWorld Combat Extended只參考概念它是改射擊彈道與護甲的大型模組，主要價值在遠程；近戰拆招這部分它幫不上
ECS 架構不採用山門紀的模擬是純 JS 物件加固定步長，人數幾十；改 ECS 是大重構，沒有好處
RBush以後再說確認是 MIT 的 JS 空間索引，但同時幾十人逐一比距離就夠快
Yuka.js 轉向行為借概念同上一份的判斷：繞步、側翼、隊形的公式可以抄，不必加套件
Shader 熱浪、全屏殘影先不要我們用 Canvas 或 PixiJS 畫小人，局部殘影已夠；全屏效果會蓋掉門派生活

八、參考

遊戲借什麼
世紀帝國、魔獸爭霸三生產與戰鬥同一張圖；只有英雄有技能和特效
全軍破敵：三國單挑圈，圈外大軍照打
隻狼、Sifu架勢（結構）才是勝負條；進階招一招一招學
魔兵驚天錄（Bayonetta）「林克時間」這類完美閃避放慢敵人的做法，最早最出名的是它的魔女時間
Hades出手前一定有預警、命中停格，畫面再亂也讀得懂
太吾繪卷架勢、提氣、見招拆招寫成可比較的數值
中文 MUD（俠客行一類）一招一式有名字、有描述，熟練了才會下一招
部落與彎刀主角在大軍裡技能清場的爽感
Kenshi同一張大地圖上生活與戰鬥；交戰圈（attack slots）；斷手斷腳的部位傷；從被雜兵打趴到一人屠城的成長
RimWorld傷勢、心情回到生活
了不起的修仙模擬器門派經營和弟子修煉放在同一張圖
絕世好武功招式連線觸發絕學、經脈內功

開源與社群

  • jynew：金庸群俠傳開源 Unity 重製（MIT，素材另有授權）。回合制，只能參考它的武功資料表。
  • Kenshi 玩家討論 attack slots：同時能打一人的近戰人數上限，大家偏好 3 到 5。
  • Yuka：MIT 的 JavaScript 遊戲 AI 庫，轉向行為的寫法可以參考。
  • Sifu 設計拆解：結構條、閃與招架的取捨、招式逐一解鎖。
  • Righteous Blood, Ruthless Blades 設計者部落格：外功、內功、輕功三分，絕招建立在三者之上。

沒有找到可以直接拿來用、又能在瀏覽器跑地圖即時武俠戰鬥的開源專案。Argon 推薦的幾個框架都是 Unity、C# 或 Godot。比較實際的是借設計，用我們自己的程式畫。

Argon 最後問到引擎和視角：山門紀是瀏覽器裡的 JavaScript，地圖用 Canvas 2D 畫，人物是 2.5D 水彩、水墨風的小人，不需要換引擎。

九、怎麼做起來

  1. 核心判定：前搖／出手／收招、四種接法、架勢條，先接在現有的狩獵與獸襲上。這一步做完就有見招拆招的味道。
  2. 周旋：敵人改成三五成群從不同方向來；角色會移動、用輕功拉開、計算應接，被圍會冒紅圈。山賊也拆成一個個人。
  3. 招式表與五境：每門武學改成有名字的招，依熟練解鎖；加上「應付過幾人、闖過幾人」的紀錄。
  4. 林克時間與絕學：完美閃避、輕功交錯，再把名功絕活一門一門接上。
  5. 群戰：結伴、合擊、陣法，最後把討伐搬上地圖打上門。

每一步的驗收就是開遊戲看一場戰鬥：看得懂、好看、想再看一場就過。只留一個確保重播結果不變的測試。
