# 硬核武學設計衝突的解法

Nov 7, 2026 · @Yuying Chen

## 結論

四個衝突都不必砸掉 Phase 4–7 想要的體驗，只要把「結果」改成由身體與物理算出來，而不是直接寫一個數字。

| 衝突 | 建議改法 | 主要參考 |
| --- | --- | --- |
| 1. 常數沒理由 | 每個常數標明是「量測值」「推導值」還是「設計旋鈕」。體能上限改成個人骨架決定的肌肉上限，疲勞改成「體能－疲勞」雙衰減模型，移速與山崖改用坡度與攤爬難度 | Banister 模型、FFMI 自然上限、Tobler 登山公式、Dwarf Fortress 材料值 |
| 2. 整門自動頓悟 | 不是「悟出」，是「看懂」：開局拳譜就含心法、身法各卷，外功練到位才讀得懂下一卷；或由伴侶／師父教 | CDDA 武學書籍、太吾讀書、KCD 技能書、N42 |
| 3. 角色特例 | 小龍女、黃蓉變成「伴侶資料列」：帶入武功、師承脈、通用技能值（如烹飪）。程式裡不出現人名 | RimWorld 背景故事與烹飪品質、CDDA 職業 JSON |
| 4. 傷害倍率 | 雙劍合璧改成「一人出招落在對手收招空檔」的時序與夹角站位，心法 ×1.28 改成「勁」與耗能這種物理量 | N42 單一成長底層、N44 攻擊令牌、第七輪 bandSyncDelay |

過度的部分只有一個：「飛身躍上三丈（約 10 公尺）山崖」在硬核物理下不可能，需要您選「改成攤爬」或「內力是唯一合法的奇幻量」（見最後一節）。

## 共同原則

四個衝突其實是同一個病：規格直接寫「結果」（倍率、門檻、自動解鎖），而不是寫「原因」（肌肉、力、時間、師承）。硬核模擬社群的習慣是反過來：只寫原因，結果讓規則算。

1. **常數三分類**，每個新常數旁邊必須標一種：
   - **量測**：有單位、有出處，例如步行 1.4 m/s、肌肉恢復 48–72 小時。Dwarf Fortress 的戰鬥就是拿真實材料的密度、衝擊屈服值在算。
   - **推導**：由量測值用公式算出，不自己另定。
   - **設計旋鈕**：故意壓縮或為了好玩而設的數，放在同一張表、寫明意圖，新增一個要您點頭。測試與驗收只能當 C（只回報）。
2. **只留一個奇幻量**。奇幻小說社群常引的 Sanderson 「硬魔法」定律：限制比能力重要，規則要讓讀者算得出來。對應到本作：除了「內力」一個有規則的量，其他一律人體與物理。藥膳、心法、輕功都不能各自开一個「突破凡人」的口子。
3. **成長只有一套底層**（N42）：身體量（肌肉、骨架、脂肪）、手熟眼熟的下限、內力上限。Phase 5 的疲勞與超量恢復應該是「肌肉」怎麼長的規則，不是第七套成長。
4. **時間尺度照常數盤點的提案**：動作用真秒、生理用日、成長與年齡用季。「一天內 3 個超量恢復週期」就是把日尺度的生理塎進秒尺度。

## 衝突 1：常數沒有理由

大部分數字都找得到真實世界的對應，而且換成真實模型後，規格想要的體驗（雜務有頂、吃得好長得快、輕功開啟高處）仍然會出現，只是有了理由。

| 規格常數 | 真實世界怎麼說 | 建議改法 |
| --- | --- | --- |
| 凡人上限 18、破限 36 | 自然肌肉量有個人上限：Kouri 1995 量到未用藥者的淨體重指數（FFMI）最高約 25，一般成年男性約 18–20。上限來自骨架與先天，食物不會把它翻倍 | 上限 = 根骨（骨架）推導的個人肌肉上限，接您 11/06 定的「骨架／肌肉／脂肪」三量。不設「破限」 |
| 雜務到 18 就不長 | 這個現象是真的，但原因是「漸進超負荷」：同一擔水對變強的人不再是刺激 | 刺激強度 = 負荷 ÷ 自身力量（沿用 3D 肌力研究的「負荷比」）。雜務負荷固定，所以自然停在某個高度；想再長就加重（石鎖、點卡窯的重水桶）。不必寫 18 |
| 每次疲勞 +25–35、滿 100 痠痛 | 運動科學用 Banister「體能－疲勞」模型：每次訓練的負荷同時加進體能（衰減時間常數約 42 天）與疲勞（約 7 天），表現 = 體能 − 疲勞。肌肉痠痛約 24–72 小時 | 負荷 = 時間 × 強度（MET 或負荷比）。疲勞以日為單位衰減。數字是引用值，不是自訂 |
| 一天 1 個成長週期，藥膳變 3（黃蓉 4） | 超量恢復一輪要一到三天，不可能一天三輪。遊戲的做法是遞減：RimWorld 每技能每天淨獲 4000 經驗後只剩 20% | 拿掉「週期數」。同一天練太多，疲勞項自然吃掉收益，就是遞減 |
| 藥膳立即消除 65% 疲勞 | 營養影響的是「能不能長」，不是「馬上恢復」。蛋白質補充對增肌有幫助但幅度有限，約每公斤體重 1.6 克以上就飽和（Morton 2018 統合分析）。Project Zomboid 就是這樣做：蛋白充足力量經驗 ×1.5，嚴重不足 ×0.7 | 食物變成「營養充足度」：不足就長不了、甚至掉肌肉；肉、蛋、藥材這類食材把它補滿。「採藥才有加成」的體驗仍在，只是變成「不採藥、只吃白飯會長不動」 |
| 移速 +35% | 平地自選步速約 1.4 m/s，訓練對平地速度改變不大；差別在上坡與負重。Tobler 登山公式給出速度與坡度的關係 | 身法提高「功率體重比」與平衡，影響上坡、負重、亂石地的速度（接您定的「練過真的走得快」） |
| 山崖門檻身法 16／24／32，高 3／7／15 丈 | 1 丈約 3.1 公尺，即約 10／22／46 公尺。人類垂直跳高頂尖約 1 公尺，跑酷蹬牆可抓到約 3–4 公尺的牆緣 | 山崖是「攤爬路線」：每条路線有高度與抓點難度，能不能上去看握力÷體重、技巧與耐力；失手就是墜落，由現有的層狀傷勢算。也可以蓋木棧、繩索繞過去 |
| 崖頂練功 ×1.25、瀑布 ×1.4 | 瀑布沖擊是真的外加負荷；崖頂則沒有生理上的理由 | 瀑布 = 負荷比變高，由「刺激強度」自然算出；崖頂的好處改成「沒人打擾、能連續練」，不打倍率 |
| 好感起始 55、開山寬限 10 日 | 沒有真實對應，純設計選擇 | 留著，但標為「設計旋鈕」並寫意圖 |

## 衝突 2：整門武功自動頓悟

建議把「悟出」改成「看懂」：心法與輕功的內容一開始就寫在拳譜的後幾卷裡，外功練到位才讀得懂。玩家感受幾乎一樣（練到小成，下一層自然打開），但來源是「學」，符合 N42。

**外界怎麼做**

- **Cataclysm DDA**：每種武術是一筆 JSON，一組招式各自有技能門檻。武術本身主要靠讀書學會，每讀一次有 1／(10 + 難度 − 主技能) 的機會，技能越高越容易讀懂。
- **太吾繪卷、Kingdom Come: Deliverance**：功法與技能書要讀或拜師才有，而且讀書本身有門檻。
- **武俠原著**：郭靖的全真內功是馬鈺在懸崖上夜夜教的；「由外而內」是一條訓練路線，不是自己想出來的。
- **真實武術**：站樁、呼吸、發勁方法都是師父口傳。外功苦練本身只產生身體適應（肌肉、骨密度、氣息控制）。

**建議**

1. **拳譜分卷**（主推）：全真入門拳譜寫成一筆資料，內含「純陽拳／玄門心法／金雁功」三卷。每卷有讀懂的前提（前一卷的火候與身體量）。前提達到後，要花時間去讀與試，悟性高的人讀得快。日誌寫「純陽拳練到小成，拳譜第二卷的吐納法終於看懂了」。
2. **師承教**：沒有拳譜的路線就由會的人教（N12 師徒教學已經有了）。小龍女是古墓派，教不了全真心法，所以主角這條必須靠拳譜。
3. **外功苦練的產出**只是身體量與手熟，它讓讀懂更快，但本身不生出武學。

A 類測試：沒有拳譜、也沒有會的人在身邊，練多久都學不到心法。這和 #506 悟招重審是分開的：那邊處理「吃虧悟出一招」，這裡只處理「整門」。

## 衝突 3：按角色寫特例

建議程式裡不出現任何人名；小龍女、黃蓉都是「伴侶資料列」裡的一列，別人也能照同一張表加進來。

**外界怎麼做**：RimWorld 的背景故事與特質是 XML 資料，寫「哪些技能加幾級、哪些工作做不了」；烹飪品質是通用烹飪技能的結果，不是某個廚師的特權。CDDA 的職業、Dwarf Fortress 的生物資料也都是同一個做法。

| 特例 | 變成哪個通用欄位 |
| --- | --- |
| 小龍女、黃蓉各自的領悟鏈 | 「師承脈」欄：古墓、桃花島各一筆資料，寫帶什麼拳譜、能教什麼（接上一節） |
| 黃蓉煮的多 1 輪 | 通用「烹飪」技能值，黃蓉這列開局就很高。菜的品質決定營養充足度（上一節的食物模型），誰烹飪高都一樣 |
| 「百花玉蜂藥膳」等菜名 | 食材與師承脈對照表。玉蜂漿是古墓的食材，而不是小龍女的倍率 |
| 合宗名稱「終南雙劍山莊」等 | 兩個師承脈組合的預設牌區，放資料表 |

A 類測試：新增一列沒名字的「測試伴侶」，只改資料不改程式，就能走完一套開局。

## 衝突 4：直接加傷害倍率

建議雙劍合璧不加任何倍率，它的強改由「兩個人配合」在時序與站位上自然打出來。這些機制大多已經在遊戲裡了。

**為什麼二打一真的比較強（真實世界的理由）**

- **反應不過來**：認知心理學的「心理不應期」（psychological refractory period）指出，兩個刺激相距很近時，對第二個的反應會明顯變慢。
- **收招空檔**：對手接住第一劍時正在收招，第二劍落在這個空檔就很難擋。遊戲裡已有失衡空檔 `balanceOpenUntil` 與收招時間。
- **一次只能面對一個方向**：兩人夹角超過 90°，對手的架勢只能護住一邊。N44 攻擊令牌與圍攻位已經模擬這件事。
- **互相掩護**：原著「玉女素心劍法」的核心是一人的破綻由另一人補上。對應 N36 的「截擊」：替同伴擋下攻向他的招。

**建議**

1. 合璧要練：兩人一起練的次數，讓「等同伴」的延遲（第七輪的 bandSyncDelay）縮短，第二劍更準落在空檔。這是 N42 的「手熟」套在搭檔身上，不是新的成長。
2. 防守方對第二個威脅的反應會變慢，慢多少用文獻值，而且對所有圍攻都成立，不只是雙劍。
3. 心法 ×1.28 也改：心法的效果寫成「勁」（下盤到拳的發力鏈效率）與「耗能」（同樣動作花的精力較少）。這正是 N42 的要求：火候用秒與勁表示，不用傷害倍率。

B 類測試：同樣兩個人，配合前後的勝率差別，由「第二劍落在空檔的比例」算出期望值來驗。「合璧要強多少」只當 C 回報。

## 建議的 issue 拆法與待您決定

建議 Phase 4–7 照您的決定先照規格做完，再開下面六個修正 issue，掛在 #513 之下。只改 hermitage 模式，舊開局 golden 不變。**還沒開**，等您點頭。

| 編號 | 內容 | 取代規格裡的 |
| --- | --- | --- |
| R1 | 常數三分類規則＋檢查工具：每個新常數必須標量測／推導／旋鈕 | 「出自 Phase N 規格」標註 |
| R2 | 身體成長改用「負荷比＋Banister 體能疲勞＋營養充足度」，上限來自根骨骨架 | 18／36、疲勞 25–35、藥膳 65%、每日 1→3 週期、瀑布 ×1.4、崖頂 ×1.25 |
| R3 | 拳譜分卷＋師承教，整門武學只能學 | 外功→心法→輕功自動頓悟 |
| R4 | 伴侶資料列＋師承脈表＋通用烹飪技能 | 小龍女／黃蓉的特例、黃蓉多 1 輪 |
| R5 | 合璧 = 時序、夹角、截擊；心法 = 勁與耗能 | 雙劍合璧 ×1.35、心法 ×1.28、耗能 −25% |
| R6 | 山崖改為攤爬路線（看下面 D1）、身法影響坡地與負重速度 | 身法 16／24／32 門檻、移速 +35% |

R2 依賴 11/06 定下的「骨架／肌肉／脂肪」三量，這個也還沒開 issue，可以一起開。

**要您決定的兩件事**

- **D1 山崖怎麼上去**：(a) 改成攤爬，輕功是身輕與平衡的技巧，完全硬核（推薦）；(b) 保留飛身躍崖，但只由「內力」這一個奇幻量用規則算出來。
- **D2 食物能不能破人體上限**：(a) 不能，食物只決定「能不能長到自己的上限」（推薦）；(b) 可以，但當作內力層的效果。
