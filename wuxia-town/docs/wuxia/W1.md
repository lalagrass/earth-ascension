# W1（#553）：換皮成山腳古鎮

- 實際主筆：Grok（經 Grok Bot 操作）
- 分支：`town/wuxia`，tag `wuxia-w1`（W0 是 `wuxia-w0` = `d841aa7`）
- 元素 id：`w01-skin`，`data/wuxia/world.config.json` 預設開
- 跟規格不一樣的地方：[DEVIATIONS.md](DEVIATIONS.md#w1553)（W1-1～W1-11，待 owner 決定的是 D3）；上游檔案修改清單：[../../UPSTREAM.md](../../UPSTREAM.md)

**規則一行沒改**：人還是隨機漫遊、兩兩聊天。換皮只換地圖、人物圖和畫面，證明見下方「開關對照」。

## 做了什麼

1. **地圖** 48×36、tile 32px（`data/wuxia/tiled/town.tmj`＋`town-tiles.tsj`）。用上游 `data/convertMap.js` 轉成 `data/wuxia/town-map.js`，重產指令是 `bash tools/wuxia/build-map.sh`。
   - 地圖內容：石板主街、南城門（匾額「山腳鎮」）、茶館、藥鋪、鐵匠鋪、井、小廣場、橫過全鎮的河與石橋、北邊的竹林與山腳小路、東邊的破舊武館、三間民居，外圍有城牆。
   - 武館門口貼著封條，圍牆西側塌了一角。W4 才啟用。
   - 測試（`convex/wuxia/w01-skin/skin.test.ts`）驗證：每個地點的入口都可以走、都能從城門走到；石橋和城門都可以通過。
2. **地點表** `data/wuxia/places.json` 共 15 個地點，欄位是 `{id, name, rect, entry, kind}`，另外有一個選填的 `label`，標示名牌位置。
   - 地點：山腳小路、竹林、河、石橋、茶館、藥鋪、小廣場、井、鐵匠鋪、武館、石板主街、城門、民居 ×3。
   - 只用在畫面：地圖上的名牌，以及人物詳情的「在茶館附近」（走在路上時顯示「在石板主街上」）。規則沒有讀這張表。
3. **素材**：全部自製，逐檔登記在 [public/wuxia/CREDITS.md](../../public/wuxia/CREDITS.md)。
   - `public/wuxia/tiles/town.jpg`：由 `tools/wuxia/bake-tiles.py` 烘焙。地面、河、街、城門、橋、井、招牌、燈籠是程式畫的。房舍、樹、竹、石、牆的材質，依 #562 W1 沿用本專案自製的水彩素材：`codex/art184-watercolor-grok` @ `16e2892c`、`codex/art184-production-grok` @ `032f09a9`。縮小副本在 `tools/wuxia/art-src/`，逐檔來源記在 `SOURCES.json`。
   - `public/wuxia/characters/folk.png`：由 `tools/wuxia/bake-folk.py` 純程式畫出 8 個古裝人物，依序是布衣男、短打、布衣女、老人、少年、長衫、郎中、說書人。每格 32×32，四個方向各 3 格，格式跟上游 `f1.ts` 相同（`data/wuxia/characters.ts`）。放大檢視圖：[w01/folk-sheet-3x.png](w01/folk-sheet-3x.png)。
   - `public/wuxia/ui/*.svg`：手寫的 5 個圖示。
4. **時辰與日夜**（`convex/wuxia/clock.ts`）
   - 時鐘：遊戲分鐘 0 是第 1 日卯正（06:00），timeScale 60。畫面左上角顯示「第 N 日 · X時」，另外標出初／正和時刻。
   - 日夜色調：夜（戌到寅，19–05 時）疊藍暗色，黃昏（酉時）偏橘，清晨（卯時）淡暖，交界處用 30 分鐘漸變。
   - 這層只是畫面，規則不讀它。
5. **介面**
   - 標題改成「山腳鎮」，按鈕和人物詳情改成繁中，用紙底墨框的樣式（`src/wuxia/wuxia.css`）。
   - 拿掉 a16z／Convex 標誌，「關於」頁註明基於 AI Town（MIT）。
   - 人物的名字和背景照 #553「不做」的規定，沒改（W2 才改）。
6. **開關**：`w01-skin: false` 時，建世界用回上游 `data/gentle.js` 地圖，人物用回上游 `32x32folk.png`。上游素材要先用 `tools/wuxia/fetch-upstream-assets.sh` 下載到本機。
7. **工具**
   - `npm run wuxia:shot`：先無頭模擬到指定的遊戲分鐘，把狀態匯出，再用 Vite 開截圖頁（`src/wuxia/shot/index.html`，跟 live 共用同一批 Pixi 元件），最後用 Playwright 截圖。不需要 Convex，也不需要 Docker。
   - `npm run wuxia:skin-diff`：開關對照。
   - `wuxia:headless` 新增 `--off`／`--on`／`--map`／`--game-minute`／`--state` 參數。
