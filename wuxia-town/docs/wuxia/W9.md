## 做了什麼

1. **選角色進鎮**（`data/wuxia/player.json`、`convex/wuxia/w09_player/`）：上游 `join` input 多一個可選的 `wuxiaRole`（WUXIA-PATCH(W9)，`convex/aiTown/player.ts`、`convex/world.ts`）。「外地少年」（W1 人物圖 `w5`）／「外地少女」（`w3`），住茶館客房（新床 `guest-bed`），有跟 AI 一樣的需求（W3）、技能（W4，起始 拳腳 10／力 15／下盤 10／耐力 20）、記憶與心念（W5，心念只顯示、不改玩家日程）、關係（W7）。不帶 `wuxiaRole` 加入時跟上游完全一樣。
2. **操作都是 input（可重播）**：`wuxiaPlayerAct`（`kind`＝`activity`／`ask`／`spar`／`apprentice`）、`wuxiaPlayerPause`，回傳 `{ ok, reason }`，被規則拒絕時給理由（「武館還沒重開」「沒有空位」「切磋要在武館或廣場」…）。
   - 點物件 → 選活動：跟 AI 同一套條件與預約（`allowed`、capacity），只是不看「日程排到才做」；走過去做。
   - 請教（自訂規則，W9-4／D10）、切磋（W6 同意規則）、拜師（W7 拜師窗口、技能差、婉拒冷卻；師父的決定在跪拜後）。
   - 對話照上游（玩家打字，AI 用 LLM 回、經 W2 守門）。
3. **閒置 30 實分鐘代管**：用角色進鎮的玩家不被上游 5 分鐘閒置規則請出鎮；超過 30 實分鐘沒有 input 就交給規則（跟 AI 一樣 `chooseNext` 選事做、睡覺吃飯），任何 input 回來就接手。
4. **單人暫停**（#562 W9）：只有一位真人時可暫停；暫停時整個 tick 不跑，繼續時把時鐘起點與所有引擎時間戳記往後平移，遊戲時鐘停在暫停那一刻（W9-8）。
5. **畫面**：右側玩家面板（模式、暫停／繼續、匯出 journal、點到的物件的活動選單、結果與最近紀錄）；人物詳情多「請教／切磋／拜師」；「進鎮」換成兩個角色鈕；點地圖上的物件格開選單（其他地方照上游走路）。
6. **匯出 journal 按鈕**：讀 W0 的 journal 資料（公開版查詢，W9-13／D11），組裝抽成 `convex/wuxia/journalFormat.ts` 與命令列 `tools/wuxia/journal.ts` 共用，下載的 `.jsonl` 可以 `npm run wuxia:replay` 重播。
7. **工具**：`npm run wuxia:player-script`（`tools/wuxia/player-script.ts`）照腳本在指定時刻送 input、被拒絕就每 30 遊戲分鐘重試，報告每個操作的結果；`runHeadless` 多 `inject`／`onInputResult`／`taps`；`wuxia:shot --script --menu`。check 第 18 項。單元測試 `tools/wuxia/player.test.ts` 4 個（全套 230 個）。
8. **CI 時間**（W9-11）：第 15／16／17D 項共用一次 seed 7 的 60 日長跑（第 30、45 日取樣，取樣＝單獨跑，判定不變）。本機 wuxia:check 617 秒；CI 14 分 34 秒（W8 收尾時 19 分 35 秒）。

引擎內沒有用 `Math.random`／`crypto.randomUUID`／`Date.now`（check 第 3 項）。LLM 不決定任何操作的結果；沒有新美術、音樂（CREDITS 不變）。
