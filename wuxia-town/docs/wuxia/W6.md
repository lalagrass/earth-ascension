# W6（#558）同地圖切磋 — 驗收紀錄

實際主筆：Grok（由 Grok Bot 代送）。分支 `town/wuxia`，tag `wuxia-w6`。元素 id `w06-spar`（預設開，`requires: ['w04-dojo', 'w05-mind']`）。含 #562 W6-11（判定只走 `resolveExchange`）。

## 做了什麼

1. **誰會切磋**（`convex/wuxia/w06_spar/data.ts`）：兩人都在武館（已重開）或廣場、疲勞 < 60、至少一方有「想變強」。在 W3 的決策裡多一個候選活動「切磋」（分數 3.5，跟其他候選一起比）；對方同意的條件：拳腳差 < 300，或對方是周教頭。同一對人每遊戲日最多 1 次（`pairDay`）。
2. **判定**（`convex/wuxia/w06_spar/duel.ts`）：每回合 1000 ms 引擎時間。`resolveExchange(attacker, defender, rng)` 用 game.rng() 抽招式與反應；反應成功率 = clamp(0.5 + (守.拳腳 + 守.下盤/2 − 攻.拳腳)/**1500**, 0.1, 0.9)（分母見「數值調整」、D6）；失敗＝守方被擊中、勢 −1、攻方續攻；成功＝換手。勢初始 3 + 耐力/250（取整，W6-3）；勢 0 認輸；20 回合未分勝負＝平手；不受傷。先手由 game.rng() 擲（W6-2）。其他系統只看 `boutView`（圓點數、最後一招、誰佔上風），不直接讀勢（#562 W6-11）。
3. **時間**：兩人先走到場子（武館 (38,24)/(40,24)，廣場 (23,23)/(25,23)，最多 5 遊戲分鐘），打 ≤ 20 回合（≤ 20 秒真實時間），之後原地收勢，整段記成 30 遊戲分鐘的活動；切磋中兩人需求與日程暫停，結束時加疲勞 +8、無聊 −20（W6-6）。
4. **旁觀**：開打時同地點、醒著、正在做事或閒著、沒在聊天的人停下手邊的事，面向場子中間，頭上「看切磋 👀」，看到打完（W6-5）。
5. **結果**：W5 記憶——雙方「切磋勝／負／平」、旁觀者「看到 X 勝 Y」（記憶 id 記在切磋紀錄裡，可追因果）；輸了 → W5 的「想變強」條件；雙方都加「2 小時份基本功」的拳腳（W6-9）；一句旁白：先放模板句（`data/wuxia/templates/spar.json`），live 再排一次 LLM（`data/wuxia/prompts/spar-narration.txt`，W2 守門＋30 字），通過才換掉（W6-7）。
6. **畫面**（`src/wuxia/spar.ts`、`src/wuxia/SparLayer.tsx`；上游 `Player.tsx`、`PixiGame.tsx` 標 `WUXIA-PATCH(W6)`）：兩人相對；攻方前衝半格、守方被擊中後退半格（白色閃光＋「中！」）、閃開則側身；勢以頭上圓點表示（紅＝剩下、白＝失去）；旁觀者轉身面向兩人；打完後贏家「勝・收勢 🙌」、輸家退半格「認輸・喘氣 😮‍💨」、勢點全空，旁白框顯示在兩人腳下。動畫全由「回合發生的引擎時間」和畫面時間算出，不存在狀態裡。
7. **工具**：`wuxia:spar-sim`（只跑判定；`--sweep` 加相近與強對弱掃描）、`wuxia:spar-report`（30 日切磋次數、結果、平均回合、阿青輸後「想變強」與練功、記憶 id；`--off` 對照）、`wuxia:spar-diff`（開／關、勝率、報告判定；check 第 15 項）、`wuxia:shot --gif`（切磋短 GIF）。單元測試 `convex/wuxia/w06_spar/spar.test.ts` 17 個、`mind.test.ts` 加 1 個（想變強時段）、`registry.test.ts` 加 2 個（菱形相依、真正的環）。

引擎內沒有用 `Math.random`／`crypto.randomUUID`／`Date.now`（check 第 3 項）。W6 沒有新增素材檔（畫面全部程式畫，見 `public/wuxia/CREDITS.md`）。
