# W3（#555）一天的生活 — 驗收紀錄

實際主筆：Grok（由 Grok Bot 代送）。分支 `town/wuxia`，tag `wuxia-w3`。元素 id `w03-life`（預設開，`requires: ['w02-folk']`，見 DEVIATIONS W3-6）。含 #562 W3 三項補充（物資有來有去、日程留白、對話 90 遊戲分鐘上限）。

## 做了什麼

1. **資料** `data/wuxia/objects.json`（井、每戶灶×6、床×6、茶館桌×4、說書台、鐵砧、藥櫃、茶爐、河邊石、竹林；每個物件 `place／tile／capacity／activities`）、`needs.json`（餓、累、悶、家事每遊戲小時增減）、`schedules.json`（依角色的時段模板，每人每天至少 2 小時留白）。
2. **引擎內決策** `convex/wuxia/w03_life/`：人閒下來時在 tick 內計分（日程權重＋需求急迫度＋`game.rng()` ±0.3 擾動），只挑有空位且 `requires` 符合的活動 → 預約物件位子 → 走到 `tile` → 計時 → 套用 `needs`／`gives` → 釋放預約。走不到或等太久就放棄重選（W3-2）。生活事件 `{t, who, act, obj}` 存在元素狀態的 `log`（環形 500 筆）。
3. **物資**（#562 W3-4）：每戶 `stock[home]` 有水、飯、柴。挑水 +水、砍竹 +柴、煮飯消耗水＋柴產出飯、吃飯消耗飯；沒飯時「煮飯」繼承「餓」的急迫度。
4. **取代漫遊**：`w03-life` 開啟時 `Agent.tick` 不再發 `agentDoSomething`（WUXIA-PATCH(W3)，`convex/aiTown/agent.ts`）。
5. **對話**：邀請由引擎內規則發起，只在閒暇活動（喝茶、聽書、發呆、吃飯）做過一半以上或剛做完、兩人同一地點時（W3-4）；工作中、睡覺時段不邀。對話最長 90 遊戲分鐘由引擎結束（走 `leave`），hunger 或 fatigue > 90 時直接離開（#562 W3-6）。LLM 只負責說什麼。
6. **畫面**：人物頭上活動 emoji＋標籤；人物詳情面板（目前活動、下一件事、4 個需求條、今日做過的事）；地圖右上「鎮況」面板（每個地點現在有誰）。
7. **工具**：`wuxia:headless --days N`、`wuxia:day-report`（時間表＋全部驗收條件逐條判定）、`wuxia:life-diff`（開／關對照，`wuxia:check` 第 11 項）、`wuxia:life-report`（從實跑 journal 重播後統計對話地點、預約、卡住、飢餓）。單元測試 `tools/wuxia/life.test.ts` 等。
8. **重播修正**（0908941d）：Convex 存回物件會重排欄位，邀請順序改依 id 排序，實跑 journal 才能重播一致。

上游修改都標 `// WUXIA-PATCH(W3): …`，並列在 `UPSTREAM.md`（agent.ts、Character.tsx、Player.tsx、PlayerDetails.tsx、Game.tsx、package.json）。沒有新增美術素材（`public/wuxia/` 不變）。
