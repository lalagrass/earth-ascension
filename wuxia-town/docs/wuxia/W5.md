# W5（#557）心念 — 驗收紀錄

實際主筆：Grok（由 Grok Bot 代送）。分支 `town/wuxia`，tag `wuxia-w5`。元素 id `w05-mind`（預設開，`requires: ['w03-life']`；武館部分搭配 `w04-dojo`）。含 #562 W5-10 補充（武館門口／張望）。

## 做了什麼

1. **事件記憶**（`convex/wuxia/w05_mind/`，引擎內）：`wuxia.mind[playerId].memories` 環形 200 筆，`{id, t, kind, other?, place?, weight, n?, what?, tEnd?}`（附加欄位見 DEVIATIONS W5-5）。來源：第一次去某地（`first_visit`）、聊過（`talk`，只記誰跟誰、在哪，內容不進規則）、聽書（`listen`，同一遊戲日併成一筆，W5-2）、昨日練功分鐘與升階（`trained`／`tier_up`，寅正結算，W5-6）、在武館外張望（`gaze`）／看到有人在武館外徘徊（`loiter_seen`，W5-4）、新人到鎮（`newcomer`，W5-10）。`weight` 每遊戲日 ×0.9。
2. **心念**（`data/wuxia/thoughts.json`，每個數值有 `_src`）：想學武、想變強、想重開武館、想回鄉、想打聽，觸發條件看近 7 日記憶，照 #557 表格。每人最多 3 個；每遊戲日寅正（04:00）評估一次；出現時給起始強度、條件仍成立每日加、不成立每日 −20，到 0 消失（W5-7、W5-8）。
3. **心念只改權重與日程**：想學武 → 阿青日程多一個時段（武館沒開時 10:00–11:30「到武館外張望」，張望或去河邊二選一；開了以後 10:00–11:00 武館加練，打樁或沙袋）、找周教頭聊天機率 ×2；想變強 → 阿青再加 11:00–12:00 加練；想重開武館 → 周教頭寫 `openedAt`、武館重開（取代 W4 的固定第 1 天，W5-9）；想回鄉 → 20:00–20:30 城門外張望；想打聽 → 林嫂優先邀新人、機率 ×2。不直接指定動作。
4. **#562 W5-10 武館門口**：物件「武館門口」（`dojo-gate`）＋活動「在武館外張望」，武館沒開時也在（W5-3、W5-12）。
5. **LLM 接法**：對話 prompt 加「你最近的心事：想學武（強度 70）」（`data/wuxia/prompts/thoughts.txt`，`convex/agent/conversation.ts` 標 `WUXIA-PATCH(W5)`）。心念只由規則產生；LLM 不產生、也不回寫心念。上游的 LLM 反思照舊，只影響對話文字。
6. **畫面**：人物詳情加「心事」欄（`src/wuxia/MindPanel`：心念名稱、強度條、「因為…」列 2–3 筆觸發記憶）；武館重開前維持破落封門（`dojoOpened`）；生活面板的「下一件事」包含心念加的時段。
7. **工具**：`wuxia:mind-report`（每人心念出現／增強／減弱／消失的日子與「因為」的記憶 id，給 `--off` 的對照檔時加練功比較）、`wuxia:mind-trace`（列觸發記憶，`--drop-memory <id>` 丟掉一筆重跑）、`wuxia:mind-diff`（開／關對照，check 第 14 項）、`tools/wuxia/mind-dialogue.ts`（心念對話 LLM 抽樣，見下面「開 LLM 實跑」）。`wuxia:headless` 輸出帶心念紀錄。單元測試 `convex/wuxia/w05_mind/mind.test.ts` 18 個。

上游修改都標 `// WUXIA-PATCH(W5): …`，列在 `UPSTREAM.md`（conversation.ts、PixiGame.tsx、PlayerDetails.tsx、package.json）。W5 沒有新增美術或音樂。引擎內沒有用 `Math.random`／`crypto.randomUUID`／`Date.now`（check 第 3 項）。
