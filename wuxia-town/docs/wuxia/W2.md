# W2（#554）鎮民身分與古風口吻 — 驗收紀錄

實際主筆：Grok（由 Grok Bot 代送）。分支 `town/wuxia`，tag `wuxia-w2`。元素 id `w02-folk`（預設開，`requires: ['w01-skin']`）。#562 沒有 W2 的補充項目。

## 做了什麼

1. **人物資料** `data/wuxia/characters.json`：6 位原創鎮民（林嫂、石虎、何郎中、老韓、阿青、周教頭），欄位 `id, name, sprite, role, home, workplace, identity, plan, voice, taboo`。`w02-folk` 開時 `createAgent`／`init` 用這份（`descriptionsFor()`），關時用回上游 `data/characters.ts`。人物圖直接用 W1 的古裝人物圖 w1–w8。
2. **Prompt**：`convex/agent/conversation.ts`（WUXIA-PATCH(W2)）在 w02-folk 開時改用 `data/wuxia/prompts/*.txt` 組 prompt：繁體中文、古代山腳小鎮背景、人物 `voice` 與 `taboo`、每句 40 字以內、不知道現代事物、不要重複自己。對話行格式改「某某對某某說：」。記憶摘要的 prompt 也改繁中（`convex/agent/memory.ts`）。txt 由 `npm run wuxia:gen-prompts` 轉成 `convex/wuxia/w02_folk/prompts.gen.ts`（DEVIATIONS W2-3）。
3. **用詞守門** `convex/wuxia/w02_folk/guard.ts`：禁用詞（`data/wuxia/anachronisms.txt`，163 個，含 50 個簡體專用常用字）、英文字母（含全形）、每句超過 40 字、整則超過 120 字、空回覆、原句重複。第一次沒過 → 帶著理由重抽一次 → 再沒過用人物模板句（`data/wuxia/templates/<id>.json`，每人 start／continue／leave 各 5–6 句，另有 `default.json`）。LLM 失敗或超過每日上限時不重抽，直接用模板句。結果寫在 `messages.metadata = { guard: pass|retry|template, reasons, attempts, cause }`。
4. **無頭替身**：無頭模擬的對話改用人物模板句（每則只抽一次 `actionRng()`，開關不改 rng 消耗），journal 也帶出訊息（`type: "message"`，不進狀態 hash）。
5. **工具**：`tools/wuxia/sample-dialogue.ts`（抽樣、守門比例、盲讀版）、`tools/wuxia/folk-diff.ts`（開／關對照）、`tools/wuxia/gen-prompts.ts`。`wuxia:check` 新增第 8–10 項。
6. **修正 W1 的部署問題**：Convex 模組路徑不能有連字號，`convex/wuxia/w01-skin/` 從 W1 起其實無法部署到 Convex。改成 `w01_skin/`，W2 用 `w02_folk/`，元素 id 不變；`wuxia:check` 第 10 項之後會擋（DEVIATIONS W2-1）。

上游修改都標 `// WUXIA-PATCH(W2): …`，並列在 `UPSTREAM.md`。沒有新增美術素材（`public/wuxia/` 不變）。
