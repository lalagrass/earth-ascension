## 做了什麼

1. **匯入**：AI Town 放到 `wuxia-town/`。上游美術、音樂與圖示共 48 檔不進 repo（清單在 `tools/wuxia/upstream-assets.txt`），本機要看畫面時用 `tools/wuxia/fetch-upstream-assets.sh` 下載。
2. **種子亂數**：`convex/wuxia/rng.ts`（mulberry32），狀態存在 `world.wuxia.rng`，跟著世界存讀。`game.rng()`／`game.rngUuid()` 取代 `agent.ts`、`player.ts` 在 step 內的全域亂數與系統 UUID。
3. **引擎時間**：`game.ts` 的 `saveDiff` 改用 step 的 `now`，不讀牆鐘時間。
4. **step 紀錄**：`wuxiaSteps` 表每個 step 一筆，欄位為 generation、startTs、endTs、now、prevTime、numTicks、inputsThrough、processedInputNumber、hash。`wuxiaSnapshots` 存第一個 step 之前的完整狀態。
5. **狀態 hash**：`convex/wuxia/hash.ts`，對 `world.serialize()` 做排序鍵的 canonical JSON 再算 sha256（純 TS 實作，live 與離線結果相同）。
6. **元素掛鉤**：`convex/wuxia/registry.ts`，每個 tick 結尾跑 `runElements`。開關讀 `data/wuxia/world.config.json`，在建世界時凍結。W0 沒有元素。
7. **工具**：`npm run wuxia:headless`（無 Docker、無 LLM 的規則模擬）、`wuxia:replay`（逐 step 驗 hash）、`wuxia:journal`（從 live Convex 匯出）、`wuxia:hash`、`wuxia:check`。
8. **LLM 每日上限**：`LLM_DAILY_TOKEN_CAP`（`convex/wuxia/llmBudget.ts`）。超過上限或 LLM 出錯時改用模板句（`templates.ts`），規則永遠不等 LLM。
9. **#562 補充**：embedding 維度改讀設定檔 `embeddingDimension`；新增 `keepAlive`（預設關）。見下方說明。
10. **CI**：`.github/workflows/wuxia-town.yml`，`wuxia-town/**` 有變動時跑 `npm ci && npm run wuxia:check`。

## live 實測（真 Convex＋真 LLM）

**方法**：box 沒有 Docker，改用 Convex CLI 的本機後端：`CONVEX_AGENT_MODE=anonymous npx convex dev --typecheck disable`。這是同一個開源 convex-backend，不需帳號。LLM 用本機 Ollama 在 CPU 上跑。

執行 `MINUTES=30 OUT=… bash tools/wuxia/live-run.sh`，流程是：

1. 清表並建世界。
2. 每 60 秒送一次 heartbeat。
3. 時間到停引擎。
4. 匯出 journal、token 用量與對話。

摘要用 `npx tsx tools/wuxia/live-report.ts <prefix> --price-in 0.15 --price-out 0.60` 產生。對話 prompt 開了 `WUXIA_REPLY_IN_ZH_TW=1`。

## 風險紀錄

- tsx 直接 import `convex/aiTown/game.ts` 跑 headless 模擬可行，不需要另寫替身。
- 引擎的 action（LLM 呼叫）在 headless 模式用規則加模板句代替，用另一條獨立的 RNG（seed×7919+1），不會影響引擎 RNG。
- live 的 `loadInputs` 只讀到 step 開始時已經寫入的 input，所以 journal 記錄 `inputsThrough`，重播時照樣只餵這些 input。
