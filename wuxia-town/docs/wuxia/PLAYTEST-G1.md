# 試玩 G1（#577）

給第一批試玩的人。不用懂程式，也不用讀規則；照下面做，玩完回答四個問題就好。一局約 20–30 分鐘。

## 怎麼開

**A. 有人給你網址**（GitHub Pages 或任何靜態主機）：直接用 Chrome／Edge／Firefox／Safari 打開。手機也可以（直式 390 寬可玩，但電腦比較舒服）。

**B. 自己在電腦上開**（需要 Node 22 與 git；不需要 Docker、不需要任何 AI 金鑰、不需要連網——裝好後可離線）：

```bash
git clone -b town/wuxia https://github.com/lalagrass/earth-ascension.git
cd earth-ascension/wuxia-town
npm ci
npm run build:local
npm run wuxia:serve         # 打開 http://127.0.0.1:8080/ai-town/ （離線可用）
```

（CI 的 `wuxia-town-site` artifact 是照 GitHub Pages 的網址前綴 `/earth-ascension/ai-town/` 建的，給部署用；自己在電腦上玩請用 B。）

## 玩法（一句話）

山腳下的小鎮照自己的日子過；你是「牽線的人」，每天有一點「緣」，可以給某個人指路、引薦、傳話、接濟、說情——只改處境，人要不要做由他們自己決定。

## 步驟

1. 首頁選 **劇本一「高人入鎮」**（第一次玩建議這個）。開場旁白點一下就收起。
2. 說書人會帶你三步：**點一個人** → **打開「顯示太極」** → **對某人「指路」**。照做就好。
3. 之後自己玩：右下角調速度（建議 64×），大事發生時會自動慢下來給你看，看完再按回 64×。晚上可以按「跳到明早」。
4. 想插手時點一個人，在「推一把」裡花緣。右上「目標」看銅／銀／金三級目標。
5. 達成金級或到期（劇本一 90 日）會出 **結算卡**，可以存成 PNG。
6. 玩完（或玩不下去）按右上「存檔」→「**回報**」，會下載一個 `shanjiao-report-dayN.json`（你的存檔＋最近 200 件事）。**不會上傳任何東西**，請把這個檔連同下面四題的回答傳給我們。

設定（右上「設定」）：倍速上限 16×／64×、大事時鏡頭要不要自動移過去、音量、按鈕顯示文字或圖示。

## 四個問題

請玩完後憑印象回答，一兩句就夠：

1. 不讀說明，看不看得出畫面上正在發生什麼？
2. 有沒有哪一刻想插手？插手之後看得出自己造成了什麼嗎？
3. 結算卡會想給別人看嗎？會想再開一局嗎？
4. 最無聊的是哪一段？

## 已知問題

- **劇本一（高人入鎮）在 90 日內很難到金級**：A5 的 5 個 seed 不論插不插手都是銅、銀，沒有金（見 FINAL-A.md 的 C 表）。到期一樣會出結算卡。這是要請你感受「難不難、悶不悶」的地方，我們刻意沒先調。
- **劇本三（兩個師父）常在第 5–9 日就直接金級結算**，銅、銀還沒達成（「有人兩門都學」比「兩門各兩個徒弟」先發生）。劇本二（不傳之秘）沒有人拿到金。
- 鎮民不說話（無言互動＋泡泡）；點泡泡的「翻成一句話」用的是模板，不是 AI。
- 手機直式時畫面上元件較擠；時間列會折成三排。
- 64× 在比較慢的電腦上會跟不上（實際倍速低於 64×，不影響結果）。
- 沒有背景音樂與環境聲，只有幾個合成提示音；沒有小地圖。
- 只有繁體中文。
- 換瀏覽器或清除網站資料會讓瀏覽器裡的存檔消失；重要的局請按「存檔」→「匯出」。
- 引擎若出錯，畫面會停住並提示「小鎮停住了」，出錯前的狀態已另存一格；請按「匯出回報檔」傳給我們。
