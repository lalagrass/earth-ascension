# 小說協作入口

先讀根目錄 [CONTRIBUTING](../CONTRIBUTING.md#小說內容與系統的審查分流) 與目標 issue；四小時認領、實際主筆／base SHA、PR 指向 dev、Earth PO 唯一共用 queue 照常適用。

- 小說 PO／主筆是「規劃小說式新分支」聊天，負責章節、編輯與內容接續；作者自校不冒充獨立技術審查。
- 純正文、對話、潤稿：作者自校，queue 輕量核範圍／連結／既定設定邊界即可交付；不等待另一位 AI 核准文學品質。完整場景／短篇收試讀，非阻擋建議不攔下一章。
- 故事聖經、章節圖、紙上分支：檢查已知事實、前後因果與回呼；按原 issue 做少量紙上走查，不為草稿建 runner 或宣稱所有組合已驗證。
- 研究文件：核主要來源、版本／授權、推薦理由與限制；未跑的例子標示意。接受研究不代表採用工具，也不強制先跑 spike。
- 系統／可執行條件：runner、reader、生成、API、狀態／存檔，以及會改效果／條件／跳轉的故事資料須非作者技術審查與受影響驗證；按實際行為分類，不按副檔名。只改文案走輕量路徑。
- 暫名、視角、語氣與節奏可先作草稿工作選擇；重大方向與共用 IP 變更回原決策者。遊戲 PO 只審遊戲共用邊界，不逐章審稿。
- #123 的工具採用、正式選擇／存讀語義及 runtime 授權仍有效；#124 內容與 #134 研究不授權 #125–127，不把小說情節寫入 Earth／SG 狀態。
- 沿用必要 CI／基本檢查，不為純小說跑 world seed、引擎或全裝置矩陣；系統改動只驗受影響部分，長輸出落檔並報摘要。公開發行前再安排適當校對、讀者／互動路徑驗證。

本入口由擁有人 2026-10-20 指示建立，追蹤 [#173](https://github.com/lalagrass/earth-ascension/issues/173)。
