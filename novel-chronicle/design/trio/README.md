三人不是每天固定同行：小滿與阿岫住館，阿祁從村裡來才湊在一起。圖把三人並排，只為一次看清對照。

## 阿岫設定更新

擁有人後續確認：阿岫雖被收養，卻受大家寵愛，穿著會更好一些；氣質鍾靈毓秀，對陌生人話少，熟悉後溫柔親切，會鼓勵主角，也有自己的興趣和生活。後續可用合身乾淨的細緻衣料、小髮飾與柔和神情呈現，參見[故事聖經](../../docs/STORY_BIBLE.md)。本圖素裝與原始提示詞保留作來源紀錄，尚未重畫成新版。阿祁仍住村裡、偶爾上館。

## 生成限制

中間的阿祁仍比故事裡「高出約半個頭」更高，臉也更成熟。這是本輪沿用既有瘦高造型時沒有收回的偏差，**不把成年身高寫進設定**。小滿的肚子包在衣服裡。圖上沒有文字、沒有飾品。

造型延續 [#245](https://github.com/lalagrass/earth-ascension/pull/245) 人物表的矮圓藍衫與瘦高褐袍。本輪畫面為原創，沒有複製既有遊戲像素或其他作品的畫面。提示詞見 [source/prompts.md](source/prompts.md)。
