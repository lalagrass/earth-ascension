# 《挑水的暑假》故事聖經（#124 設計稿）

狀態：**穿越者進入熊孩子身體、暑假到爺爺道館、與同齡人挑水並逐漸察覺變化，已由專案擁有人指定為開頭**（2026-10-20）。實際主筆：Codex。本文與[第一章樣稿](../story/chapter-1.md)、[三章因果圖](CHAPTER_MAP.md)提出可審的原創小說寫法；暫名、人名、語氣、視角、選擇節奏、跨作品年代及存讀語義須在 [#123](https://github.com/lalagrass/earth-ascension/issues/123) 定案。技術提案見 [TECHNICAL_DESIGN](TECHNICAL_DESIGN.md)，工具研究另見 [#134](https://github.com/lalagrass/earth-ascension/issues/134)。沒有小說 runtime 或遊戲規則變更。

## 讀者承諾

現代宅宅醒在架空過去一個貪吃、莽撞、身形較胖的孩子身上。他想靠穿越者的先見之明躲過苦工，暑假卻被這具身體的父母送到爺爺的山村道館。第一件差事是與熟練的堂弟挑水。他從笨拙、喘不過氣，慢慢學會用身體做事，也察覺恢復和精神狀態有不能立即解釋的變化。讀者的選擇影響他如何說出異常、向誰學習與是否願意共同承擔；不能替他保證修仙成功。

故事的可見進步分兩層：**技術與耐力**可由挑擔姿勢、步距、路線、完成趟數以及需要休息多久呈現；**異常**先只表現在相同負荷下恢復較快、感官更清楚等有限觀察。主角、爺爺與讀者在第一章都不能僅憑感受斷定原因是靈氣。體重不作笑點、善惡標籤或必須「修正」的缺陷；笑點來自他自以為熟悉穿越套路，卻要從腳下石階重新學起。

## 語氣與視角候選

樣稿採**貼近小滿的第三人稱**：讀者可聽到現代宅宅的心聲，其他人仍只能看到他的行動與言語。語氣為生活喜劇混合緩慢的未知感，既容許「早知道多走兩層樓」的自嘲，也保留挑水真實的費力。#123 可比較第一人稱日記式版本；若改視角，先檢查未來情報與其他角色內心是否洩漏。角色沒有被要求講古風套話；時代感由工具、路程、作息與關係建立。

## 三章小弧與延續

1. **第一章〈第一桶水〉**：穿越、暑假被送道館、堂弟對照、挑水失敗、正常技巧與第一個微小的異常。小滿決定要不要放下面子學、要不要告訴爺爺。
2. **第二章〈同一條山路〉**：數日後同條路與同重量的對照；堂弟既教他也感到自己可能被忽略。小滿如何說明感受，以及是否過度試探身體，決定兩人的信任與是否有人能幫他辨別現象。
3. **第三章〈明天再下山〉**：道館有日常的水量缺口，不強制災難。小滿可選單獨逞強、合作分工或先休息核對身體；短篇結尾回答他是否願意面對下一個早晨，保留穿越與復甦的大謎題。

本切片的平凡結局是他能穩穩挑完自己那半桶、承認堂弟也出了力，兩人約定明天一起去；不因沒有英雄事件就判失敗。後續長篇可以從道館收徒、援村或身世疑問延伸，但不在這三章預支遊戲未批准的獸患、戰鬥或新能力。
