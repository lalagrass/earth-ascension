# 《挑水的暑假》三章選擇與因果圖（#124 設計稿，#251 人物修訂）

## 事前已知與揭露邊界

- 小滿知道自己來自現代、如今在另一具孩子身體裡；旁人只見他的言行變了。讀者跟著小滿知道這件事，不能讀到其他人物未說出的內心。
- 爺爺、阿祁與阿岫都看見小滿初次挑水易喘；阿祁當日從村裡來幫忙，傍晚回村，隔幾日再來才看見變化。阿岫住道館，能看見這幾日實際練習，兩人的觀察不能互相代替。
- 小滿可感到恢復較快，但第一章無人有足夠證據將其定為靈氣效果。不得讓他無代價使用現代知識或未知功法。

## 選擇、可見代價與後文回呼

| 選項 ID | 當時看得懂的取捨 | 即時變化 | 必須出現的後文回呼 |
|---|---|---|---|
| `c1-ask`／`c1-solo` | 放下面子學姿勢，或自己再試以保住面子 | 前者提早掌握技巧；後者仍能練但多花力氣 | 阿岫看見兩路的實際練習；阿祁隔幾日再來時，是先主動提點，或等小滿先開口。兩路都可正常進步。 |
| `c1-tell`／`c1-record` | 告訴爺爺身體感受，或先私記避免被限制 | 爺爺能觀察並設休息界線，或暫時不知情 | 第二章有人幫忙核對與否；第三章若逞強，知情的爺爺會用具體觀察提醒。 |
| `c2-share`／`c2-deflect` | 阿祁再來時讓他參與對照，或暫留自己的祕密 | 阿祁有資訊與發言權，或只看見小滿變快；阿岫只說自己親眼所見 | 第三章合作時阿祁如何回應小滿；不能把被隱瞞者寫成已知異常，也不能讓阿岫替小滿決定揭露。 |
| `c2-steady`／`c2-test` | 按約定趟數練，或多走一趟確認變化 | 加趟者獲得更多觀察，同時承受疲憊與可能失約 | 第三章水量缺口時是否需要休息；不把「測試」變免費進度。 |
| `c3-together`／`c3-alone` | 與其他人分擔，或獨自完成自己能做的部分 | 三人當日工作與互信不同；獨挑者仍可被勸休息 | 收束段明說每人實際做了什麼與阿岫是否自願承擔，不能一人替全道館解決。 |
| `c3-stay`／`c3-write` | 與住館的阿岫約定明日繼續，或先留下記錄／給家人交代 | 一個是日常承諾，一個是向外界負責；阿祁當晚回村 | 結尾讀者看得到承諾對象、已知事實與未解問題；兩者均非失敗。 |

`c1-learn` 的兩路在 `c1-evening` 匯流時必須有不同一句：請教者記得阿祁教的腳步，獨試者記得自己摸索和對方欲言又止；不能只複製同段正文。阿岫在兩路都可指出實際路況，但不憑空知道小滿的心聲。`c2-cousin` 匯流前需回應爺爺是否知情，以及阿祁不在的幾日由誰見證；`c3-water-need` 前需回應阿祁是否知情及小滿有否逞強。這些是寫作者的 promise ledger，不靠自動計分證明完成。

## 三條紙上走查

1. **合作與安靜結尾**：`c1-ask → c1-tell → c2-share → c2-steady → c3-together → c3-stay`。小滿與阿岫練了幾日，阿祁再來時可比較他確實走過的路；爺爺與阿祁都只把異常當待查觀察。三人按能力分完今天的水，阿祁回村，小滿與阿岫約好明天繼續；沒有能力確認或英雄事件。
2. **藏起祕密，獨挑受限**：`c1-solo → c1-record → c2-deflect → c2-test → c3-alone → c3-write`。小滿確實比第一天進步，也因多測一趟更累；阿祁無法理解突然的距離，阿岫看見他多走卻不知道他的祕密，爺爺要求停下。小滿留下對自身變化的記錄，向父母交代道館生活；未解異常不作成功宣告。
3. **晚些坦白，重新合作**：`c1-solo → c1-record → c2-share → c2-test → c3-together → c3-stay`。小滿一開始保面子，在阿岫陪著練了幾日後主動讓再來的阿祁幫忙對照；加趟後須承認自己也會累。三人分擔，信任從晚些坦白開始，不能寫成從頭便毫無芥蒂。

每條均從開頭走到結尾、沒有未定節點；兩個結局都可達。後續若把這份圖轉為可執行資料，必須另驗證所有組合的節點可達、前置與回呼，再依 #123 決定工具和版本語義。紙上走查只證明這三條，不能宣稱六個選擇的所有組合已驗證。

## 與遊戲互相供材的最小方式

小說給遊戲參考的是「空桶下山／裝水／負重上山／倒水」的視覺節奏、爺孫對話，以及住館者與偶爾來訪的村裡堂弟看待進步的不同角度。遊戲 [#155](https://github.com/lalagrass/earth-ascension/issues/155) 的畫面稿可供小說作者校對山路、桶與步態。兩者只共享可審的地點／角色候選與動作來源；小說的選項、結尾、穿越真相不會透過改寫遊戲事件資料自動成立。
