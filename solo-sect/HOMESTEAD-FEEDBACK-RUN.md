# 荒居 R11–R20 本地試玩

解壓後在包含`solo-sect`的根目錄：

```sh
python3 -m http.server 8804 --bind 127.0.0.1 --directory solo-sect
```

瀏覽器開 `http://127.0.0.1:8804/homestead.html?frontier`。不需要npm、帳號、遠端服務；多檔ES modules要HTTP，不是直接雙擊HTML。若8804已被你使用，換空埠並對應網址，不要關他人服務。此本地分支尚未推送；其他機器先實際取得ZIP或等明確授權發布後才能checkout，不要假設本地路徑可跨機器開。

1. 勾「生活與山林」，選性情、守家/學會應對/長久安寧與天賦，開始後先不派工作或建造，看角色自安家、搬料、種菜、煮飯及使用住處。置頂看飽腹（高=吃飽）、精力、真活動與速度。
2. 1×/4×/16×或暫停。頁面初次載入「重要山林事件降至1×」預設勾選，真預警/打包/抵源/清源/返家時降速，可關掉或隨時再加速，不會替你下指令。重要經過在原山林卡內可收合查看，最多12項，只本次頁面/讀檔後，不跨檔保存；真總探行仍來自原帳本。
3. 試「尋求長久安寧」然後選避戰：仍安家、練步，但不打包出征。允許應戰不會偷偷重設你已暫緩的出行；要恢復自主近山再按「允許自主再考慮」。你也能自在留居，不需清源才算結局。
4. 有能力/現成菜後，可直接點打包。尚未打包時同一撤回鍵顯示「取消備糧」，沒有扣料理/探行；已在外必須真返家、未吃路糧真退回。路糧優先可選現有熱飯/拌食/燉菜，缺時用現成餐，不會為偏好另製作。開始備糧後先取消才可改本次餐與同行意向。
5. 林舟日5起白天可能來訪。想同行才實際聊天/送現成菜/切磋/教學；拒絕原因顯示在同一明細：在場/手上工作/信任/步勢/需求。想邀請不等於對方已同意；未勾同行可自己走，不必等。希望獨處在備糧時取消邀請探行，在途中解除同行後對方自己走離，主角可繼續或撤回，不瞬移。
6. 清理唯一獸徑後不再排新侵擾（已在場的敵人按原規則結束），可以照料小家、休閒或交流，不會自動換更強的來源。守家/練武仍有其成本與用途。

原模式/既有存檔保留，舊v5缺路糧偏好預設auto，不變成高級料理。沒有新增存檔/備份/槽位/同步產品；本版新模式5仍無本篇轉接契約，會明示拒絕。不要混搭舊JS覆讀實驗資料。

## 可重跑工程證據

在`solo-sect`，Node24本輪實測：

```sh
node --test test/*.test.mjs
node tools/homestead-frontier-acceptance.mjs
node tools/homestead-frontier-compat.mjs --output ./FRONTIER-R20-COMPAT.json
```

正式矩陣寫`FRONTIER-R20-METRICS.json`；可用`HOMESTEAD_METRICS`另定檔名，避免不同reviewer互相覆寫。真舊reader檢查需git/tar及`556e40ec5f6b18b663b6a383c60d90432b5d318c`歷史；ZIP不含.git，缺時明確失敗，不能把未跑寫通過。工具臨時目錄用系統TMPDIR，可從其他cwd啟動。

可選的正常UI自動驗證（**玩家不用安裝**）：已有允許的Playwright/Chromium時，在`solo-sect`設定`HOMESTEAD_PLAYWRIGHT`為可import的本機module路徑/URL（或不設、使用已裝playwright package）、`HOMESTEAD_CHROMIUM`為已裝允許的browser執行檔，執行`node tools/homestead-feedback-integration-browser.mjs`。`HOMESTEAD_URL`可指定自己的HTTP位址。不得為此重試被政策拒絕的Firefox/WebKit下載；沒有環境就記未測。

## 真人20–30分鐘探索（建議3–5位，尚未執行）

- 前5分鐘不派工，記第一次不懂的時間/世界時間/倍率，現在能說出需求、角色要做什麼嗎？
- 自選一條方向；重要事件自動降速是幫助還是干擾？關閉後是否看得見過程？
- 試一次改方向/避戰/取消備糧，操作結果是否符合預期？介入是想改生活還是為了解卡？
- 願意社交/探行的人，自選路糧與是否同行；能理解對方拒絕及退出原因嗎？不要求每人全走全部。
- 最後記原話：下一步想做什麼、想不想再回來？允許無聊/不喜歡，樣本不是市場驗證。
