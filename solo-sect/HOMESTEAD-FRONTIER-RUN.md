# 生活與山林：十輪本地試玩

解壓後在包含solo-sect的根目錄執行：

```sh
python3 -m http.server 8804 --bind 127.0.0.1 --directory solo-sect
```

開 `http://127.0.0.1:8804/homestead.html?frontier`。HTTP是多檔ES modules所需，不必npm、帳號或外部服務。雲端工具內有驗證機路徑，玩家不用跑那些工具。

## 可以怎麼玩

1. 新局勾「生活與山林」，選性情、方向、根骨／悟性。先不派工，看他真的採木、搬料、蓋屋、耕作、吃熱飯；可用暫停／1×／4×／16×。
2. 守家會在吃住穩定後造／加固短柵欄，預警時去扣門。明細能改手動門控、立修補／暫停；兩端可繞，這不是自由築城。傷害可恢復，不需為了活命必戰。
3. 學會應對會自然練到基本步勢；明細可選已會的招式、練一次或避戰。有效完成才長能力，不是站著加XP。
4. 日5起白天林舟可能走來。展開「防線、招式與訪客明細／操作」：談天／真送現成菜建立信任；對方先吃睡或在忙就等。信任足夠可約一件真搬柴，或準備好自己後切磋、教學。可希望獨處，不需社交才能安家。
5. 近山需要基本步勢、吃睡與一份已有料理。可明選邀林舟，但必須對方在場、願意與需求合適；不行會說原因。去的是本圖右上唯一獸徑，真走路，能隨時撤回。食物進包不算吃下，沒吃的返家退回。
6. 清理此來源後不再排新侵擾；已在場山豬仍正常離場。可以留居，沒有強迫下一場戰爭／更強替代來源。預設安家內容有限，安居與休閒也是成果。

方向可中途改，直接派工優先且新活動只做一次；在近山改派生活工作會先返家。手動撤回會暫緩自動再出發，可按「允許再考慮近山」。暫停工程不會自行恢復。Enter可激活按鈕／明細，Escape收合明細並回summary；全鍵盤／輔具體驗仍待真人驗。

## 版本界線

本版保留原自主／classic／legacy資料與介面；沒勾新模式就不新增此NPC／侵擾。舊1–4在新版讀取，不自動轉成新模式。新模式資料5讓舊程式明確拒讀；不要混搭舊JS。沒有新增存檔產品，既有介面保留，實驗資料請勿拿舊程式覆讀。新模式暫無本篇轉接契約，會明示拒絕，不假帶入NPC／武學或源頭。

只有Cloud Chromium驗證；Firefox/WebKit因既有政策下載受阻未重試，非真機Safari／手機驗收。全部工程／AI走查不等於真人覺得好玩。圖是原創幾何、規則試玩值；並非完整模擬市民／世紀帝國／天下霸圖或16型系統。

## 20–30分鐘探索腳本（建議3–5位真人，尚未執行）

- 先5分鐘不派工，記首次卡住的真時間／世界時間／倍率／原本期待；問現在角色要做什麼、為何先吃睡。
- 每人選一條方向，試一次高層改向或暫停；確認自己的意見是否改變生活，不必每人全走所有內容。
- 指出一項真用過的建設或招式價值；看得懂可用木料／工地占用、為何林舟拒絕或願幫忙嗎？
- 自願試社交／近山的人，觀察路糧、同行與撤回；介入是因想改生活，還是為了解卡？
- 最後問：下一步想做什麼、會願意再回來嗎？記原話，允許無聊／不喜歡。樣本不是市場結論；不把16×混速說成1×耗時。

## 工程重跑

在solo-sect：`node --test test/*.test.mjs`；`node tools/homestead-frontier-acceptance.mjs`；`node tools/homestead-frontier-strategies.mjs`。舊版兼容需保留git歷史，再跑`node tools/homestead-frontier-compat.mjs`。Playwright UI工具用Cloud已裝路徑與`/usr/bin/chromium`，不是玩家安裝要求；其他機器需自行配置允許的測試環境，不繞受阻下載。
