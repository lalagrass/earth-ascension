# 單人家園試玩（H14–H18）

真人尚未執行。建議3–5人，每人20–30分鐘，屬探索性樣本，不是市場驗證。用乾淨瀏覽器設定檔／獨立本機origin，保護原資料。

## 開始

在repo根目錄：

```sh
python3 -m http.server 8794 --bind 127.0.0.1 --directory solo-sect
```

開 `http://127.0.0.1:8794/homestead.html`。主要新局是獨居；不用社交、幫手或學徒。可暫停與調速，記錄用過的倍速；混速時間不能當正常速度完成時間。現有存讀入口保留，本輪不要求操作備份、轉接或槽位管理。

## 給試玩者

你一個人來到荒地。先看上方可用木料、食物和種子，採果、搬回、吃飯，試著建一間屋。藍圖可以先立，材料會實際搬去工地；右側能看升級前後改善。工程可暫停，材料和已做進度保留。

有了家，再自行選菜園、灶與床鋪。採集、建造、耕作、料理做成了才累積本領；看一眼等級和耗力差別。床鋪只在屋內使用時提高休息率，熱飯比野果更能填飽肚子。可以做長凳、花叢，坐下來舒服一會，也可以先不做。短暫感受會消退，不必為維持它一直忙。

## 主持人只觀察，不教最佳解

1. 首次卡住時記下想做什麼、畫面文字與嘗試；先等玩家理解，再只給必要提示。
2. 請玩家說明：一根運往工地的木料還能不能花？選一項技能，升級有什麼實際差別？選一項建設，為何想蓋？
3. 讓玩家自己決定下一件投入；觀察是否為了解卡而盲點、是否看懂休息／料理／閒坐，是否願意安心停留。
4. 結束問「下次想回來做什麼？不想回來的原因也可以說」。不要求讚美，也不把AI流程標成真人喜歡。

每人記匿名代號、裝置／瀏覽器／輔具、倍速、首次卡住、主持提示、玩家原話、下一步自主性、想不想回來及理由。另記焦點消失、看不清標籤、錯誤訊息和重現步驟。AI已驗流程不能替代這些真人理解與樂趣證據。
