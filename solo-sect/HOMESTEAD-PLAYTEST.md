# 荒居 H9–H13：探索性試玩

此為H9–H13歷史腳本。最新主要流程改為真正獨居，請用 [H14–H18獨居腳本](HOMESTEAD-H18-PLAYTEST.md)；不要求社交／招募或存檔管理。

此腳本為真人準備，**尚未招募／執行，不是市場驗證**。建議3–5位，每位20–30分鐘；喜歡生活模擬與首次接觸者均可。Mac僅由使用者本人操作，工程代理不遠端操作。使用全新瀏覽器設定檔／乾淨本機origin，避免任何已有遊戲資料。

## 啟動（本地，不需部署）

在repo根目錄執行：

```sh
python3 -m http.server 8793 --bind 127.0.0.1 --directory solo-sect
```

開 `http://127.0.0.1:8793/homestead.html`。不要直接雙擊HTML，ES modules需要HTTP。可選名字／性情，按「先去荒地」。數值為試玩值，可用暫停、1×、4×、16×；紀錄用過的倍速，不能把混速時間當正常完成時間。

## 給試玩者的話

你搬到一片荒地。試著讓自己吃飽、有地方睡，再慢慢做出想住的小家。按鈕可以派工；「清除指派」讓人物自主生活。藍圖會先搬材料，再施工，手上的物資還未入庫。下一步提示可以收合。

可以獨居，也可以慢慢認識村路上的阿蓮。長凳是閒坐位置，沒有額外數值獎勵；花叢只改外觀。若不想做任何工程，可以留居看人物生活。接回山門紀是另外一個可選去向，不是通關要求；先看既有轉接預覽，取消也可以。

既有手動存讀仍可用。荒居與原本篇分開，轉接是原有兩個獨立槽；本輪沒有開發新的存檔功能。試玩不要求操作匯出、匯入、備份或槽位管理。

## 主持人步驟（不先教最佳解）

1. 前5分鐘：請玩家自行找吃的、理解人物正在做什麼，嘗試建第一間屋；有卡住先記錄，再只給一個必要提示。
2. 接著5–10分鐘：請說出修繕／菜園／灶／倉棚其中兩項的具體價值，再自行選下一件。觀察是否為了解卡而盲點，而非做自己想做的事。
3. 最後5–10分鐘：請自行選長凳或花叢，也可都不做、維持留居；可看同伴選項或轉接預覽但不強迫確認。觀察能否辨認施工、長成、料理／冷灶、休息／閒坐。
4. 結束詢問：現在最想做什麼？如果明天回來，想看什麼？有沒有想做但找不到的操作？不要用誘導問句要求讚美。

## 每人記錄表

- 匿名代號、日期、裝置、瀏覽器、是否用鍵盤／輔具、曾玩過的生活模擬：
- 倍速／暫停使用情形；第一次卡住的時間與畫面文字：
- 當時想做什麼、試過哪個操作、是否需要主持人提示：
- 能否說明一項升級的具體改善（原話）：
- 能否從畫面辨認目前工作與已建成果；有無看不清的標籤：
- 下一步選擇及理由；自願投入或只為了解卡：
- 是否想再回來、原因（可答否；不轉寫成滿意度分數）：
- 實際錯誤／焦點遺失／訊息難理解的重現步驟：

先區分程式錯誤、文字理解、節奏喜好，再依實際問題修。小樣本不能推論整體玩家喜好；AI可執行流程也不能冒稱真人喜歡。H13交付後停止，不自動展開新里程碑。
