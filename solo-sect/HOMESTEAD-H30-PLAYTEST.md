# H29–H30探索性試玩（真人尚未執行）

版本：`codex/solo-sect-homestead-h29-h30`，由H28 e081f2b延續；完整結果見[H30回顧](HOMESTEAD-H30-REVIEW.md)。用現有HTTP啟動方式開homestead.html，獨居新局。建議3–5位、各20–30分鐘，屬探索樣本不是市場驗證。測試者可用暫停／倍速，記錄其選擇，不把混速時間當1×完成時間。

1. 不先指路，觀察能否吃飽並完成首屋；第一次卡住在哪裡、是缺材料還是不懂操作？
2. 屋好後請他做出喜歡的小家，但先不說有配色／家名。記錄是否找到入口、認得預覽與套用、能否自行取消。
3. 問：這項選擇會耗料或改善休息嗎？讓他比較原木／苔綠／赭紅，說出哪裡變了；不要誘導『更好看』。
4. 試中文名稱、取消再修改、恢復原貌；有鍵盤使用習慣者用Tab／Enter／Escape。記錄看不清、意外套用或失焦。真實中文輸入法需另留環境／輸入過程紀錄，不能拿自動insertText當已驗IME。
5. 接著自由經營，觀察是否自願改屋／耕作／料理／閒坐；問下次回來想做什麼，以及是否真的想再回來。沒有想法也如實記錄。

每人記：環境／版本、首個困惑、能否說明純外觀與生活收益差異、喜歡／不喜歡的具體原因、操作自願或為解卡、希望後續建造能看見什麼。不要只記『完成任務』；AI正常流程及438測試不代替本表的人類回應。
