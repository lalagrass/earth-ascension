# 荒居自主生活試玩 A01–A20

在解壓根目錄（內含solo-sect）執行：

```sh
python3 -m http.server 8804 --bind 127.0.0.1 --directory solo-sect
```

瀏覽器開 `http://127.0.0.1:8804/homestead.html`。不需要npm／帳號／外部服務。這是ES modules，多檔案請用HTTP開，不用直接雙擊HTML。

開始新局、選性情後先不派工，觀察角色自行安家、做飯與改善生活。可用1×／4×／16×與暫停；倍率混用不能當1×實際等待。先看「近期打算」與角色為何先吃睡，之後再改一次生活方向。

直接派工預設做一件後回自主，成果要搬回；建造是完整一項工程。可明選持續，或清除手動指令回自主。要否決角色打算請用「暫緩此打算」，暫停工程不會自動恢復。

三性情不等於16型完整系統。預設有限兩條家園改善與兩項興趣，不強迫蓋滿。角色會有不同家景與休憩，也可能真正完成內容後安居；尚無真人證明長期好玩。

原有存讀介面保留，沒有新增存檔功能。新自主局是資料版本4，防止H50舊程式誤讀後關掉自主；舊1/2/3仍可在新版讀取，舊classic局不自動變自主局。`?classic`／`?legacy`只供保留原路徑。不要用H50舊檔案混搭新版JS；需使用整包相同版本。

沒有新增社交／武學／襲擊／碰撞尋路；後續較大方向是另一份待交接十輪工作，不包含於這包。只有Cloud Chromium自動驗證；其他引擎／真人／真手機未驗，參見工程回顧。所有圖與測試記錄是AI工程證據，不冒稱真人試玩。
