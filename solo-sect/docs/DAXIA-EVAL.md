**擁有人提到的開源專案**（用 GitHub API 查）：
- NRules/NRules：存在，C#，1657 星，MIT。規則引擎。
- Siccity/xNode：存在，C#，3750 星，MIT。節點編輯器。
- 「CEvent／GameEvents」：沒有公認的專案，只有小型練習專案，例如 RLindquist1/GameEventsSystem（5 星）。
- 背包系統：peter-kish/gloot（990 星）、alfredbaudisch/GodotDynamicInventorySystem（666 星）、adammyhre/Unity-Inventory-System（283 星）。

結論：都不能直接用，因為語言和引擎不同。可以借的只有做法：
- 規則寫成資料表加一個判定函式。我們的 `RULES` 和 `JHEV` 已經是這樣。
- 事件用單一入口派發。我們的 `log`、`think`、`choices` 已經是這樣。

**其他參考**（loop125 已打開）：
- RimWorld Skills：做事長技能；每日 4000 xp 之後只拿 20%。
- Kenshi Strength：搬重物、戰鬥長力量。
- LoL Armor：雙曲線遞減。

## 3. 選定的保守子集

1. **`laborgrow` 勞作練體（主要）**：保留既有的「做活長力氣、走路長腳力」，只補上「力氣進戰鬥」：
   - 招式傷害 ×(1 ＋ 力氣/400)。力氣 100 時最多 +25%；常見的 10–30 是 +2.5～7.5%。參考臂力每點 +0.5% 會心，我們沒有會心，所以改成小幅傷害加成。
   - 門派戰力每人 + 力氣/10。
   - 防刷：參考大俠敏捷每日上限 10 點和 RimWorld 每日軟上限，**做活**長的力氣每人每日超過 3 點後只拿 20%。練功、切磋不受影響。
   - 只顯示玩家知道的東西：弟子卡寫「勞作力氣 今日 x/3」，規則說明寫出公式。
2. **`valor` 門派勇名（次要，輕量）**：門派層級一個 −100～100 的「勇」軸，只接既有事件：
   - 迎戰山賊 +2，打贏再 +2；付錢了事 −3。
   - 接下挑戰帖 +2；量力婉拒 −2。
   - ≥ 50「勇名在外」：門派戰力 ×1.05。≤ −50「軟柿子」：山賊威脅 ×1.1。
   - 顯示在山賊欄（這是玩家自己門派的名聲，玩家知道）。
3. **不做**：悟性與體質成長、武道六派、偷竊下毒、懸賞板、名聲報復（查不到）、易物公式。

## 4. 決定 110–114

110. 借鏡範圍只做 `laborgrow` 和 `valor` 兩條，都放在開局開關後面，預設勾選；舊檔一律關閉。（理由：最貼近既有系統，不新增資源或面板）
111. 力氣進傷害走 `moveMul` 這個唯一入口，所以狩獵、遠行、試煉一起生效；係數 1/400。（理由：只改一處，比照 loop114 的護盾做法）
112. 每日軟上限只套在做活的力氣，練功不套。（理由：只擋新的刷法，不削弱既有的練功）
113. 勇名以門派為單位，不做每人一條德軸。（理由：弟子已經有價值觀；以門派為單位，資訊對玩家透明）
114. 擁有人的錯誤描述（陽派、臂力靠打鐵、名聲報復）照實記錄，不照著實作。
