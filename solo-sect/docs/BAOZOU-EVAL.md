## 1. 熟練度（武學評價）實際資料

### 1.1 暴走英雄壇（手機版）
來源：TapTap 動態 205339420163836570、gl.ali213.net/wenda/29737.html、gamersky Content-884258_16（三者名稱略有出入）。

| 評價 | 等級 |
|---|---|
| 不堪一擊 / 略知一二 / 初學乍練 / 懂得皮毛（亦作「了解皮毛」）/ 初出茅廬 | 1 / 10 / 20 / 30 / 40 |
| 初窺門徑 / 略有小成 / 略有大成 / 出類拔萃 / 登堂入室 | 50 / 60 / 70 / 80 / 90 |
| 青出於藍、心領神會、爐火純青、融會貫通（各分 1–10 重） | 100–190、200–290、300–390、400–490 |
| 罕見敵手 → 神乎其技 → 傲視群雄 → 所向披靡 → 登峰造極 → 返璞歸真 | 500 起每百級一階（有一來源把返璞歸真放在 500） |

「每個階段十個等級」的結構是從 100 級（青出於藍）起才有「一重～十重」；前面是每 10 級換一個稱號。使用者說的「從初出茅廬起、十個等級」應是這兩層混在一起的印象。

已查到、有出處的「效果」：
- 99 級要突破（和好友閉關），TapTap 623332393842903818。
- 一般等級上限 600，超過不計，TapTap 661175153698278971；有效悟性每 10 點多 1 級，最多 17。
- 傷害 = Σ[屬性 ×（斜率 × 等級 + 截距）]，TapTap 535917712187066350 —— 也就是**每一級都線性加傷害**，稱號本身不帶額外效果。
- 招式（式）隨等級解鎖，每式成長固定，TapTap 217230413565791411。
- 每級所需潛能 =（0.01 × 等級³ + 10）× 系數 ×（1 − 悟性 × 0.001），TapTap 15215170989066366；修煉速度 =（36000 + 720 × 有效根骨）/時 ×（1 + 床等加成），TapTap 683116818952358408。
- **未知**：各稱號或各「重」是否另有解鎖（被動、特效）。查不到任何出處，視為沒有。

### 1.2 經典 GMUD（文曲星《英雄壇說》）
來源：cnblogs larack/p/3772475、百度百科。50 個成語，每 5 級換一個（不堪一擊 0、毫不足慮 5 … 初出茅廬 30 … 返璞歸真 245–255）。人物總評要所有武學平均升 5 級才會動。百科另有 7 等容貌表。**成語純顯示**，效果來自等級數字本身。

**結論**：兩款遊戲的「熟練度稱號」都是**等級數字的顯示**，真正效果是「等級越高傷害線性越高、到某些級數解鎖招式、某些關卡要突破」。

## 4. 和既有系統的重疊與「不重複計算」

- 造詣（loop78–88 成長分層）：吃**原始投入**，作用是同類學習加速。熟練度「重」只看該武學 xp，作用是該武學招式威力。兩者輸入、輸出都不同，不重複。
- 階段加成（ART_GAIN.tierDmg 0.1／階、小成冷卻、圓滿傷害、招式解鎖）保持不變。「重」的加成設計成**階內補間**：每重 +tierDmg/20＝+0.5%，十重共 +4.5%，到下一階時重歸一重（淨跳 +5.5%），全程單調、不會比原本少。
- 瓶頸：xp 卡 54.9／99.9 時顯示「大成前 十重（瓶頸）」，不會因卡關多出等級。
- 化境之後的星（返璞歸真）不動，「重」只到化境為止。
