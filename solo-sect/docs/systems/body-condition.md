# 身體由負荷長出來（R2 #521，取代 Phase 5 #510 的體魄週期）

R9 起唯一新局是終南隱居，所有新局都走這條體魄通路；立匾後的人仍保留已長出的身體狀態。負重與疲勞更新不另抽亂數。

能長多少由三個原因決定，沒有另外寫死的上限：

1. **負重比**（參考 Kenshi）：每份活都有一個「全力負重」`load`，代表對幾點臂力或身法的人來說，這份活算全力。
   - 刺激 = `min(1, load / 現有能力)`。同一擔水，對已經變強的人刺激就小。
   - 挑水同時練臂力與身法，兩者分開計。
2. **體能－疲勞**（Banister 1975 fitness–fatigue 模型）：每份活同時加體能 F 與疲勞 G。
   - 加的量 = 刺激 × 這份活佔「一個全力工作日」的比例。
   - 第二十六輪起，42／7 是 Banister 的**現實日**量測；先換成年，再按 28 日遊戲年落成 F／G 各約 3.2198／0.5366 遊戲日的時間常數。生理吃睡仍是完整一日，時間分層見[時間與尺度](time-and-scale.md)。
   - 疲勞到「每天做滿一個工作日的穩態」就是痠痛：痠痛時做活只累，不長。
   - 歇息與藥膳都不會當場消掉疲勞，只能等日子過去。
3. **營養**（參考 Project Zomboid 的蛋白質倍率）：上一餐決定這份活能長多少體能，不影響疲勞。
   - 白飯 ×0.7。
   - 藥膳（有肉有藥）×1.5。

**個人上限**：上限 = 起始值 ×（1 + 2 × 根骨／5）。
- 根骨 5 可以練到起始值的三倍。
- 根骨 2 約 1.8 倍；起始 10 時恰好是舊的 18。
- 臂力 = 起始值 +（上限 − 起始值）×（1 − e^(−F／體能尺度)）。越接近上限長得越慢。
- 只升不降。退化另議。

D2（擁有人 2026-11-08）：日常飲食與藥膳只決定長得多快，不能突破上限。能突破上限的罕見奇物留給之後的內力系統。
