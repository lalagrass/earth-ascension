# Phase 5：體魄、疲勞與藥膳（#510）

僅隱居或明確開啟 `herbalDiet` 的局使用這條通路；原門派局仍用既有 `workStrCap` 與原成長，不消耗新的亂數。角色完成挑水、砍柴、採石、種菜、採藥或練拳時，依活動增加臂力或身法；雙屬性挑水把當次成長均分。煮飯有藥材時才生成藥膳，逐份保留廚者；食用後才有破限效果。市場買藥也能提供原料，玩家不採藥且不買藥時不會觸發。

## 常數與校準

下列均出自 [Phase 5 詳規](../plans/PHASE5-LABOR-FATIGUE-HERBAL-DIET.md)，不借醫學臨床劑量：

| 常數 | 意義與校準目標 |
|---|---|
| `mundaneCap=18`, `martialCap=36` | 雜務保健極限與藥膳破限極限；讓 10／18／26 分別落在不同動作階。 |
| `fatigueMax=100`; 工作疲勞 `water/chop/quarry/farm/forage/train=30/30/35/25/25/35` | 25–35 的規格帶；約 3–4 次體力活動痠痛，畫面可見從做活到恢復的節奏。 |
| `dailyGain=1.2`, `workGain=0.3` | 無藥一日體魄至多 1.2；每次 0.3 是四次活動共 1.2 的分配，雙屬性均分。 |
| `defaultCycles=1`, `mealCycles=3`, `skilledCookCycles=4` | 正常一日一次，藥膳開到三次；廚藝達 16 者親煮才有第四次。當日總額按週期數乘 1.2。 |
| `mealRelief=65` | 用飯立刻降低 65 點疲勞；從滿疲勞 100 降至 35，給下一輪做活餘地。 |
| `herbalDietUntil=t+DAY`, 外功 XP `×1.35` | 藥力維持整日；規格要求「由外而內」速度 +35%，沿純陽拳／羅漢手外功 XP 及既有入內回饋傳遞。它不乘戰鬥傷害或勝率。 |
| `12`, `16`, `18` 的畫面階界 | 詳規的生疏、回穩、保健圓滿、破限四階，只改動作晃幅、濺水及琥珀色光暈。 |
| 琥珀暈 `45×80`、透明度 `0.25` | 依現有微距窗 360×220 和人物高度調到覆蓋軀幹、不遮住動作；純畫面，不改模擬。 |
| 歇息輕疲勞減免 `25` | 沿本表最輕的單次雜務疲勞（種菜／採藥）抵銷一份；痠痛滿格則先完成恢復週期。 |

疲勞滿時 `soreness=true`，繼續做活無體魄成長。歇息完成可清疲勞並記恢復週期；無藥時週期與日額仍阻止當日再加點。用飯先消除疲勞，再擴充當日週期並掛藥力；換日重置疲勞、週期和日額，但未到期的藥力仍在。每份藥膳只供一人，R4 起廚藝達 16 者親煮由該份的 `skilled` 記錄判斷；4.8 前舊隱居檔若仍有 `rong` 記號也保留原效果，不因同住而讓別人煮的飯多一週期。

Phase 5 在規則 4.4 時只替隱居路線建立體魄欄位；R9 規則 5.0 起隱居是唯一開局，舊 quick/full/saves golden 已退場。動作熟練度只是顯示，不寫回人物或模擬。
