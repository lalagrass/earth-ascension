# 身體由負荷長出來（R2 #521，取代 Phase 5 #510 的體魄週期）

只有隱居局，或明確開啟 `herbalDiet` 的局，會走這條通路。舊門派局照舊使用 `workStrCap` 與原有成長，也不消耗新的亂數。

能長多少由三個原因決定，沒有另外寫死的上限：

1. **負重比**（參考 Kenshi）：每份活都有一個「全力負重」`load`，代表對幾點臂力或身法的人來說，這份活算全力。
   - 刺激 = `min(1, load / 現有能力)`。同一擔水，對已經變強的人刺激就小。
   - 挑水同時練臂力與身法，兩者分開計。
2. **體能－疲勞**（Banister 1975 fitness–fatigue 模型）：每份活同時加體能 F 與疲勞 G。
   - 加的量 = 刺激 × 這份活佔「一個全力工作日」的比例。
   - 換日時，F 依 42 日的時間常數衰減，G 依 7 日衰減。
   - 疲勞到「每天做滿一個工作日的穩態」就是痠痛：痠痛時做活只累，不長。
   - 歇息與藥膳都不會當場消掉疲勞，只能等日子過去。
3. **營養**（參考 Project Zomboid 的蛋白質倍率）：上一餐決定這份活能長多少體能，不影響疲勞。
   - 白飯 ×0.7。
   - 藥膳（有肉有藥）×1.5。

**個人上限**：上限 = 起始值 ×（1 + 2 × 根骨／5）。
- 根骨 5 可以練到起始值的三倍。
- 根骨 2 約 1.8 倍；起始 10 時恰好是舊的 18。
- 臂力 = 起始值 +（上限 − 起始值）×（1 − e^(−F／體能尺度)）。越接近上限長得越慢。
- 只升不降。退化另議。

D2（擁有人 2026-11-08）：日常飲食與藥膳只決定長得多快，不能突破上限。能突破上限的罕見奇物留給之後的內力系統。

## 常數

分類與出處見 [`hermitage-constant-audit.json`](hermitage-constant-audit.json) 的 `r2_*` 群組。

| 常數 | 類別 | 依據 |
|---|---|---|
| `fitnessTau=42`、`fatigueTau=7`（日） | 量測 | Banister & Calvert 1980；Busso 2003 |
| `workdayShare=1/3` | 設計旋鈕 | 一天約八小時全力重活可以長期維持 |
| `load` 擔水 12、劈柴 12、採石 14、練拳 14、種菜 8、採藥 8 | 設計旋鈕 | 該份活對幾點臂力或身法的人算全力 |
| `nutrition` 白飯 0.7、藥膳 1.5 | 參考 | Project Zomboid 蛋白質倍率 |
| `bestGain=2`、`rootMax=5` | 參考／推導 | 新手力量訓練約可到兩三倍；根骨尺度 1–5 |
| `SORE_AT`、`FITNESS_SCALE` | 推導 | 每天做滿一個工作日時的疲勞穩態；體能穩態 F* 的一半 |
