# 第八輪 N52：看得見的成長與門規作息

## N60：共用關節上的像素紙娃娃

`pose-render.mjs` 的關節、插值與 N55 成長播放秒數仍是唯一動作來源。`paper-doll.mjs` 把頭、髮、軀幹、上臂、前臂、大腿、小腿及手持物畫成小尺寸離屏像素圖，依關節端點旋轉、平移；只改畫面，不讀寫模擬。人物差異從外觀資料列及穩定的角色 id 取得髮型、衣色、明暗、膚色與體型。沒有角色專屬動作分支；主角、同伴、名俠、山賊、師父與招式殘影共用同一繪製器。

像素密度採約 1 畫布像素 1 色塊，深棕輪廓、左上淺色受光，取本倉 `assets/cousin.png` 的小人閱讀方式作參考；像素形狀在本倉重新繪製，未拆用其圖層，也沒有下載外部素材。每塊的 18×19、20×25、10×18 圖像尺寸對準原 57px 骨架頭頂與 25px 軀幹，不引入新戰鬥或工作常數。不同服色和髮型是盲測三人可配對的視覺訊號；紙娃娃不在存檔增欄位。參考 RimWorld 的分層身體與 cutout 動畫的轉軸做法，沒有複製其圖、美術表或程式。

## N59：日常人物共用骨架（#490）

`ACTIVITIES` 原本就是本作設施提供的 smart object 動作表；它現在多記一個純畫面的 `pose` 名稱。`pose-render.mjs` 按真實 `task.act/phase` 與路徑讀同一套 `DAILY_POSES`：站、走、蹲、坐、劈、挑、搬運。練功和交手仍先讀原套路／攻防姿勢；沒有資料列的任務或角色回站姿，不再讓畫布直畫 `hero.png` 的 5×6 動作表。阿禾、石生等出身同行讀相同骨架，既有性別、衣色只改畫法；山賊與遠行近景也用這個骨架。參考 The Sims smart object 的資料驅動選動作思路，沒有使用其圖像、資料表、程式或數值。

每個日常循環的 2 秒只表示畫面節拍，延續原挑水節拍；劈砍的 `4×0.7` 秒加原 `chopPause` 延續 N55 既有顯示節奏，與任務完成秒數無關。共用骨架頭頂約 57px（頭心 −49、半徑 8），因此雇工條放腳下 −58px、狩獵血條再上移 20px；目標是兩條資訊高於頭頂而不壓住人臉。坐姿的彎膝、蹲姿的低手和走路左右跨步只用既有像素尺度，按首日對照板校準，所有座標只在畫布中使用。未知任務先站穩，避免畫到整張圖片。

人物卡首行只從 `src/growth-adapter.mjs` 取得。它讀目前主修武學的 `xp` 與既有 `TIERS` 門檻，顯示階段、離下一階的熟練差額、當天漲幅。這些門檻原本就屬武學規則，N52 沒有新增升階機率或成長倍率。第十輪 N42 收斂底層時改轉接函式的讀值即可。UI 記錄上次顯示的階段、當日初值，僅用於跳字、小卡與今日要事；不寫進存檔，亦不改模擬。

右欄常駐時間速度、今日一件要事與選中角色；人物、門派、遠行、紀錄四分頁收納其餘資料。原生 `select` 在呈現時轉成選項按鈕或格子，保留原有 `change` 路徑。十六型直接選型為 4×4 格，其他大於六項先展開。建造區先列現階段能開工或已開工的項目，其他放在條件清單。右欄資源用署名的 game-icons 圖示，標題與卡片用 815 字霞鶩文楷子集，圖框及按鈕選 Kenney CC0 羊皮紙；授權見 `assets/ui/LICENSES.md`。圖示與素材只改顯示。

`ROUTINE_DEFAULT = { dawn: 'train', day: 'free', dusk: 'free' }` 是本輪 issue 明定的預設早課。每時段可設練功、靜坐、幹活、自由；玩家指派仍優先，生存需求仍優先。早課練功但心情低於既有 `MOOD.low` 時，先靜坐。山賊來犯時暫停例行作息排序，回到現有危機評分，避免守山者離柵。作息只改可執行行為的排序，不給固定熟練、心情或香火錢。晨課令卡與三個固定加成移除。3.3 遷移刪舊 `jh.morning`、`morningOn`、`morningDay`，給預設作息；已得到的加成仍留在原資源與技能中。

- 登門與招收：一次性的人選／條件，會改門派人員。
- 重大江湖與喜劇抉擇：依事件觸發，選項有不同後果；不是每日例行。

其中江湖卡是否詢問仍受既有「重大抉擇每次詢問我」設定控制；晨課令不再存在於任何例行候選。

## N54 頭上文字與素材護欄（#482）

世界內理由：讀者一次只能分辨一個人的一句話；練哪一式比身分重要，選中與滑過是主動查閱，不應被雜訊擋住。參考 [MapLibre GL JS symbol collision](https://maplibre.org/maplibre-style-spec/layers/#symbol-sort-key) 的優先佔位概念，未複製其程式。`label-layout.mjs` 用資料表定序：選中／滑過 > 主角 > 交手 > 練功 > 普通名字 > 設施；同級依穩定 id 排序。每人一行「名字｜在做什麼」，身分保留人物卡。低優先文字與已佔框相交就收起；滑過提升為查閱優先權，tooltip 仍能讀完整句。

畫面常數不是模擬係數：13px 字體使用14px保守字格、4px描邊留白、22px行框，校準目標為漢字和 emoji 包圍盒零交集，寧可多收字；74px頭頂偏移使標籤高於既有約70px小人。滑過橫向24px／腳下8px容差代表小人可點輪廓，並非命中範圍。所有值僅影響顯示。Canvas 與 `label-overlap.mjs` 共用候選、框和排列；工具從任選種子的第10日早課取練功人數最多的第一幀，不另造情境。短暫特效浮字不屬於常駐標籤。

`check-assets.mjs` 明確逐檔檢查來源／授權，不用萬用字元替新增素材背書；接在現有 CI 山門紀 job 呼叫的 `test/run.sh quick`，無需新增 workflow 權限。紀錄分頁底部保留 CC BY 圖示署名。圖檔離線隨 repo，肖像96色、長邊512、總量12,000,000 bytes；原圖在git歷史，生成圖的第三方權利清查仍在 #481。
