# 名功榜與威力曲線（#403）

研究依據是 `docs/plans/ARTS-REFERENCES.md` 與 `docs/plans/ARTS-ACQUISITION.md`。三方一致的名次直接用。不一致的沿用參考文件的建議，並在出處欄標出來。數字是本遊戲自己的化境錨點，不是外部資料的攻擊力。

## 換算

名次段 → 化境威力：絕頂 92–100、一流 74–88、名門 56–70、常見 38–52、入門 18–32。

五個火候的威力 = 化境 × 0.40、0.58、0.74、0.88、1.00，四捨五入成整數。出手用這五個數取代舊的「每階 +10%、圓滿以上再 ×1.15」。常見段的化境 45 對齊舊係數，所以沒被點名的武學強度不變。

## 本包不改曲線

這些武學的化境錨在 45，五檔比例相同，火候係數與現在一致。

- 豬籠城寨四門：如來神掌、十二路譚腿、洪家鐵線拳、五郎八卦棍。另開一系列再定。
- 獅子吼：功夫電影人物的絕活，不在這次金庸包。
- 神木毒功：已退場。
- 本遊戲自創或合參、三方表沒有名次的：風雷掌腿、流風迴雪劍、腐骨抽髓指、乾坤霸刀、左右互搏、奇門五轉、星宿毒經、藥王神篇、陣圖殘篇、醫經抄本、百毒譜。左右互搏、奇門、毒經、藥王已有自己的故事效果，不再用曲線加第二層。

## 各派樹（只含遊戲裡已有的武學）

路線是入門 → 延伸 → 絕招 → 拜師關卡 → 絕學。開局會把 `tree24` 併進本門樹。華山劍法已經在氣宗、劍宗的 `tree24` 上，教學用得到，這一步不改樹的程式。缺的刀法、身法與拜師關卡見參考文件第三節補漏，本包不新造武學。

- **華山氣宗**：華山心法、劈石破玉拳 → 華山劍法、混元掌 → 奪命連環三仙劍 → 掌門才修紫霞 → 絕學不在這棵樹上（辟邪走劍譜）。
- **華山劍宗**：劍宗心法、基礎劍法 → 華山劍法、狂風快劍 → 奪命連環三仙劍 → 思過崖 → 獨孤九劍。
- **武當**：武當心法、武當長拳 → 武當綿掌、柔雲劍法、八卦遊龍步 → 太極拳 → 掌門才修純陽無極功；太極劍不得高過太極拳 → 絕學即太極劍／太極拳。
- **峨眉**：吐納、峨眉劍法 → 峨眉九陽功、金頂綿掌、天罡指 → 臨濟十二莊、回風拂柳劍。沒有拜師關卡。
- **桃花**：吐納、碧波心法 → 落英神劍掌 → 蘭花拂穴手；玉簫劍法要碧波心法小成 → 玉簫即本派劍上的絕學。
- **古墓**：吐納、天羅地網勢 → 玉女心經、玉女素心劍 → 玄鐵、黯然仍是名俠劇情，不進一般池。
- **星宿**：吐納、抽髓掌 → 化功大法（掌門）、三陰蜈蚣爪、摘星功。化功不進一般池。
- **丐幫**：吐納、蓮花掌、瘋魔杖法 → 混天氣功、逍遙遊 → 降龍與打狗棒不在 `tree24`，只走洪七公。
- **明教**：聖火心法、鷹爪擒拿手、青蝠身法 → 七傷拳（掌門） → 九陽、乾坤只走張無忌主線。
- **天地會**：吐納、雲龍心法、百花錯拳、雲龍劍、神行百變。化骨綿掌不在學習池。
