# 名功榜與威力曲線（#403，#408 改扇形）

研究依據是 `docs/plans/ARTS-REFERENCES.md` 與 `docs/plans/ARTS-ACQUISITION.md`。三方一致的名次直接用。不一致的沿用參考文件的建議，並在出處欄標出來。下面的倍率是本遊戲自己的，不是外部資料的攻擊力。

## 換算

招式表上的傷害只留形狀。每門先取自己最強一招的每秒傷害（傷害 ÷ 冷卻，範圍不計），各招再除以這個數。範圍、冷卻、門內哪一招較重都留著。強度只走扇形：

`mul(t) = 共同曲線(t) × (1 + (R − 1) × f(t))`

共同曲線是 `[0.40, 0.58, 0.74, 0.88, 1] × FAN_BASE`。`f` 是 `[0, 0, 0.35, 0.7, 1]`。基準 `FAN_BASE = 13`，由 `tools/calib-fan.mjs` 實測校準（見 arts.md）。大成起名次才進威力。化境時 `f` 是 1，這一檔就是 `FAN_BASE × R`。

`R` 按名次段：入門 0.8、常見 1、名門 1.6、一流 2.4、絕頂 3.5。同段裡依下面的名次前後微調，排第一的 +10%，排最後的 −10%，中間線性。段裡只有一門就不調。沒點名的武學放在常見正中，`R = 1`，不做這層微調。

打狗棒法放在一流段末，乾坤大挪移放在名門段末。名聲在，傷害不是它們的本分，強度交給絕活。
如來神掌排在絕頂段末（降龍等三方一致名功之後）。

## 化境實際倍率

化境倍率就是調過的 `R`。化境每秒 = `FAN_BASE × 倍率`，指的是正規化之後、還沒乘武功與內力之前，該門最強一招的每秒傷害。程式保留全精度，表上倍率取三位小數。

| 對照 | 化境倍率 | 倍數 |
|---|---|---|
| 絕頂段基數 / 入門段基數 | 3.500 / 0.800 | 4.375 |
| 降龍十八掌 / 基礎拳 | 3.617 / 0.780 | 4.637 |
| 葵花寶典 / 吐納（兩段的兩端） | 3.850 / 0.720 | 5.347 |
| 常見正中，以及沒點名的武學 | 1.000 | 每秒 13 |

4 到 5 倍對的是段基數，以及降龍對基礎拳。葵花對吐納把同段的 ±10% 拉滿，會到 5.35 倍，這是名次微調的結果，不另縮。

## 豬籠城寨系列（#411 電影勝負與絕活依據）

豬籠城寨四門源自電影《功夫》，按電影情節的勝負展現、江湖名聲與隱居高手設定排名次段與絕活：

1. **如來神掌（絕頂，R = 3.617）**：
   - **電影勝負**：阿星遭火雲邪神重傷瀕死、打通任督二脈後覺醒，最終以「萬佛朝宗」從天而降一掌震懾火雲邪神（火雲邪神使用的一流頂級蛤蟆功徹底落敗認輸）。為電影中武學頂點。
   - **絕活**：`万佛朝宗`（大成起，耗真氣 20，掌力雄渾 ×1.6，巨力震退 30）。
2. **五郎八卦棍（名門，R = 1.580）**：
   - **電影勝負**：三大隱居高手之一油炸鬼身懷宋代楊家將傳承之棍法。在天殘地缺（琴魔）攜古琴音波刀氣暗夜襲擊時，八卦棍以長兵器陣支撐最久、突破音波近身，展現長兵克制與堅韌守勢。
   - **絕活**：`長兵點刺`（大成起，耗真氣 4，長兵點刺逼退對手 16）。
3. **洪家鐵線拳（名門，R = 1.560）**：
   - **電影勝負**：三大隱居高手之一裁縫隱世之硬氣功。雙臂鐵環開合沉雄，硬抗群斧摧枯拉朽；但面對遠程無形音波刃時受制於拳腳近戰距離。
   - **絕活**：`硬進破架`（大成起，雙臂鐵環硬進 ×1.25，破開對手招架）。
4. **十二路譚腿（常見段首，R = 1.100）**：
   - **電影勝負**：三大隱居高手之一苦力強北少林譚腿。長街突襲瞬息踢倒群敵，起腿快疾剛猛；但防禦無護體硬功，暗夜先遭琴魔音波突襲折損。
   - **絕活**：`先發制人`（大成起，先手一擊腿風掃亂對手下盤，踢倒 1.3）。
