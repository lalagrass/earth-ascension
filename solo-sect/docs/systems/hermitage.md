# 荒山雙人隱居（Phase 4，規則 4.3）

規格：[Phase 4](../plans/PHASE4-HERMITAGE-DUO-OPENING.md)；路線：[終南總綱](../plans/HERMITAGE-QUANZHEN-GUMU-ROADMAP.md)。新局明選 `heroSpec.hermitage` 才啟動。主角與伴侶同住，`s.hermitage` 記伴侶、四階領悟、未開山狀態。舊局不加欄位；舊門派的武學候選、亂數、日程不變。

## 起手與制度

- 全真純陽拳、玄門心法、金雁功、昊天掌、全真劍與先天功採 Phase 4 指定樹。全真候選池不混入舊門派或古墓伴侶的自選招；先天功只登錄資料，高崖取得待 Phase 6。終南雙劍宗此輪只註冊身分，不提前開山。
- 純陽拳十二段用既有 N48 架勢自行編排，沒有借用外部拳譜圖。每讀完一次既有 `study.dur` 對照一段，十二段讀畢才學會；羅漢十八手原逐段讀譜不變。
- 新招 `cy1`–`cy3` 的秒數、射程、原始勁直接沿用現有基礎拳三招，昊天掌沿用推山掌前兩招，全真劍沿用基礎劍兩招。資料只換名稱及所屬武學，沒有另造命中率或出手常數。火候仍由現行武學曲線決定。
- 小龍女依詳細 Phase 4 契約，起手只帶 `stepFeather` XP 10、`basicSword` XP 15；`herbal` 14、`agility` 16、養蜂特質。黃蓉帶基礎拳和 `xiaoyaoStep` XP 10，`cooking` 16、`herbal` 12；基礎拳的入門 XP 10 沿用同列逍遙遊 XP 10，詳細契約只說入門。未指定的身體能力承接既有角色模板，不開新能力表。
- 初始好感 55、同住滿兩日、下一階的小成、第三階好感 60 和共修四階均出自 Phase 4 規格。同住日只在兩人都在山上時累計；小成沿現有 `TIERS[1]`，不另設門檻。黃蓉四招沿同樣的「同住／本招小成／好感或並肩／本招小成」資料鏈；這是其未列出細門檻時的最低一致讀法。第四階合參畫面沿用既有 `meditate.dur`，不改模擬結算。
- 隱居期只暫停門派月俸、建築維護、門規與門派會武。日常吃飯、勞作、巡山、敵襲仍用原模擬，不給無敵或免費物資。開山切換見下文 Phase 7。

## Golden 與重現

規則 4.3 遷移只補已在隱居的舊檔欄位。舊局 golden 在雜湊前只將 `rules` 正規化為 4.2 並略去空的 4.3 遷移步，其他每一個存檔欄位仍比對；既有 quick、full、saves 檔應逐格保持原雜湊。新模式另用 `test/golden/hermitage.json` 鎖小龍女／黃蓉兩線的第 1、3、5 日。以 Node 22 執行 `node tools/golden.mjs --check`。

## Phase 5：一份藥膳是一份飯

[Phase 5 規格](../plans/PHASE5-LABOR-FATIGUE-HERBAL-DIET.md)把藥膳定義為「該鍋飯升級」而非加料後多出一份飯。灶房完成一鍋普通飯後，有草藥時把其中一份 `food` 轉為一份 `medFood`，帳本記廚房 `food` 出 1、`herb` 出 1、`medFood` 入 1。角色有藥膳即可選用飯；用餐優先消耗一份 `medFood`，增加原用飯飽足並獲溫養，不再同時扣普通 `food`。沒有藥膳時沿用原飯菜與原帳本；舊開局不啟用這個庫存。糧食危機與日常備糧把藥膳按一份可用餐食計入：有藥膳時不報斷糧，糧荒閘門、種菜／出獵優先級、煮飯存量與共餐邀請沿同一份數判斷；野豬來犯仍獨立觸發危機。送飯任務依舊使用普通飯，故仍檢查 `food`。

## Phase 7：開山與道統

雙人仍在山中是手動立匾的基本條件；自然提示需主角已悟心法與身法、伴侶第二階，或已踏上第一座崖、守山勝過一波。這三條路只決定何時提示，不擲抽籤。手動點「立匾開山」或自然達標都打開三選一卡；即使既有其他事件設定自動抉擇，立宗道統仍交給玩家。這沿用本作 `choices`／`heroAuto`，沒有新事件排程器。

- **陰陽合宗**：全真加古墓登記為 `zhongnan`，羅漢加桃花登記為 `longrong`；其他組合仍可選雙堂，牌匾預設「雙脈山莊」。`s.sect.dualTree` 留兩樹，`tree` 為聯集；每位弟子依根骨、悟性與憨厚／輕靈性格分入外堂或內堂，師父隨堂。兩樹均可作正宗根基，外門倍率自然為 1。
- **正宗立匾**：決策卡或 API 的 `{ banner: 'partner' }` 可選伴侶一脈，預設主角一脈。另一脈列 `secretLineage`，只有掌門、伴侶與首徒的個人名冊包含它；普通新徒沒有秘傳資格。
- **萬流歸宗**：以 `wuming` 開山，保留兩人的武學樹，牌匾可自訂。這沿既有無名派不罰外門的通路，不另增常數。

`foundHermitageSect` 將 `active` 關閉、`founded` 和開山日記入存檔，名聲加 10（出自 Phase 7 規格）、所有在山人物得到原 `newLook` 鼓舞。`econ.graceUntil = foundedDay + UPKEEP.graceDay`；`graceDay` 既有值 10，本輪只改起算點，不追討隱居日。收徒、完整擴建、市集在立匾後開放；原藥膳疲勞週期與山崖能力繼續。規則 4.6 遷移只為隱居存檔補道統欄位；舊局雜湊仍逐欄鎖住，只排除新版本號與空遷移步。

## H0：未立匾不接門人

依 [H0 規格](https://github.com/lalagrass/earth-ascension/issues/518) 與既有 Phase 7 開山狀態，荒山上有人住並不等於已成立可拜師的山門。隱居未立匾時，名俠奇遇的登門卡與一般收徒共用 `unfoundedHermitage` 隔離；立匾後由原本的奇遇和 N58 食宿／指導驗收繼續決定誰留下。新隱居開場只記茅廬日誌。4.7 遷移清除舊隱居存檔已排隊、尚未解決的名俠卡，不移走已在山上的人；舊門派局不走這條條件。
