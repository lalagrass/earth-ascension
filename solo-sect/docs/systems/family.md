# 成親的人自己決定要不要孩子（R7 #524，規則 5.1）

擁有人 2026-11-08 定案：「拿掉收養，完全不合理」，並同意 D4，大人與孩子只用一個時鐘。程式在 [`src/family.mjs`](../../src/family.mjs)。

## 規則

1. **沒有收養。** 收養卡、`adopt()` 與「山下鬧饑荒」的孤兒都拿掉了；遊戲沒有模擬村莊，也就沒有孩子從那裡來。
2. **兩人各自決定。** 每天換日時，每對夫妻各自依下面幾點判斷想不想要孩子，結果與理由記在 `childWish`，畫面上的家族列會顯示：
   - 價值觀：主要價值是「武」或「逍遙」的人，不想被家室牽住。沒有價值觀的人，性格「灑脫」代表同一種不想安定。
   - 年紀：母親超過 40 歲就不再懷孕。
   - 處境（與 N58 收徒同樣看糧、床、安全）：
     - 糧：不能正在斷糧，也不能有人餓得發昏。山上的飯是隨吃隨煮，所以看的是有沒有在挨餓，不看囤了多少。
     - 床：床位要夠多睡一人。
     - 安全：沒有山賊在山上，也沒有排定的來犯。
3. **兩人都想才懷孕。** 每天懷上的機率，由「想要孩子的伴侶約 85% 在一年內懷上」換算成每日機率。只有一方想要時，亂數再小也不會懷孕。同性伴侶不會懷孕。
4. **懷孕真的影響母親。**
   - 體重隨懷孕進度增加，足月時多約兩成。走路速度除以這個倍數，做活時間乘以這個倍數。
   - 約第 4 週知道有孕以後不上陣：不守柵、不迎擊、不出獵、不巡山、不出遠門。
5. **生產與遺傳。** 足月（9 個月）生產。
   - 孩子的根骨與悟性各自落在父母之間。
   - 性格兩項：一項來自父母之一（養育），一項是天性。
   - 價值觀取父母平均的一半。
   - 新生兒是白身，不承襲父母的招式、經歷與身體紀錄。
6. **單一時鐘。** 所有人在自己的生日滿一個大人年（28 日）時長一歲，孩子不再三天長一歲。
   - 嬰兒期到 3 歲，只吃和睡。
   - 14 歲成年。成年時身體起點取父母體格的平均，再依 R2 的負荷長。

## 常數

分類與出處見 [`hermitage-constant-audit.json`](hermitage-constant-audit.json) 的 `r7_*` 群組。

| 常數 | 類別 | 依據 |
|---|---|---|
| `gestationYears=0.75` | 量測 | 足月妊娠約 40 週 |
| `conceiveYear=0.85` | 量測 | Gnoth 等 2003：想要孩子的伴侶約 85% 在一年內懷上 |
| `knownYears=1/13` | 量測 | 約第 4 週停經才知道有孕 |
| `motherMaxAge=40` | 量測 | ACOG 第 589 號意見：40 歲後自然受孕率大幅下降 |
| `massGain=0.22` | 量測 | IOM 2009：正常體重孕婦建議增重 11.5–16 公斤 |
| `girlShare=100/205` | 量測 | WHO：出生性別比約 105 男比 100 女 |
| `babyAge=3` | 參考 | RimWorld Biotech 的嬰兒期 |
| `yearDays=28`、`adultAge=14` | 設計旋鈕（沿用） | 既有 GEN v1.4 |
| 每日受孕機率 | 推導 | `1 − (1 − conceiveYear)^(1/yearDays)` |
| 上陣禁令 | 參考 | ACOG 第 804 號意見：孕期避免有碰撞風險的運動 |
