# 武學卡（規則 2.8）

現行規格。扇形與化境倍率在 [arts-ranking.md](arts-ranking.md)。研究依據在 [ARTS-REFERENCES.md](../plans/ARTS-REFERENCES.md) 與 [ARTS-ACQUISITION.md](../plans/ARTS-ACQUISITION.md)。

## 出手

招式表上的傷害只留形狀。每門武學先找出自己最強一招的每秒傷害（傷害 ÷ 冷卻，範圍不計），再把各招除以這個數。範圍、冷卻、門內哪一招較重，都留著。強度只走扇形曲線。

`mul(t) = 共同曲線(t) × (1 + (R − 1) × f(t))`。共同曲線是 `[0.40, 0.58, 0.74, 0.88, 1] × FAN_BASE`。基準 `FAN_BASE`（約 14.5）為程式在載入時動態計算：取常見段各門最強一招每秒傷害中位數（約 9.0）乘上舊規則常見武學化境實際倍率（1.61），確保常見段維持原數值水準。`f` 是 `[0, 0, 0.35, 0.7, 1]`。入門、小成各門相同。大成起，`R` 才拉開。化境實際倍率見名功榜。

沒點名的武學 `R = 1`。打狗棒法在一流段末，乾坤大挪移在名門段末。

悟性、性格、門派偏向只進修練速度（`artMulParts`）。不進出手。郭靖前 20 日的降龍標記仍讓第一道瓶頸較好過，不再乘傷害。

品階 `grade` 只用於顯示，以及練功的「品階難度」。內力上限、減傷不再乘品階。`GRADE_NG24` 已刪。

造詣上限寫在每門的 `growCap`。沒另寫的，沿用入門 20、普通 35、精品 55、絕學 75。這張表不進出手。

十重仍是階內的小補，跟曲線分開。

## 學習

`learn` 收：`req`、`secret`、有的話再加上 `wuxingMin`、`alt24`、`ceiling`。

`ceiling.arts` 是前置比例。練功時，這門的熟練不得超過那些武學裡最高的一門；沒學會的當 0。已經更高的熟練不會被砍掉，所以劇情直接給的火候留得住。

- 太極劍、太極爪、玄虛刀不得高過太極拳。
- 乾坤大挪移不得高過聖火心法與九陽神功裡較高的那一門。光明頂那張卡只開第一層（入門）。反震寫在武學的 `on`，不再另外記一份固定反震。已經更高的熟練不會被砍掉。

#409 補上各派樹上缺的武學。這些門不進名次段，扇形的 R 是 1。入門、小成跟大家一樣。大成以後多開的那一招，是它們跟入門拉開的地方。

拜師關卡寫在 `elder`。氣宗要華山心法、劈石破玉拳、基礎劍法、混元掌、華山劍法都到小成；劍宗要劍宗心法、基礎劍法、華山劍法都到小成。過了這道門才進養吾劍法、太岳三青峰、奪命連環三仙劍、狂風快劍。劍掌五連環還要華山劍法與混元掌同時到大成。明教的光明聖火功、聖火令、大騰挪要聖火心法與鷹爪擒拿都到小成。

臨濟十二莊依火候開莊：入門一莊、小成兩莊、大成三莊、圓滿五莊、化境六莊。

彈指神通在桃花本門樹上，前置碧波心法小成。落英神劍掌改成自己練：碧波到小成的當天在島上看出掌路，次日才學會。

玉簫劍法的前置改成碧波心法小成，再加上基礎劍法小成。這是學習條件，不改桃花的劇情流程。

打狗棒法的提示改成：洪七公傳到降龍第二段起，傳給在場的黃蓉。誰拿到，程式本來就是這樣，這一步只改提示。

其餘名功仍走原來的劇情或秘笈，不進一般學習池。洪七公傳功、辟邪、獨孤觀破、紫霞層數、張無忌主線、葵花卡、斷臂玄鐵、楊過入門黯然、海大富化骨，這一步都不改流程。

## 絕招

降龍十八掌、辟邪劍法、打狗棒法：大成、圓滿、化境各開一招。太極劍、七傷拳資料裡只有兩招，所以只開到圓滿。獨孤九劍的招式仍由觀破發放；`specials` 只記火候，不繞過觀破。

觀破對齊五檔的形狀，用的是本遊戲自己的觀破值。總訣仍是第四晚過招就給，不看觀破。破劍、破刀、破槍、破鞭、破索、破箭落在熟其招式（約大成）。破掌在熟其招式和看破之間（約大成到圓滿）。破氣要到看破，並且身上有一門化境或紫霞九層（約圓滿）。狂風卷地要過了看破（約化境），仍然先得有總訣，不能靠火候直接開。

沒有這張表的武學，仍是每一階開招式表裡的下一招。

洪七公三段傳功給三招：見龍在田、飛龍在天、亢龍有悔。已經傳過的招寫在 `taught`，不受火候限制。熟練仍只到該段，後兩招的曲線火候要自己練上去。

## 絕活

六門名功各有一份 `on`。出手時按事件套用，不靠武學 id 分支，也不做全域的剛、巧、柔相剋。

事件有六種：打中 `hit`、格開 `block`、讓過 `dodge`、打重 `crit`、挨打 `gethit`、擊倒 `kill`。火候不到 `need`，或內力不夠付 `qi`，這一下就不發動，普通傷害照舊。

- 降龍十八掌：大成起，打中時掌力加重並震退，內力一次扣 16。
- 獨孤九劍：看破至少一式之後，用九劍的招打中會更痛，而且自己不格擋。巡山裡料中來勢的那一下，戰報補一句，回血仍是原來的公式。
- 辟邪劍法：大成起，對同一個對手的第一下連刺，內力扣 6。之後的劍照普通傷害。
- 太極劍：大成起，挨打時把一部分力道反震回去。
- 七傷拳：大成起，打中更痛，自己也掉一截氣血。沒有聖火或九陽就落在催動第四階，威力 ×0.65，這是硬催的代價，不是品階倍率。
- 打狗棒法：大成起，打中時絆住對手的腳，內力扣 4。

#410 再補六門。句子裡仍然不寫係數。

- 玄鐵劍法：大成起，打中破開招架，這一擊更重。斷臂仍然直接給大成。
- 黯然銷魂掌：大成起才在戰報點出「心緒越沉越重」。輕重本身仍是原來的心情公式，不在絕活上再乘一次。楊過入門仍是大成。
- 蛤蟆功：大成起，氣血見底而且內力還夠，才蓄勢反擊。氣血沒見底不耗內力。不再和乾坤共用這一記。
- 乾坤大挪移：從第一層起，挨打時挪開一部分來力，餘勢反震回去。舊檔若還留著另一份反震，只算武學上這一份。
- 九陰白骨爪：大成起，打中破開護體，這一爪更重，自己的俠義往下掉。
- 玉簫劍法：大成起，簫聲擾了對手的節奏。不另設音律技能。

狩獵的打中、擊倒、挨打，以及黃昏試煉那一拳，都會走這份資料。巡山逐拍結算：連續傷害含絕活與紫霞劍招、玉女合擊的期望，出手當下才扣內力、傷己、震退、絆腳、破招架、蓄勢、音律；挨打當下才反震與挪移。會武與江湖挑戰讀的是同一份每秒傷害，所以名功在這三處都看得到。異屬逆催的第四階恢復 0.65。正宗的 1.25 不回來。

觸發時戰報寫一行，等級是中，避免招名裡的字把畫面暫停。

## 戰報與人物面板（#406）

狩獵戰報、巡山戰報、人物面板各用一句話說出主因，例如絕活觸發、看破來勢、內力見底、這門是怎麼換來的。句子裡不寫係數。這一句不改傷害，也不改誰贏。

內功各有所長見 [neigong.md](neigong.md)。豬籠城寨四門（如來神掌、十二路譚腿、洪家鐵線拳、五郎八卦棍）已在 #411 點名進扇形曲線與絕活（如來神掌絕頂 R=3.617、八卦棍與鐵線拳名門 R=1.580/1.559、譚腿常見首 R=1.100）。獅子吼仍維持 `R = 1`，化境每秒 45。
