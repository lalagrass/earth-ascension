# 武學卡（規則 2.6）

現行規格。數字錨點在 [arts-ranking.md](arts-ranking.md)。研究依據在 [ARTS-REFERENCES.md](../plans/ARTS-REFERENCES.md) 與 [ARTS-ACQUISITION.md](../plans/ARTS-ACQUISITION.md)。

## 出手

每門武學有 `curve`：入門、小成、大成、圓滿、化境五個整數。化境取自名功榜，其餘四檔是化境乘 0.40、0.58、0.74、0.88 後四捨五入。

出手的火候項＝舊的階係數 ×（該檔曲線 ÷ 常見錨點同一檔）。常見錨點的化境是 45，所以沒被點名的武學，這一段與舊規則相同。名功的化境更高，同火候就更痛。

悟性、性格、門派偏向只進修練速度（`artMulParts`）。不進出手。郭靖前 20 日的降龍標記仍讓第一道瓶頸較好過，不再乘傷害。

品階 `grade` 只用於顯示，以及練功的「品階難度」。內力上限、減傷不再乘品階。`GRADE_NG24` 已刪。

造詣上限寫在每門的 `growCap`。沒另寫的，沿用入門 20、普通 35、精品 55、絕學 75。這張表不進出手。

十重仍是階內的小補，跟曲線分開。

## 學習

`learn` 收：`req`、`secret`、有的話再加上 `wuxingMin`、`alt24`、`ceiling`。

`ceiling.arts` 是前置比例。練功時，這門的熟練不得超過那些武學裡最高的一門；沒學會的當 0。已經更高的熟練不會被砍掉，所以劇情直接給的火候留得住。

- 太極劍不得高過太極拳。
- 乾坤大挪移不得高過聖火心法與九陽神功裡較高的那一門。

玉簫劍法的前置改成碧波心法小成，再加上基礎劍法小成。這是學習條件，不改桃花的劇情流程。

打狗棒法的提示改成：洪七公傳到降龍第二段起，傳給在場的黃蓉。誰拿到，程式本來就是這樣，這一步只改提示。

其餘名功仍走原來的劇情或秘笈，不進一般學習池。洪七公傳功、辟邪、獨孤觀破、紫霞層數、張無忌主線、葵花卡、斷臂玄鐵、楊過入門黯然、海大富化骨，這一步都不改流程。

## 絕招

降龍十八掌、辟邪劍法、打狗棒法：大成、圓滿、化境各開一招。太極劍、七傷拳資料裡只有兩招，所以只開到圓滿。獨孤九劍的招式仍由觀破發放；`specials` 只記火候，不繞過觀破。

沒有這張表的武學，仍是每一階開招式表裡的下一招。

洪七公三段傳功的熟練只到大成，所以當場只開第一招。戰報仍會點名後兩段的招名。要練到圓滿、化境，那兩招才進招式欄。這是已知的落差，流程先不動。

## 存檔

`RULES_VERSION` 是 2.6。舊檔讀入就蓋上這個版本，不改檔裡的熟練。新數字在程式裡，不在存檔欄位。

## 絕活

六門名功各有一份 `on`。出手時按事件套用，不靠武學 id 分支，也不做全域的剛、巧、柔相剋。

事件有六種：打中 `hit`、格開 `block`、讓過 `dodge`、打重 `crit`、挨打 `gethit`、擊倒 `kill`。火候不到 `need`，或內力不夠付 `qi`，這一下就不發動，普通傷害照舊。

- 降龍十八掌：大成起，打中時掌力加重並震退，內力一次扣 16。
- 獨孤九劍：看破至少一式之後，用九劍的招打中會更痛，而且自己不格擋。巡山裡料中來勢的那一下，戰報補一句，回血仍是原來的公式。
- 辟邪劍法：大成起，對同一個對手的第一下連刺，內力扣 6。之後的劍照普通傷害。
- 太極劍：大成起，挨打時把一部分力道反震回去。
- 七傷拳：大成起，打中更痛，自己也掉一截氣血。內功催動裡「沒有聖火或九陽就虛浮」仍在，那是下一支要拆的品階催動。
- 打狗棒法：大成起，打中時絆住對手的腳，內力扣 4。

狩獵的打中、擊倒、挨打，以及黃昏試煉那一拳，都會走這份資料。巡山仍是整場結算，只接了獨孤的不格擋和讓過。

觸發時戰報寫一行，等級是中，避免招名裡的字把畫面暫停。

## 這一步還沒做

戰報用一句話說出勝負主因，是後面的步驟。內功各有所長見 [neigong.md](neigong.md)。豬籠城寨四門與獅子吼的曲線錨在 45，強度維持現狀。
