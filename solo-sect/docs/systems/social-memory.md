# N46 人際記憶

戰鬥、切磋與教學只送出事件種類和人物；`SOCIAL_EVENTS` 資料列決定被誰記住、單向好感、期限與面板句子。`recordSocialEvent` 寫入想法並更新好感；每日 `fadeSocialThoughts` 撤回已淡去想法當時實際增加的值。持續日數為 `null` 的重要記憶不設定到期日，不另分支處理。這些記憶另存於 `socialThoughts`，不受舊聊天帳本每對六則的上限擠掉。

好感的量尺沿用原本一次切磋 +2、一次普通聊天約 +4、傳功 +6：切磋落敗記 +2，並肩撐過圍攻 +5，師父教會一招 +6、拉住惱羞 +6、替同伴成功攔招 +8。這些是相對日常互動的事件分量，不是勝率加成。短期切磋想法保留 12 日，較重的並肩與惱羞想法保留 30 日，分別對照一次短期練功與一個月門派生活；救命和傳藝以無期限表示。到期只撤回該筆想法實際加到的值，已到好感上限者不會多扣。

N44 的眼熟原已讀同伴關係；現在取雙向好感平均，讓受救者對救援者的感謝也進入默契量尺。地圖救援僅在成功截擊時記錄，圍攻記憶僅在至少兩名山賊圍攻、兩名守門弟子共同守住時記錄。切磋由現有掌腿與敏捷能力比較，平手不虛構勝負。拉住惱羞者必須在同一守門工作、兩個滑步距離內、手上無正在出招，才能阻止硬攻。

參照 #460 所列的「事件形成想法、想法改變好感」資料導向做法；沒有複製外部人物、台詞、數值或程式。
