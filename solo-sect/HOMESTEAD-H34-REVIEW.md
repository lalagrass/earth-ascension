# 荒居 H3–H4 試玩回顧與下一輪

來源：`codex/solo-sect-homestead` H1–H2 @ `359149a`；本輪仍是 Cloud 本機實驗，不合入本篇、不上傳。本輪數值是試玩值。

## 本輪玩家實際可做

- H3：一位固定身分的訪客每日白天沿村路來去；可談天、送一份熱飯，或先採虛構草藥，再照料一次扭傷。交談與送飯每日各一次，照料事件一次。好交往的主角會自發談天，勤勞者可能主動照料；喜靜者完全可獨居。草藥機制不是現實醫療建議。
- H4：小屋落成、關係與對方意願足夠時可邀同一人短住。幫手可自主或指定砍柴、照料菜園，各自吃睡、攜物歸倉。真正同住滿一日且關係更深時，玩家可與其同意成為學徒；也可請其離開。回村後同日不能重邀，隔日再來時保有需求與學徒身分。
- 畫面漸進顯示建築；菜園成熟度與熱飯所需材料可見。新增地圖村路、訪客／幫手與草藥坡。

## 工程驗收與界線

- `node --test solo-sect/test/homestead.test.mjs`：H1–H4 21/21；`node --test solo-sect/test/sim.test.mjs`：本篇 30/30。五組各 12,000 tick 的作者隨機改令／邀請／離開／定期存讀沒有讀檔失敗；此為守恆冒煙，不是平衡量測。
- 作者用真 Chromium 從頁面新局、立小屋藍圖、完成訪客交談／採藥照料、邀請、指派砍柴、跨日收徒、存檔、重載；畫面無 `pageerror`。圖見 `shots/homestead-h3.png` 與 `shots/homestead-h4.png`。
- 荒居存檔仍只用 `solo-sect.homestead.v1` 鍵，內部 schema 由 v1 遷移至 v2；本篇 `solo-sect-save` 不碰。舊 H1–H2 荒居檔補新欄位，未知版本與不一致預約／背包資料拒讀。仍是單一瀏覽器本機槽位。
- 獨立 reviewer 發現儲物棚覆寫草藥容量、跨日誤當住滿一天、離開重邀重置需求、幫手背包多餘 bonus 鍵可造物、草藥在途 UI 名稱缺漏；作者均已修正並加受影響反例。Reviewer 複審後另跑五組各 20,000 tick 的雙人改令／每 53 tick 存讀，以及 v1 在途遷移、晚間跨日與次日重邀反例；在本輪範圍未發現剩餘阻擋。Reviewer 亦看過真圖並以 Chromium 驗證入口與存讀。
- 未經真人長玩、跨瀏覽器、長時間效能或數值平衡驗收；沒有聲稱耐玩性或成本改善。沒有外部程式與美術移植。

## 下一系列規格建議（未實作）

**H5 田宅成形**：先做小屋下一階與藥田、稻田兩塊固定地；種子、成熟、收穫、藥材及米糧進同一倉庫，豬圈只在飼料循環穩定後列為第二小包。優先看 H4 雙人耗糧是否過快，再定配方。驗收是連續數日一人／兩人均能吃睡、田地缺種缺水時可恢復、收穫與在途存讀守恆；新增設施仍由物件階段宣告工作。風險是作物與飼料引入新死循環、UI 資源太多。

**H6 山門交接試作**：先寫可審的荒居→本篇單向對照表與試轉換存檔，不直接把兩套引擎合一。對照住處、菜園／藥田、糧食、草藥熟練、主角與可選學徒；保留原荒居檔以便回退。本篇舊檔絕不自動進荒居。驗收是有／無學徒的轉換檔能用本篇既有 loader 讀入並跑一日、物資不重複，舊本篇檔字節不變；待產品擁有人確認實際場景與資源映射才做正式入口。風險是本篇人物／設施／時間版本不相容與「已成學徒」身分語義落差。
